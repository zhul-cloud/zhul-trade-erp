## 原因与实施

- **UI-047 列表滚动后盖住顶部栏与标签栏**：销售订单列表滚到底，表格的固定列（单号、操作）浮在顶栏和标签栏上面。antd 6 的固定列按列数算 z-index，销售订单列表列多，单号列算到 21，超过顶栏（20）与标签栏（19）；询盘、报价、形式发票列少，没超过，所以正常。
  - 修复：`global.less` 给 `.ant-table-wrapper` 加 `isolation: isolate`，表格自成层叠上下文，表格内部的 z-index 不再和页面外壳比较。所有用 antd 表格的页面一起生效。
  - 排查其他页面里 z-index 不低于 3 的元素：只有商品、客户、供应商表单与商品详情底部的固定操作栏（设计如此，在页面底部），没有其他会盖住顶栏的元素。
- **UI-048 来源单号与客户 / 供应商合在一列**：按 2026-11-11 确立的「单据页统一规范」，来源单号单独一列，客户、供应商单独一列。
  - 采购需求（按订单看）：「来源单号 · 客户」拆成「来源单号」「客户」（`CustomerCell`，名称与国家）。
  - 采购订单详情明细：同上（明细行各自来自不同订单，行上保留来源单号）。
  - 销售出库（三个页签）：拆成「客户」与「来源单号」，来源单号放在负责人、审计列之前。
  - 发货跟踪（发货记录、到货差异）：「来源单号 · 采购对象」拆成「供应商」与「来源单号」。原有「来源」列指发货方式（采购发货 / 供应商直发），不是来源单号，名称不变。
  - 退款申请、退货入库两页随 `after-sales-return-docs` 改造，不在这里改。
