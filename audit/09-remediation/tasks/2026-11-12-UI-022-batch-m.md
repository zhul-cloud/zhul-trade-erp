## 原因与实施

- **UI-022 操作入口键盘不可达**：认领时检索全站，不止审查列出的 6 个页面：共 296 处 `<a>` 没有 href、只绑 onClick（117 个文件），浏览器不把它们放进 Tab 顺序。用 TypeScript 语法树批量改为原生 `<button type="button" className="zhul-link">`，属性与子节点不变；`zhul-link` 在全站样式里去掉按钮外观，颜色、悬停、按下色取 antd 的链接色令牌，焦点框沿用全站 `button:focus-visible`。原生按钮自带 Tab、Enter、空格。新增扫描测试 `src/actionLinks.test.ts`，以后再出现只绑 onClick 的 `<a>` 即失败。带 href 的链接与 Umi `Link` 不在范围内。
- **UI-026 标签关联到背景控件 / 字段无名称**：全部 18 个 `ModalForm` / `DrawerForm` 加表单 `name`（如 `userCreate`、`roleEdit`），生成的输入框 id 带表单前缀，不再与列表搜索表单重名；客户收货信息抽屉 `PartyDrawer` 的 Form 加 `name="party"`。费用单抽屉的自绘标签字段补 `aria-label`（名称、费用类别、发生日期、收款方类型 / 名称、供应商或货代、店铺平台与名称、币种、金额、所属事业部、付款方式、垫付人、添加型号、说明）。`UnitSelect` 原来不接收 Form.Item 注入的 `id`，客户表单「所属事业部」标签也指不到控件，改为转发 `id` 与 `aria-label`；`SupplierPicker` 支持 `aria-label`。
- **UI-028 实施**：后端快速建客户已接收 `businessUnitId` 并在本人不属于事业部且公司有多个事业部时拒绝空值，只改前端：`CustomerQuickCreateModal` 用 `useBusinessUnits`，条件满足时显示必填「所属事业部」（`UnitSelect`），`SaveCustomerPayload` 加 `businessUnitId`。浏览器实测发现新建询盘里点「新建客户」后客户下拉不收起、盖在新建客户弹窗上，改为受控 `open`，点击时先收起（jsdom 复现不了浮层残留，以浏览器前后对比为证据）。
- **UI-030 实施**：
  - 后端：工作台链接分别带 `?status=3`、`?status=6`、`?unpaid=1`、`?progressCode=RECEIVED`，经营看板毛利为负带 `?loss=1&dateFrom=本月1日&dateTo=今天`。PI 待收款条件抽到 `PiStore.unpaid`，工作台、PI 列表 `unpaid` 筛选与 PI 统计 `unpaidCount` 共用；销售订单分页加 `lossOnly`（进行中且毛利 < 0）。
  - 销售订单统计 `progressCounts` 改为列出全部进行中的进度（没有订单的计 0）：原来只列有订单的进度，「订单待出运」为 0 时点进列表，订单状态框露出代码 `RECEIVED`（浏览器实测发现）。
  - 前端：询盘列表 `initialFilters` 读 `status` 并清空日期（重置时清掉状态）；PI 列表快捷筛选加「待收款 N」，地址 `unpaid=1` 时选中；销售订单列表加「快捷筛选 · 毛利为负」，`initial()` 读 `loss`、`progressCode`，带状态或毛利为负且没带日期时不限日期。
- **合并后 develop CI 失败**：#270 与 #269（AI 背调前检查）几乎同时合并，#269 新增 2 处只绑 onClick 的 `<a>`，被 #270 的扫描测试拦下（develop 推送运行 43238006500，前端 1 条失败）；随后 #271 已把这 2 处改成按钮，develop 与 release/1.21.0 CI 均通过。
- **UI-028、UI-030 认领**：认领时核实问题仍在。UI-028 按完整客户表单的条件（启用事业部、本人主部门不属于事业部、可选事业部多于一个）在快速建客户弹窗加必填「所属事业部」；UI-030 五个待办逐个核对后端口径：待确认 / 可以报价按询盘状态 3 / 6，PI 待收款为「已发送或已转订单且未付清」，订单待出运为进行中且进度 RECEIVED，毛利为负为本月销售日期起、进行中且毛利 < 0，均不限日期上限。前两项与订单待出运用列表已有筛选带过去；PI 待收款与毛利为负列表没有对应条件，新增快捷筛选。原型放在 `docs/03-产品原型/03-业务域/11-12工作台待办与快速建客户/`（确认后随 UI-028、UI-030 一起提交），等用户确认后开发。
