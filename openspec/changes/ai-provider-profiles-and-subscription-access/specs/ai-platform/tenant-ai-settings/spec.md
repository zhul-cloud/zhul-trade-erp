# Spec Delta

## MODIFIED Requirements

### Requirement: 租户维护自己的 AI 配置
能访问「业务设置 → AI 设置」菜单的用户 SHALL 查看本租户配置，有 `system:ai-config:edit` 权限者可修改、测试连接与获取模型列表。各服务商的 API Key、解析和翻译模型、两种思考强度、搜索上限 SHALL 独立保存，API 与订阅也相互隔离。订阅访问另受使用权限约束，普通租户仅能改运行方式与服务商。配置变化无须重启；AI 配置不出现在通用系统参数列表。

#### Scenario: 两个租户各用自己的配置
- **WHEN** 甲配置 Claude Key，乙配置 OpenAI Key，各提交询盘解析
- **THEN** 各使用本租户对应服务商 Key，互不影响且均不继承平台 API Key

#### Scenario: 修改立即生效
- **WHEN** 租户保存当前 API profile 的解析模型后提交询盘解析
- **THEN** 新任务使用新配置，编排服务无须重启

#### Scenario: 只能查看的用户
- **WHEN** 用户有 AI 设置菜单、没有编辑权限，尝试保存、测试或获取模型列表
- **THEN** 页面只读，请求被拒；无菜单者查询配置也被拒

#### Scenario: 非法取值
- **WHEN** 保存未注册服务商、非法思考强度或超出 1–100 的搜索上限
- **THEN** 请求失败并指出字段，所有原配置保持不变

#### Scenario: 同租户同时配置两个 API
- **WHEN** 租户先后保存 Claude 与 OpenAI Key 和不同模型，再反复切换服务商
- **THEN** 两组配置同时保留，切回显示对应组，不沿用另一服务商的 Key 或模型

#### Scenario: 平台切换运行方式
- **WHEN** 平台为同服务商分别保存 API 和订阅的不同模型、思考强度及搜索上限，再切换运行方式
- **THEN** 两组值各自保留，订阅不覆盖 API 配置

### Requirement: 留空项使用默认值
模型与思考强度留空时 SHALL 使用该服务商推荐值：Claude 解析 `claude-opus-5-5`、翻译 `claude-haiku-5-5`；OpenAI 解析 `gpt-6.1-sol`、翻译 `gpt-6-luna`；思考强度 `medium`，搜索上限 20。服务商默认 `claude`。页面初次加载某 profile 时预填该 profile 的已保存值或默认值，切换时加载目标 profile 的已保存值或默认值，不携带另一组自定义模型。当前有未保存修改时先让用户保存、放弃或取消切换，保存仅影响当前 profile。

#### Scenario: 只填服务商和 Key
- **WHEN** 租户只配置 OpenAI Key，其余留空
- **THEN** 解析用 `gpt-6.1-sol`、翻译用 `gpt-6-luna`、强度 `medium`、搜索上限 20

#### Scenario: 平台尚未保存订阅 profile
- **WHEN** 对应服务商订阅已登录且用户有使用权限，但平台未显式保存该服务商订阅配置
- **THEN** 使用该服务商的平台默认订阅 profile，不要求新增启用开关

### Requirement: API Key 加密存储并脱敏展示
API Key SHALL 按 `system/data-encryption` 加密存储，仅返回本租户、对应 API profile 的已配置标记与脱敏值（前 7 位、固定 16 个点、后 4 位；不足 12 位整串固定 27 点），不返回明文。Key 留空仅保持本 profile 原值；替换前二次确认。Key 仅在本次请求内存中解密，日志与错误不含明文；订阅响应和顶部摘要不显示 Key。

#### Scenario: 查看已保存的配置
- **WHEN** 用户查看自己的 API profile
- **THEN** 输入区显示脱敏值，源码与接口不含明文，顶部状态不显示 Key

#### Scenario: 只改模型不改 Key
- **WHEN** 只改 OpenAI 翻译模型且 Key 留空
- **THEN** 仅保留 OpenAI 原 Key，不读取 Claude Key

#### Scenario: 更换 Key
- **WHEN** 填写新 Key 点击保存
- **THEN** 确认后仅替换对应 profile，并记录修改人、修改时间

#### Scenario: 订阅不带 API 凭据
- **WHEN** 获授权租户查看或使用平台订阅
- **THEN** 响应不含平台 API Key、其脱敏值或 CLI 凭据，执行订阅的 api_key 强制为空

### Requirement: 未配置时的处理
未保存租户选择或 API profile 无 Key 时 SHALL 视为 AI 未配置，不继承平台 API。订阅无使用权限、全部服务商未登录或状态未知时 SHALL 视为订阅不可用，不转换成付费 API。用户主动 AI 操作在预检失败时不创建任务；联系人音译等附带操作跳过并记录安全原因，普通业务保存照常成功。

#### Scenario: 未配置时解析询盘
- **WHEN** 未配置 AI 的租户主动解析询盘
- **THEN** 提示在 AI 设置中配置，不创建任务，询盘保留原状态

#### Scenario: 未配置时保存商机
- **WHEN** 未配置、无订阅权限或无可用订阅的用户保存含英文联系人的商机
- **THEN** 商机保存成功，音译跳过，日志记录不含凭据的原因

#### Scenario: 平台已配置但租户未配置
- **WHEN** 平台已有 API Key，而租户未配置自己的 AI 选择
- **THEN** 不自动使用平台 Key 或自动开通订阅

#### Scenario: 已保存订阅被撤权
- **WHEN** 租户曾保存订阅配置，平台撤回其使用权限
- **THEN** 保存的订阅模式保留为不可用，不显示可进入的订阅按钮，新任务被拒，不自动用租户或平台 API Key

### Requirement: 模型下拉列表
可编辑模型 SHALL 支持手动输入和首次展开获取列表。API 查询使用当前 profile 输入 Key，留空仅用该 profile 已保存 Key；OpenAI 过滤非对话模型。平台订阅中 Codex 可列账号模型与默认，Claude 使用推荐模型。获授权普通租户订阅模型只读继承平台；对订阅列表请求也检查权限并拒绝伪造模型、强度、搜索或 Key 字段。列表请求不执行付费推理。

#### Scenario: 用 Key 获取 Claude 模型
- **WHEN** Claude API profile 填写有效 Key 后展开模型选择
- **THEN** 列出该 Key 可用模型并标推荐模型

#### Scenario: 手动输入不在列表中的模型
- **WHEN** 有编辑权限的租户在 API profile 或平台在订阅 profile 手填模型名
- **THEN** 可保存，执行时由相应服务商校验

#### Scenario: 没有 Key
- **WHEN** OpenAI API profile 的输入和已保存 Key 都为空
- **THEN** 仅列 OpenAI 推荐模型，不借用其他 profile Key

#### Scenario: Codex 订阅
- **WHEN** 平台有权限且 Codex 已登录，展开订阅模型列表
- **THEN** 列出该账号可用模型并标默认；普通租户仅查看平台所选值

#### Scenario: 获取失败
- **WHEN** 模型查询认证失败
- **THEN** 提示不含 Key 的原因，允许编辑者使用推荐值或手填；普通租户继承只读不变

### Requirement: 测试连接
AI 设置 SHALL 允许有编辑权限者保存前测试；API 检查对应 Key 与两个模型，仅查模型接口，不执行付费推理。订阅测试另检查当前使用权限和登录状态，普通租户只可传运行方式与服务商，模型、强度、搜索和 Key 均从平台 profile 解析，伪造字段请求被拒。测试结果逐项显示安全原因，不保存配置。

#### Scenario: Key 有效且模型可用
- **WHEN** Claude API Key 有效且所选模型可查询
- **THEN** 分项显示 Key 与两个模型可用

#### Scenario: 模型不存在
- **WHEN** OpenAI API profile 使用不存在的模型名
- **THEN** 分项显示模型不可用原因，不串查其他服务商

#### Scenario: Key 无效
- **WHEN** 当前 profile Key 无效
- **THEN** 显示认证失败，不保存任何配置

#### Scenario: 无权或伪造订阅测试
- **WHEN** 已撤权用户请求订阅测试，或普通租户传入自选订阅模型或 Key
- **THEN** 请求被拒，编排订阅执行器不被调用

### Requirement: 订阅登录状态
有 AI 菜单与订阅使用权限者 SHALL 查看各服务商 `logged_in`、`logged_out`、`unknown` 三态及检查时间。已登录显示绿灯，未登录显示红灯，查询失败或未知不得冒充未登录；不显示邮箱或账号信息。登录命令仅平台响应包含，普通租户 JSON 中完全省略相应字段。无使用权限者不可调用订阅状态接口。

#### Scenario: 平台租户查看
- **WHEN** 平台有权限且 Codex 已登录、Claude 未登录
- **THEN** 显示对应绿灯、红灯及容器内登录命令

#### Scenario: 普通租户请求状态接口
- **WHEN** 获授权普通租户查询订阅状态
- **THEN** 返回状态和检查时间，JSON 不含登录命令字段；未获授权租户被拒

#### Scenario: 状态查询故障
- **WHEN** CLI 状态命令超时、缺失或返回无法识别的结果
- **THEN** 对应服务商为未知，界面明确提示未知且禁止新选

## REMOVED Requirements

### Requirement: 订阅方式只供平台租户
**Reason**: 改为按平台资源授权开放，凭据仍仅保留服务器。
**Migration**: 平台现订阅选择保留；普通租户必须由平台通过套餐授权并满足用户权限后自行选择，不自动开通。

## ADDED Requirements

### Requirement: 订阅使用受平台资源授权控制
个人订阅入口与调用 SHALL 受 `system:ai-config:use-subscription` 按钮资源控制，区别于编辑 AI 配置权限。平台遵循既有超级管理员与角色规则；普通租户管理员受套餐限制，普通员工还受角色限制。新权限不自动加入全部租户套餐，仅赋平台内置管理员角色。平台通过套餐授予或撤回，同套餐租户共同生效；独立控制可用独立套餐，不新增开关页面。

#### Scenario: 租户管理员不能自行开通
- **WHEN** 套餐未授订阅权限，租户管理员尝试勾选权限、伪造订阅保存或调用任务
- **THEN** 入口隐藏且服务端拒绝，不改变平台授权或产生订阅调用

#### Scenario: 套餐和角色双重限制
- **WHEN** 套餐包含订阅资源而普通员工角色不包含，或反之
- **THEN** 员工不能使用；租户管理员仅在套餐包含时可使用

#### Scenario: 全局资源停用与别名
- **WHEN** 平台停用已知订阅资源，或其他资源声明相同权限码
- **THEN** 停用立即使新调用无权，别名不授予订阅使用权

#### Scenario: 撤权不受旧页面影响
- **WHEN** 用户页面仍开着，平台移除套餐资源或角色权限
- **THEN** 之后的保存、订阅测试、订阅模型查询和新订阅任务均重查并拒绝

### Requirement: 普通租户订阅配置只读继承
普通租户订阅的解析模型、翻译模型、两种思考强度及搜索上限 SHALL 实时取对应平台订阅 profile，页面标明继承且不可编辑；平台对应 profile 缺失时用平台默认值。普通租户仅保存运行方式与服务商，保存、测试、模型查询提交任何继承字段或 Key（含空字段）均拒绝，不静默忽略。

#### Scenario: 平台更新订阅配置
- **WHEN** 平台修改 Claude 订阅模型与搜索上限
- **THEN** 使用 Claude 订阅的获授权租户刷新后看新值，后续未开始任务使用新值，租户 API profile 不变

#### Scenario: 恶意修改继承字段
- **WHEN** 普通租户直接提交订阅搜索上限、模型、思考强度或 apiKey
- **THEN** 整个请求被拒且原配置不变

### Requirement: 订阅选择仅使用已登录服务商
有权限的普通租户 SHALL 仅允许选择已登录服务商的订阅；全部未登录或未知时订阅方式置灰。平台可选择未登录服务商配置订阅模型并查看登录命令，但其实际任务仍须有可用登录。已保存服务商不可用而另一家已登录时，服务端有效选择按稳定顺序回退，并展示实际服务商；全部不可用则保留保存值并显示不可用。不自动保存回退值、不回退 API。页面未主动再选时保持当前仍可用选择，刷新采用服务端有效值；切换不自动保存或自动调用模型。

#### Scenario: 登录服务商自动回退
- **WHEN** 已保存 Claude 订阅失效而 Codex 已登录
- **THEN** 有效服务商为 OpenAI，并继承平台 OpenAI 订阅模型，保存值仍为 Claude

#### Scenario: 全部未登录或未知
- **WHEN** 普通租户看到两服务商均非已登录
- **THEN** 禁用新订阅选择，现订阅显示不可用，新任务不创建

### Requirement: AI 设置原型与页面表达
AI 设置 SHALL 使用真实服务商 logo，保持服务商卡片在运行方式之前，顶部状态不显示 Key。原有有效用途、模型、计费与限制说明 SHALL 保留，仅修正因共享或权限语义变化而不准确的部分；不新增无意义或重复描述，不以删减有效说明制造空洞，布局须层次清晰、排版优雅。普通租户仅见状态与继承配置，平台才见登录命令。所有页面开发前 MUST 用 OpenPencil 交付平台、获授权租户、无权及不可用状态原型并取得用户确认。

#### Scenario: 原型未确认
- **WHEN** OpenPencil 原型尚未获用户确认
- **THEN** 页面实现任务保持未开始，不用其他原型工具跳过确认
