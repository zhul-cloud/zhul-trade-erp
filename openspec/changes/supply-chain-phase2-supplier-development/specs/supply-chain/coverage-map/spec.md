## ADDED Requirements

### Requirement: 按供应商看覆盖矩阵
覆盖矩阵 SHALL 在「按覆盖状态」「按无货」之外增加「按供应商」视图。范围与供应商开发清单相同：有需求对象或在主动拓展里的品牌 × 二级品类。

- 格子显示「合格 n / 要求 n」、热度和线索供应商数。
- 颜色按缺口分档：缺口为 0 为达标色，缺 1 家为提醒色，缺 2 家及以上为警示色。
- 有进行中开发任务的格子标「开发中」。
- 可以按一级品类、品牌、热度筛选，可以只看有缺口的。
- 点格子跳到「供应链跟进」的「供应商开发」板块，筛选为该品牌 · 品类并展开；有开发任务的可以直接进专项详情。
- 有「维护专项」权限的用户可以在没有开发任务的有缺口格子下方直接「建开发任务」。

供应商名称的可见规则与供应商开发清单相同。

#### Scenario: 按供应商看全景
- **WHEN** 用户切换到「按供应商」
- **THEN** 矩阵显示每个品牌 × 品类的合格家数与要求家数，缺 2 家以上的格子用警示色

#### Scenario: 格子直接建开发任务
- **WHEN** 主管在 Omron · 伺服电机（合格 0 / 要求 3，没有开发任务）格子下方点「建开发任务」
- **THEN** 打开带开发目标的建专项弹窗，目标 3 家
