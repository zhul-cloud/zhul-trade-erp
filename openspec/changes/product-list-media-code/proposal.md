# Proposal

## Why

用户 2026-11-26 对商品档案列表提了三点：
- 想按档案完整度排序，先补最缺资料的商品。现在完整度只能在当前页内排序，换页就乱了；
- 想直接筛出有图片、有视频的商品（现在只有「缺图片」）；
- 列表看不到商品编号，商品列也没有图，认商品全靠读型号。

## What Changes

- 商品列表的「完整度」列可点表头按完整度排序（全部商品范围，服务端排序），同一完整度按更新时间倒序；取消排序回到默认顺序。
- 增加「有图片」「有视频」两个筛选：有图片 = 已设主图（与完整度的「图片视频」模块、「缺图片」筛选口径一致，两者互补）；有视频 = 至少一个视频。可与其他筛选组合。
- 列表第一列增加「商品编号」（即商品 ID，与商品候选页显示的商品编号一致）。
- 商品列有主图时在品牌型号前显示 40×40 缩略图，点击可看大图；没有主图的保持现有样式。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `product/product`：商品列表显示商品编号与主图缩略图，支持按完整度排序、按有图片 / 有视频筛选。

## Impact

- 后端：商品列表查询增加完整度排序（复用 `CompletenessSql` 各模块条件拼成排序表达式）、有图片 / 有视频筛选，列表项返回主图地址。
- 前端：`product/products/index.tsx` 增加商品编号列、缩略图、筛选项，完整度改为服务端排序（去掉当前页内排序）。
- 数据库：迁移 V1.5.61.9 给商品物流、海关、参考价三张表补 `product_id` 索引（生产实测完整度排序从约 5.9 秒降到约 0.15 秒），可回退。
- 与 `feat/ui-redesign` 分支同样改动商品列表的列宽与列设置，合并时需处理冲突。
