## Context

- 现有「粘贴报价」：选渠道与店铺 → 粘贴 → 规则识别 → 可编辑预览 → 填入草稿（`inquiry/sourcing-quote`「粘贴报价快速回填」）。
- 现有 AI 基础设施：后端写 `ai_task`，AI 编排服务按 `skill_id` 调用技能，回调后由 `AiTaskResultHandler` 校验结果；前端轮询任务状态（参考客户跟进的 `followup-extract`）。

## Decisions

1. **AI 只做「认型号 + 抽字段」，匹配与换算由后端兜底。** 输入给 AI：原文、当前任务的型号清单（明细 id、型号、客户原写法、数量）、本人其他待处理任务的型号清单（任务编号、型号）、货况与货期字典、税率字典。AI 返回每一行：对应的明细 id（只能从清单里选）、原文片段、单价、是否含税与税率、货况、货期、备注、把握（确定 / 请核对）；以及「其他任务的型号」与「都不在任务里的型号」。后端校验：明细 id 必须属于当前任务、单价不能为负、货况货期税率必须是字典值（不是时置空并标「请核对」），然后按现有规则换算不含税价。
2. **预览沿用现有粘贴报价的预览**，多两处：每行显示「AI 识别」与把握，「请核对」的行标橙色；底部「其他任务里的型号」按任务列出（任务编号、型号数），点任务编号跳到那个任务并自动打开粘贴报价、带上原文。原文只保存在当前页面，离开我的询价就清掉，不入库。
3. **异步执行，弹窗内等待。** 点「AI 识别」后弹窗显示识别中（通常 10–30 秒），可以取消；超过 90 秒或失败时提示，并提供「按规则识别」。同一个人同一时间只跑一个识别。
4. **AI 未开启（租户 AI 设置里没有可用模型）时**，弹窗只有「按规则识别」，与现在一样。
5. **填入规则不变**：同一渠道且同一店铺的草稿覆盖，否则追加；已提交且不能修改的型号不填入。

## Risks / Trade-offs

- [AI 把相似型号认错] → 明细 id 只能从当前任务里选；预览逐行显示原文片段，采购确认后才填入，且只是草稿。
- [长原文超时] → 原文上限 20,000 字；超过时提示分段粘贴。
- [多人比价时把别人的价当成自己的] → 只填入本人的草稿，与现有粘贴报价一致。

## Migration Plan

无数据库迁移。AI 编排服务新增技能目录，随服务镜像发布。
