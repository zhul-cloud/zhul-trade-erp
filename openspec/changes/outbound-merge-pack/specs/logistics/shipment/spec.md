# Spec Delta

## MODIFIED Requirements

### Requirement: 出运单
有「出运单编辑」按钮权限的业务员 SHALL 能新建出运单（类型代码 SH，内部单据，如 `SH20261014001`）：选择客户与货代，勾选这家货代已收到的、同一客户的「已交货代」销售出库单（可以来自多张订单）与直发货代的供应商发货单。一张销售出库单或直发发货单只能在一张有效的出运单上。合并打包组里的销售出库单共用箱子，要整组放进或移出同一张出运单：勾选组内一张时同组的其他单一起勾选，只放一部分时提示「OB… 与 OB… 合并打包了，要放在同一张出运单」。出运单状态：待出运、已出运、已作废。待出运时可以增减销售出库单、作废（填写原因，放进去的销售出库单与直发货回到可选）。

#### Scenario: 两张订单一票出运
- **WHEN** 客户 Hoorain 的 SO1、SO2 各有一张已交深圳捷运的销售出库单
- **THEN** 业务员可以把两张销售出库单放进同一张出运单；另一个客户的销售出库单不在可选列表中

#### Scenario: 合并打包整组放进出运单
- **GIVEN** OB1、OB2 合并打包并已交货代
- **WHEN** 业务员新建出运单时只勾选 OB1 保存
- **THEN** 系统提示「OB1 与 OB2 合并打包了，要放在同一张出运单」，不能保存；页面上勾选 OB1 时 OB2 自动一起勾选
