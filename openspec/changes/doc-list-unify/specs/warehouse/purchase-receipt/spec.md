## MODIFIED Requirements

### Requirement: 采购入库页
「仓库管理 → 采购入库」SHALL 按单据列表骨架展示：搜索条件区（关键词、状态）+ 主内容区（操作行、表格、分页）。仓库人员看全部（不按采购员过滤），兼职采购不能访问。状态下拉的选项为「待收货 · N」（N 为在途发货单数，为 0 时只显示「待收货」）与「已入库」，默认「待收货」，切换后立即查询：
- **待收货**：在途的发货单，列与「发货跟踪 → 发货记录」一致（发货单号 · 发货日期、采购对象、型号 · 数量、品牌、品类、快递 · 单号、预计到货日期（已过日期的标「超时未到」）、来源单号、采购员），按发货日期从早到晚；关键词可以按快递单号、采购订单号、型号、采购对象搜索；操作「验收入库」，点发货单号打开发货单详情。
- **已入库**：按单据页统一规范，列依次为入库单号 · 收货日期、采购对象、型号 · 数量、品牌、品类、合格 · 不良 · 差异、状态（已入库 / 已冲销）、来源单号（发货单号、采购订单号）、收货人、创建时间、创建人、更新时间、更新人、查看；默认按更新时间倒序。点单号或「查看」打开采购入库单详情页。

「直接收货」放在主内容区操作行的右侧，两种状态下都显示。型号 · 数量列多个型号时可点「查看」看全部型号。

#### Scenario: 按快递单号找到货
- **WHEN** 仓库人员在状态「待收货」下输入快递单号末四位「8812」并查询
- **THEN** 列出快递单号包含 8812 的在途发货单

#### Scenario: 状态在搜索条件栏
- **WHEN** 仓库人员打开采购入库，有 3 张在途发货单
- **THEN** 搜索条件区的状态下拉显示「待收货 · 3」，页面顶部没有分段按钮；改选「已入库」后表格立即换成采购入库单
