## MODIFIED Requirements

### Requirement: 报价单型号明细格式与商品档案跳转
报价单详情（含草稿编辑）的型号明细 SHALL 按「单据型号明细格式」显示：品牌、品类、型号为三列，每行都显示品牌与品类；型号下面依次显示订货号（有时）与「查看素材」。明细不显示来源单号，来源询盘单号只在表头显示（见「来源单号」）。型号对应的商品档案先取来源询盘型号已建档的商品档案，没有时按品牌 + 型号匹配。有商品档案菜单权限的人点型号，在当前标签打开该商品档案详情，并可按「跳转后可返回原页面」回到这张报价单；草稿有未保存的修改时，先按现有的离开提示确认。没有权限或没有对应商品档案时，型号只显示文字。报价单 PDF、Excel 与文字报价的版式不变。

#### Scenario: 每行都显示品牌
- **WHEN** 报价单有 3 行都是 SIEMENS 的型号
- **THEN** 3 行的品牌列都显示 SIEMENS

#### Scenario: 明细不显示来源
- **WHEN** 打开一张来自询盘 IQ20261004001 的报价单
- **THEN** 型号明细只有品牌、品类、型号等列，没有「来源询盘」列；表头说明行显示「来源单号 IQ20261004001」，可点开

#### Scenario: 点型号看商品档案再返回
- **WHEN** 有商品档案权限的业务员在报价单 QT20261105001 上点型号 6ES7214-1AG40-0XB0
- **THEN** 当前标签打开该商品档案详情，标题上方显示「← 返回 报价单 QT20261105001」，点后回到这张报价单

#### Scenario: 导出不变
- **WHEN** 业务员导出报价单 PDF
- **THEN** PDF 的列与改版前相同，不出现来源单号与订货号
