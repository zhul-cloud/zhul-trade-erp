## 1. 原型

- [x] 1.1 OpenPencil 原型：部门管理设置事业部、费用单与其他收入选事业部、结汇单选事业部、收款账户归属、登记收款的收错账户提示、三个统计页的事业部切换与经营统计的直接费用 / 分摊成本两段，用户确认后再开发

## 2. 数据库

- [x] 2.1 迁移：部门加事业部标记与开始核算月份；客户、商机、询盘、报价、PI、销售订单、收款到账、收款账户、结汇单、费用单、其他收入加所属事业部及索引；系统设置加最低分摊比例（默认 20%）
- [x] 2.2 反向 SQL

## 3. 后端

- [x] 3.1 事业部设置：一级部门标记 / 取消标记校验、开始核算月份；标记第一个事业部时回填已有数据
- [x] 3.2 用户所属事业部；客户、商机创建时写入，公共部门登记人须选择；下游单据跟随上游；客户转移可选是否转事业部
- [x] 3.3 收款账户归属与按事业部 + 币种的默认账户；PI 取本事业部账户
- [x] 3.4 收款归属订单、收错账户提示与标记；未认领到账按账户、认领后按订单
- [x] 3.5 结汇按（事业部, 币种）先进先出与估算汇率
- [x] 3.6 费用单、其他收入的事业部 / 公共；关联订单的跟随订单
- [x] 3.7 公共分摊计算（最低比例、都无销售额平分、开始核算月份、尾差）及单元测试（边界：0 销售额、单事业部、最低比例 × 数量 > 100%）
- [x] 3.8 统计可见事业部集合；利润统计、经营统计、销售统计加事业部条件与越权校验
- [x] 3.9 契约测试：各事业部之和等于全公司；没有事业部的公司结果不变

- [x] 4.2 费用单、其他收入、结汇单、收款账户表单与列表的事业部字段和筛选（没有事业部的公司不显示）
