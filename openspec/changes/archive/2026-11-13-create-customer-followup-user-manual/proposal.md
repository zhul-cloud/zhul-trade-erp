## Why

现有用户手册以文字为主，内部员工尤其是第一次使用系统的员工需要在页面和说明之间反复对照，学习成本高。现在以“客户跟进”为第一份示例，建立可复用的图文用户手册规范，并产出可直接内部转发的 Markdown 和 PDF 手册。

## What Changes

- 新增统一的用户手册编写规范，沉淀面向小白用户的语言、结构、截图、标注、版本和 PDF 发布要求。
- 新增客户跟进图文用户手册，覆盖今日待办、五个跟进板块、记一次跟进、客户详情、团队视图、客户经营、主动开发、订单履约和售后评价等已实现流程。
- 为关键操作配套产品原型截图、编号标注、白话说明、填写示例、操作结果和常见问题。
- 输出 Markdown 源文件和可直接发给公司内部员工阅读的 PDF 文件。
- 在手册中标明适用角色、适用版本、更新时间和截图来源；页面或流程变化时按版本同步更新。

## Capabilities

### New Capabilities

本变更只涉及用户文档和发布物，不新增或改变系统运行时能力，因此不创建新的产品能力规格。

### Modified Capabilities

无。现有客户跟进功能需求不变。

## Impact

- 文档目录：`docs/05-使用手册/`
- 产品原型和截图来源：`docs/03-产品原型/03-业务域/03-销售管理/07-客户跟进/`
- 参考需求：`openspec/specs/crm/customer-followup/spec.md`
- 可能涉及 PDF 生成工具或文档渲染依赖，但不修改前端、后端、数据库、API 或生产部署配置。
