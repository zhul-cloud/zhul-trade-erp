## ADDED Requirements

### Requirement: 新建销售订单
销售订单列表 SHALL 提供「新建销售订单」，先选择创建方式（参照新建报价单）：
- 按 PI 创建（需要 PI 菜单权限）：列出自己数据范围内可以转订单的 PI——已发送、有水单或到账、没有未发送的新版本、没有有效订单——按发送时间从新到旧，每张显示 PI 编号、客户与国家、合计、收款状态、最近一笔水单或到账、业务员，可按 PI 编号或客户搜索；选中一张后进入与 PI 页「转成订单」相同的确认（填写销售日期），结果与在 PI 上转订单完全相同。顶部提示「你有 N 张 PI 已收到水单或到账、还没有转成订单」。
- 手动创建（需要「手动创建订单」按钮权限）：打开手动建单（见「手动创建销售订单」）。
没有其中一种权限时，该方式置灰并标「没有权限」；两种都没有时不显示「新建销售订单」。

#### Scenario: 按 PI 创建
- **WHEN** 业务员点「新建销售订单」，选「按 PI 创建」，在列表中选 FWPI20261006001（已有水单），确认销售日期
- **THEN** 生成销售订单，与在 FWPI20261006001 上点「转成订单」的结果相同

#### Scenario: 不能转的 PI 不列出
- **WHEN** 客户的 PI 中一张还没有水单、一张已转成订单、一张有未发送的 Rev.2
- **THEN** 这三张都不出现在「按 PI 创建」的列表中

#### Scenario: 没有可转的 PI
- **WHEN** 业务员选「按 PI 创建」，但没有任何可以转订单的 PI
- **THEN** 提示「现在没有可以转订单的 PI：PI 需要已发送、有水单或到账，且没有未发送的新版本」
