## Why

销售订单目前只是 PI 的确认单（生成、查看、取消），日常跟单需要的信息都没有：没有销售日期（客户昨天付款、今天建单，跨月统计就错了），看不出现货还是期货，状态只有「有效 / 已取消」，不知道每个型号由哪位采购负责、进度到哪一步，也算不出这一单实际赚了多少。另外有些订单没有走报价单和 PI，需要直接手动建单。

## What Changes

- **两种建单方式**：由 PI 转成（沿用）；手动创建，只填必填项：客户、币种（默认美元）、销售日期（默认当天）、型号 / 数量 / 单价（采购成本价、采购员选填）。
- **销售日期**：订单记录销售日期，统计按销售日期。由 PI 转成时默认取这张 PI 最早一笔有效水单或到账的日期，没有时取当天，转订单时可改。
- **现货 / 期货**：每个型号行标现货或期货（由 PI 转成时按货期带出：货期为「现货」的为现货，其余为期货），可改；订单只要有一行是期货就显示「期货」。
- **订单状态用字典管理**：字典「销售订单状态」初始为 待采购 → 已下单 → 已入库 → 已交货代 → 已出运 → 已完成，另有「已取消」；在「系统管理 → 字典」里可改名称、调整顺序、停用中间步骤，「待采购」「已完成」「已取消」为内置、不能停用。每个型号行各有自己的进度，由人手动推进（可批量），订单状态取进度最慢的一行；全部型号「已出运」后点「客户已收货」订单变为「已完成」。以后有了采购、物流模块再自动推进。
- **采购员按型号行**：默认取这个型号被选为采购成本价的那条回价的采购员，可改；订单上列出全部采购员，可按采购员筛选。一单多位采购员时各自对应自己的型号。
- **新 / 老客户**：订单创建时记下新 / 老客户（由 PI 转成时按来源询盘；手动创建时客户有过有效订单为老客户），供统计。
- **收款**：列表的收款状态显示为进度条（已到账 / 合计）；订单详情汇总收款的付款方式（如「阿里巴巴信用保障 USD 300.00 · 银行转账 USD 700.00」）。手动创建的订单没有 PI，收款直接记在订单上，同样支持上传水单、财务确认、认领到账与平台收款。
- **订单毛利**：订单详情显示销售额（原币与折合人民币）、实收人民币、采购成本与毛利：收齐款后毛利 = 实收人民币 − 采购成本，没收齐时显示预计毛利 = 销售额折合人民币 − 采购成本。
- **币种**：俄罗斯卢布已是可维护币种（汇率管理里录入卢布汇率即可下单），本次不需要改动。
- **列表**：增加销售日期、现货 / 期货、订单状态（字典名称）、采购员、收款进度条；可按销售日期、状态、现货 / 期货、采购员筛选。

## Capabilities

### New Capabilities
（无）

### Modified Capabilities
- `sales/sales-order`: 由 PI 转成时的销售日期；新增手动创建；「订单不可修改只能取消」改为内容不可改、进度与采购员等跟单信息可改；列表与详情的新字段；新增订单状态与进度、采购员、现货 / 期货、订单毛利的要求。
- `sales/payment-receipt`: 收款可以记在手动创建的订单上。

## Impact

- **数据库**（新迁移脚本）：订单增加销售日期、新 / 老客户、来源（PI / 手动）、订单进度码、完成时间；订单行增加现货 / 期货、进度码、采购员；收款记录增加订单 ID（手动订单的收款）；平台字典「销售订单状态」；按钮权限「手动创建订单」「更新订单进度」。
- **后端**：手动建单、编辑跟单信息（进度、采购员、现货 / 期货）、客户已收货；转订单的销售日期；订单收款（手动订单）；列表筛选与汇总；订单毛利。
- **前端**：订单列表与详情改版、手动建单抽屉、批量推进进度、订单收款面板（手动订单）、转订单弹窗的销售日期。
- **原型**：订单列表、订单详情（进度、采购员、收款汇总、毛利）、手动建单、批量更新进度、转订单弹窗。
