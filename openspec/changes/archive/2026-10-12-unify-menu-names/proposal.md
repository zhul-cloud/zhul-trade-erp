## Why

菜单名称混用了三种风格：按单据（报价单、采购单）、按动作（入库验收、出库打包）、带后缀（收款管理、付款记录），成对的业务也不对称（采购单对销售订单、入库验收对出库打包）。新同事要先记住每个菜单的叫法才能找到页面，菜单名和页面里的单据名也对不上（菜单「入库验收」，页面里叫「入库单」，单据编号规格里又叫「采购入库单」）。趁供应链与财务模块刚上线、使用的人还少，统一一次命名规则并按规则改名。

## What Changes

- 修订导航的「菜单命名规则」：
  - 分组一律叫「领域 + 管理」，设置类分组除外；
  - 叶子菜单按单据、库存作业、基础资料、处理入口、任务、看板与统计分类命名；
  - **新增：看板与统计只读**，有操作的页面不能叫看板或统计；
  - 页面里的单据名称与菜单一致。
- 按规则改名：
  - 分组：业务管理 → 销售管理，单证物流 → 物流管理，商品资料 → 商品管理；
  - 销售与采购：客户询盘 → 询盘单，历史询价 → 询价记录，采购单 → 采购订单；
  - 仓库：入库验收 → 采购入库，出库打包 → 销售出库，暂存货 → 闲置库存，拍摄任务 → 实拍任务；
  - 物流与财务：货代对账 → 运费账单，收款管理 → 收款单，应付管理 → 应付单，付款记录 → 付款单；
  - 设置：单据模版 → 单据模板，单据编号（设置页）→ 编号规则。
- 页面里的单据名跟着改：入库单 → 采购入库单，出库单 → 销售出库单，对账单 → 运费账单，付款记录 → 付款单等。改动范围包括标题、按钮说明、提示与报错文字、导出文件名和操作日志的模块名。
- 顺带修正导航规格里过期的内容：「内容任务」改为现在的「资料任务」，补上「运营管理」分组。
- 不改：页面访问地址、权限码、单据编号前缀与类型代码、数据库表名与代码标识符、已有操作日志的历史文字。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `system/navigation`：侧边栏分组与菜单名称、菜单命名规则（新增看板与统计只读）、改名后权限不变。
- `system/document-numbering`：类型代码列表与前缀适用范围里的单据名称，设置页名称「编号规则」。

## Impact

- 数据库：新增迁移，更新菜单与按钮资源的名称，以及单据类型、操作日志模块等字典的显示名称。
- 前端：菜单文案、路由标题、各页面标题与面包屑、页面内文字与导出文件名，涉及询盘、采购、仓库、物流、财务、商品、设置等页面。
- 后端：返回给用户的提示与报错文字、导出文件名与表头、单据类型显示名称、操作日志模块名。
- 测试：导航契约测试，以及断言报错文字的各模块契约测试。
- 规格：其他主规格里的旧名称一并替换为新名称，只换叫法，不改行为。
- 原型：已有原型不重画，之后新做的原型使用新名称。
