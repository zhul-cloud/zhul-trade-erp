## Why

财务单据统一的第三批（最后一批）：报销单、费用单、其他收入。现状：

- 三张单据都只能在列表的抽屉里看，没有独立详情页；费用单、其他收入的修改与作废在列表行上，操作记录只写在通用操作日志里。
- **费用单**、**其他收入**生效后还能改金额（费用单在付款或进报销单之前可以改金额、收款方、付款方式），与 2026-11-13 定下的财务单据规则不一致：生效后金额、币种、汇率、核销关系都不能改，录错作废重开。
- **报销单**没有备注，付款截图只能在登记已付时上传。
- 付款单、应付单、余额提现等处提到报销单号、费用单号时只能跳到列表。

## What Changes

**三张单据都有独立详情页**

| 单据 | 详情页 | 明细 |
|---|---|---|
| 费用单（FE） | `/finance/expenses/:id` | 分摊到的订单型号（销售订单、品牌、型号、分摊金额、人民币）与合计；不关联订单的显示「公司费用，不分摊到订单」 |
| 报销单（BX） | `/finance/reimbursements/:id` | 报销的各项：来源单号、类型（采购垫付、费用垫付、快递运费、收到退款等）、收款方 · 说明、日期、金额、截图，与合计 |
| 其他收入（OI） | `/finance/other-incomes/:id` | 只有一笔金额，不设明细表；系统生成的汇兑损益在关联单据里列出来源退款单 |

- 布局与其他单据相同：左边基本信息、明细、备注与附件，右边关联单据、操作日志；
- 操作移到详情页：费用单「修改」「作废」，其他收入「修改」「作废」，报销单「撤回」（提交人）、「登记已付」「撤销已付」（报销付款权限）；
- 列表单号可点、加「查看」，去掉抽屉；报销单页的「待报销」页签与批量登记已付不变。

**修改按财务单据规则收紧**

| 单据 | 生效后能改 | 不能改（录错作废重开） |
|---|---|---|
| 费用单 | 名称、类别、分摊月数、所属事业部、关联售后单、分摊到订单型号（合计仍须等于金额）、说明、凭证 | 发生日期、币种、金额、汇率、收款方、付款方式、垫付人 |
| 其他收入 | 类别、所属事业部、说明、凭证 | 日期、金额 |
| 报销单 | 备注、附件（付款截图等） | 各项与合计；撤回后重新提交 |

- 作废条件不变：费用单没有付款、没进报销单才能作废；其他收入系统生成的不能手动作废；
- 详情页「备注与附件」随时可改说明与凭证（费用单、其他收入有效时；报销单未撤回时）。员工垫付的费用单至少保留一张凭证。

**备注、附件与操作日志**

- 报销单新增备注（500 字）；附件沿用报销付款截图的归属 `REIMBURSE`，详情页可增删；
- 费用单、其他收入沿用原有的说明与凭证；
- 写单据操作日志：费用单的登记、修改（写明改了什么）、作废、进入报销单与撤出；其他收入的登记、修改、作废；报销单的提交、撤回、登记已付、撤销已付；三张单据的改备注、增删附件。原有的通用操作日志照写。

## Capabilities

### Modified Capabilities

- `finance/expense`：费用单详情页；生效后只改非金额字段；列表去掉抽屉。
- `finance/other-income`：其他收入详情页；生效后只改非金额字段；列表去掉抽屉。
- `finance/reimbursement`：报销单详情页、备注附件与操作日志。

## Impact

**数据库**

- 迁移 V1.5.33：`fin_reimbursement` 新增 `remark varchar(500) NOT NULL DEFAULT ''`；不建新表。
- 回退：删除该列即可。

**后端**

- 三张单据的详情接口补关联单据、日志、可编辑；新增改备注、增删附件接口；
- 费用单、其他收入修改接口拒绝金额类字段变化；
- 写 `DocLogs`。

**前端**

- 新建三个详情页，调整三个列表；`DOC_META` 中 BX、FE、OI 链接到详情页。

**不影响**

- 费用分摊、应付生成、报销提交与付款、汇兑损益生成、经营统计口径都不变；权限码不变。
