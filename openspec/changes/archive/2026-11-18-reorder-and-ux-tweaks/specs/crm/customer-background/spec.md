# Spec Delta

## ADDED Requirements

### Requirement: 档案补全按业务员筛选

「档案补全」左侧待补全列表顶部 SHALL 提供「业务员」筛选（默认全部业务员），只对数据范围为全部或自定义的人显示；选了业务员只列该业务员名下的待补全客户，仍受数据范围限制。筛选后没有客户时，列表内提示「这个业务员名下的客户档案都补全了」，筛选仍可修改。

#### Scenario: 主管按业务员看

- **WHEN** 数据范围为全部的主管在档案补全选择业务员「张伟」
- **THEN** 待补全列表只列张伟名下的客户，数量随之变化

#### Scenario: 只能看自己客户的业务员

- **WHEN** 数据范围为本人的业务员打开档案补全
- **THEN** 不显示「业务员」筛选
