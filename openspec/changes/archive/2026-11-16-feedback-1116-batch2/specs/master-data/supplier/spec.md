# Spec Delta

## MODIFIED Requirements

### Requirement: 服务商体积系数
供应商类型为「服务商」的记录就是货代（货代、快递公司），SHALL 在「货代管理」维护（见 logistics/forwarder），不再出现在供应商管理：供应商列表、导出与供应商选择器不列出服务商，新增、编辑供应商时的类型不再提供「服务商」。货代有「体积系数」（正整数，默认 5000），用于按计费重分摊运费，在货代管理里填写。发货通知与出运单选择货代时只列出启用的货代。

#### Scenario: 货代用 6000
- **WHEN** 货代「深圳捷运」的体积系数设为 6000
- **THEN** 它承运的出运单按 长 × 宽 × 高 ÷ 6000 计算体积重

#### Scenario: 供应商管理里没有货代
- **WHEN** 采购员打开供应商管理，或在询价时选择供应商
- **THEN** 看不到类型为服务商的货代、快递公司
