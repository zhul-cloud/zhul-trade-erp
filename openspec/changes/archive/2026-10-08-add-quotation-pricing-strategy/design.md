## Context

报价单编辑页的定价现在只能逐行操作（按毛利率、按加价、直接填售价），计算口径在前端 `quotation/calc.ts` 与后端 `QuotationCalculator` 各有一份并保持一致。无货型号在新建时被跳过（按询盘）或要求手填售价（挑选），发送时校验每行有售价。品牌快照来自询盘原文；品牌主数据 `product_brand.brand_name` 是英文名，别名表 `product_brand_alias` 收录了「西门子」「三菱」等写法，询盘型号上有 `brand_id`（识别到时）与 `brand_key`。

## Goals / Non-Goals

**Goals:**
- 客户看到的单据上品牌统一是英文，旧报价单、旧 PI 重新导出也生效。
- 报价策略在前端即时计算、即时预览，应用后仍是普通的逐行售价，保存、发送、版本对比都不需要特殊处理。
- 无货型号能出现在报价单和导出里，不影响合计、毛利、开 PI。

**Non-Goals:**
- 不为替代型号自动询价或报价；要给替代型号报价，另行询价后作为新行加入。
- 不改定价策略页已有的品相毛利率、红线与建议毛利率决策顺序。
- 不改系统内页面的品牌显示（仍显示询盘原文，便于和询盘对照）。

## Decisions

1. **英文品牌在渲染时解析，不改快照**：新增 `BrandNames`（品牌模块下），按 报价 / PI 行的品牌快照查英文名：先按询盘型号的 `brand_id`，再按归一化品牌名匹配主数据名称或别名（本租户与平台），都没有时返回原文。文字报价、报价单渲染（`QuotationRenderModels`）、PI 渲染（`PiRenderModels`）统一走它，一次渲染批量查询。
   - 备选：新建报价行时把英文名写进快照。放弃原因：旧单据不生效，且品牌主数据后补别名时无法自动纠正。

2. **报价策略纯前端计算**：在 `quotation/pricing/strategy.ts` 实现各策略，复用 `calc.ts` 的口径（售价人民币 → 外币两位小数 → 反算毛利率），配单元测试。应用时把结果写成每行的外币售价（定价方式 3-直接填外币售价），走现有保存接口。
   - 后端只新增两个读写点：历史价查询、分层档位读写。
   - 目标利润的分摊：
     1. 按成本占比得到基础毛利率 m0（使 Σ 成本 × m0 / (1 − m0) ≈ 目标，用二分法求解）；
     2. 每行 m = clamp(m0 + 随机偏移, 红线, 95%)；
     3. 按外币取整后算实际净利润，与目标的差按成本占比再修正一次；
     4. 不取整时，剩余的几分钱误差放在数量最少的一行（一分钱对合计影响最小；数量相同取成本最大的）。
   - 随机数用可复现的种子（「换一组」时更换种子），保证预览与应用一致。
   - 目标总价同理：二分求统一毛利率，使外币小计合计 = 目标。

3. **分层档位存租户配置**：沿用定价策略的租户配置（`sys_config`，`PricingSettings` 读写），新增一个 JSON 配置项 `quotation.strategy.cost-tiers`（与定价策略里「低值耗材分层」是两回事，不共用），迁移写入平台默认值（300 → 35%、3000 → 20%、其余 12%）；读取时租户没有就用平台的。保存需要「定价策略」编辑权限。

4. **历史价接口**：`GET /quotations/{id}/price-history`，对该报价单当前查看版本的有价行，按客户 + 归一化型号查：
   - 已发送报价单的当前有效版本行（排除本单）；
   - 有效销售订单的型号行。
   每个型号各取最近一条（成交优先）。返回日期、单据编号、币种、单价；超过 3 张表的组装在 Service 层完成。

5. **无货行**：
   - 新建时按询盘也带入无货候选，行上 `no_stock = 1`、售价为 0（沿用现有的非空售价列，「无货且售价为 0」即无货行，不改成可空以免影响现有金额计算），新增 `replacement_model` 快照（取询盘型号停产时的替代型号）。
   - 无货行小计为 0，自然不影响合计；毛利只算有采购成本价的行，无货行没有成本，本来就不参与。
   - 发送校验跳过无货行。
   - 开 PI 候选排除无货行。
   - 业务员填了售价后 `no_stock` 保持 1 作为来源标记，但按「有售价」参与计算，页面不再标「无货」（判断条件：无货且售价为 0）。

6. **无货行渲染**：
   - 文字报价：模版引擎对无货行不套用户模版的行格式，固定输出「型号 品牌 数量 no stock[, discontinued, replacement: X]」，避免出现「$」后跟空值。
   - Excel：单价单元格写文本「No stock」（不写数字），小计留空；合计公式本来就对小计求和，空单元格不影响。
   - 描述后追加替代型号。

## Risks / Trade-offs

- [随机打散让同一张单每次打开看到的结果不同] → 只在抽屉预览时随机，应用后即为固定售价；种子在抽屉打开期间不变，只有点「换一组」才变。
- [品牌别名匹配不到导致仍输出中文] → 匹配不到时保留原文，并在报价编辑页对非英文品牌给出提示「品牌 西门子 没有英文名，请在品牌资料里补充」（只提示）。
- [历史价跨币种不能直接沿用] → 只展示、不换算，避免汇率差带来的误报价。

## Migration Plan

- 新迁移脚本：`quotation_item` 新增 `replacement_model`；`sys_config` 写入分层档位平台默认值。
- 存量：已有无货行（之前手填过售价的）保持原样。
