## Why

供应链 ①–④ 与 ③a、③b 上线后，一张订单的真实成本已经分散在各处：采购订单行价格、付款时的实付人民币、到货差异的折价与退货运费、分摊到型号行的国内与国际运费、费用单分摊。但订单毛利仍然只按报价时的「采购成本价 × 数量」计算，看不到实际赚了多少；采购砍价也只能在单张采购订单上看。

公司现在用《成本核算》表手工按单核算：收入 = 毛额 × 结汇汇率，成本 = 采购 + 运费 + 杂费 + 交易服务费，按单标「已结算 / 未结算」。另外每月手工整理公司、业务员、客户的销售报表。

这是供应链第 ③ 期的最后一块（③c）：让系统按同样的口径自动算出每张订单的实际毛利，替代《成本核算》表。前置变更 `purchase-invoice-and-fx-settlement` 先把开票成本和结汇汇率录准。

## What Changes

- **订单型号行实际成本**（新）：按以下各项相加，按实际付出的金额计（公司不做出口退税）：
  - 采购货款：单价 × 数量 × 实际汇率；外币采购订单按付款时的实付人民币折算，没付完的部分先按下单汇率估算；
  - 开票成本；
  - 采购订单上的其他费用；
  - 退货运费（加）与不良折价（减，列为质量索赔）；
  - 国内运费、国际运费；
  - 费用单分摊；
  - 收款手续费（平台手续费与银行中转差额）。

  还没有采购订单、还没入库的部分，用采购订单单价或报价时的采购成本价补足。
- **收入与毛利**：收入按毛额 × 到账汇率计算（结汇后为实际汇率，未结汇时按估算汇率），和《成本核算》表一致；毛利 = 收入 − 实际成本。
  - 同时满足以下条件时为「**已结算**」，否则为「未结算」，并列出还差的项：已收齐并结汇；已全部入库；外币货款已付清；国际运费已对账。
- **订单详情**（改）：「订单毛利」改为成本明细，按型号行列出各项成本、行毛利，每项都能追溯到来源单据。
- **销售订单列表**（改）：增加「毛利」列，显示金额、毛利率与「已结算 / 未结算」，可以按毛利排序。
- **采购管理 → 砍价统计**（新菜单，只读）：
  - 按采购员、供应商、品牌、品类、月份汇总；
  - 砍价率按目标金额加权；
  - 质量索赔、开票成本单独列。
- **财务管理 → 利润统计**（新菜单，只读）：
  - 按月份、业务员、客户汇总收入、实际成本、毛利与毛利率；
  - 都按新 / 老客户拆分，收入另按线上 / 线下拆分；
  - 客户维度显示国家与订单数；
  - 可以只看已结算，点击可以进入订单。

  它覆盖现有《公司销售报表》《业务销售报表》《客户销售报表》里收入与毛利的部分。
- 不做：
  - 闲置库存用到其他订单；
  - 利润统计导出；
  - 客户退款、运营成本与公司经营月报（另开「经营报表」变更）；
  - 商机、询盘、报价、转化率等漏斗指标（另开「销售漏斗报表」变更）。

## Capabilities

### New Capabilities

- `finance/order-cost`：订单型号行实际成本、收入与毛利口径、「已结算 / 未结算」判定、订单详情成本明细。
- `finance/profit-stats`：利润统计页。
- `purchase/bargain-stats`：砍价统计页。

### Modified Capabilities

- `sales/sales-order`：「订单毛利」改为按实际成本与毛额收入计算，列表增加毛利列。
- `system/navigation`：采购管理增加「砍价统计」，财务管理增加「利润统计」。

## Impact

- **后端**：
  - 新增成本计算服务：按订单批量读取采购订单行、开票、入库、到货差异、付款核销、运费分摊、费用单分摊与收款记录，不新增成本表；
  - 新增砍价统计、利润统计接口；
  - 订单详情与列表接口增加成本字段。
- **数据库**：新增迁移，加两个菜单与授权：
  - 砍价统计：授给有「询价分配」菜单的角色；
  - 利润统计：授给有「收款单」菜单的角色；
  - 管理员两个都授。
- **前端**：订单详情成本明细、订单列表毛利列、两个统计页。
- **原型**：用 OpenPencil 出订单成本明细与两个统计页。
- **依赖**：必须在 `purchase-invoice-and-fx-settlement` 之后实施。
