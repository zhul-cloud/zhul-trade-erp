## Why

客户压价时，业务员要知道「还能让多少」：现在是每次手工建一张成本测算表（固定汇率 6.6～6.8、逐行填成本与售价、算总毛利、填让利与折扣看实际毛利率），费时且容易填错。PI 里本来就有每行的采购成本、售价与毛利率红线，可以直接在系统里算出来，确定后一键生成带整单折扣的 PI 新版本。

## What Changes

- **议价测算**：PI 详情增加「议价测算」（右侧抽屉，只在系统内显示，不出现在导出的 PI 上），按 PI 当前查看的版本计算：
  - 每行与整单的成本、售价、毛利、毛利率与红线；
  - 「最多还能让」：整单毛利率降到红线为止还能让的金额与点数（点数 = 占小计的百分比），已经低于红线时显示「已低于红线」；
  - 输入让利点数或目标总价，即时算出让利后的合计、毛利与毛利率，低于红线标红，并列出会低于各自红线的型号；
  - 汇率默认取 PI 的汇率，可以临时改一个汇率测算（只影响测算，不改 PI）。
- **应用到 PI**：确定后点「生成 PI 新版本」：已发送的 PI 出新版本并带上整单折扣（按点数时为百分比折扣，按目标总价时为金额折扣），草稿或修改中的 PI 直接改折扣，都不自动发送。
- **导出测算表**：按现有手工表的格式导出 Excel（固定汇率、型号、数量、成本单价 / 总价、销售单价 / 总价、总毛利、让利、实际毛利、实际毛利率，保留公式），方便发给主管或存档。

## Capabilities

### New Capabilities
（无）

### Modified Capabilities
- `sales/proforma-invoice`: 新增「议价测算」的要求。

## Impact

- **后端**：议价测算导出接口（按 PI 版本、汇率、让利方式与数值生成 Excel）；测算本身在前端计算，口径与现有 PI 计算一致，后端提供同口径的计算工具类与单测（导出时复用）。
- **前端**：PI 详情的「议价测算」按钮与抽屉、应用到 PI（出新版本 / 改折扣）。
- **数据库**：无。
- **原型**：议价测算抽屉（正常、低于红线两种状态）。
