# Spec Delta

## MODIFIED Requirements

### Requirement: 提交任务给 AI 编排服务
系统 SHALL 以统一契约向 AI 编排服务提交任务：请求携带 skill 标识、输入数据、回调地址，以及发起任务时当前租户按顺序挑出的可用连接方式列表（每项含用法、服务商、模型设置，API 方式的 Key 为解密后的值，只出现在请求体中，不写入 AI 任务记录和日志）；AI 编排服务同步返回受理确认（202 状态码及任务标识），实际处理结果通过异步回调返回，回调同时带回实际完成调用所用的连接方式与模型、以及执行中发生的切换（原连接方式、原因分类、时间，不含 Key）。Java 侧不同步等待处理完成。

#### Scenario: 提交后不阻塞等待
- **WHEN** Java 后端向 AI 编排服务提交一个任务请求
- **THEN** AI 编排服务在受理后立即返回确认，Java 后端不阻塞等待处理结果

#### Scenario: 任务携带发起时的配置
- **WHEN** 租户提交任务后、编排服务处理完成前修改了 AI 配置或调整了顺序
- **THEN** 已提交的任务仍按提交时携带的列表处理，之后提交的任务使用新配置

#### Scenario: Key 不落库
- **WHEN** 任务提交成功后查看 AI 任务记录与后端、编排服务日志
- **THEN** 都不包含 API Key 明文

#### Scenario: 回调带回切换情况
- **WHEN** 任务执行中从 Claude API 切换到 OpenAI API 后完成
- **THEN** 回调带回实际使用 OpenAI API 及其模型，以及一条 Claude API 的切换记录（原因分类，不含 Key），后端据此记录任务并让 Claude API 进入暂停
