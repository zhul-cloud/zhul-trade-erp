## Why

询价协作已经能按型号回齐采购成本价，但「报价」这一段还完全在系统外：业务员拿着成本价自己心算加价、自己换算美元，再手工复制《报价模版.xlsx》改型号和价格发给客户；每个人手里的模版版本不一样，客户收到的格式也不统一；同一客户的几个询盘想合在一张单里报，只能自己拼。售价是否低于利润底线没人能看到，客户询盘也停在「可报价」，没有「已报价 / 已成交」的记录可统计。

## What Changes

- **定价策略（按《工控自动化产品定价策略 SOP》V6）**：按售价计算毛利率（售价 = 进价 ÷ (1 − 毛利率)）；按货况（品相）给出建议毛利率与红线，国产替代一律 62%，没有品相的低值耗材按金额分层；停产急件、现货优势品牌、老客户、品相待查时提示「建议主管核价」（只提示不拦截）。
- **系统汇率**：汇率统一在「系统管理 → 汇率设置」维护（变更二次确认、留历史），报价单只读取用并保存快照，不再各自填写。
- **报价单**：业务员为一个客户建报价单，可以从该客户的多个客户询盘中挑选型号（含单个询盘、单个型号）合并报价；每行显示进价（人民币 / 外币）、毛利率、售价（人民币 / 外币）、金额与净利润（外币 / 人民币），业务员输入毛利率或售价、另一项自动计算，低于红线标红提示但不拦截；有效期默认 15 天；可以加运费、银行手续费等费用行；挑选型号时询盘按日期倒序、分批加载并支持搜索，适应询盘和型号很多的客户。
- **三种输出**：
  - 文字报价：按「文字报价模版」生成可一键复制的英文报价，默认每个型号一行（如 `1756-PB72 Allen-Bradley 1 $463.2 1-2 days original new 1 year warranty time`），直接发到 WhatsApp / 国际站消息；
  - 正式报价单：按「报价单模版」生成 Excel（业务员可下载后手改）、PDF、图片三种格式；PDF 与图片做压缩，便于网络差的客户接收。
- **单据模版管理**：报价单、PI、CI、PL 与文字报价五类单据模版统一管理，每类可上传多个版本、设置一个默认版本，所有业务员导出时都用默认版本；上传时校验占位符。本次只实现「报价单」与「文字报价」的生成，PI / CI / PL 的生成随后续订单、发货模块实现。
- **报价单状态与客户询盘联动**：报价单 草稿 → 已发送 → 已成交 / 未成交，以及已作废；未成交原因取系统字典「未成交原因」（按分类分组，可在字典管理中维护）；报价单标为已发送时，其中型号所属的客户询盘进入「已报价」；标为成交 / 未成交时同步推进客户询盘状态。

## Capabilities

### New Capabilities
- `quotation/pricing-rule`: 定价策略——毛利率口径、品相毛利率与红线、建议毛利率决策顺序（国产替代 / 品相 / 低值耗材分层）、建议主管核价提示。
- `system/exchange-rate`: 系统汇率的维护、变更记录与业务统一取用。
- `system/amount-display`: 全系统金额显示规范（「币种代码 金额」，如 CNY 4,120.00），并同步调整询盘、商品参考价、客户 / 供应商等已上线页面。
- `quotation/quotation`: 报价单的建立（含跨询盘挑选型号）、编辑、费用行、状态流转、文字报价与正式报价单导出（Excel / PDF / 图片及压缩）、查看范围。
- `document/document-template`: 单据模版管理——类型（报价单、PI、CI、PL、文字报价）、版本上传与占位符校验、默认版本、停用。

### Modified Capabilities
- `inquiry/inquiry-intake`: 「客户询盘状态」明确「已报价 / 已成交 / 未成交」由报价单推进的规则。
- `inquiry/sourcing-quote`: 「在线录入询价结果」的只读范围从「整个询盘已报价后」改为「型号已出现在已发送报价单中」，同一询盘里还没报出的型号可以继续询价（支持只报部分型号）。

## Impact

- **数据库**（新迁移脚本）：`quotation`、`quotation_item`、`quotation_fee`、`quotation_send_log`、`pricing_condition_margin`、`pricing_amount_tier`、`exchange_rate`、`exchange_rate_log`、`document_template`、`document_template_version`；`dict_item` 增加英文名称字段（货况、货期补英文名，供文字报价与单据使用）；货况字典「国产高仿」更名为「国产替代」（SOP 要求，禁止对外使用「高仿」）；新增字典「未成交原因」；新增菜单「报价中心 → 报价单 / 定价策略」「系统管理 → 汇率设置 / 单据模版」及按钮权限。
- **后端**：新模块 `com.zhul.erp.modules.quotation`（报价单、定价策略）；`modules.system` 增加系统汇率与 `modules.document`（单据模版、渲染）；`CustomerInquiryServiceImpl` / `SourcingProgress` 增加由报价单推进的状态变更入口；Excel 渲染用 Apache POI，PDF 转换依赖服务器上的 LibreOffice（headless），图片由 PDF 渲染并压缩。
- **前端（全局）**：`utils/format.ts` 新增统一的 `formatAmount(value, currency)`，替换询盘模块的 `formatCny`、通用的 `formatYuan` 及各页面手写的金额格式（约 30 处）；`.claude/context/ui-design-patterns.md` 补充金额显示规范。
- **前端**：`pages/quotation`（报价单列表、新建 / 编辑、预览与导出、定价策略）、`pages/system/exchange-rate`、`pages/system/document-template`；客户询盘详情增加「去报价」入口与关联报价单。
- **部署**：服务器需安装 LibreOffice 与中英文字体（`dev-up.sh` 检测并给出提示），否则 PDF / 图片导出不可用、Excel 导出不受影响。
- **财务口径**：金额一律 `DECIMAL`，单价与金额两位小数 HALF_UP，汇率 6 位；跨模块联动（报价单状态 → 客户询盘状态）与报价单保存在同一事务内。
- **原型**：在 `docs/03-产品原型/03-业务域/02-报价中心/01-定价与报价/` 新建原型。
