## Context

- 价格来源：每个型号明细已有「采购成本价」（`inquiry_item.selected_quote_id` → `sourcing_quote.unit_price_cny`，人民币不含税），由询价协作与兼职审核产生。
- 客户主数据已有默认币种、贸易术语与地点、客户等级（`customer.currency / incoterm / incoterm_place / customer_grade`）。
- 系统里还没有汇率表：现有含汇率的记录（如商品参考价）都是单据上手工录入汇率，6 位小数。
- 客户询盘状态里「已报价 / 已成交 / 未成交」已定义但没有任何入口推进；`QUOTE_LOCKED_STATUSES` 目前在询盘级别锁定回价。
- 公司现有四个 Excel 模版（报价、PI、CI、PL）都有抬头、Logo（图片）、合并单元格与 `=K5*L5`、`=SUM(M5:M12)` 这类公式，样例数据直接写在单元格里。
- 服务器与开发机目前都没有安装 LibreOffice。

## Goals / Non-Goals

**Goals:**
- 业务员在一个页面完成：挑型号 → 看建议价与利润率 → 改价 → 复制文字报价或导出 Excel / PDF / 图片 → 标记已发送。
- 所有业务员导出的单据格式由「默认版本」统一，模版可以由管理员自助改版，不需要发版。
- PDF / 图片小而清晰，适合弱网客户。

**Non-Goals:**
- 不做低利润审批流（只提示）。
- 不做 PI / CI / PL 的生成（只做模版管理）；不做订单。
- 不做自动汇率（接口取数）；不做报价单邮件 / WhatsApp 直发。
- 不做多语言单据（导出固定英文，与现有模版一致）。

## Decisions

### 1. 数据模型
- `quotation`：编号、客户、币种、汇率（DECIMAL(18,6)）、汇率来源与时间、贸易术语与地点、有效期、状态（1-草稿、2-已发送、3-已成交、4-未成交、5-已作废）、未成交原因与说明、复制来源、合计原币 / 本位币（DECIMAL(18,2)）、发送时间；业务表标准字段（`tenant_id`、`deleted_at` 等）。
- `quotation_item`：报价单、来源客户询盘、来源型号明细、型号 / 品牌 / 描述 / 货况 / 货期 / 质保 / 数量的快照、采购成本价快照（人民币）、建议毛利率与依据快照、红线快照、毛利率与售价（以最后修改项为准）、单价 / 金额原币与本位币、行号。成本与规则都存快照：之后采购改价或规则调整，不影响已建报价单的利润率口径。
- `quotation_fee`：名称、金额原币 / 本位币。
- `quotation_send_log`：发送方式与时间（可多条）。
- `pricing_condition_margin`：货况码值、建议毛利率、红线（DECIMAL(5,2)，百分比）；`pricing_amount_tier`：进价上限、毛利率；转人工提示的启停与「现货优势品牌」清单存租户配置（沿用 `SourcingSettings` 的配置表）。初始值取自 SOP 第十章与 `报价规则.json`。
- `exchange_rate`（租户 × 币种：汇率 DECIMAL(18,6)、来源、更新人、更新时间）与 `exchange_rate_log`（原值、新值、操作人、时间）。报价单保存汇率快照与快照时间。
- 字典：`dict_item` 新增 `item_name_en varchar(64)`（字典管理中可编辑「英文名称」），迁移为货况（original new / like new / refurbished / used / dismantled / domestic alternative / to be confirmed）与货期（in stock / 1-2 days …）补英文名；货况码值 `DOMESTIC_ALT` 的名称由「国产高仿」改为「国产替代」；新增系统字典 `quotation_lost_reason`（未成交原因，18 项，名称带【分类】前缀，前端按前缀分组）。
- `document_template`（租户 × 类型一条，记默认版本）与 `document_template_version`（版本号、说明、文件 key 或文本内容、上传人、状态）。xlsx 文件走现有私有文件存储（`PrivateFileStorage`），按租户隔离。

### 2. 价格计算：后端为准，前端同口径即时显示
后端 `QuotationPricing` 负责建议毛利率（按 SOP 决策顺序：国产替代 → 品相 → 低值耗材分层 → 品相待查）与各列计算（BigDecimal，中间不舍入，金额 2 位 HALF_UP，毛利率 1 位 HALF_UP）。行上保存定价方式（按毛利率 / 按加价）、毛利率、加价金额与售价（外币），以业务员最后修改的那一项为准反算其他项；前端统一用 `formatAmount(value, currency)` 显示为「币种代码 金额」；前端用同一公式即时显示，保存时后端重算校验。转人工提示（停产急件 = 型号生命周期停产 且 询盘紧急；现货优势品牌按 `PriceKeys` 品牌键匹配；老客户取客户询盘的新老客户标记，并查该客户最近 3 张已成交报价单的合计毛利率；品相 / 生命周期待查）只返回提示，不影响保存。SOP 中的审批流程、到手净利率红线、客户目标价触发条件暂不实现（见 Open Questions）。

### 3. Excel 渲染：Apache POI 填充模版
- 解析：遍历所有单元格找 `${…}`；表头占位符直接替换（数值字段写成数字单元格，保证公式可算）；含 `${item.…}` 的行是明细模版行（只能有一行），`${fee.…}` 行同理。
- 展开：在明细模版行下方插入 n−1 行（`shiftRows`），逐行复制样式、行高与行内合并区域后填值；费用行同理。
- 公式：插入后，凡引用「明细模版行单行区域」的 SUM 等公式（如 `SUM(M5:M5)`）改写为覆盖全部明细行（`SUM(M5:M16)`）；行内公式（`=K5*L5`）随复制按行号平移。
- 图片：`shiftRows` 不移动图片锚点，渲染后对锚点在明细行之下的图片按插入行数平移。
- 上传校验复用同一套解析：未知占位符、明细行缺失或多于一行时报错并给出单元格位置。
- 转换现有公司模版：本变更提供一个福唯版的占位符模版（把样例行收成一行占位符行、`SUM` 改为单行区域），作为租户 1005 的 V2 由管理员上传，示例 V1 为不含公司信息的通用版。

### 4. PDF / 图片：LibreOffice headless + PDFBox
- PDF：渲染好的 xlsx 写临时文件，调用 `soffice --headless --convert-to 'pdf:calc_pdf_Export:{"ReduceImageResolution":{"type":"boolean","value":"true"},"MaxImageResolution":{"type":"long","value":"150"},"Quality":{"type":"long","value":"80"}}'`（LibreOffice 7.4+ 支持 JSON 导出参数）完成降采样与 JPEG 压缩；转换前用 POI 设置打印区域、A4、按宽度缩放到一页（`fitToWidth=1`）。
- 进程管理：单独的转换服务类，串行队列 + 单进程（`-env:UserInstallation` 指向独立目录避免锁冲突），超时 30 秒，失败时报「PDF / 图片暂时无法生成」并记录日志；启动时探测 `soffice` 是否可用，不可用时 PDF / 图片按钮置灰并提示。
- 图片：PDFBox 以 120 dpi 渲染每页，纵向拼接，宽度超过 1600 像素时等比缩小，ImageIO 以 JPEG 质量 0.8 输出。
- 备选：纯 Java 的 xlsx→PDF（如 Aspose 收费、开源库对合并单元格与图片支持差）——放弃；用 HTML 重新排版——模版需维护两份，放弃。

### 4.1 实时预览与分页
- 预览接口 `POST /api/v1/quotations/preview` 接收编辑中的报价单内容（不落库），走与导出相同的 Excel 渲染 → LibreOffice 转 PDF，再用 PDFBox 以 96 dpi 渲染为每页一张 JPG（质量 0.7）返回；前端停止输入 1 秒后请求，新请求发出时取消上一个未完成的请求。
- 为控制转换压力：按「模版版本 + 报价单内容」的哈希缓存最近一次结果（同样内容不重复转换）；每个用户同一时刻只保留一个预览请求在队列里，排队中的旧请求被新请求替换；预览请求优先级低于正式导出。
- 分页：渲染时用 POI `setRepeatingRows` 把明细模版行的上一行（表头行）设为每页重复；Excel 打印本身不拆行；页脚页码由模版的页眉页脚 `&P / &N` 提供，示例模版内置，上传校验时若报价单模版没有页码字段只给提示不拦截。
- 借鉴来源：开源项目 easy-invoice-pdf 的「编辑即预览」与长单据分页处理；该项目为 AGPL-3.0、纯前端 PDF 渲染、无 Excel 输出，只借鉴交互，不引入代码。

### 5. 文字报价
自实现轻量模板：`${…}` 替换 + `{{#items}}…{{/items}}` 块重复，不引入模板引擎依赖。文字模版里的单价去掉末尾 0（`${item.unitPriceShort}`），货况、货期取字典英文名小写（`${item.conditionEn}`、`${item.leadTimeEn}`）。默认 V1 文本按公司现行格式，每个型号一行：

```
{{#items}}
${item.model} ${item.brand} ${item.qty} ${quotation.currencySymbol}${item.unitPriceShort} ${item.leadTimeEn} ${item.conditionEn} ${item.warranty} warranty time
{{/items}}
```

### 6. 报价单状态 → 客户询盘状态（事务边界）
`markSent` / `markWon` / `markLost` / `void` 在同一事务内：更新报价单 → 按客户询盘 ID 升序逐个 `SourcingProgress.lock` → 按规格推进询盘状态 → 写操作日志。只推进「询价中 / 可报价 / 已报价」的询盘，已取消的不动。按 ID 升序加锁，与回价提交（同样先锁询盘行）不会互相死锁。

### 7. 回价只读改为型号级
现有「询盘进入已报价后回价只读」改为「型号出现在已发送（及之后状态）的报价单中则只读」：新增判断 `QuotationLocks.isLocked(itemId)`（存在状态 ∈ {已发送, 已成交, 未成交} 且未删除的报价行），`MyTaskServiceImpl.requireEditable`、兼职审核 `lockedTask`、采购成本价指定 `setCostQuote` 改为按本次涉及的型号判断；询盘已取消仍整单只读。分配工作台「已回价」页签的筛选规则不变。

### 8. 权限与菜单
新增一级菜单「报价中心」：报价单（业务员）、定价策略（查看 + 按钮「编辑定价策略」）；「系统管理 → 汇率设置」（按钮「修改汇率」）与「系统管理 → 单据模版」（按钮「管理单据模版」）。迁移只把这些授给内置「租户管理员」，「报价单」菜单额外授给已有「客户询盘」菜单的角色（业务员要能报价）。

## Risks / Trade-offs

- [服务器要装 LibreOffice 和中文字体，增加部署依赖] → 只有 PDF / 图片依赖它；`dev-up.sh` 与部署文档检测并提示；不可用时 Excel 仍能导出。
- [管理员上传的模版格式千奇百怪，渲染结果走样] → 上传即校验占位符；提供「预览导出」，设为默认前先看效果；提供示例模版与占位符说明。
- [LibreOffice 渲染与 Excel 有细微差异（字体、行高）] → 原型阶段用福唯模版实测并调整模版本身；PDF 以 LibreOffice 结果为准。
- [转换耗时（冷启动 2–5 秒）] → 单进程常驻 + 队列；前端显示生成中状态。
- [型号级锁定改变了现有「整单只读」行为] → 已在规格中修改并补场景；相关契约测试同步调整。

## Migration Plan

1. 迁移脚本建表、加菜单与按钮权限，在平台租户（tenant_id=0）写入五类示例 V1 模版（文件随应用放在 `resources/document-template/`，`file_key` 为 `classpath:` 路径）并设为平台默认，写入 SOP 初始的品相毛利率、红线、低值耗材分层与转人工配置。
2. 福唯租户的四个占位符模版由管理员在上线后上传为 V2 并设为默认。
3. 回滚：新菜单下线即可；型号级锁定回退为询盘级锁定不影响数据。

## Open Questions

- SOP 第七章的审批流程（低于建议起点需组长 / 主管审批、低于红线需联合审批）：按此前确认本次只提示不拦截；如要落地审批流，另开变更。
- SOP 的「客户目标价明显低于建议价」转人工条件：系统目前没有记录客户目标价，暂不实现；「到手净利率」红线待财务测算后再纳入。
- 低值耗材金额分层的「金额」按单件进价（人民币）判断（SOP 写作「价格不超过 300 元」），如应按售价判断请指出。

- 「查看采购成本」是否需要单独权限、让部分角色看不到成本与利润率：本次不做，沿用「能看客户询盘就能看采购成本价」的现状。
- 报价单编号是否需要带公司前缀（如 `FOUWELL-QT…`）：本次用 `QT` + 日期 + 序号，导出时可在模版里自行加前缀文字。

## 决策补充（实现阶段，2026-10-05）

- **内置模版不逐租户复制**：五类 V1 只在平台租户（tenant_id=0）存一份，`builtin=1`；每个租户看到的版本 = 平台内置版本 + 本租户上传的版本。租户没有自己的 `document_template` 行、或行里 `default_version_id` 为空时，默认版本沿用平台默认。租户第一次上传、设默认或启停时才创建自己的行。停用内置版本只对本租户生效，记在本租户行的 `builtin_disabled`，不改平台版本。好处：新租户开通不需要额外初始化，以后升级内置模版只改一处。定价策略同理：平台租户的值作为默认，租户第一次保存时复制出自己的一套（转人工提示与品牌清单沿用 `SysConfig` 已有的「租户覆盖、否则取租户 0」做法）。系统汇率只按租户维护、不回退平台值，各公司自己设置。
- **PI / CI / PL 上传只校验能否打开**：占位符随订单、发货模块确定，本次不做占位符校验。
- **Flyway 关闭占位符替换**：文字报价种子模版含 `${item.model}` 等占位符，`spring.flyway.placeholder-replacement=false`，项目其他迁移脚本没有用到 Flyway 占位符。
