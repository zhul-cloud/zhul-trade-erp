## MODIFIED Requirements

### Requirement: 外贸客户档案字段
系统 SHALL 为每个客户维护以下信息，并在保存时做服务端校验：
- 基本信息：客户编码、客户名称（英文，必填，≤200）、中文名称（≤100）、简称（≤50）、客户角色（终端用户 / 系统集成商 / 经销商 / 贸易商 / OEM 设备厂 / 维修服务商 / 其他，管理页必填）、应用行业、官网（合法网址）、客户等级（A / B / C / 未分级，默认未分级，手工标记）、客户来源（阿里巴巴国际站 / 中国制造网 / 独立站 / 展会 / 社交媒体 / 老客户转介绍 / 主动开发 / 其他）、负责业务员（必填）、小满客户编号（≤50）、状态、备注（≤500）
- 注册地址与税务：国家/地区（必填，取自系统国家清单）、州/省、城市、邮编、详细地址（英文，≤300）、税号（≤50）、时区（IANA 时区名）
- 主联系人：姓名（≤100）、职位（≤50）、邮箱、电话、WhatsApp（国际格式：`+`、数字、空格、`-`、括号，≤30）、其他联系方式（≤100）
- 默认交易条件：默认币种（USD / EUR / GBP / JPY / RUB / CNY，必填，默认 USD）、贸易术语（Incoterms 2020）、术语地点、付款方式、定金比例（0–100 整数）、账期（0–365 天）、信用额度（非负，两位小数）及其币种、运输方式、目的港

英文字段（客户名称、详细地址）不允许包含中文、日文、韩文字符；欧洲语言的变音字母（如 ß、ü、é）允许。

#### Scenario: 完整档案保存成功
- **WHEN** 用户填写全部字段且格式正确后保存
- **THEN** 系统保存客户，列表中出现该客户，详情页各字段与填写一致

#### Scenario: 英文名称含中文
- **WHEN** 用户把客户名称填为「德国ABC自动化」
- **THEN** 系统拒绝保存并提示「单据字段请使用英文」

#### Scenario: 国际电话格式
- **WHEN** 用户填写电话 `+49 (89) 1234-5678`
- **THEN** 系统接受该电话，不按国内手机号规则校验
