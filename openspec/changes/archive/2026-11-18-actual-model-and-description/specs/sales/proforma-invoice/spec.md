# Spec Delta

## ADDED Requirements

### Requirement: PI 型号与客户型号

PI 行 SHALL 沿用来源报价行的型号与客户型号；由询盘型号生成的行，型号取该询盘型号当时的单据型号（有真实型号取真实型号，否则取确认型号）。型号与客户型号忽略大小写、空格与符号后不同时，PI 详情、编辑页与预览的型号下面 SHALL 显示「客户型号：…」。导出的 `${item.model}` 使用 PI 行的型号。

#### Scenario: 由报价单开 PI

- **GIVEN** 报价行型号 LC2D18B7C，客户型号 LC2D18B7
- **WHEN** 业务员按这张报价单开 PI
- **THEN** PI 该行型号为 LC2D18B7C，下面显示「客户型号：LC2D18B7」

### Requirement: 真实型号变更后的 PI

来源询盘型号的真实型号被填写、修改或清空后，系统 SHALL 在同一次保存中把 PI 草稿与编辑中新版本里对应的行更新为新的单据型号（客户型号随之更新）。已发送的当前有效版本与历史版本不修改；型号与当前单据型号不同时，详情该行 SHALL 提示「真实型号已更新为 …，请与客户确认」；之后点「修改」生成的新版本取当前的单据型号。已转订单、已作废、已关闭的 PI 不提示。

#### Scenario: PI 草稿跟随

- **GIVEN** PI 草稿第 1 行型号 LC2D18B7
- **WHEN** 业务员在询盘详情把真实型号填为 LC2D18B7C
- **THEN** PI 草稿第 1 行型号变为 LC2D18B7C，下面显示「客户型号：LC2D18B7」

#### Scenario: 已发送的 PI

- **GIVEN** PI FWPI20261118001 已发送，第 1 行型号 LC2D18B7
- **WHEN** 采购填写真实型号 LC2D18B7C
- **THEN** PI 内容不变；详情第 1 行提示「真实型号已更新为 LC2D18B7C，请与客户确认」；业务员点「修改」生成的 Rev.2 该行型号为 LC2D18B7C
