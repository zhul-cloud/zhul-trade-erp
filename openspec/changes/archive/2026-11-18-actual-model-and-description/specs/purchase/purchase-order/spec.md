# Spec Delta

## ADDED Requirements

### Requirement: 采购订单行描述

采购订单行 SHALL 记录描述：排入草稿或在需求池生成采购订单时取采购需求的描述。采购订单详情的行在「型号 · 品牌」之后显示「描述」列，没有时显示「—」，过长时折行。已有的采购订单行按来源订单型号行回填描述。

#### Scenario: 详情显示描述

- **WHEN** 采购需求 A（描述「CPU 1214C DC/DC/DC」）排入草稿采购订单
- **THEN** 草稿采购订单该行的描述列显示「CPU 1214C DC/DC/DC」

### Requirement: 真实型号变更后的采购订单

采购需求因真实型号变更而改了型号时，系统 SHALL 在同一次保存中把该需求在草稿采购订单里的行改为新型号，并在该采购订单的操作日志记「真实型号更新：旧型号 → 新型号」。已下单的采购订单不修改；其行型号与采购需求当前型号不同时，详情该行 SHALL 标红提示「真实型号已更新为 …，请与供应商核对」，并在操作日志记同样的内容；已取消的采购订单不处理。

#### Scenario: 草稿采购订单跟随

- **GIVEN** 需求 LC2D18B7 已排入草稿采购订单 FWPO20261118001
- **WHEN** 业务员填写真实型号 LC2D18B7C
- **THEN** 草稿该行型号变为 LC2D18B7C，操作日志记「真实型号更新：LC2D18B7 → LC2D18B7C」

#### Scenario: 已下单的采购订单只提示

- **GIVEN** 需求 LC2D18B7 已在 FWPO20261117003 下单给供应商
- **WHEN** 采购填写真实型号 LC2D18B7C
- **THEN** FWPO20261117003 该行型号仍为 LC2D18B7，详情该行标红提示「真实型号已更新为 LC2D18B7C，请与供应商核对」，操作日志记录这次更新
