## Why

客户档案目前只有名称、国家、联系人、电话、邮箱，是国内通用 ERP 的思路，撑不起外贸做单：没有英文地址和税号，PI、CI 的买方抬头只能手写；没有币种、贸易术语、付款方式，报价和合同每次都要重新录；没有收货人、通知方，提单和装箱单无从带出；也没有"客户归谁"，业务员能看到全公司的客户。客户 PRD 已按外贸改写为 V1.1（`docs/02-产品PRD/01-主数据域/00-主数据中心/01-客户管理/00-客户基本信息/客户基本信息管理-PRD-V1.0.md`），原型已定稿（`docs/03-产品原型/01-主数据域/00-主数据中心/01-客户管理/00-客户基本信息/`），本变更按两者落地。

## What Changes

- 客户表扩展为外贸档案：客户编码、英文名称/中文名称/简称、客户角色、应用行业、官网、客户等级（手工）、客户来源、负责业务员、小满客户编号、备注；注册地址（国家/州省/城市/邮编/英文地址）、税号、时区；主联系人（姓名、职位、邮箱、国际电话、WhatsApp、其他联系方式）；默认交易条件（币种、贸易术语及地点、付款方式、定金比例、账期、信用额度及币种、运输方式、目的港）
- 新增客户单证主体子表：收货人 / 通知方 / 发票抬头，每类一条默认，每客户最多 20 条，随客户一起保存
- **按负责业务员的数据权限**：客户管理的列表、详情、编辑、删除、导出、选择器搜索按角色「数据权限范围」过滤（全部 / 自定义部门 / 仅本人），这是系统里第一个真正按该配置过滤的业务数据
- 新增转移负责人（单条 / 批量），转移记录写入操作日志；编辑页不能直接改负责人
- **BREAKING（相对已上线行为）** 查重从"同名提示、可复用或仍然新建"改为"规范化名称 + 国家命中即阻止保存"，提示负责业务员姓名；询盘里的快速创建同样适用
- **BREAKING（相对已上线行为）** 删除从"直接软删除"改为"已被询盘引用的客户不允许删除，只能禁用"；新增批量删除
- 询盘里的快速创建改为必填英文名称 + 国家（国家改为从清单选择），其余字段取默认值（角色未设置、负责人为创建人、币种 USD）
- 列表、新增、编辑、详情页按原型重做为独立页面；新增导出（Excel）；导入按钮置灰占位
- 新增国家默认时区数据，详情页显示客户当地时间

**不在本次范围内**：
- 联系人管理模块（多联系人）、客户等级按采购额自动计算、信用额度占用与超限拦截、PI/CI 等单据本身（本次只提供取数所需的数据）
- 公海、跟进提醒等小满已有能力；与小满的数据同步或导入
- 批量导入客户

## Capabilities

### New Capabilities
- `master-data/customer-party`：客户的收货人、通知方、发票抬头等单证主体维护及默认规则
- `access/data-scope`：按角色「数据权限范围」计算当前用户可见的负责人集合，供业务数据按负责人过滤

### Modified Capabilities
- `master-data/customer`：新增外贸档案字段、编码、查重、负责人与转移、数据权限过滤、删除限制、批量删除、导出、快速创建规则。该能力的既有需求仍在未归档的 `add-inquiry-management`、`add-customer-supplier-management` 中，主规格目录下还没有文件，所以本次以 ADDED 形式追加；其中「同租户内客户名称重复提示」「创建客户记录（仅名称必填）」「客户记录仅支持软删除（直接删除）」三条被本变更的新需求取代，归档时需按本变更修订（见 tasks 最后一组）

## Impact

- **数据库**：新迁移（`V1.2.9__customer_trade_profile.sql`，版本号冲突则顺延）：`customer` 表加字段与索引；新建 `customer_party` 表；新增按钮权限 `partner:customer:transfer`、`partner:customer:export` 并加入标准版、旗舰版套餐
- **后端**：
  - `framework/security` 新增数据权限解析组件（读 `account.admin_flag`、`user_basic.role_code/dept_id`、`role.permission_scope`、`role_org`、`user_department`、`department`）
  - `masterdata` 模块客户相关 DO/DTO/Service/Controller 大幅扩展；新增 `customer_party` 的实体与 Mapper；导出；转移
  - `CustomerService` 的 `getById`、`search` 保持不按数据权限过滤（询盘模块在内部用它们校验客户和按名称筛选询盘），新增带权限的查询只给客户管理接口用
  - 国家默认时区数据（classpath JSON）与接口
- **前端**：`src/pages/partner/customer/` 重写为列表 + 表单页 + 详情页 + 转移弹窗 + 单证抽屉；`config/routes.ts` 加隐藏路由；`access.ts` 加权限位；`components/CustomerQuickCreateModal` 改为国家下拉并处理"已存在"阻止；`services/zhul/masterdata.ts` 类型补字段
- **不影响**：`customer_inquiry`、`inquiry_order` 的表结构与接口；供应商模块
