## ADDED Requirements

### Requirement: 外贸客户档案字段
系统 SHALL 为每个客户维护以下信息，并在保存时做服务端校验：
- 基本信息：客户编码、客户名称（英文，必填，≤200）、中文名称（≤100）、简称（≤50）、客户角色（终端用户 / 系统集成商 / 经销商 / 贸易商 / OEM 设备厂 / 维修服务商 / 其他，管理页必填）、应用行业、官网（合法网址）、客户等级（A / B / C / 未分级，默认未分级，手工标记）、客户来源（阿里巴巴国际站 / 中国制造网 / 独立站 / 展会 / 社交媒体 / 老客户转介绍 / 主动开发 / 其他）、负责业务员（必填）、小满客户编号（≤50）、状态、备注（≤500）
- 注册地址与税务：国家/地区（必填，取自系统国家清单）、州/省、城市、邮编、详细地址（英文，≤300）、税号（≤50）、时区（IANA 时区名）
- 主联系人：姓名（≤100）、职位（≤50）、邮箱、电话、WhatsApp（国际格式：`+`、数字、空格、`-`、括号，≤30）、其他联系方式（≤100）
- 默认交易条件：默认币种（USD / EUR / GBP / JPY / CNY，必填，默认 USD）、贸易术语（Incoterms 2020）、术语地点、付款方式、定金比例（0–100 整数）、账期（0–365 天）、信用额度（非负，两位小数）及其币种、运输方式、目的港

英文字段（客户名称、详细地址）不允许包含中文、日文、韩文字符；欧洲语言的变音字母（如 ß、ü、é）允许。

#### Scenario: 完整档案保存成功
- **WHEN** 用户填写全部字段且格式正确后保存
- **THEN** 系统保存客户，列表中出现该客户，详情页各字段与填写一致

#### Scenario: 英文名称含中文
- **WHEN** 用户把客户名称填为「德国ABC自动化」
- **THEN** 系统拒绝保存并提示「单据字段请使用英文」

#### Scenario: 国际电话格式
- **WHEN** 用户填写电话 `+49 (89) 1234-5678`
- **THEN** 系统接受该电话，不按国内手机号规则校验

### Requirement: 交易条件字段联动校验
系统 SHALL 按以下规则校验默认交易条件：选了贸易术语时术语地点必填；付款方式含定金时定金比例必填；付款方式为 L/C 远期、D/A、O/A 时账期必填；信用额度与信用额度币种必须同时填写或同时为空。不适用的联动字段保存为空。

#### Scenario: 贸易术语缺地点
- **WHEN** 用户选择 FOB 但术语地点为空
- **THEN** 系统拒绝保存并提示「请填写术语地点，如 FOB 的装运港」

#### Scenario: 赊销缺账期
- **WHEN** 付款方式为 O/A 赊销且账期为空
- **THEN** 系统拒绝保存并提示账期必填

#### Scenario: 信用额度缺币种
- **WHEN** 用户填写信用额度 200000 但清空了信用额度币种
- **THEN** 系统拒绝保存并提示「信用额度需要同时填写金额和币种」

#### Scenario: 切换付款方式后清掉无关字段
- **WHEN** 用户把付款方式从「T/T 定金 + 发货前付尾款（定金 30%）」改为「T/T 全额预付」并保存
- **THEN** 定金比例保存为空

### Requirement: 客户编码唯一且不可修改
系统 SHALL 保证客户编码在同租户未删除客户中唯一，仅字母数字、最长 20 位，创建后不可修改。管理页新增时编码可留空，由系统生成 `CUS` + 5 位补零主键（与已有编码冲突时追加数字后缀）；快速创建一律自动生成。

#### Scenario: 留空自动生成
- **WHEN** 用户新增客户时不填编码
- **THEN** 保存后客户获得形如 `CUS00012` 的编码

#### Scenario: 编码重复
- **WHEN** 用户填写的编码已被同租户其他未删除客户使用
- **THEN** 系统拒绝保存，在编码字段提示「客户编码已存在，请更换」

#### Scenario: 编辑不能改编码
- **WHEN** 更新请求中携带了不同的编码
- **THEN** 系统忽略该值，原编码不变

### Requirement: 客户名称与国家查重
系统 SHALL 在新增或修改客户名称、国家时，按"规范化名称 + 国家"与同租户未删除客户比较，不受数据权限范围限制；规范化指转为小写、去掉标点和空白、去掉结尾的常见公司后缀（Co / Company / Ltd / Limited / LLC / Inc / Corp / Corporation / GmbH / AG / SA / SAS / SRL / BV / Pty / PLC / LLP 等）。命中已有客户时阻止保存，提示「该客户已存在，负责业务员：[姓名]」，不返回对方客户的其他信息。

#### Scenario: 公司后缀不同仍判重
- **WHEN** 已有德国客户「ABC Automation GmbH」，用户新增德国客户「abc automation」
- **THEN** 系统阻止保存并提示「该客户已存在，负责业务员：张伟」

#### Scenario: 同名不同国家允许
- **WHEN** 已有德国客户「ABC Automation GmbH」，用户新增奥地利客户「ABC Automation GmbH」
- **THEN** 系统允许保存

#### Scenario: 对方客户不在自己范围内
- **WHEN** 仅本人权限的业务员新增的客户与另一名业务员负责的客户重复
- **THEN** 提示中只包含对方负责业务员姓名，不返回客户编码、联系人等信息

### Requirement: 负责业务员与转移
系统 SHALL 为每个客户记录负责业务员。新增时默认为当前用户；数据权限为「自定义」或「全部」的用户可以指定为自己数据范围内的其他业务员。编辑客户时不能修改负责业务员，只能通过「转移」：支持单条和批量，需要客户转移权限，新负责人必须在操作人的数据范围内且为在职用户，可填写转移原因（≤200）。每次转移写入操作日志（原负责人、新负责人、操作人、时间、原因）。

#### Scenario: 批量转移
- **WHEN** 业务主管勾选张伟、李娜负责的两个客户，转移给赵敏并确认
- **THEN** 两个客户的负责业务员变为赵敏，操作日志各记录一条转移

#### Scenario: 转给范围外的人
- **WHEN** 请求把客户转移给操作人数据范围之外的业务员
- **THEN** 系统拒绝转移，负责人不变

#### Scenario: 编辑时带了负责人
- **WHEN** 更新请求中携带了不同的负责业务员
- **THEN** 系统忽略该值，负责人不变

### Requirement: 客户列表与筛选
系统 SHALL 提供按数据范围过滤的客户分页列表，支持按编码（模糊）、名称（模糊，同时匹配英文名、中文名、简称）、国家、客户角色、客户等级、客户来源、负责业务员、状态组合筛选，默认按更新时间倒序，每页 10 / 20 / 50 条，返回总数。列表中每条返回负责业务员姓名和主联系人。

#### Scenario: 名称匹配中文名
- **WHEN** 用户在名称筛选中输入「北欧包装」
- **THEN** 返回中文名称包含「北欧包装」的客户

#### Scenario: 组合筛选
- **WHEN** 用户筛选国家=德国、等级=A、状态=启用
- **THEN** 只返回同时满足三个条件且在自己数据范围内的客户

### Requirement: 客户详情
系统 SHALL 提供客户详情，包含全部档案字段、单证主体、负责业务员姓名与部门、系统信息，并按客户时区给出当前当地时间；数据范围外或已删除的客户返回「客户不存在或无权查看」。

#### Scenario: 查看详情
- **WHEN** 用户查看一个时区为 Europe/Berlin 的客户
- **THEN** 页面显示客户当地时间、与北京时间的时差，以及是否处于当地 9:00–18:00 工作时间

### Requirement: 删除限制与批量删除
系统 SHALL 只允许软删除未被任何客户询盘或询盘单引用的客户；已被引用的客户拒绝删除并提示「该客户已有询盘或单据记录，不能删除，可改为禁用」。批量删除时跳过被引用和已不存在的客户，其余删除，并返回删除数、因引用跳过数、已不存在数。

#### Scenario: 删除被引用的客户
- **WHEN** 用户删除一个已有客户询盘的客户
- **THEN** 系统拒绝删除，客户保持不变

#### Scenario: 批量删除混合情况
- **WHEN** 用户批量删除 3 个客户，其中 1 个已有询盘
- **THEN** 删除 2 个，提示「已删除 2 个，1 个已有询盘或单据记录，不能删除，可改为禁用」

### Requirement: 导出客户
系统 SHALL 支持按当前筛选条件和数据范围导出客户档案为 Excel，上限 5000 条，超出时提示缩小筛选范围；需要客户导出权限。

#### Scenario: 导出受数据范围限制
- **WHEN** 仅本人权限的业务员导出客户
- **THEN** 文件中只包含其本人负责的客户

### Requirement: 快速创建客户
系统 SHALL 在询盘等场景支持快速创建客户：只要求英文名称和国家（从国家清单选择），其余取默认值（客户角色未设置、负责业务员为创建人、默认币种 USD、状态启用），编码自动生成；查重规则与管理页相同，命中时返回已有客户的编号与名称供选择使用，但仅当已有客户在创建人的数据范围内时才允许直接选用。

#### Scenario: 快速创建成功
- **WHEN** 业务员在客户询盘录入弹窗中快速创建「Pacific Controls Pty Ltd」、国家澳大利亚
- **THEN** 客户创建成功并自动选中，编码自动生成，负责业务员为该业务员，客户角色显示「未设置」

#### Scenario: 快速创建命中已有客户
- **WHEN** 快速创建的名称与国家命中业务员自己负责的已有客户
- **THEN** 不新建，提示已存在并允许直接选用该客户

#### Scenario: 命中他人客户
- **WHEN** 快速创建命中数据范围外的已有客户
- **THEN** 不新建，只提示「该客户已存在，负责业务员：[姓名]」，不能选用
