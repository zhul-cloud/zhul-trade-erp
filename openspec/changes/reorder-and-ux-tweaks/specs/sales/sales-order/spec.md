# Spec Delta

## ADDED Requirements

### Requirement: 再下一单

有「手动创建订单」按钮权限的业务员 SHALL 能在销售订单列表的操作列点「再下一单」（费用订单不显示）：打开手动创建订单并预填原订单的客户、币种、型号（按商品档案）、数量、单价、采购成本价、采购员、现货 / 期货与普通费用；已全部取消的型号行不带。订单号、销售日期（当天）、收款与进度都重新开始，附件与备注不复制。原订单的型号没有商品档案（或已停用）时，该行提示「需要先建档」，建档后在该行选中或删掉该行才能创建。

#### Scenario: 按原订单预填

- **GIVEN** 订单 SO20261109004 有 4 个型号与运费 USD 60.00
- **WHEN** 业务员在列表点该订单的「再下一单」
- **THEN** 打开「再下一单」，客户、币种、4 个型号的数量与单价、运费都已填好，销售日期为今天，提示「已复制 SO20261109004 …」；确认后生成新的订单号

#### Scenario: 有型号还没建档

- **GIVEN** 原订单第 4 行 6SL3210-1KE21-3UF1 没有商品档案
- **WHEN** 业务员点「再下一单」
- **THEN** 该行标出需要先建档，「创建订单」不可点；建档后在该行选中商品或删掉该行即可创建

#### Scenario: 没有手动建单权限

- **WHEN** 没有「手动创建订单」权限的业务员打开订单列表
- **THEN** 操作列只有「查看」，直接调用再下一单接口被拒绝
