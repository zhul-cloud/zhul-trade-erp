# 帮助文字清单

列表页的帮助图标（ⓘ）里写什么，逐条取自现有代码的脚注、卡片副文字或注释，不另编。改到某页时先在这里补行，再画原型、写代码。

- **来源**：写明取自哪段代码，方便以后核对。
- **改写原则**：去掉「点表头可排序」这类界面上看得出来的话，其余业务口径保持原意。

代码位置：`zhul-erp-frontend/src/pages/sales/orders/index.tsx`。

| 位置 | 帮助文字 | 来源 |
|---|---|---|
| 关键词 | 可搜：订单编号、PI 编号（不带前缀也能搜到）、客户名称或简称、型号。包含匹配，整段文字一起匹配 | `search-scope.md` 销售订单行 |

## 销售订单详情

代码位置：`zhul-erp-frontend/src/pages/sales/orders/detail.tsx`，以及同目录的 `CostCard.tsx` 和 `src/pages/sales/components.tsx`（`ChainCard`）。

| 位置 | 帮助文字 | 来源 |
|---|---|---|
| 订单进度 | 订单状态取进度最慢的型号 | 订单进度卡片标题旁的说明（「勾选型号后可批量更新」删去，表格勾选框已经说明） |
| 型号明细 | 成交内容（型号、单价、费用）不能直接改：减少型号数量用「部分取消」，其他变更请取消订单（手动创建的订单，有「修改订单费用」权限的人可以改费用）。全部取消的型号保留显示，不再参与进度与货物状态。销售日期、约定付款日（手动订单）、进度、采购员、现货 / 期货可以随时改，改动写操作日志 | 型号表格下方的脚注 |
| 收款 | 收款登记在 PI 上，这里只读显示（手动订单：没有 PI，收款直接登记在订单上；费用订单：收款到账后订单自动完成，不走采购和出运） | 收款卡片里的说明，按订单类型三选一 |
| 费用订单 | 订单已收齐款或已完成，后来要另收运费等费用时，新建一张费用订单单独收款 | 费用订单卡片没有记录时的说明 |
| 订单毛利 | 毛利 = 收入（毛额 × 结汇汇率）− 实际成本（含开票成本与收款手续费）；还没确定的部分按采购订单单价或采购成本价估算。采购成本与毛利只在系统内显示，不进任何导出单据 | 毛利卡片底部的两段说明 |
| 成本明细 | 浅色为还没确定的数字；虚线数字可以悬停查看来源单据 | 成本明细卡片标题行右侧的说明 |
| 来源 / 去向 | 型号从询盘到订单经过的单据 | 卡片标题旁的说明（「点击可跳转」删去） |

「还差：…」（成本未结算的原因，取自后端 `OrderCostCalc` 的 `pending`）是状态信息，照常显示在标题下方，不收进帮助图标。
