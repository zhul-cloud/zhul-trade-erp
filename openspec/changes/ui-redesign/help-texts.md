列表页的帮助图标（ⓘ）里写什么，逐条取自现有代码的脚注、卡片副文字或注释，不另编。改到某页时先在这里补行，再画原型、写代码。

- **来源**：写明取自哪段代码，方便以后核对。
- **改写原则**：去掉「点表头可排序」这类界面上看得出来的话，其余业务口径保持原意。

**结构**：
- 统计页的条件选了就生效：用 `FilterCard` 的无按钮写法（不传 `onSearch`、`onReset`，不显示「重置」「查询」），标签在上；常显统计期间与至多两个常用条件，其余收进「更多筛选」（砍价统计的供应商、品类，利润统计的新 / 老客户）；砍价统计的品牌、品类照旧回车或离开输入框生效。
- 原统计卡片都是指标，改为汇总行，口径与数字不变；卡片副文字作汇总行的副文字或帮助。毛利、预计盈亏、砍价金额改为按涨跌着色（`useDeltaColor`，原来销售统计、经营统计的毛利写死绿色）；无货分析的「较上期」用 `DeltaText`（按方向着色、配箭头）。不表达涨跌的写死颜色去掉：经营统计「退款与其他收入」与退款列、销售统计待付款、询价统计完成率 / 有价率 / 询价中 / 待回价、无货排行的无货数量。利润统计「未结算」有单时改为带图标的警告标签。
- 分组、视图切换（按月份 / 按业务员 / 按客户等）放在主卡片操作行右侧；利润统计「包含未结算 / 只看已结算」改为快捷筛选「只看已结算」。
- 询价统计的按月份、按人员、无货分析是三类内容，分段按钮改为页签。
- 图表：这几页没有图表库。无货分析的「无货率走势」是单系列柱图，用图表第一个系列色（主题色，`palette.link`）标出本期，往期用次要文字色（`mute`，浅色约 4.4:1）；百分比标签用正文色，本期加粗（主题色纯文字只给可点击的内容）；品牌、品类排行里的无货率小进度条按「进度条」规则用主题色（原来都是警告色，原型 V3 的视觉按本变更规则改）。销售统计漏斗的阶段块原来写死蓝底白字，改为主题色浅底、正文色数字。
