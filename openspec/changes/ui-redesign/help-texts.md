# 帮助文字清单

列表页的帮助图标（ⓘ）里写什么，逐条取自现有代码的脚注、卡片副文字或注释，不另编。改到某页时先在这里补行，再画原型、写代码。

- **来源**：写明取自哪段代码，方便以后核对。
- **改写原则**：去掉「点表头可排序」这类界面上看得出来的话，其余业务口径保持原意。
