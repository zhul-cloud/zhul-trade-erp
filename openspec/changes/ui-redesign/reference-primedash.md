# PrimeDash 参考记录

用户 2026-11-20 指定参考 PrimeDash（ICreator Studio 出品，基于 Vuetify，演示站 `demos.icreatorstudio.com/demo-1/`），要求学习它的配色风格，并提供它的 6 种主题色。

- **观察方法**：在演示站登录（账号、密码由网站预填）后，用浏览器读取运行时主题变量和组件的计算样式，并对比截图。
- **覆盖范围**：订单列表、发票详情、商品新增、用户列表、数据表格、按钮、标签、CRM 仪表盘。浅色、深色都看了，6 种预设逐个切换对比。
- **未看的页面**：登录、落地页、餐厅、加密货币等与 ERP 无关的页面没有看。

## 使用规则

改造中遇到拿不准的组件（2026-11-20 用户要求）：
1. 先在演示站找对应的示例页（组件页 `/demo-1/components/*`、表单页 `/demo-1/forms/*`、应用页 `/demo-1/ecommerce/*`、`/demo-1/apps/*`）。
2. 在浅色和深色下各看一遍，并至少切换默认琥珀和另外两种主题色对照。
3. 把看到的做法和取舍补进本文件，再定方案。

演示站设置存在 `localStorage`，可以直接改：`app-prime-1-theme`（`light` / `dark`）、`app-prime-1-preset`（主题色色值）。

## 主题机制

- 设置面板有 4 组选项：
  - 皮肤：Classic、Modern、Decent、Bordered；
  - 模式：跟随系统、浅色、深色；
  - 菜单：竖向、横向；
  - 预设：6 个主题色。
- 设置存在浏览器 `localStorage`（`app-prime-1-theme`、`app-prime-1-preset` 等），按人保存。
- **切换预设只改 `primary` 一个颜色**。成功、警告、信息、错误、次要色都不变，按钮文字色 `on-primary` 一律是白色。
- 6 个预设的 `primary` 取值：

| 名称 | 色值 |
|---|---|
| 青绿（默认） | `#0D9394` |
| 天蓝 | `#078DEE` |
| 紫 | `#7635DC` |
| 宝蓝 | `#2065D1` |
| 琥珀 | `#FDA92D` |
| 红 | `#FF3030` |

## 跟着主题色变化的部件

在 CRM 仪表盘上按计算样式统计，主题色出现在：
- 主按钮和图标按钮；
- 选中的菜单项（文字为主题色，加浅灰底）；
- 链接与编号（如订单号）；
- 复选框、单选、开关；
- 进度条、环形进度、时间线圆点；
- 头像与图标的浅底小方块；
- 标签（chip）；
- 全部图表系列（面积、柱状、标记）。

## 提示条（Alert）

- 默认是浅底配同色字（tonal），圆角 8。
- 「Types」组每种语义带固定图标：成功是对勾圆、信息是 i 圆、警告是感叹号圆、错误是叉圆。
- 另有左侧色条（border-start）、描边（outlined）、紧凑（compact）三种变体。
- 文字直接用原色，在浅底上看不清（对比度见下文「切换预设时看到的问题」）。
- 对照结果（2026-11-20）：琥珀浅色下，主色提示条和警告提示条几乎同色，只能靠图标分开；琥珀深色下，深色浅底配原色字可读；宝蓝下主色蓝与信息青能分开。

## 深色模式

- 页面底色 `#151521`，卡片 `#1E1E2D`，表头 `#2F3944`，正文 `#E7E3FC`（87%）。
- 底色偏蓝紫，卡片仍用阴影。

## 切换预设时看到的问题

- **琥珀**：主按钮和警告按钮几乎一样，白字在 `#FDA92D` 上的对比度只有 1.93:1。
- **红**：主按钮和错误按钮同色。深色模式下，图表全是红色，容易被看成亏损或异常。
- **状态标签文字**：用原色写字，在浅底上对比度只有 1.7–2.6:1，看不清。
- **深色底**：偏蓝紫，和用户要求的「暗黑更黑」不符。

## 本变更的取舍

**照搬**：
- 模式三选一；
- 6 个预设的色相；
- 切换预设只改主题色、状态色不变的机制；
- 浅色模式的底色、卡片（白、圆角 10、柔和阴影、不加边框）、正文与边框灰阶；
- 表头、表格行、输入框、按钮、标签的尺寸与形态。

**调整**：
- 提示条一律带类型图标。默认主题色是琥珀，警告条靠图标与琥珀主色区分。
- 规范要求、参考站没有的部分：标签页栏（放在顶栏卡片里）、页面标题、汇总行、搜索区标签放在输入框上方（沿用已上线的单据列表统一规范）、快捷筛选行。样式都用参考站已有的元素来拼。
- 字体：英文和数字用 Public Sans，中文用系统字体。
- ERP 数据密度高，所以：
  - 正文仍是 14px，菜单项改为 14px；
  - 侧栏 220、顶栏 56；
  - 表格行高按销售订单现状（多行单元格）保持。
- 去掉面包屑（PrimeDash 有），依据见 `specs/system/navigation`。

**不采用**：
- 皮肤切换、横向菜单：维护成本高，破坏统一；
- 偏蓝紫的深色底：深色模式用中性近黑；
- 浮动的「Buy Now」、设置面板悬浮按钮这类演示站元素。
