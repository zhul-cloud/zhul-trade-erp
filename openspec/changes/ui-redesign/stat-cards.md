# 统计卡片清单

从前端代码整理（2026-11-20，`feat/ui-redesign`，基于 develop 8b284d01），按 `specs/system/interface-style`「统计卡片的去向」分类。分类由产品负责人确认。

- **条件类**：对应一个筛选条件，改为快捷筛选，点击后按该条件筛选。
- **指标类**：金额、比率等汇总数字，改为页头下方的汇总行。
- **数字口径**：沿用卡片现在的统计口径，不新增统计。
- **待核实接口**：改造时先核对列表接口是否已有对应筛选。没有的话不加后端，这张卡按指标类显示，表中标「待核实接口」。

## 不属于列表统计卡片的

以下是统计页的指标卡、详情页的摘要或工作台组件，不按本表转换，分别按统计页、详情页和工作台的原型处理：
- **统计分析**：销售、询价、砍价、利润、经营统计；供应链团队看板的覆盖率指标。
- **详情页摘要**：采购订单详情、客户档案经营等级、客户跟进记录、定价策略抽屉。
- **工作台**：商机统计、采购员看板等组件。
