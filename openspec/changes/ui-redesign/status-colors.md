# 状态与语义色对照

从前端代码整理（2026-11-20，`feat/ui-redesign`，已合入 develop f79ac93f），来源有三类：`Pill`、`Tag` 上直接写的颜色；`label`/`tone` 状态配置；按状态编码着色的映射表。新界面只有五种语义色（见 `design.md` 第 2 节），分歧项由产品负责人确认。

## 归类规则

| 现有颜色 | 新语义色 |
|---|---|
| green、success、lime | 成功 |
| orange、warning、gold | 警告 |
| red、error、volcano | 错误 |
| accent、blue、cyan、processing、geekblue | 信息 |
| gray、mute、default | 中性 |
| violet、purple、magenta | 逐个判断：类别和属性标签归中性；状态按下面的原则归类 |

状态的归类原则：已完成、正向结果归成功；等人处理（含待审批、待拍摄这类等内部人员处理的）、需要留意归警告；失败、逾期、异常归错误；进行中、已发出归信息；草稿、终止状态归中性。
