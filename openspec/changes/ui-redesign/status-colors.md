# 状态与语义色对照

从代码现有的 `Pill`、`Tag` 着色和状态配置整理（2026-11-20，`zhul-erp-frontend/src`，不含测试）。新界面只有五种语义色，见 `design.md` 第 2 节。

## 归类规则

| 现有颜色 | 新语义色 | 说明 |
|---|---|---|
| green | 成功 | 已完成、已通过、正向结果 |
| orange | 警告 | 等人处理、即将到期、需要留意 |
| red | 错误 | 失败、逾期、异常、低于红线 |
| accent、cyan、blue | 信息 | 进行中、已发送、说明性标记 |
| gray、mute | 中性 | 草稿、已取消、已作废、已停用等终止状态 |
| violet | 中性 | 现有紫色都是类别标签（如员工垫付、兼职、AI 生成），不是状态；新界面不用紫色 |

类别、属性类标签（客户类别、渠道、归属等）不表达状态，统一用中性色。
