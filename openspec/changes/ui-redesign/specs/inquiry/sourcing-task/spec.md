# Spec Delta

## MODIFIED Requirements

### Requirement: 分配工作台搜索与筛选
询价分配 SHALL 在页签上方提供搜索框与采购员下拉，对所有页签生效。

- 搜索框匹配任务编号、询盘单号、品牌、品类、型号，规则与「我的询价」一致。
- 采购员下拉列出租户内全部采购，筛选当前由该采购在办的任务；「待分配」页签在选了采购员时为空。
- 页签上的数字按搜索与筛选条件统计；页头下方汇总行的待分配、询价中、超时、待审核仍按全部任务统计（原四张统计卡片，附最久等待、多人比价、超时时限、兼职回价等副文字）。

#### Scenario: 按型号搜索
- **WHEN** 主管在询价分配搜索「6ES7 315」
- **THEN** 各页签只列出含该型号的任务，页签数字随之变化，汇总行「待分配」「询价中」数字不变

#### Scenario: 按采购员筛选
- **WHEN** 主管选择采购员「林熙」
- **THEN** 「询价中」只列林熙在办的任务（含多人比价中有林熙的），「待分配」为 0
