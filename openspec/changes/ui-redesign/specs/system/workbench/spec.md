# Spec Delta

## MODIFIED Requirements

### Requirement: 老板看板
老板看板 SHALL 回答「这个月赚了多少、钱收回来没有、风险在哪」，依次包含（金额按本位币人民币，口径与对应统计页一致，默认本月并与上月比较）：
- **本月成交额**（主角卡）：本月成交额、较上月的增减，近 12 个月每月成交额柱图（只突出本月，往期为中性色），以及一句结论（本月是否为近 12 个月最高、近 12 个月合计）；口径同经营统计。没有经营统计权限时不显示主角卡，成交额回到经营概览；
- **经营概览**：毛利、毛利率、实收回款、费用，及较上月的增减（口径同经营统计、利润统计）；上月为 0 算不出增减时改写上月的数，上月没有数据时写「上月没有可比数据」；没有主角卡时前面加上成交额；
- **资金**（有应收管理、应付管理、结汇管理任一菜单权限时显示，各项只在有对应菜单权限时出现）：应收未收合计，与「应收管理」同口径、同数（有效销售订单还没收齐的剩余金额，按订单汇率折人民币），点击进入应收管理；有已逾期（过了约定付款日）时显示「其中已逾期 CNY …」并用错误色提醒；没有逾期而有已发出、还没转成订单的 PI 待收款时（还需要 PI 菜单权限），显示「另有 N 张 PI 待收 CNY …」。本月到期应付与其中已逾期应付（已逾期用错误色），未结汇外币余额（按币种）；
- **风险提醒**：过期未收款 PI、超过预计到货日仍未到货的采购订单、未处理的到货差异、毛利为负的订单，各显示数量，点击进入对应列表；格子按菜单权限出现，位置不随数量变化；全部为 0 时格子保留、数量为中性色，标题旁写「全部正常」；
- **销售漏斗**：本月新增商机、询盘、报价、PI、成交订单的数量与逐级比例（本级 ÷ 上一级）；各级是本月各自新增的数量，不是同一批客户的转化，比例超过 100% 时不显示，口径写在帮助里；
- **排行**：业务员本月成交额前 5、客户本月成交额前 5；客户排行显示国旗与客户名称，悬停显示国家 / 地区与主联系人。

#### Scenario: 上月为 0 时写上月的数
- **WHEN** 本月实收回款 CNY 0.00，上月也是 0
- **THEN** 实收回款卡第三行写「上月 CNY 0.00」，不留空；毛利率上月没有成交时写「上月没有可比数据」

#### Scenario: 与经营统计一致
- **WHEN** 老板看板显示本月成交额 120 万、毛利 18 万
- **THEN** 经营统计选本月时显示同样的成交额与毛利

#### Scenario: 过期未收款计入逾期的手动订单
- **GIVEN** 今天 2026-12-20；有效订单 SO20261116002 约定付款日 2026-12-15，合计 USD 1,000.00、已到账 USD 400.00；有效订单 SO20261116003 没有约定付款日，未付款 USD 500.00；另有一张已发出、还没转订单的 PI 未付款
- **WHEN** 老板打开老板看板
- **THEN** 资金的「应收未收」与应收管理的应收合计相同（不含那张还没转订单的 PI），「其中已逾期」为 SO20261116002 剩余 USD 600.00 折人民币（SO20261116003 不计入）；点「应收未收」进入应收管理

#### Scenario: 漏斗比例超过 100%
- **WHEN** 本月询盘 6 张、报价单 12 张
- **THEN** 漏斗的「报价」显示数量 12，不显示比例

#### Scenario: 客户排行显示国家与联系人
- **WHEN** 本月成交额最高的客户是 Pacific Controls（Australia，主联系人 Tom）
- **THEN** 客户排行第一行显示澳大利亚国旗与 Pacific Controls，悬停显示「澳大利亚 · Tom」
