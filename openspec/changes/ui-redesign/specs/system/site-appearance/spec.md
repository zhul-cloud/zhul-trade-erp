# Spec Delta

## MODIFIED Requirements

### Requirement: 登录页使用外观配置
登录、注册、找回密码等登录前页面 SHALL 显示外观配置中的 Logo（未设置时显示默认 Logo）、系统副标题、登录页背景（未设置或加载失败时用默认背景）与底部文字（未设置时用默认文字），不在页面代码中另写品牌文字。

#### Scenario: 修改副标题
- **WHEN** 平台管理员把系统副标题改为「福唯外贸业务平台」
- **THEN** 登录页 Logo 下方显示「福唯外贸业务平台」

#### Scenario: 上传 Logo
- **WHEN** 平台管理员在外观中上传 Logo 图片
- **THEN** 登录页显示该图片，不再显示默认 Logo

### Requirement: 默认 Logo
未设置 Logo 时，系统 SHALL 显示一个纯色圆角方块，中间为系统名称第一个字，不使用渐变：底色为用户当前的主题色，文字颜色与该主题色的主按钮一致；浏览器标签图标不随主题和主题色变化，固定为青绿底白字。系统名称为空时使用「烛」。

#### Scenario: 默认名称
- **WHEN** 系统名称为「烛龙ERP」且未上传 Logo
- **THEN** 登录页、侧边栏与浏览器标签图标都显示写着「烛」字的纯色方块

#### Scenario: 深色主题下的默认 Logo
- **WHEN** 用户切换到深色主题且未上传 Logo
- **THEN** 侧边栏的默认 Logo 为主题色的深色取值，在近黑背景上清楚可见；浏览器标签图标仍为青绿底白字

#### Scenario: 改名后默认 Logo 跟随
- **WHEN** 系统名称改为「福唯ERP」且未上传 Logo
- **THEN** 默认 Logo 中的字变为「福」
