# Spec Delta

## MODIFIED Requirements

### Requirement: 应收管理

系统 SHALL 在「财务管理 → 应收管理」只读列出有效销售订单里还没收齐的款：
- 范围：只算有效的销售订单（不含已取消、售后补发），收款状态为「已到账」「无需收款」的不列。从形式发票转来的订单，已收、手续费差额取形式发票上的收款汇总。
- 计算：未收 = 订单合计 − 已到账 − 手续费差额，未收不大于 0 的不列。折人民币 = 未收 × 订单汇率，HALF_UP 保留 2 位；人民币订单按 1 折算。
- 到期：
  - 约定付款日早于今天为逾期，显示逾期天数；
  - 今天到 7 天后为「7 天内到期」；
  - 今天到月底为「本月到期」（后两项都不含已逾期）；
  - 没有约定付款日的为「未约定」。
- 汇总：页头下方的汇总行显示应收未收（客户数、订单数）；已逾期、7 天内到期、本月到期是搜索条件区下的快捷筛选，带金额与订单数，金额都折人民币，按全部应收统计。点快捷筛选即按该到期条件筛选（三项互斥），再点一次取消。
- 两种看法：
  - 按客户：每个客户显示业务员、订单数、分币种未收、折人民币、其中逾期、最早到期，展开看这个客户的每张订单。逾期金额大的客户在前。
  - 按订单：逐张列出订单号、客户、来源单号、业务员、订单金额、已收、未收、折人民币、约定付款日、状态，逾期的在前（逾期越久越前），再按约定付款日从近到远，未约定的在最后。
- 筛选：客户、订单号或 PI 编号关键字，业务员、币种点「查询」生效；「到期」（含未约定）在更多筛选里，也点「查询」生效。
- 数据范围：按当前用户的数据权限过滤订单负责人。

本页是汇总视图，不是单据列表：按到期排序，不显示创建人、更新人等审计列。

#### Scenario: 形式发票转来的订单按 PI 的已收算
- **WHEN** 订单合计 USD 1,000，它的形式发票已到账 USD 300，约定付款日为 12 天前，订单汇率 7.2
- **THEN** 这张订单未收 USD 700，折人民币 ¥5,040.00，状态为「逾期 12 天」，计入「已逾期」

#### Scenario: 收齐、取消的订单不出现
- **WHEN** 一张订单收款状态为「已到账」，另一张订单已取消
- **THEN** 两张都不出现在应收管理里，也不计入汇总

#### Scenario: 点快捷筛选
- **WHEN** 财务点快捷筛选「7 天内到期」
- **THEN** 列表只剩约定付款日在今天到 7 天后、还有未收的订单，这项快捷筛选显示为选中；再点一次恢复全部
