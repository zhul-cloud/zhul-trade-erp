# Spec Delta

## MODIFIED Requirements

### Requirement: 应付单页
「财务管理 → 应付单」SHALL 列出应付单：编号、收款方（供应商、线上店铺、货代，标出类型）、付款方式（对公、对私、未定）、来源单据（可点击打开）、币种、应付金额、已付、未付、供应商欠款、下一期到期日（标「已逾期 N 天」「N 天内到期」「待入库」）、状态，以及创建时间、创建人、更新时间、更新人；默认未付、部分付款的排在前面，已付清、已关闭的在后，同一状态内按更新时间倒序；可以按到期日排序。

- 筛选：关键词（应付单号、收款方、来源单号）、状态（切换后立即查询）、收款方类型、付款方式（选后立即查询）；更多筛选里有到期（已逾期、7 天内到期、本月到期、待入库）、币种、待退款、已关闭。
- 标记为「待退款」的应付单在欠款旁显示「待退款」及标记天数，见「采购订单取消后的收尾」。
- 快捷筛选（按全部应付单统计，按人民币）：本月到期未付、已逾期未付、7 天内到期、供应商欠款，各带金额与张数（供应商欠款带待退款笔数）；四项互斥，点击即筛出对应应付单，再点一次取消。
- 点编号或「查看」打开应付单详情页（见「应付单详情」），不再用抽屉。
- 有「付款登记」权限的财务可以从列表的「付款」「退款」或详情页发起付款（见「登记付款」）。

已关闭且没有欠款的应付单默认不显示，可以在更多筛选里勾选「已关闭 · 一并显示」。

#### Scenario: 筛出逾期
- **WHEN** 财务点击快捷筛选「已逾期未付 · CNY 12,000.00 · 2 张」
- **THEN** 列表只显示有逾期未付期次的应付单，按最早逾期的到期日排序

#### Scenario: 已关闭默认不显示
- **WHEN** 一张没有付款的采购订单被取消
- **THEN** 它的应付单「已关闭」，默认不出现在应付列表

#### Scenario: 未付的排在前面
- **WHEN** 财务打开应付单页，有一张今天刚付清的应付单和一张上周生成的未付应付单
- **THEN** 未付的那张排在前面，已付清的排在后面

#### Scenario: 筛出待退款
- **WHEN** 财务在更多筛选里勾选「只看待退款」后点「查询」
- **THEN** 列表只显示采购订单取消时选了「会退款」、公司付款还没退回的应付单

#### Scenario: 筛出对私的应付
- **WHEN** 财务在应付单页按付款方式选「对私」
- **THEN** 列表只显示付款方式为对私的应付单，每行付款方式列显示中性灰标签「对私」
