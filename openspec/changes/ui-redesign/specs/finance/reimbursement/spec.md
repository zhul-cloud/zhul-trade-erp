# Spec Delta

## MODIFIED Requirements

### Requirement: 登记报销已付
有「报销付款」按钮权限的财务 SHALL 能对待付款的报销单登记已付：付款方式（公司对公，选对公账户；或私对私，选对私账户，如法人个人账户转给员工）、付款日期（不能晚于当天）、转账截图（必传）、说明。登记后报销单为「已报销」，记录付款人与时间，不能再撤回；登记错了财务可以撤销已付，报销单回到「待付款」。

财务 SHALL 能批量登记已付：在报销单页勾选多张「待付款」的报销单（可以是不同报销人，一次最多 50 张），表格上方的操作行显示「已选 N 张（M 人）」与合计 CNY …，点右侧「批量登记已付」后一次填写付款方式、付款账户、付款日期、转账截图与说明，弹窗按报销人分组列出所选报销单与各人小计。确认后每张报销单各生成一张报销付款单（金额为该报销单合计），共用同一组转账截图与说明，状态都变为「已报销」；之后仍按单张撤销已付。批量登记在一个事务内完成：任一张已不是「待付款」（被撤回或已被别人登记）时全部不登记，提示「BX… 已不是待付款，请刷新后重新勾选」。

#### Scenario: 财务付款给员工
- **WHEN** 财务对 BX20261012001 登记已付：招商银行基本户、10-15、转账截图
- **THEN** 报销单为「已报销」，陈晨在报销单页看到付款日期与截图

#### Scenario: 法人私对私付给员工
- **WHEN** 财务对待付款的报销单选「私对私」，付款账户选对私账户「招商银行 · 张总 ****1234」，上传转账截图后登记
- **THEN** 报销单为「已报销」，详情显示「私对私 · 招商银行 · 张总 ****1234」，生成的报销付款单付款方式为私对私

#### Scenario: 批量登记两个人的报销单
- **WHEN** 财务勾选陈晨的 BX20261012001（CNY 300.00）、BX20261013002（CNY 120.00）和李娜的 BX20261013005（CNY 80.00），选招商银行基本户、11-03、上传转账截图后批量登记
- **THEN** 三张报销单都为「已报销」，生成三张报销付款单（CNY 300.00、120.00、80.00），截图三张单都能看到；弹窗中显示「陈晨 2 张 CNY 420.00 · 李娜 1 张 CNY 80.00」

#### Scenario: 其中一张已被撤回
- **WHEN** 财务勾选了 3 张报销单，提交前陈晨撤回了 BX20261013002
- **THEN** 系统提示「BX20261013002 已不是待付款，请刷新后重新勾选」，三张都不登记

### Requirement: 撤回待报销项
员工 SHALL 能在报销单页「待报销」里撤回本人还没进报销单的单项，撤回即作废该项，必须填写原因并二次确认：

- **采购货款**（员工垫付的付款单）：按 `finance/supplier-payment`「作废付款」作废，应付单的已付与状态随之恢复；它产生的欠款已被抵扣到其他应付单的，提示先撤销抵扣，不能撤回。
- **已收到退款**：作废这条退款登记，恢复应付单的欠款。
- **费用单**：按 `finance/expense` 的作废规则作废费用单。
- **国内快递运费、退货运费**：不提供撤回，提示「快递费随快递单处理」「退货运费随退货单处理」。

已进入有效报销单的项不能撤回，提示先撤回报销单。撤回写入原单据的操作日志（「从待报销撤回：<原因>」）。财务把页头右侧的范围切到「全部」（复审 S3 统一为「我的 / 全部」）后也能撤回他人的单项，权限同各单据的作废权限。

#### Scenario: 撤回登记错的垫付
- **GIVEN** johnny 的待报销里有 PY20261119001 CNY 700.00，还没提交
- **WHEN** johnny 撤回这一项（原因「采购已取消，店铺已退款」）
- **THEN** PY20261119001 为「已作废」，从 johnny 的待报销里消失，AP20261119001 的已付回到 CNY 0.00

#### Scenario: 已进报销单不能撤回
- **WHEN** 林熙要撤回已在待付款报销单 BX20261110001 中的一项
- **THEN** 系统提示「这一项已在报销单 BX20261110001 中，请先撤回报销单」

#### Scenario: 快递费不在这里撤回
- **WHEN** 陈晨查看待报销里的快递费 SF1234
- **THEN** 这一项没有「撤回」，提示「快递费随快递单处理」
