# Spec Delta

## MODIFIED Requirements

### Requirement: 报价单列表与查看范围
系统 SHALL 提供报价单列表：按数据权限（按询盘单负责人 / 报价单创建人）过滤，展示报价单编号、客户（名称、国家与新 / 老客户标记，与询盘单列表一致）、型号（首个型号，下面一行「共 N 个型号 · 查看」，点「查看」弹窗看全部型号；与询盘单列表一致）、品牌、品类（按报价明细去重，以标签显示，与询盘单列表一致）、总数量（全部型号数量之和）、币种与合计、合计毛利率、状态（未成交时显示原因）、来源询盘、业务员（报价单负责人）、发送时间，以及创建时间、创建人、更新时间、更新人；可按关键词（编号、客户、型号）、状态、币种、业务员、创建日期筛选，默认按创建时间倒序。操作列提供「文字报价」，打开与报价单详情相同的文字报价弹窗（取该报价单默认查看的版本），所有状态的报价单都可以打开；与详情页一致，只有草稿与已发送的报价单在复制后可以标为已发送或记一次发送。询盘单详情中列出包含其型号的报价单。兼职采购不能访问报价单。

型号（按型号数）、总数量、币种 · 合计三列 SHALL 可以点表头排序（正序、倒序、取消排序），在服务端排序、翻页后保持，合计按折合人民币比较；不排序时按创建时间倒序。

#### Scenario: 询盘详情看到报价单
- **WHEN** 业务员打开一个其型号出现在两张报价单中的询盘单
- **THEN** 详情的「报价单」区域列出这两张报价单的编号、状态与合计，点击可打开

#### Scenario: 按总数量排序
- **WHEN** 业务员在报价单列表点两次「总数量」表头
- **THEN** 列表按总数量从多到少排列，翻到第 2 页仍按这个顺序

#### Scenario: 列表显示型号、品牌、品类
- **WHEN** 报价单有 3 行：6ES7214-1AG40-0XB0（西门子，PLC）、6ES7313-6CE01-0AB0（西门子，PLC）、E3Z-D61（欧姆龙，传感器）
- **THEN** 列表该行型号显示「6ES7214-1AG40-0XB0」，下面一行「共 3 个型号 · 查看」，品牌显示「西门子」「欧姆龙」，品类显示「PLC」「传感器」

#### Scenario: 从列表打开文字报价
- **WHEN** 业务员在报价单列表点某张草稿报价单的「文字报价」并复制
- **THEN** 弹出与详情页相同的文字报价弹窗；复制后可以标为已发送，列表随之刷新状态
