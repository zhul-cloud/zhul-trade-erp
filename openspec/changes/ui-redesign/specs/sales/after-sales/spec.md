# Spec Delta

## MODIFIED Requirements

### Requirement: 售后管理页
「销售管理 → 售后管理」SHALL 列出售后单，按更新时间倒序，按数据范围（负责人或订单业务员在当前用户可见范围内）显示。状态用下拉选择（处理中、待客户确认、已结案、已撤销，不选为全部；处理中、待客户确认后面带数量；默认处理中，切换后立即查询）；筛选：客户、问题等级、原因、负责人、关键字（售后单号、订单号、型号）；快捷筛选：「需要更新客户」（已逾期）、「已逾期或快到期」，两者互斥，打开时状态放开为全部。列：售后单号、客户、订单、型号摘要、等级、原因、方案、负责人、下一步与截止时间（截止事项、「已逾期」标红、「快到期」标橙）、状态，以及创建时间、创建人、更新时间、更新人。快捷筛选「需要更新客户」后面带已逾期的售后单数；本月结案数显示在页面顶部的汇总行。

销售订单详情 SHALL 显示这张订单的售后单（单号、等级、状态），点击打开。

#### Scenario: 下次更新时间已过
- **WHEN** 处理中的售后单截止时间为昨天
- **THEN** 列表中该时间标红并显示「已逾期」，打开快捷筛选「需要更新客户」时列出

#### Scenario: 快到期
- **WHEN** 处理中的售后单 40 分钟后到截止时间
- **THEN** 列表中该时间标橙并显示「快到期」
