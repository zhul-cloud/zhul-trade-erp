# Spec Delta

## MODIFIED Requirements

### Requirement: 销售退货页
「销售管理 → 销售退货」SHALL 列出销售退货单，按数据范围（售后单负责人或订单业务员在当前用户可见范围内）显示。状态用下拉选择（待确认、待入库、已入库、已作废，不选为全部；默认待确认，切换后立即查询，重置回到待确认）；筛选：客户、处理方式、关键字（退货单号、售后单号、订单号、型号、快递单号）。列：退货单号、来源单号（售后单号）、客户 · 订单、型号摘要（型号 × 数量）、处理方式、快递单号、入库情况（实收 / 合格）、退款（关联退款申请的金额与状态）、状态，以及创建时间、创建人、更新时间、更新人；按更新时间倒序。

销售退货单 SHALL 由表头与明细组成：表头记录单号、售后单、订单、客户、处理方式、客户寄回快递、说明、状态；明细每行记录订单型号行、型号、品牌、退货数量、成交单价，入库后显示实收与合格数量。

销售退货单 SHALL 有独立的详情页（`/sales/returns/:id`，标签页标题为单号），列表点单号、其他单据的来源单号都打开它。详情页显示表头（来源单号为售后单号）、明细、退货入库单与退款申请（单号、状态，可点开）、操作日志。
