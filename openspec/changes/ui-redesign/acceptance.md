## 每页都看的几点

以下几点每个列表页都适用，单页里不再重复：

1. 页头：左边标题，右边最多一个实底主按钮；没有面包屑。
2. 切换控件（D61、S3）：
   - 看不同对象或视图用页头下方的下划线页签，数量写「名称 N」；
   - 按状态筛选用搜索区的「状态」下拉，选项带数量；
   - 只看自己 / 看全部用页头右侧灰底的「我的 / 全部」。
3. 搜索区一行：常用条件的名称写在框内（如「状态 全部 ▾」），其余收进「更多筛选」。
4. 主卡左上角写「共 N 条」，勾选后变「已选 N 张 · 取消选择」。快捷筛选为 0 时只写名称（S8）。
5. 表格：
   - 1366 宽默认显示的列放得下；放不下时横向滚动，首列固定在左、操作列固定在右；
   - 「创建」「更新」两列和次要列在右上角「列」里打开（D25、D55）；
   - 单号是墨色粗体，悬停变主题色；鼠标停在单号上右侧出现复制图标（D23、D66）；
   - 需要注意的行在最左侧有色条，不整行铺底色（D7）；
   - 属性标签（现货、对公、客户指定等）是中性灰，彩色只给流程状态（S4）。
6. 金额写成「CNY 1,234.00」，不出现 `¥`（S8）。
7. 加载时不闪「共 0 条」；没有数据时居中显示图标和一句话，有下一步的给按钮（S8、C4）。
8. 顶栏切换深色模式后再看一遍：卡片有细边、文字清楚。

详情页另看：页头标题和流程状态在一行，「更多」在主按钮之前；单据详情上方左宽右窄（右栏 340，收付款与毛利），宽表放下方通栏（P9、R25）。
