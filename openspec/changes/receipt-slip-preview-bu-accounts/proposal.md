# Proposal

## Why

财务在「收款单 → 待确认」点水单附件会打开新窗口，看完还要切回来登记，来回切换容易看错单；PI、订单、收款单详情、未认领到账里的附件也一样。登记到账的收款账户下拉列出全部事业部的账户，容易选到别的事业部的账户（虽然有收错提示，但最好一开始就只给本单据的账户）。

## What Changes

- 水单与到账附件（待确认列表、收款单详情、未认领到账、PI 详情、订单详情、认领弹窗）点开改为当前页弹窗预览：图片可左右切换同组图片，PDF 内嵌显示，其他文件直接下载，弹窗里可下载。
- 登记到账的收款账户下拉默认只列单据所属事业部的账户（默认选该事业部的默认账户），底部「显示其他事业部账户（n）」展开后按「本单据事业部 / 其他事业部」分组；选了其他事业部的账户，仍显示原有的「可能收错账户」提示与标记。未启用事业部时列出全部账户；未认领到账没有单据，仍列出同币种的全部账户。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `sales/payment-receipt`：「上传付款水单」增加附件在当前页预览；「收款归属事业部与收错账户提示」增加账户默认只列本单据事业部。

## Impact

- 只改前端：`finance/receipts`（待确认、详情、未认领到账）、`sales/pi`（详情、登记到账与认领弹窗）、`sales/orders`（详情），复用询盘的附件预览弹窗 `useFilePreview`。
- 后端接口不变，无数据库迁移。
