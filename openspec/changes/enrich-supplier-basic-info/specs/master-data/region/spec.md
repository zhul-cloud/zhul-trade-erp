## Purpose

提供中国省、市、区三级行政区划数据，供供应商等主数据的「所在地区」字段做级联选择，保证地区取值统一、可检索。

## ADDED Requirements

### Requirement: 查询省市区三级行政区划
系统 SHALL 提供一个只读接口，返回全国省、市、区三级行政区划树，每个节点包含行政区划代码和名称；登录用户即可调用，不需要额外按钮权限。

#### Scenario: 获取区划树
- **WHEN** 已登录用户请求行政区划数据
- **THEN** 系统返回以省为根的树，包含「上海市 → 上海市 → 浦东新区」这样的三级路径

#### Scenario: 未登录
- **WHEN** 未携带有效登录凭证请求行政区划数据
- **THEN** 系统返回未登录错误
