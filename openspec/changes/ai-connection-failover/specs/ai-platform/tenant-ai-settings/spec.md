# Spec Delta

## MODIFIED Requirements

### Requirement: 租户维护自己的 AI 配置
能访问「业务设置 → AI 设置」菜单的用户 SHALL 能查看本租户的 AI 配置，另有「编辑 AI 设置」按钮权限的用户 SHALL 能修改、调整顺序、启用或关闭、测试连接与获取模型列表。配置由各连接方式自己的设置、使用顺序与启用开关组成：连接方式是服务商（`claude` / `openai`）与用法（本公司 API Key `api` / 平台订阅 `subscription`）的组合，页面按 API 组、订阅组分别列出，组内可拖拽排序（规则见 `ai-platform/connection-failover`）；每个服务商的本公司 API Key 设置各自保存 Key、解析模型、翻译模型、解析与翻译的思考强度（`low`、`medium`、`high`、`xhigh`、`max`）、单次解析的最大搜索次数（1–100 的整数），互不覆盖。每个租户的配置互不可见；修改后该租户之后提交的 AI 任务立即使用新配置，不需重启任何服务。AI 配置不出现在系统参数的通用列表中。

#### Scenario: 两个租户各用自己的配置
- **WHEN** 租户甲配置服务商 `claude` 与自己的 Key，租户乙配置服务商 `openai` 与自己的 Key，两人各提交一个询盘解析
- **THEN** 甲的任务用甲的 Key 调用 Claude，乙的任务用乙的 Key 调用 OpenAI，互不影响

#### Scenario: 修改立即生效
- **WHEN** 租户把解析模型从留空改为 `claude-sonnet-5-5` 并保存，随后提交询盘解析
- **THEN** 该任务使用 `claude-sonnet-5-5`，编排服务没有重启

#### Scenario: 只能查看的用户
- **WHEN** 用户有 AI 设置菜单、没有「编辑 AI 设置」权限，打开页面后尝试保存或拖动顺序
- **THEN** 页面只读显示配置与顺序、不能拖动，保存请求被拒绝；没有该菜单的用户连查看也被拒绝

#### Scenario: 非法取值
- **WHEN** 保存时服务商为 `deepseek`、思考强度为 `fast` 或最大搜索次数为 0
- **THEN** 保存失败并提示对应字段的可选值或范围，原配置不变

#### Scenario: 两家的 Key 同时保存
- **WHEN** 租户已保存 Claude 的 Key，再填写 OpenAI 的 Key 与模型并保存
- **THEN** 两家的 Key、模型、思考强度与搜索次数各自保留，都参与按顺序使用

#### Scenario: 关闭某个连接方式
- **WHEN** 租户关闭 OpenAI API Key 卡片的启用开关并保存
- **THEN** 之后的任务不再使用 OpenAI 的 Key，已保存的 Key 与模型设置保留，重新打开后照常参与

### Requirement: 未配置时的处理
租户没有任何已配置且启用的连接方式（API 方式都没有填写 Key 或都已关闭，且没有可参与的平台订阅）时，SHALL 视为「AI 未配置」，不使用其他租户或平台的配置：用户主动发起的 AI 操作（询盘解析、型号描述翻译）不创建任务，直接提示「AI 未配置，请在业务设置 → AI 设置 中填写」；业务保存时顺带触发的 AI 任务（保存商机时的联系人名音译）跳过并记录日志，业务保存照常成功。

#### Scenario: 未配置时解析询盘
- **WHEN** 未配置 AI 的租户提交询盘解析
- **THEN** 提示 AI 未配置，不产生 AI 任务，询盘保持提交前的状态

#### Scenario: 未配置时保存商机
- **WHEN** 未配置 AI 的租户保存一个联系人为英文名的商机
- **THEN** 商机保存成功，联系人名不翻译，日志记录跳过原因

#### Scenario: 平台已配置但租户未配置
- **WHEN** 平台租户已填写 Key，租户 1001 未配置，租户 1001 提交询盘解析
- **THEN** 提示 AI 未配置，不使用平台的 Key

### Requirement: 租户使用平台订阅
获授权的租户的平台订阅 SHALL 作为订阅组参与按顺序使用（默认启用，可关闭），使用平台为该服务商设置的订阅模型、思考强度与搜索次数，这些设置在租户页面只读，租户提交的修改不生效；订阅不使用 API Key。平台未登录的订阅视为不可用并跳过。创建 AI 任务时没有任何可用的连接方式、且原因是订阅不可用时，用户主动发起的 AI 操作不创建任务并提示「AI 暂不可用，请在业务设置 → AI 设置 中检查连接方式」，业务保存时顺带触发的任务跳过；提示不说明平台账号的原因。

#### Scenario: 使用平台的订阅设置
- **WHEN** 平台为 Claude 订阅设置解析模型 `claude-opus-5-5`、思考强度 `high`，获授权租户的 API 方式都不可用，订阅组第一位是 Claude 平台订阅，提交询盘解析
- **THEN** 任务按订阅方式、`claude-opus-5-5`、`high` 执行，不使用任何 API Key

#### Scenario: 选中的订阅失效
- **WHEN** 获授权租户只用平台订阅，订阅组顺序为 Claude、OpenAI，平台的 Claude 退出登录后提交询盘解析
- **THEN** 任务使用 OpenAI 平台订阅；AI 设置页的 Claude 平台订阅显示不可用

#### Scenario: 不能选不可用的订阅
- **WHEN** 获授权租户没有可用的 API 方式，平台的两家订阅都未登录，提交询盘解析
- **THEN** 提示 AI 暂不可用，不创建任务；租户可以调整订阅的顺序与开关，但不能让未登录的订阅参与使用

### Requirement: 测试连接
AI 设置页面 SHALL 在每张连接方式卡片上提供「测试连接」，用该卡片当前填写的值测试，不需先保存；Key 留空时用已保存的 Key。API 方式下检查 Key 是否有效以及解析模型、翻译模型是否可用，只调用服务商的模型查询接口，不产生调用费用；订阅方式下检查该服务商的 CLI 是否已登录。结果逐项显示成功或失败原因，失败原因不含 Key。测试成功时解除该方式的暂停。

#### Scenario: Key 有效且模型可用
- **WHEN** 用户在 Claude API 卡片填写有效的 Key，模型留空，点击测试连接
- **THEN** 显示 Key 有效、`claude-opus-5-5` 与 `claude-haiku-5-5` 可用

#### Scenario: 模型不存在
- **WHEN** 在 OpenAI API 卡片把解析模型填为 `claude-opus-5-5`，点击测试连接
- **THEN** 显示 Key 有效、解析模型不可用及服务商返回的原因

#### Scenario: Key 无效
- **WHEN** 填写错误的 Key 点击测试连接
- **THEN** 显示认证失败，不保存任何内容

#### Scenario: 测试成功解除暂停
- **WHEN** Claude API 处于暂停中，用户点击测试连接且通过
- **THEN** 卡片不再显示暂停，下一个任务先用 Claude API

### Requirement: 平台订阅按套餐授权给公司
平台订阅的使用权 SHALL 是 AI 设置下的按钮资源「使用平台订阅」（权限码 `system:ai-config:use-subscription`），由平台在套餐中勾选授予、取消勾选收回；同一套餐的公司同时生效。平台租户始终可用，不需授权。判断以公司所属套餐为准，与具体员工的角色无关；该资源被停用时视为所有租户都未授权。新增该资源时不自动加入任何现有套餐。

#### Scenario: 授权后可选平台订阅
- **WHEN** 平台在租户 1001 的套餐中勾选「使用平台订阅」，平台的 Claude 已登录
- **THEN** 租户 1001 的 AI 设置页出现订阅组，Claude 平台订阅显示可用，排在 API 组之后参与使用

#### Scenario: 未授权时没有订阅入口
- **WHEN** 租户 1001 的套餐未勾选「使用平台订阅」
- **THEN** 页面只有 API 组；直接调用接口保存订阅的顺序或启用状态被拒绝，原配置不变，任务也不会用到平台订阅

#### Scenario: 收回授权
- **WHEN** 租户 1001 的 API 方式都不可用、靠平台订阅使用 AI，平台在套餐中取消勾选
- **THEN** 租户 1001 之后发起的 AI 操作提示 AI 未配置、不创建任务（没有本公司 API Key 时已无可用的连接方式）；AI 设置页不再显示订阅组，并引导填写本公司 API Key

### Requirement: AI 设置页面以连接方式列表呈现
AI 设置页面 SHALL 以两组卡片列出连接方式：API 组（各服务商的本公司 API Key）在上、订阅组（各服务商的平台订阅）在下，组内按使用顺序排列并可拖拽调整。每张卡片显示序号、服务商、启用开关与自己的状态：API Key 显示已配置（附脱敏 Key）或未配置；平台订阅对平台显示已登录 / 未登录，对租户显示可用 / 不可用；暂停中的显示原因与恢复时间。点开一张卡片在右侧编辑它的 Key 与模型设置。页面所有修改（顺序、启用开关、填写或更换 Key、修改模型）都只通过有修改时出现的底部保存条保存，页面上没有其他保存按钮。未授权的租户不显示订阅组。

#### Scenario: 切换后统一保存
- **WHEN** 用户把 OpenAI API Key 卡片拖到 Claude API Key 前面
- **THEN** 底部出现保存条；保存前顺序不变，保存后新的 AI 任务先用 OpenAI 的 Key

#### Scenario: 不能跨组拖动
- **WHEN** 用户把平台订阅卡片拖向 API 组
- **THEN** 卡片回到订阅组原位置，顺序不变

#### Scenario: 选中的订阅不可用
- **WHEN** 租户订阅组排第一的平台订阅不可用
- **THEN** 该卡片显示不可用，任务按顺序改用下一个可用方式，页面不显示平台账号相关说明

#### Scenario: 没有可用的连接方式
- **WHEN** 租户所有连接方式都不可用（未配置、已关闭、未登录或暂停中）
- **THEN** 顶部状态显示 AI 暂不可用，并指出需要处理的卡片，不显示平台账号相关说明
