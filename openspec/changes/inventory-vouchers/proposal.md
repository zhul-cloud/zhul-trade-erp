## Why

公司的正式账在畅捷通 T+ 里记。现在会计要对着采购入库、出运、成本调整这些单据，在 T+ 里手工编库存相关的凭证，工作量大，而且两边的数字容易对不上。库存三级账和库存月结已经把每个月库存的进出与成本算准并锁定了，可以直接拿来生成凭证。用户 2026-11-22 定：ERP 不记正式账，只按月生成业务凭证，导出给会计导入 T+；第一期只做库存相关的凭证。

## What Changes

- **业务凭证（新）**：库存月结结账时，系统为当月的库存单据**按单据**自动生成凭证。一张单据的一次库存动作对应一张凭证；冲销、撤销、作废单独出一张红字凭证。凭证日期取业务日期，摘要带动作、单号和往来单位，T+ 与 ERP、供应商可以逐笔对账（用户 2026-11-22 定：单据不多，按单据）。凭证分四类：
  - **采购入库**：采购入库单、折价接收，借库存商品，贷应付账款（供应商辅助核算）；采购退货单借应付账款，贷库存商品。
  - **销售成本结转**：出运单，借主营业务成本，贷库存商品；退货入库单，借库存商品，贷退货入库（默认主营业务成本）。
  - **其他出库**：按出库类型（报废、转样品、货代丢失、货损）借各自的科目，贷库存商品。
  - **成本调整**：一张调整单一张凭证。在库部分记库存商品，已出运部分记主营业务成本，其他出库部分记对应出库类型的科目；对方科目按触发原因设置，默认应付账款，按供应商分行。
- **和库存账核对**：每个月显示「期初 + 凭证里库存商品的净额 + 不生成凭证的库存变动 = 期末」，期初和期末取库存月结。不生成凭证的库存变动指期初、补关联商品、系统外入库（金额 0）和商品合并，单独列出来。核对不上时标红并说明差在哪里。
- **导出给 T+**：按 T+ 凭证导入模板导出 Excel，会计在 T+ 里导入。导出后标「已导出」，记录导出人和时间。
- **科目设置**：会计可以设置每个业务对应的 T+ 科目编码，以及供应商对应的 T+ 往来单位编码；没设置的供应商用 ERP 里的供应商编码。科目没设齐时不能导出，并提示缺哪些科目。
- **反结账**：作废这个月的凭证（保留记录）。已导出的凭证，提示会计在 T+ 里同步删除。重新结账后重新生成。
- **新菜单**：「财务管理 → 业务凭证」，排在「库存月结」之后。

不做：收款、付款、费用、结汇的凭证，以及财务单据按月锁定（后续期做）；T+ 接口直接推送；外币核算（应付账款只记人民币）；在 ERP 里记总账、出报表。

## Capabilities

### New Capabilities
- `finance/business-voucher`：按单据从库存业务生成凭证；科目与往来单位对照设置；凭证与库存账核对；按 T+ 凭证导入模板导出；业务凭证页。

### Modified Capabilities
- `finance/period-close`：「结账」时生成当月业务凭证；「反结账」时作废当月凭证，并在凭证已导出时提醒。
- `system/navigation`：「财务管理」分组在「库存月结」之后新增「业务凭证」。

## Impact

- **数据库**：
  - 新建四张表：业务凭证（来源单据、动作、日期、摘要、状态）、凭证分录、月份导出记录、科目设置（业务项 → T+ 科目编码）；`supplier` 加 T+ 往来单位编码。
  - 新增菜单「业务凭证」，以及查看、科目设置、导出三个权限。
  - 科目设置按租户预置一套常用科目（库存商品 1405、主营业务成本 6401、应付账款 2202 等，按小企业 / 企业会计准则的一级科目编码），会计按自己 T+ 里的科目改。
- **后端**：
  - 新增 `finance` 下的凭证服务：按来源单据与动作分组库存流水、成本调整明细，生成凭证。
  - 生成和作废挂在库存月结的结账、反结账里，在同一事务内完成。
  - 核对和 Excel 导出。
- **前端**：业务凭证页（月份列表；月份详情含核对、按类型筛选的凭证列表、展开看分录、单号打开单据；导出），科目设置。
- **外部依赖**：导出列以用户 T+ 版本的「凭证导入模板」为准。开发前需要用户从 T+ 导出一份凭证导入模板和科目表。
- **原型**：先出 OpenPencil 原型（业务凭证页、凭证详情、科目设置），用户确认后再开发。
