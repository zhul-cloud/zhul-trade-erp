## MODIFIED Requirements

### Requirement: 我的询价任务

系统 SHALL 为采购人员提供「我的询价任务」：只列出分配给自己且未取消的任务，可按状态筛选。待处理列表中超时的任务最先、其次紧急的任务，其余按更新时间倒序；已回价列表按更新时间倒序。更新时间取任务的更新时间与本人在该任务最近一次保存回价时间的较晚者，并在列表上展示。每个任务展示询盘等级、新老客户、所属业务员与报价截止；正式采购还能看到客户名称，用来判断是否是长期合作的老客户、优先找货；兼职采购看不到客户名称。任务详情展示每个型号的确认型号、数量与单位、描述、生命周期与替代型号、难度、询价话术（可一键复制），以及按淘宝、1688、闲鱼顺序排列的货源直达搜索链接。所有采购人员都看不到客户联系方式、原始询盘内容与附件，以及其他采购人员的询价记录。

#### Scenario: 正式采购看到客户名称

- **WHEN** 正式采购打开我的询价任务
- **THEN** 每个任务展示客户名称、询盘等级、新老客户与所属业务员

#### Scenario: 兼职采购看不到客户名称

- **WHEN** 兼职采购打开我的询价任务
- **THEN** 任务不展示客户名称，其余信息照常展示

#### Scenario: 他人任务

- **WHEN** 采购人员请求查看未分配给自己的任务
- **THEN** 系统拒绝并提示无权查看

#### Scenario: 刚保存回价的任务排到前面

- **GIVEN** 待处理有任务 A（分配较早）与任务 B，都没有超时、都不紧急
- **WHEN** 采购在任务 A 里保存了回价草稿
- **THEN** 待处理列表里任务 A 排在任务 B 前面，更新时间为刚才保存的时间

#### Scenario: 超时与紧急仍置顶

- **GIVEN** 待处理有一个超时任务、一个紧急任务与一个刚更新的普通任务
- **WHEN** 采购打开待处理列表
- **THEN** 顺序为超时任务、紧急任务、普通任务

#### Scenario: 已回价按更新时间倒序

- **WHEN** 采购打开已回价列表
- **THEN** 任务按更新时间从新到旧排列

## ADDED Requirements

### Requirement: 粘贴报价快速回填

系统 SHALL 在我的询价任务详情提供「粘贴报价」：采购先选渠道与店铺名称（渠道为供应商时选供应商），粘贴店家回复的原文后由系统按规则识别，结果进入可编辑的预览，确认后作为对应型号的回价草稿填入编辑区，不自动保存或提交。识别规则：
- 型号只在当前任务的型号中匹配，比较时忽略大小写、空格、横杠、下划线、斜杠与点；一行里同时出现多个型号时取最长的匹配。
- 单价取该行中去掉型号后的金额：优先取「单价 / 价格 / 报价 / ¥ / 元」等字样后的数字；没有字样时取既不是数量（紧跟「台 / 个 / 只 / 件 / pcs」或前面有「要 / 数量 / ×」）也不是货期的数字中的第一个。含税写法沿用询价包导入的规则（「含税」「含税3%」「含3%税」，没写税率按 13%），出现「未税 / 不含税」时为未税。
- 货期识别「现货 / 有货」「N 天 / N-M 天」「N 周 / N-M 周」「N 个月」，按区间上限换算成天数后落到货期字典项（现货、≤2 天、≤3 天、≤5 天、≤7 天、≤2 周、≤4 周、≤8 周，超过为「8周以上」）。
- 货况识别「全新 / 原装 / 正品」为全新原装，「99新」「翻新」「二手」「拆机」「国产 / 替代」分别对应；整行与整段都没写货况时默认全新原装。
- 没有匹配到型号、也没有价格的行作为整段通用说明：其中的含税 / 未税、货况、货期套用到所有识别出、且该项没有单独写明的行；整段通用说明的原文追加到每行备注。
- 匹配到型号但取不到价格的行在预览中标「缺单价」，需要手填或忽略；有价格但没匹配到型号的行标「未匹配」，可手动指定型号或忽略。
- 同一型号识别出多行时都列出并提示，由采购保留其中一行或都保留。
填入时，若该型号已有同一渠道且同一店铺（或供应商）的草稿，覆盖该条；否则追加一条。已提交且不可修改的型号不填入并提示。

#### Scenario: 每行一个型号带现货与周期

- **GIVEN** 任务里有 LXM32AD30N4、LXM32AD18N4、BMH1003P16A2A、BMH0702P12A2A 四个型号
- **WHEN** 采购选淘宝、店铺「施耐德工控店」，粘贴「LXM32AD30N4，要 1 台 3140 现货 / LXM32AD18N4，要 2 台 2237 现货 / BMH1003P16A2A，要 1 台 2562 5周 / BMH0702P12A2A，要 2 台 3263 5周 / 未税包邮 全新原装正品 假一罚万」并识别
- **THEN** 预览出 4 行，单价分别为 3140、2237、2562、3263，前两行货期现货、后两行货期 4-8周，都为未税、全新原装，备注带「未税包邮 全新原装正品 假一罚万」

#### Scenario: 单价写在型号后面

- **GIVEN** 任务里有 AX32-30-10-80、TA25DU-19M 两个型号
- **WHEN** 采购粘贴「AX32-30-10-80单价120 / TA25DU-19M单价72」并识别
- **THEN** 预览出 2 行，单价 120、72，型号里的 30、10、80、19 不被当成单价

#### Scenario: 写法不同的型号也能匹配

- **GIVEN** 任务里有型号 6ES7 214-1AG40-0XB0
- **WHEN** 粘贴的一行写成「6es72141ag400xb0 980含税」
- **THEN** 该行匹配到 6ES7 214-1AG40-0XB0，单价 980、含税、税率 13%

#### Scenario: 认不出的行

- **WHEN** 粘贴的一行有价格但型号不在任务里
- **THEN** 预览把该行标「未匹配」，采购可以选一个任务型号或忽略；忽略的行不填入

#### Scenario: 填入草稿不提交

- **GIVEN** 型号 A 已有淘宝「施耐德工控店」的一条草稿
- **WHEN** 采购用同一渠道与店铺粘贴识别后确认填入
- **THEN** 型号 A 的这条草稿被新单价覆盖，其他型号追加一条草稿；回价没有保存，采购点保存或提交后才生效

#### Scenario: 已提交的型号不填入

- **WHEN** 识别出的型号已经提交且不能再修改
- **THEN** 该行不填入，预览提示「已提交，不能修改」
