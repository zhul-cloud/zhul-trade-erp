## Context

`InquiryStatusSync.target(报价单状态集合)` 决定询盘状态：已成交 / 部分成交 → 已成交；已发送 → 已报价；未成交或已作废 → 未成交；其余不变。作废、标未成交、发送、订单回退等都会调用它。询盘行上已维护回价进度 `priced_item_count / total_item_count`。

## Decisions

1. **作废视为没报过**：`target` 去掉「已作废 → 未成交」；新增一种结果「回到报价前」，在报价单状态集合里只有已作废（或已作废加草稿）时返回。`sync` 遇到这个结果时按询盘的回价进度定状态：`total > 0 且 priced == total` → 可报价，否则询价中。只在询盘当前是已报价 / 未成交时回退（询价中、可报价的本来就对）。
2. **未成交优先于作废**：集合里有未成交时仍是未成交，与「客户明确不要」的语义一致。
3. **数据修复用 Flyway**：`V1.2.41`，把状态为未成交、当前有效型号行所在的报价单（未删除）里没有已发送 / 已成交 / 部分成交 / 未成交、但至少有一张已作废的询盘，按回价进度改为可报价或询价中。只动这一类，记录在迁移脚本注释里。

## Risks / Trade-offs

- [统计口径变化：作废导致的「未成交」会变少] → 这是期望的修正；被标为未成交的不受影响。
