## MODIFIED Requirements

### Requirement: 库存台账
「仓库管理 → 库存台账」SHALL 按自然月（按流水的业务日期）与仓库提供库存三级账的两个视图，顶部切换「类目账」「明细账」，月份与仓库筛选两者共用：

- **明细账**（三级）：按商品列出进销存汇总：期初数量与金额、本月入库数量与金额、本月出库数量与金额、本月成本调整金额、期末数量与金额。期初为该月之前全部流水的合计，期末 = 期初 + 入库 − 出库，期末金额 = 期初金额 + 入库金额 − 出库金额 + 成本调整金额；本月入库含操作类型入库、调入，本月出库含出库、调出；转出与转入只改变合格与不良，不计入入库出库；预占与释放不计入；成本调整只计金额。可以按关键词（型号、品牌）和一级品类筛选。点数量打开库存流水并带上商品、仓库与月份筛选。
- **类目账**（二级）：按商品所属的一级品类汇总明细账，每个一级品类一行，按算式排：期初金额 + 本月入库金额 − 本月出库金额 + 在库成本调整 = 期末金额，并列出该品类的商品数；选「全部仓库」时另列本月销售成本作参考（不进算式）。商品挂在二级品类上的按它的上级一级品类汇总，没有品类的归「未分类」。只列当月有期初、进出或期末的品类，按期末金额倒序。点某个品类切到明细账并带上该品类筛选。
- **总账**（一级）：类目账的合计行就是总账，等于各品类之和，也等于明细账全部商品的合计；选「全部仓库」时与同月库存月结的期初、入库、出库、在库成本调整、期末一致。

已结账的月份显示「已结账」，类目账与明细账的数字都与月结快照一致，品类取结账时商品所属的一级品类（见 `finance/period-close`）。全部仓库合计时调入与调出抵消。两种视图都可以导出 Excel。

#### Scenario: 月度台账
- **WHEN** 查看 2026-11、公司仓库的明细账，A 在 11 月前结存 0，11 月采购入库 10、调拨出 10
- **THEN** A 一行：期初 0、入库 10、出库 10、期末 0，金额按批次单价计

#### Scenario: 台账里的成本调整
- **WHEN** 2026-12 公司仓库 A 期初 5 个 ¥500.00，本月外币付清使 A 的批次单位成本从 ¥100.00 调到 ¥102.00
- **THEN** A 一行：期初 5、¥500.00，入库 0，出库 0，成本调整 ¥10.00，期末 5、¥510.00

#### Scenario: 类目账按一级品类汇总
- **WHEN** 2026-11 全部仓库：A（二级品类「小型 PLC」，上级为一级品类「PLC 与控制器」）入库 ¥26.70；B（一级品类「其他」）入库 ¥6.95、报废出库 ¥1.39；C 没有品类，期末 ¥19.00
- **THEN** 类目账三行：PLC 与控制器 期末 ¥26.70、未分类 期末 ¥19.00、其他 0 + 6.95 − 1.39 + 0 = ¥5.56；合计行 期初 0、入库 ¥52.65、出库 ¥1.39、期末 ¥51.26，与 2026-11 库存月结一致

#### Scenario: 从类目账下钻到明细账
- **WHEN** 在 2026-11 类目账点「PLC 与控制器」
- **THEN** 切到明细账，月份与仓库不变，一级品类筛选为「PLC 与控制器」，只列 A；明细账合计与类目账这一行相同

#### Scenario: 按仓库看类目账
- **WHEN** 仓库选「公司仓库」查看类目账
- **THEN** 各品类按公司仓库的流水汇总，不显示销售成本列；合计行等于公司仓库明细账的合计
