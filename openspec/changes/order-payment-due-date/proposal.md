# Proposal

## Why

手动订单和费用订单的收款直接记在订单上，老板看板「应收未收」已经计入（BUS-081），但「其中过期未收款」仍只统计过了有效期的 PI。订单上没有约定付款的日期，系统无法判断一张手动订单是否已经拖欠。老板看到的逾期金额会偏少，业务员也无从知道哪张订单该催款。

## What Changes

- 手动订单和费用订单新增一个可选的「约定付款日」：新建时可以填，详情页可以修改或清空。修改写入操作日志。PI 转成的订单和售后补发订单不提供这个字段，它们的收款不记在订单上。
- 订单详情显示约定付款日。有效订单过了约定付款日还没付清时，标出「已逾期 n 天」。
- 老板看板「资金」里的「其中过期未收款」在过期 PI 之外，计入过了约定付款日、还没付清的有效手动订单和费用订单，按各自剩余未收的原币金额分币种合计。没有填约定付款日的订单不算逾期。
- 不改 PI 的过期规则，也不改「风险提醒」里「过期未收款 PI」的数量和「过期未收款的 PI」卡片。它们仍只看 PI，并且链到 PI 列表。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `sales/sales-order`：新增「订单约定付款日」需求，覆盖手动订单和费用订单的约定付款日（新建时填写、详情修改、逾期标记）。
- `system/workbench`：「老板看板」的资金部分，「其中过期未收款」计入过了约定付款日、还没付清的手动订单和费用订单。

## Impact

- **数据库**：`sales_order` 新增可空列 `payment_due_date`（DATE），需要一个新的 Flyway 迁移。只加列，回退时删掉这一列即可，已有订单的取值都是空。
- **后端**：
  - 手动建单、新建费用订单的请求增加可选的 `paymentDueDate`。
  - 新增「修改约定付款日」接口，权限同修改销售日期。
  - `SalesOrderVO` 返回约定付款日和逾期天数。
  - `BossWidgets.cashWidget` 的过期未收款合计要计入这些订单。
- **前端**：
  - 手动建单弹窗、新建费用订单弹窗各加一个日期选择。
  - 订单详情信息卡加「约定付款日」字段，带编辑按钮和逾期标记。
  - UI 按项目规则先出 OpenPencil 原型，经确认后再开发。
- **配置**：没有新的 `.env` 配置项。
