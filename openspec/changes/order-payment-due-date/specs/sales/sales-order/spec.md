# Spec Delta

## ADDED Requirements

### Requirement: 订单约定付款日
手动创建的订单与费用订单 SHALL 可以记录选填的「约定付款日」（客户承诺付清的日期），用于判断是否拖欠：新建手动订单、新建费用订单时可以填写；有效订单（进行中或已完成，非历史迁移）的详情可以修改或清空，修改写操作日志（原值 → 新值），能看订单详情的人都可以修改，同修改销售日期。约定付款日不能早于销售日期，之后改销售日期也不能晚于约定付款日。PI 转成的订单与售后补发订单的收款不记在订单上，不提供这个字段，直接调用接口时提示「这张订单的收款不记在订单上，不能设置约定付款日」。

#### Scenario: 建单时填约定付款日
- **WHEN** 业务员手动创建订单，销售日期 2026-11-16，约定付款日选 2026-12-15
- **THEN** 订单详情显示约定付款日 2026-12-15

#### Scenario: 不填
- **WHEN** 业务员手动创建订单时没有填约定付款日
- **THEN** 订单正常生成，详情约定付款日显示「—」，不判断逾期

#### Scenario: 早于销售日期
- **WHEN** 订单销售日期 2026-11-16，业务员把约定付款日改为 2026-11-10
- **THEN** 系统提示「约定付款日不能早于销售日期」，不保存

#### Scenario: 改销售日期晚于约定付款日
- **WHEN** 今天 2026-11-16，订单约定付款日 2026-11-10，业务员把销售日期改为 2026-11-12
- **THEN** 系统提示「销售日期不能晚于约定付款日」，不保存

#### Scenario: 修改写日志
- **WHEN** 业务员把 SO20261116002 的约定付款日从 2026-12-15 改为 2026-12-31
- **THEN** 详情显示 2026-12-31，操作日志记录「修改约定付款日 2026-12-15 → 2026-12-31」

#### Scenario: PI 转成的订单没有这个字段
- **WHEN** 打开由 PI 转成的订单详情
- **THEN** 信息卡没有「约定付款日」

### Requirement: 订单逾期未收款标记
有效的手动订单或费用订单，约定付款日早于今天、收款状态不是「已到账」时 SHALL 视为逾期未收款：订单详情的约定付款日旁标「已逾期 n 天」（n = 今天 − 约定付款日）。付清（收款状态「已到账」）、订单取消或清空约定付款日后不再标记；约定付款日当天不算逾期。

#### Scenario: 过了约定付款日还没付清
- **GIVEN** 今天 2026-12-20，订单约定付款日 2026-12-15，合计 USD 1,000.00，已到账 USD 400.00
- **WHEN** 打开订单详情
- **THEN** 约定付款日旁显示「已逾期 5 天」

#### Scenario: 当天不算逾期
- **GIVEN** 今天 2026-12-15，订单约定付款日 2026-12-15，还没付款
- **WHEN** 打开订单详情
- **THEN** 不显示逾期标记

#### Scenario: 付清后不再标记
- **WHEN** 逾期订单登记到账后收款状态变为「已到账」
- **THEN** 详情不再显示「已逾期」
