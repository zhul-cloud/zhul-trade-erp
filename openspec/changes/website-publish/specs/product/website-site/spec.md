## Purpose

站点管理：一个公司可以有一个或多个独立站（站群），每个站点有自己的网址、语言、发布方式、代码仓库与部署凭据、商品范围、品类对照、售价规则和清缓存要求，供独立站发布使用。

## ADDED Requirements

### Requirement: 站点

有站点管理权限的用户 SHALL 能在「运营管理 → 站点管理」新建、修改、停用本公司的站点。一个公司可以有多个站点，网址在全平台唯一。每个站点有以下配置：

| 配置 | 规则 |
| --- | --- |
| 名称 | 必填，本公司内唯一，最长 50 字 |
| 网址 | 必填，`https://` 开头，不带路径，如 `https://fouwell.com` |
| 语言 | 至少一种，可选英文、俄文；每种语言有地址前缀（英文默认为空，俄文默认 `/ru`），第一种为默认语言 |
| 商品页地址模板 | 必填，包含 `{slug}`，如 `/products/{slug}/`；完整链接 = 网址 + 语言前缀 + 模板 |
| 发布方式 | 「自动发布」或「只复制」；只复制时不需要仓库与部署配置，按现在的手工方式发布 |
| 代码仓库 | 自动发布时必填：仓库地址（`https://` 开头）、分支、访问令牌 |
| 部署 | 自动发布时必填：方式为 SSH 同步，填写主机、端口、用户、目标目录、私钥 |
| IndexNow 密钥 | 选填；填了以后发布成功时向 Bing、Yandex 推送 |
| 商品范围 | 选填，按品牌、品类（含下级）筛选，空表示本公司全部商品 |
| 非正品品牌 | 选填，品牌列表；这些品牌的商品不出现「正品」类说法 |
| 售价规则 | 系数（默认 1.05，0.5–10，两位小数）、币种（美元） |
| 需要人工清缓存 | 是或否；选是时填写清缓存的操作说明（最长 500 字），确认上线时显示 |
| 状态 | 启用或停用 |

访问令牌、私钥、IndexNow 密钥 SHALL 加密保存。页面和接口只显示「已配置」和末四位，不返回明文；修改时留空表示不变。日志、发布单步骤记录、错误信息里都不能出现这些凭据。

站点停用后不能发布；已发布的商品留在站点上，发品任务保持「已发布」。

#### Scenario: 新建 fouwell.com
- **WHEN** 管理员新建站点「Fouwell」：网址 `https://fouwell.com`，语言英文（无前缀）和俄文（`/ru`），模板 `/products/{slug}/`，自动发布，填写仓库、部署和 IndexNow 密钥，需要人工清缓存
- **THEN** 站点保存成功，为「接管中」（见 `product/website-import`）；凭据显示为「已配置 ····a1b2」

#### Scenario: 网址重复
- **WHEN** 另一家公司也新建网址为 `https://fouwell.com` 的站点
- **THEN** 系统拒绝并提示「这个网址已被其他站点使用」

#### Scenario: 凭据不回显
- **WHEN** 管理员打开站点配置
- **THEN** 访问令牌一栏显示「已配置 ····a1b2」，接口返回中没有令牌明文

### Requirement: 检测连接

有站点管理权限的用户 SHALL 能对自动发布的站点点「检测连接」。系统通过发布服务检查四项，逐项显示「通过」或失败原因，不改变站点和线上内容：
- 能拉取仓库；
- 仓库里有 ERP 适配脚本（见 `product/website-publish`「站点数据约定」）；
- 能登录部署服务器，并写入目标目录；
- 网址能访问。

#### Scenario: 部署私钥不对
- **WHEN** 管理员检测连接，部署私钥与服务器不匹配
- **THEN** 前两项通过，「部署服务器」显示「登录失败：密钥被拒绝」，网址一项照常检测

### Requirement: 品类对照

自动发布的站点 SHALL 维护「ERP 品类 → 站点品类」的对照。站点品类是站点自己的品类代码（如 `controllers`、`drives`），可以在站点上新增。对照按二级品类设置，二级品类没有设置时用一级品类的对照。

发布时商品的品类找不到对照，这个商品不能发布，并提示「品类『xx』还没有对照站点品类」。对照修改后，已发布商品的站点品类变了，这些商品的任务标「内容有更新」。

#### Scenario: 用一级品类兜底
- **GIVEN** 一级品类「传感器」对照为 `sensors`，二级品类「接近开关」没有单独设置
- **WHEN** 发布一个品类为「接近开关」的商品
- **THEN** 这个商品的站点品类为 `sensors`

### Requirement: 站点管理权限

站点 SHALL 由菜单权限「站点管理」控制能否查看，按钮权限「修改站点」控制新建、修改、停用、检测连接、品类对照、导入与比对。只能看到和管理本公司的站点。两项权限加入租户套餐，内置管理员角色拥有全部。

#### Scenario: 只能看
- **WHEN** 只有「站点管理」菜单权限的用户打开站点配置
- **THEN** 可以查看（凭据只显示是否已配置），没有保存、检测连接、导入按钮
