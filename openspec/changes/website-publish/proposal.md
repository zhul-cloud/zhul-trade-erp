## Why

独立站 fouwell.com 现有 148 个商品，商品数据、图片、视频、俄文翻译都由本机 llm-wiki 的「工作流 G」手工维护，部署也要在本机运行脚本。ERP 已经能生成独立站的英文和俄文营销内容，也会生成独立站的发品任务，但最后一步仍要人手工搬运。

用户 2026-11-26 定：
- 由 ERP 统一管理独立站的商品信息、价格和素材，先预览，再一键发布；
- 发布后自动完成构建、检查、部署，把上线链接写回 ERP，由人工确认；
- 已上线的商品先导入 ERP 统一管理；
- 以后要支持一个公司有多个独立站（站群），独立站的配置做成可配置。

## What Changes

- **站点管理（新）**：「运营管理 → 站点管理」，一个公司可以有多个站点。每个站点的配置：
  - 名称、网址、语言（英文、俄文，各自的地址前缀）、商品页地址模板；
  - 发布方式：自动发布，或只复制（站点没有接入时退回现在的手工方式）；
  - 代码仓库与分支、仓库令牌、部署服务器（SSH 主机、端口、用户、目录、私钥）、IndexNow 密钥；令牌、私钥、密钥加密保存，页面只显示是否已配置；
  - 商品范围（按品牌、品类，空表示全部）、品类对照（ERP 品类 → 站点品类）、非正品品牌名单、售价规则（询价最低价 × 系数，默认 1.05，换算成美元）；
  - 发布后是否需要人工清缓存，以及清缓存的操作说明。
- **站点商品（新）**：每个商品在每个站点上一条记录，包括链接别名（发布后锁定）、售价和来源、站点状态、导入时站点原有的内容、上次发布的快照。
- **预览与一键发布（新）**：
  - 预览逐个商品显示页面上会出现的内容（英文、俄文、规格、图片、视频、价格、链接），以及与上次发布相比的差异和检查结果。
  - 阻断项必须先处理：品类没对照、缺少必填字段、没有图片、链接别名冲突。提醒项可以照样发布：没有价格、没有视频、非正品品牌。
  - 点「发布」生成一张发布单，可以一次包含多个商品。
- **发布服务（新容器 `site-publisher`）**：按发布单依次执行：拉取仓库 → 写入站点数据和素材 → 运行站点自己的构建脚本 → 用真实浏览器在本地检查（主图能加载、缩略图数量对、视频区块在，英文和俄文都查）→ 提交 → 部署 → 线上检查 → 推送仓库 → 推送 IndexNow → 把链接写回 ERP。同一站点同一时间只执行一张发布单；任何一步失败都会停下，并记录在哪一步、什么原因。
- **导入站点现有商品（新）**：
  - 读取站点仓库里现有的商品数据，按品牌加型号匹配商品档案，预览「已匹配 / 未匹配 / 字段差异」。
  - 确认后写入站点商品，把这个站点的发品任务标为已发布并带上线上链接。
  - 导入后做一次「一致性比对」：用 ERP 数据试构建，与线上现有数据逐个字段对比。差异全部消除或确认后，站点才切换为「以 ERP 为准」，在这之前不能从 ERP 发布。
- **同步更新**：已发布商品的营销内容、规格、售价、用于发品的素材变了，这个站点的任务就标「内容有更新」，运营预览差异后一键同步。
- **发品任务改动**：
  - 独立站按站点各生成一个任务（「商品 × 站点」）；
  - 自动发布的站点不能手工标「已发布」，状态为 待发布 → 发布中 → 已上线待确认 → 已发布；
  - 确认时，如果站点要求人工清缓存，要先勾选「已清缓存」。
- **站点仓库适配**（在 `fouwell-website` 仓库里做）：新增 ERP 数据适配脚本（把 ERP 的站点数据转成 `data.js`、`photos.js`、`videos.js`、`i18n-ru.js`，然后构建）、检查脚本，以及导出现有商品的脚本。
- **菜单**：「运营管理」最后新增「站点管理」。

不做：
- 商品下架或从站点删除；
- 多个站点分别维护不同的营销内容（先共用一份，按商品范围区分）；
- 页面截图预览；
- 自动清 SiteGround 缓存；
- 网址跳转（链接别名发布后锁定）；
- 收录跟踪（见 `website-index-tracking`）。

## Capabilities

### New Capabilities
- `product/website-site`：站点管理（站点配置、凭据、商品范围、品类对照、售价规则、清缓存提示、接管状态）。
- `product/website-publish`：站点商品、发布预览与检查、一键发布与发布单、发布步骤与失败处理、同步更新、站点数据约定。
- `product/website-import`：导入站点现有商品、一致性比对、切换为以 ERP 为准。

### Modified Capabilities
- `product/listing-task`：独立站按站点生成任务；站点停用时取消；自动发布站点的状态和确认（含清缓存勾选）；内容更新的判断范围扩大到规格、售价、素材；列表显示站点名。
- `system/navigation`：「运营管理」新增「站点管理」。

## Impact

- **数据库**：
  - 新建五张表：站点、站点凭据（加密）、站点品类对照、站点商品、发布单（含明细和步骤日志）；
  - 发品任务加站点字段，以及「发布中」「已上线待确认」两个状态；
  - 新增菜单「站点管理」，以及站点管理、发布、确认上线三个权限。
- **后端**：站点服务、售价计算（询价回价最低价 × 系数 ÷ 美元汇率，保留 2 位小数，四舍五入）、站点数据导出、发布单调度与回调、导入与比对、发品任务的状态改动。
- **前端**：站点管理（列表、配置、导入、比对）；发品任务里独立站的预览、发布、发布单进度、确认上线。
- **部署**：
  - 新增 `site-publisher` 容器（git、Node、Chromium、rsync，限制处理器和内存），只在内网访问；
  - 新增共享令牌配置项；
  - 生产服务器需要能访问 GitHub 和 SiteGround 的 SSH。
- **外部仓库**：`zhul-cloud/fouwell-website` 要合并适配脚本（单独提 PR）。
- **原型**：站点管理、导入与比对、发布预览、发布单进度、确认上线，先出 OpenPencil 原型，用户确认后再开发。
- **依赖**：依赖 `product-video-task`（视频素材）；`website-index-tracking` 依赖本变更。
