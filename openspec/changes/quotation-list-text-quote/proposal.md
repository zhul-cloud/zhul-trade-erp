# Proposal

## Why

报价管理、形式发票列表只显示型号数，看不出报的是什么货，要逐张点开；询盘管理列表已经显示型号、品牌、品类。文字报价只能进详情页打开，发给客户前还要手改货况、货期：给客户的报价一般统一写全新原装，货期要在采购报的基础上留出余量，现在每次都要逐行改文字。

## What Changes

- 报价管理、形式发票列表：「型号数」改为「型号」列（首个型号，下面一行「共 N 个型号 · 查看」，点开看全部），新增「品牌」「品类」两列，显示方式与询盘管理列表一致。
- 报价管理列表操作列新增「文字报价」，打开与详情页相同的弹窗。
- 文字报价弹窗新增两个下拉：
  - 报价货况：默认「全新原装」，选定后所有有货行按所选货况输出。
  - 报价货期：默认「按采购货期顺延」，每行取采购回价的货期往后挪一档（现货→1-2天、3-5天→5-7天）；也可以选一档货期统一输出。
  - 只影响本次生成的文字，不改报价单、不改模版。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `quotation/quotation`：「文字报价」增加报价货况、报价货期；「报价单列表与查看范围」显示型号、品牌、品类并提供文字报价入口。
- `sales/proforma-invoice`：「PI 列表与查看范围」显示型号、品牌、品类。

## Impact

- 后端：报价单、PI 列表接口增加首个型号、品牌、品类（按明细去重）；文字报价接口增加货况、货期两个可选参数；不改表结构，没有数据库迁移。
- 前端：`quotation/index.tsx`、`sales/pi/index.tsx` 列表列；`quotation/dialogs.tsx` 文字报价弹窗；列表复用询盘列表的型号、标签组件。
- 不涉及金额计算与财务数据。
