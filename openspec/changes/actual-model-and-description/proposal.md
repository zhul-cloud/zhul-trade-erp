# Proposal

## Why

客户询盘写的型号常常不完整或有误（如询价 LC2D18B7，真实型号是 LC2D18B7C）。系统里已有「真实型号」字段，但按现行规则它只用于商品建档：报价、PI、销售订单、采购需求、采购订单一路沿用询盘的确认型号，采购照单去买就会买错，仓库验货、CI/PL 报关也和实物对不上。另外，询盘的描述已经一路带到了销售订单，但销售订单详情不显示，采购需求和采购订单根本没有描述，采购只能看型号。

## What Changes

- **真实型号由业务员和采购共同维护**：沿用询盘型号上现有的一个「真实型号」，采购照旧在「我的询价」填，业务员可以在询盘详情和报价单草稿里填或改；后填的覆盖先填的，记录最后修改人与时间。
- **单据型号以真实型号为准**（**BREAKING**：推翻现行规则「真实型号只影响建档，不改变询盘确认的型号与已发出的报价」）：新生成的报价单、PI、销售订单、采购需求、采购订单的型号，有真实型号时取真实型号，没有时仍取确认型号。
- **保留客户型号作为参考**：报价单、PI、销售订单的型号与客户询价时的型号不同时，型号下面显示「客户型号：…」；单据模版新增占位符 `${item.customerModel}`（型号相同时为空），租户可以加到报价单、文字报价、PI 模版里。CI、PL 和采购侧只显示真实型号。
- **后改真实型号的处理**：还没给外部看到的单据自动跟着改（报价单草稿、PI 草稿、销售订单中还没发货的型号行、对应的采购需求、草稿采购订单）；已经发给客户或供应商的单据不自动改，型号旁标出「真实型号已更新为 …」，提醒人去沟通（已发出的报价单、已发出的 PI、已下单的采购订单）。
- **描述带到采购侧并显示**：销售订单详情的型号明细增加「描述」列（中文描述，数据已有）；采购需求、采购订单增加描述，生成时从销售订单型号行带过来，存量数据由迁移回填；采购需求与采购订单详情显示描述。
- 涉及的列表与详情明细先出 OpenPencil 原型，经确认后再开发页面。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `inquiry/sourcing-quote`：「采购回填真实型号」不再只影响建档；回填后按新规则带到下游单据。
- `inquiry/inquiry-intake`：业务员在询盘详情填写、修改真实型号；记录最后修改人与时间。
- `quotation/quotation`：生成报价行时型号取真实型号并记录客户型号；草稿可改真实型号；草稿自动跟随、已发送版本提示真实型号已更新；明细显示客户型号。
- `sales/proforma-invoice`：PI 行带上客户型号；草稿自动跟随，已发送提示；明细显示客户型号。
- `sales/sales-order`：型号明细增加描述列与客户型号；未发货型号行自动跟随真实型号。
- `purchase/purchase-requirement`：需求记录描述；型号随销售订单行的真实型号更新；列表显示描述。
- `purchase/purchase-order`：采购订单行记录描述并在详情显示；草稿行自动跟随真实型号，已下单的行提示与供应商核对。
- `document/document-template`：报价单、文字报价、PI 模版新增占位符 `${item.customerModel}`。

## Impact

- **数据库**：新迁移（版本号开发时按当时最新顺延，预计 V1.5.45，可回退）。
  - `inquiry_item`：加最后修改真实型号的人与时间。
  - `quotation_item`、`pi_item`、`sales_order_item`：加客户型号 `customer_model`。
  - `purchase_requirement`、`purchase_order_item`：加描述 `description`，并从 `sales_order_item` 回填。
- **后端**：
  - 询盘：真实型号保存接口增加业务员入口。
  - 报价、PI、销售订单、采购需求、采购订单：生成逻辑取真实型号，并带上客户型号、描述。
  - 真实型号变更后同步更新下游单据：询盘模块发布同步事件，报价、销售、采购模块各自处理，与保存真实型号在同一事务内。
  - 单据渲染新增占位符。
- **前端**：
  - 询盘详情、报价单编辑可以填写真实型号。
  - 共用的单据型号单元格显示客户型号和「真实型号已更新」提示。
  - 销售订单、采购需求、采购订单的明细增加描述列。
- **对用户的影响**：
  - 已有单据不会因为上线而改变。
  - 上线后填写或修改真实型号，会改动上述还在内部的单据。
  - 发给客户的报价单、PI 默认版式不变；要在单据上显示客户型号，需要在模版里加上新占位符。
- **不涉及**：
  - 价格台账、询价记录、商品匹配仍按确认型号或真实型号的现有规则。
  - 手动创建的销售订单行（没有来源询盘）不变。
  - 没有新的配置项。
