# Spec Delta

## MODIFIED Requirements

### Requirement: 订单型号明细格式与商品档案跳转
销售订单详情的型号明细 SHALL 按「单据型号明细格式」显示：品牌、品类、型号为三列，每行都显示品牌与品类；型号下面依次显示客户型号（与型号忽略大小写、空格与符号后不同时显示「客户型号：…」）、订货号（有时）与「查看素材」；型号列之后紧跟「描述」列，显示型号行的中文描述（来自报价行，没有时显示「—」，过长时折行）。明细不显示来源单号，来源单号（形式发票号、售后单号、原订单号或「手动创建」）只在表头显示（见「来源单号」）。型号对应的商品档案按以下顺序确定：订单行自身记下的商品档案（手动订单）；来源询盘型号已建档的商品档案；按品牌 + 型号匹配到的商品档案。有商品档案菜单权限的人点型号，在当前标签打开该商品档案详情，并可按「跳转后可返回原页面」回到这张订单；没有权限或没有对应商品档案时，型号只显示文字。订单导出与发给客户的单据版式不变。

#### Scenario: 由 PI 转成的订单
- **WHEN** 订单由 PI20261104002 转成，型号 6ES7214-1AG40-0XB0 的来源询盘型号已建档，订货号 6ES7214-1AG40-0XB0
- **THEN** 该行品牌列显示 SIEMENS，品类列显示品类名，型号可点击，下面显示订货号与「查看素材」；明细没有来源列，表头说明行显示「来源单号 PI20261104002」

#### Scenario: 手动订单
- **WHEN** 打开一张新建的手动订单
- **THEN** 型号按建单时选的商品档案跳转，表头来源单号显示「手动创建」，描述列显示「—」

#### Scenario: 没有商品档案权限
- **WHEN** 只有销售订单权限、没有商品档案菜单权限的业务员打开订单
- **THEN** 型号显示为普通文字，不能点击

#### Scenario: 显示描述与客户型号
- **WHEN** 订单行型号 LC2D18B7C，客户型号 LC2D18B7，描述「接触器 18A 线圈 AC24V」
- **THEN** 型号下面显示「客户型号：LC2D18B7」，描述列显示「接触器 18A 线圈 AC24V」

## ADDED Requirements

### Requirement: 真实型号变更后的销售订单

来源询盘型号的真实型号被填写、修改或清空后，系统 SHALL 在同一次保存中把引用该询盘型号、还没有出库（该型号行没有未作废的出库记录）且未取消的销售订单型号行更新为新的单据型号（客户型号随之更新），并按「真实型号变更后的采购需求」「真实型号变更后的采购订单」同步采购侧。已有出库记录或已取消的型号行不修改、不提示。订单的金额、数量与进度不变。

#### Scenario: 还没发货的订单跟着改

- **GIVEN** 订单 SO20261118001 的型号行 LC2D18B7 进度为「已下单」，还没有出库
- **WHEN** 采购填写真实型号 LC2D18B7C
- **THEN** 该订单行型号变为 LC2D18B7C，下面显示「客户型号：LC2D18B7」，单价、数量与进度不变

#### Scenario: 已出库的型号行不改

- **GIVEN** 订单行 LC2D18B7 已经出库交给货代
- **WHEN** 业务员填写真实型号 LC2D18B7C
- **THEN** 该订单行型号仍为 LC2D18B7，不显示提示

### Requirement: 转订单时型号以真实型号为准

PI 转成销售订单时，有来源询盘型号的型号行 SHALL 取该询盘型号当前的单据型号（有真实型号取真实型号，否则取确认型号），并记下客户型号；采购需求随订单行生成，采购照这个型号买。PI 上客户看到的型号不变。

#### Scenario: PI 发出后才填了真实型号

- **GIVEN** 已发送的 PI 第 1 行型号 LC2D18B7，之后采购填写了真实型号 LC2D18B7C
- **WHEN** 业务员把这张 PI 转成订单
- **THEN** 订单第 1 行型号为 LC2D18B7C，下面显示「客户型号：LC2D18B7」，生成的采购需求型号为 LC2D18B7C
