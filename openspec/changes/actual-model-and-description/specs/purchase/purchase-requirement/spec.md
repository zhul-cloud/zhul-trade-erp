# Spec Delta

## MODIFIED Requirements

### Requirement: 由销售订单生成采购需求
销售订单生成时（由 PI 转成或手动创建），系统 SHALL 在同一事务内为每个型号行生成一条采购需求，记录：
- 来源订单与型号行、型号、品牌、品类、描述（型号行的中文描述，没有时为空）、需求数量（等于型号行数量）；
- 目标价：型号行的采购成本价（人民币、不含税），生成时快照，之后修改询价记录或回价不影响；没有采购成本价时为空；
- 采购员：型号行的采购员（可为空）；
- 建议采购渠道：被选为采购成本价的那条回价的供应商；回价来自线上店铺、没有关联供应商时，记录平台与店铺名称（同样是确定的采购渠道）；没有回价时为「还没定」。

上线时，为「有效」且型号行进度为「待采购」的存量订单补生成需求；进度已在「待采购」之后的型号行视为已在系统外下单，不生成需求。已有的采购需求按来源订单型号行回填描述。

#### Scenario: 转订单生成需求
- **WHEN** PI 转成订单 SO20261009001，型号 A × 100（采购成本价 ¥1,000.00，回价来自供应商甲、询价人张三），B × 20（没有回价）
- **THEN** 生成两条需求：A × 100、目标价 ¥1,000.00、采购员张三、建议供应商甲；B × 20、目标价为空、采购员为空、建议供应商为空

#### Scenario: 目标价不随回价变化
- **WHEN** 订单生成后，有人在询价记录里把 A 的回价改为 ¥950.00
- **THEN** 需求 A 的目标价仍为 ¥1,000.00

#### Scenario: 记录品类
- **WHEN** 订单型号行 A 的品类为「PLC」
- **THEN** 需求 A 的品类为「PLC」，采购需求列表的型号列显示「6ES7214-1AG40-0XB0 · 西门子 · PLC」

#### Scenario: 记录描述
- **WHEN** 订单型号行 A 的描述为「CPU 1214C DC/DC/DC」
- **THEN** 需求 A 的描述为「CPU 1214C DC/DC/DC」

## ADDED Requirements

### Requirement: 采购需求显示描述

采购需求页的两个视图（按订单展开的型号行、按型号）SHALL 在型号列之后显示「描述」列，内容为需求记录的描述，没有时显示「—」，过长时折行；关键字筛选同时匹配描述。

#### Scenario: 按描述找需求

- **WHEN** 采购员在采购需求页关键字输入「线圈 AC24V」
- **THEN** 列出描述含「线圈 AC24V」的需求，描述列显示完整描述

### Requirement: 真实型号变更后的采购需求

销售订单型号行因真实型号变更而更新型号时，系统 SHALL 在同一次保存中把该型号行的采购需求（「订单已取消」的除外）的型号改为新型号，并更新需求的更新时间；需求的数量、目标价、采购员与渠道不变。

#### Scenario: 需求跟随订单行

- **GIVEN** 订单行 LC2D18B7 的采购需求还没下单
- **WHEN** 该订单行因真实型号变为 LC2D18B7C
- **THEN** 采购需求型号变为 LC2D18B7C，按订单视图里该订单排到前面（更新时间为现在）
