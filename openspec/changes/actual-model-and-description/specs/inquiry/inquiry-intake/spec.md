# Spec Delta

## ADDED Requirements

### Requirement: 业务员填写真实型号

询盘单详情的型号明细 SHALL 让能修改该询盘的人（按现有修改询盘的权限与数据权限）填写或修改每个型号的「真实型号」（≤128 字，清空表示没有真实型号）。它与采购在「我的询价」填写的是同一个值，后填的覆盖先填的；询盘已取消时不能修改。保存后按真实型号重新做商品匹配（规则同「采购回填真实型号」），并带到下游单据。

#### Scenario: 业务员和客户确认后填写

- **GIVEN** 询盘型号 LC2D18B7 还没有真实型号
- **WHEN** 业务员和客户确认后，在询盘详情给该型号填写真实型号 LC2D18B7C
- **THEN** 保存成功，型号下面显示「真实型号：LC2D18B7C」，采购在「我的询价」看到同一个真实型号

#### Scenario: 后填的覆盖先填的

- **GIVEN** 采购已填写真实型号 LC2D18B7C
- **WHEN** 业务员把真实型号改为 LC2D18B7D
- **THEN** 询盘详情与「我的询价」都显示 LC2D18B7D

#### Scenario: 已取消的询盘

- **WHEN** 业务员在已取消的询盘里修改真实型号
- **THEN** 系统拒绝并提示「询盘已取消，不能修改」

### Requirement: 真实型号修改记录

系统 SHALL 记录每个询盘型号真实型号的最后修改人与修改时间（不论由业务员还是采购修改）。询盘详情与「我的询价」在真实型号旁显示「由 某人 于 时间 填写」；清空真实型号时一并清空记录。

#### Scenario: 显示最后修改人

- **WHEN** 采购张三于 11 月 18 日 10:20 填写真实型号 LC2D18B7C
- **THEN** 询盘详情该型号显示「真实型号：LC2D18B7C」，旁边显示「张三 · 2026-11-18 10:20」
