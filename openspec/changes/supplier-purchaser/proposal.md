# Proposal

## Why

用户 2026-11-26 反馈：新增供应商时希望能指定「所属采购员」，一眼知道这家供应商归谁对接。现在供应商上没有负责人，只能凭记忆或去翻采购订单。

## What Changes

- 供应商增加「所属采购员」（选填，候选为本租户有效用户），新增、编辑时可选，供应商详情显示。
- 供应商列表增加「所属采购员」列（只显示）。
- 只做登记，不参与其他业务：不带入采购需求、采购订单，不限制数据权限。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `master-data/supplier`：供应商增加所属采购员，新增、编辑时选择，详情与列表显示。

## Impact

- 数据库：供应商表加「所属采购员」一列（用户 ID，加索引），无回填，可回退。
- 后端：供应商保存、详情、列表返回所属采购员。
- 前端：供应商新增 / 编辑表单、详情、列表列。
- 与 `feat/ui-redesign` 分支同样改动供应商列表，合并时需处理冲突。
