# access/data-scope Specification

## Purpose
按角色上配置的「数据权限范围」计算当前登录用户能看到哪些负责人的业务数据，让客户等按负责人归属的数据只对相关人员可见。

## Requirements

### Requirement: 按角色数据权限范围计算可见负责人
系统 SHALL 根据当前用户的账号与主角色计算其数据可见范围：
- 管理员账号（admin_flag=1）：同租户全部数据
- 角色数据权限为「全部」：同租户全部数据
- 角色数据权限为「自定义」：负责人属于角色所配置部门（含这些部门的下级部门）的数据，加上自己负责的数据
- 角色数据权限为「仅本人」或「无权限」：只有自己负责的数据
- 没有配置主角色：按「仅本人」处理

用户所属部门取其主部门以及用户部门关联中的全部部门。

#### Scenario: 仅本人
- **WHEN** 数据权限为「仅本人」的业务员张伟查询客户列表
- **THEN** 只返回负责业务员为张伟的客户

#### Scenario: 自定义部门
- **WHEN** 业务主管王强的角色数据权限为「自定义」，配置了华东销售部，张伟和李娜属于华东销售部，赵敏属于华南销售部
- **THEN** 王强能看到张伟、李娜和他自己负责的客户，看不到赵敏负责的客户

#### Scenario: 下级部门包含在内
- **WHEN** 角色自定义配置了「销售中心」，华东销售部是销售中心的下级部门
- **THEN** 华东销售部业务员负责的客户对该角色可见

#### Scenario: 管理员不受限
- **WHEN** 租户管理员账号查询客户列表
- **THEN** 返回本租户全部客户，包括未分配负责人的客户

### Requirement: 数据范围判定在服务端强制执行
系统 SHALL 在服务端对列表、详情、编辑、删除、导出、转移、选择器搜索统一应用数据范围，不依赖前端隐藏。

#### Scenario: 越权访问详情
- **WHEN** 仅本人权限的业务员直接请求一个由其他业务员负责的客户详情接口
- **THEN** 系统返回「客户不存在或无权查看」，不返回任何客户字段

#### Scenario: 越权编辑
- **WHEN** 业务员对数据范围外的客户提交更新、删除或转移请求
- **THEN** 系统拒绝操作，数据不发生变化

### Requirement: 统计按事业部限定可见范围
利润统计、经营统计、销售统计 SHALL 按当前用户的数据权限限定可查看的事业部：

- 管理员账号或数据权限为「全部」：可查看任一事业部，也可查看全公司合计；
- 数据权限为「自定义」，且所配置的部门都在同一个事业部之内：只能查看该事业部，看不到其他事业部与全公司合计；
- 其他情况（自定义部门跨事业部或包含公共部门、仅本人）：按各统计页原有的业务员范围过滤，事业部筛选只列出其数据范围涉及的事业部，不显示全公司合计。

限定在服务端执行，直接请求其他事业部的统计数据时返回「无权查看该事业部」。

#### Scenario: 合伙人只看本事业部
- **WHEN** 中国制造网事业部合伙人（数据权限「自定义」，配置中国制造网事业部）打开经营统计
- **THEN** 只显示中国制造网事业部的数据，事业部筛选不可切换，看不到阿里国际站事业部与全公司合计

#### Scenario: 老板切换事业部
- **WHEN** 管理员打开利润统计
- **THEN** 默认显示全公司合计，可切换为阿里国际站事业部或中国制造网事业部

#### Scenario: 越权请求
- **WHEN** 阿里国际站事业部合伙人直接请求中国制造网事业部的利润统计接口
- **THEN** 系统返回「无权查看该事业部」，不返回任何数据
