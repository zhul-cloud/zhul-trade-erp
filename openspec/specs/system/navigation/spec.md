# system/navigation Specification

## Purpose
菜单框架按部门组织侧边栏：每个部门的人打开系统先看到自己部门的一组菜单，组内按业务流程先后排列；同时约定菜单命名规则，让以后新增的模块按同一框架挂进来。

## Requirements

### Requirement: 按部门分组的菜单框架
系统 SHALL 按以下分组与顺序组织侧边栏（括号内为尚未上线、上线时挂入该分组的功能）：
- 工作台
- 销售管理：商机、客户、询盘单、报价单、PI、销售订单、销售统计
- 采购管理：兼职看板、询价分配、我的询价、询价记录、采购需求、采购订单、供应商发货、供应商、询价统计、砍价统计
- 仓库管理：采购入库、销售出库、闲置库存、实拍任务
- 物流管理：出运单、运费账单
- 财务管理：收款单、退款单、结汇单、应付单、付款单、报销单、费用单、其他收入、利润统计、经营统计（、应收）
- 商品管理：商品、商品候选、资料任务、品牌、品类、系列（价格体系上线后归入商品管理或单独分组，届时再定）
- 运营管理：商品运营
- 业务设置：定价策略、汇率、收款账户、单据模板、编号规则、快递时效
- 系统管理：用户、角色、部门、岗位、菜单、字典、系统设置、操作日志、登录日志
- 租户管理（仅平台账号）：租户、套餐

侧边栏按当前用户的菜单权限过滤：分组下没有可访问的菜单时整个分组不显示；没有页面的分组与菜单不出现在侧边栏。调整分组不改变各页面的访问地址，原有书签与链接继续可用。

#### Scenario: 业务员的侧边栏
- **WHEN** 业务员（有工作台、商机、客户、询盘单、报价单、PI、销售订单与询价记录权限）登录
- **THEN** 侧边栏依次为「工作台」「销售管理」（商机、客户、询盘单、报价单、PI、销售订单、销售统计）「采购管理」（询价记录），不出现财务管理、业务设置与系统管理

#### Scenario: 采购员的侧边栏
- **WHEN** 采购员（有询价分配以外的采购菜单与供应商权限）登录
- **THEN** 侧边栏的「采购管理」下依次为我的询价、询价记录、采购需求、采购订单、供应商发货、供应商

#### Scenario: 未上线的功能不占位
- **WHEN** 租户管理员登录，而应收功能尚未上线
- **THEN** 「财务管理」下没有应收菜单

#### Scenario: 原地址继续可用
- **WHEN** 业务员打开调整前收藏的询盘单详情链接
- **THEN** 页面正常打开，面包屑显示「销售管理 / 询盘单 / …」

#### Scenario: 仓库人员的侧边栏
- **WHEN** 内置角色「仓库」的用户登录
- **THEN** 侧边栏只有「工作台」「仓库管理」（采购入库、销售出库、闲置库存、实拍任务）与「财务管理」（报销单）

#### Scenario: 财务的侧边栏
- **WHEN** 有收款单、结汇单、应付单、付款单、报销单、费用单、利润统计权限，没有退款单、其他收入、经营统计权限的财务登录
- **THEN** 「财务管理」下依次为收款单、结汇单、应付单、付款单、报销单、费用单、利润统计

#### Scenario: 采购员看到报销单
- **WHEN** 有采购订单菜单的采购员登录
- **THEN** 侧边栏出现「财务管理」，下面只有「报销单」

#### Scenario: 采购负责人看到砍价统计
- **WHEN** 有「询价分配」菜单的采购负责人登录
- **THEN** 「采购管理」最后两项为「询价统计」「砍价统计」；只有采购订单菜单的采购员看不到它们

#### Scenario: 财务看到利润统计
- **WHEN** 有收款单菜单的财务登录
- **THEN** 「财务管理」下有「利润统计」，排在「经营统计」之前

#### Scenario: 财务看到退款单与经营统计
- **WHEN** 有收款单菜单的财务登录
- **THEN** 「财务管理」下依次为收款单、退款单、结汇单、应付单、付款单、报销单、费用单、其他收入、利润统计、经营统计

### Requirement: 菜单命名规则
菜单名称 SHALL 遵循以下规则，新增或调整菜单时逐条对照：

- 分组叫「领域 + 管理」，只有设置类分组例外（「业务设置」「系统管理」「租户管理」）；「工作台」单独一项，不再用作其他菜单的名称。
- 叶子菜单不加「列表」「管理」「记录」等后缀，不超过四个字，按页面内容归入下列一类：
  - 单据：「对象 + 单」或外贸固定说法，如询盘单、采购订单、付款单、运费账单、PI、出运单；
  - 库存作业：「业务来源 + 入库或出库」，成对命名，如采购入库、销售出库；
  - 基础资料：直接用对象名词，如客户、供应商、品牌、汇率、闲置库存；
  - 处理入口：页面上要做分配、录入等操作的岗位入口，用「对象 + 动作」或「我的 + 对象」，如询价分配、我的询价；
  - 任务：「内容 + 任务」，如资料任务、实拍任务；
  - 看板与统计：「对象 + 看板」「对象 + 统计」，如兼职看板、商机统计。
- 看板与统计 SHALL 只读：只展示数字、图表与待办，点击后跳到对应页面处理，页面上不做分配、录入、审批等业务操作；需要操作的页面不能叫看板或统计。
- 页面标题、面包屑与菜单名称一致；页面里对该单据的称呼（详情标题、按钮说明、提示与报错文字、导出文件名）使用同一个单据名称。
- 改名只改显示的名称，页面访问地址、权限码、单据编号前缀与类型代码不变。

本次改名：业务管理 → 销售管理，客户询盘 → 询盘单，历史询价 → 询价记录，采购单 → 采购订单，入库验收 → 采购入库（入库单 → 采购入库单），出库打包 → 销售出库（出库单 → 销售出库单），暂存货 → 闲置库存，拍摄任务 → 实拍任务，单证物流 → 物流管理，货代对账 → 运费账单（对账单 → 运费账单），收款管理 → 收款单，应付管理 → 应付单，付款记录 → 付款单，商品资料（分组）→ 商品管理，单据模版 → 单据模板，单据编号（设置页）→ 编号规则。

#### Scenario: 页面标题与菜单一致
- **WHEN** 仓库人员点击「仓库管理 → 采购入库」，打开一张入库记录
- **THEN** 页面标题为「采购入库」，面包屑为「仓库管理 / 采购入库」，详情标题与提示文字称其为「采购入库单」

#### Scenario: 看板只读
- **WHEN** 兼职采购打开「兼职看板」，点击一条待处理任务
- **THEN** 跳到「我的询价」中的该任务进行录入，看板页面本身没有录入或分配的按钮

### Requirement: 调整菜单后权限不变
菜单重新分组或改名 SHALL 不改变任何角色能访问的页面与操作：原来能访问某页面的角色，调整后仍能访问且能在侧边栏看到它；新增的分组自动授给拥有其下任一菜单的角色，并加入包含这些菜单的租户套餐。

#### Scenario: 调整后仍能访问
- **WHEN** 改名前拥有「客户询盘」「报价单」权限的角色登录
- **THEN** 侧边栏「销售管理」下显示询盘单与报价单，打开后与改名前一样可用
