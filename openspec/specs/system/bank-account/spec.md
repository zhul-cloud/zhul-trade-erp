# system/bank-account Specification

## Purpose
收款银行账户让租户统一维护对客户展示的收款信息，PI 等对外单据按币种带出正确的账户，换账户时不必修改单据模板。

## Requirements

### Requirement: 维护收款账户
系统 SHALL 允许租户在「业务设置 → 收款账户」维护多个收款银行账户（需要「收款账户」编辑权限），每个账户包含：账户类型（对公账户、对私账户，新增时必选，默认对公）、币种（USD、EUR、GBP、JPY、RUB、CNY）、银行名称、账户名称、账号、SWIFT Code、银行所在国家 / 地区、银行地址、Bank Code、Branch Code、备注、状态（启用 / 停用）。同一币种可以有多个账户，该币种有启用的对公账户时，其中恰好一个为默认账户；对私账户（如法人个人账户）不能设为默认，用于私对私付款。列表显示账户类型。账号在列表与日志中脱敏显示（只显示后 4 位），详情与单据中完整显示。修改与停用写操作日志。单据前缀不在收款账户页设置（见「编号规则」）。

#### Scenario: 新增美元账户
- **WHEN** 管理员新增 JPMorgan Chase Bank N.A., Singapore Branch 的美元账户，这是第一个美元账户
- **THEN** 该账户自动成为美元默认账户，列表中账号显示为 ****7803

#### Scenario: 停用默认账户
- **WHEN** 管理员停用美元默认账户，而美元还有另一个启用账户
- **THEN** 系统提示先把另一个账户设为默认，状态不变

#### Scenario: 新增对私账户
- **WHEN** 管理员新增账户类型为「对私账户」的人民币账户「法人 张三 · 招商银行」
- **THEN** 账户保存为对私，不会成为人民币默认账户；设为默认时提示「对私账户不能设为默认」

### Requirement: 单据取用收款账户
新建 PI 时系统 SHALL 默认带出与 PI 币种相同的默认收款账户，业务员可改选同币种或其他币种的启用账户；PI 保存所选账户的内容快照，之后账户信息修改不影响已发送的 PI 版本。PI 币种没有任何启用账户时提示「还没有 USD 收款账户，请联系管理员在系统管理中添加」，仍可保存草稿但不能发送。

#### Scenario: 人民币 PI 带出人民币账户
- **WHEN** 业务员新建币种为 CNY 的 PI，租户有默认人民币账户
- **THEN** PI 的收款账户为该人民币账户

#### Scenario: 没有收款账户
- **WHEN** PI 币种为 EUR，租户没有启用的欧元账户
- **THEN** PI 可保存为草稿，发送时提示「还没有 EUR 收款账户，请联系管理员在系统管理中添加」

### Requirement: 收款账户归属事业部
每个收款账户 SHALL 属于一个事业部（新增时必选）。默认账户按「事业部 + 币种」确定：同一事业部同一币种有启用的对公账户时，其中恰好一个为默认账户。开 PI 等对外单据时，按单据所属事业部带出该事业部该币种的默认账户，也只能从本事业部的账户中选择。列表显示所属事业部并可按事业部筛选。

#### Scenario: 两个事业部各有美元默认账户
- **WHEN** 阿里国际站事业部与中国制造网事业部各有一个启用的美元对公账户
- **THEN** 两个账户分别是各自事业部的美元默认账户；中国制造网事业部的 PI 带出中国制造网事业部的美元账户

#### Scenario: 本事业部没有该币种账户
- **WHEN** 中国制造网事业部开欧元 PI，而该事业部没有启用的欧元账户
- **THEN** 系统提示「中国制造网事业部没有可用的欧元收款账户，请先在收款账户中添加」
