# logistics/freight-allocation Specification

## Purpose
把国内快递运费与国际运费分摊到箱和订单型号行：计费重取毛重与体积重（长×宽×高÷体积系数）的大者，先按计费重分到箱，再按货值分到箱内型号行；两位小数 HALF_UP，尾差给计费重最大的一项，为后续成本核算提供依据。

## Requirements

### Requirement: 运费分摊
国内运费（交国内快递时登记）与国际运费（登记出运时登记）SHALL 分摊到箱，再分摊到订单型号行，保存分摊结果，供订单实际成本使用：
- 体积重 = 长 × 宽 × 高（厘米）÷ 体积系数；计费重 = max(毛重, 体积重)；国内快递的体积系数固定为 5000，国际运费取货代主数据的体积系数（默认 5000）；
- 先按各箱计费重把运费分到箱（国内运费先按出库单的计费重之和分到出库单），再按箱内各型号的货值（订单单价 × 箱内数量，折人民币）分到型号行；
- 中间过程保持完整精度，结果按 HALF_UP 保留两位小数；尾差放到计费重最大的箱，箱内放到货值最大的行，分摊合计等于实际运费；
- 运费修改或撤销时重新分摊，旧结果作废。

#### Scenario: 尾差
- **WHEN** 国际运费 ¥100.00 分到计费重相同的 3 箱
- **THEN** 3 箱分别为 ¥33.34、¥33.33、¥33.33，合计 ¥100.00

#### Scenario: 箱内按货值
- **WHEN** 第 1 箱分到 ¥60.00，箱内 A 货值 ¥400.00、B 货值 ¥200.00
- **THEN** A 分 ¥40.00、B 分 ¥20.00
