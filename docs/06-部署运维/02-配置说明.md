# 配置

所有服务共用项目根目录的 `.env`，模板是 `.env.example`，**每个变量的含义和默认值以 `.env.example` 里的注释为准**，本文只说明需要特别注意的部分。`.env` 和 `storage/` 下的运行数据都被 Git 忽略，不要提交。

## 必填的密钥

启动后端前必须填写，每项使用不同的随机值：

| 变量 | 用途 | 注意 |
| --- | --- | --- |
| `JWT_SECRET` | 登录令牌签名，至少 32 字符 | 更换后所有人需要重新登录 |
| `AES_KEY` | 敏感配置字段加密 | **已有数据时不要更换**，否则已加密的配置无法解密 |
| `AI_TASK_CALLBACK_TOKEN` | 后端与 AI 编排服务之间的回调令牌 | 两个服务读同一个变量，只配一次 |

`scripts/docker-dev` 会自动生成空着的这三项。手动生成：Linux / macOS 运行三次 `openssl rand -hex 32`；PowerShell 7 运行三次：

```powershell
[Convert]::ToHexString([System.Security.Cryptography.RandomNumberGenerator]::GetBytes(32))
```

AI 解析的服务商（Claude 或 OpenAI）和 API Key 不在 `.env` 中，由每个租户在系统的「业务设置 → AI 设置」中填写，见 [AI 编排服务](04-AI编排服务.md)。

## 写 `.env` 的注意事项

- `$` 可能参与 Compose 变量插值，含特殊字符的值用单引号，例如 `DB_PASSWORD='包含$符号的密码'`。
- 不要把凭据作为镜像构建参数。
- 检查配置用 `docker compose --profile app config --quiet`。完整的 `config` 输出会展开所有密钥，不要公开粘贴。
- 改了 `.env` 后用 `docker compose up -d <服务名>` 重建容器才会生效，单纯 `restart` 不会加载新的变量。

## 端口与地址

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `WEB_BIND_ADDRESS` / `WEB_PORT` | `0.0.0.0` / `8000` | 浏览器访问入口 |
| `CORS_ALLOWED_ORIGINS` | 空（只允许 `http://localhost:*`） | 用户访问的页面地址，逗号分隔；**生产必须填写**，否则登录等请求返回 403 |
| `BACKEND_BIND_ADDRESS` / `BACKEND_HOST_PORT` | `127.0.0.1` / `8080` | 分服务器时改成本机内网 IP |
| `MYSQL_BIND_ADDRESS` / `MYSQL_HOST_PORT` | `127.0.0.1` / `3306` | 本机开发连接用 |
| `REDIS_BIND_ADDRESS` / `REDIS_HOST_PORT` | `127.0.0.1` / `6379` | 同上 |

宿主机端口和容器内端口不同。例如 `MYSQL_HOST_PORT=3307` 时，本机 Java 连 `localhost:3307`，容器里的后端仍然连 `mysql:3306`。

容器名是固定的（`zhul-erp-*`），同一个 Docker Engine 上只能运行一套；不同服务器可以各自使用这些名称。

## HTTPS

前端容器监听 HTTP 80，宿主机默认映射 8000。公网生产应使用现有负载均衡或网关的 HTTPS 入口，或为 Nginx 配置 TLS。TLS 在前置网关终止时，按实际受信代理拓扑配置协议转发；当前 Nginx 使用自身的 `$scheme`，不会无条件信任客户端传入的 `X-Forwarded-Proto`。验证登录、跳转、Cookie 和回调地址后再对外开放。

## 其他

- `DB_CONNECT_RETRIES`（默认 12）：后端启动时 Flyway 连接数据库的重试次数，不是无限等待。
- `FLYWAY_LOCATIONS`：生产保持 `classpath:db/migration`；只有本地体验才追加 `classpath:db/dev-data`。
- `JAVA_TOOL_OPTIONS`：JVM 内存参数、truststore 参数等。
- 后端镜像内置 LibreOffice Calc 和中文字体，用于单据转 PDF / 图片。
- Nginx 上传限制 100 MB（Cloudflare 免费版单个请求上限 100MB，视频业务上限 95MB）；私有上传只能经后端鉴权接口访问，没有公开目录映射。
