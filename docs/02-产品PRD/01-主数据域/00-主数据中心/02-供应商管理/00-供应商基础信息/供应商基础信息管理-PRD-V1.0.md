# 供应商管理 - 供应商基础信息 PRD

**文档版本：** V1.0
**创建时间：** 2026-05-09
**功能范围：** 主数据中心供应商管理模块下的供应商基础信息增删改查管理

---

## 一、功能概述

**功能目标：** 统一维护企业供应商主数据，涵盖工商信息、联系方式、结算账户等核心数据，为采购、结算等业务域提供标准、权威的供应商信息来源，避免数据分散和重复录入。

**使用角色：** 数据管理员、超级管理员

**入口路径：** 主数据域 → 00-主数据中心 → 02-供应商管理 → 02-供应商基础信息

---

## 二、数据字段定义

### 2.1 基本信息

| 字段名 | 字段标识 | 类型 | 必填 | 说明 |
|--------|---------|------|------|------|
| 供应商编码 | supplier_code | 文本 | 是 | 全局唯一，最大长度 20 位，仅支持字母数字；支持手工录入或系统自动生成，创建后建议不可修改 |
| 供应商名称 | supplier_name | 文本 | 是 | 最大长度 100 字符，建议与营业执照登记名称一致 |
| 供应商简称 | short_name | 文本 | 否 | 最大长度 50 字符，用于列表及单据简略展示 |
| 供应商类型 | supplier_type | 枚举 | 是 | 生产商 / 经销商 / 服务商 / 代理商 / 其他 |
| 所属行业 | industry | 枚举 | 否 | 制造业 / 原材料 / 信息技术 / 物流运输 / 金融服务 / 其他（可扩展） |
| 状态 | status | 枚举 | 是 | 启用 / 禁用，默认启用 |

### 2.2 工商信息

| 字段名 | 字段标识 | 类型 | 必填 | 说明 |
|--------|---------|------|------|------|
| 统一社会信用代码 | credit_code | 文本 | 否 | 18 位标准格式，全局唯一（已录入时不允许与其他供应商重复）；格式校验：1位登记机关代码+17位数字/字母 |
| 法人代表 | legal_representative | 文本 | 否 | 最大长度 50 字符 |
| 注册资本 | registered_capital | 数字 | 否 | 单位：万元，保留两位小数，最大值不限 |
| 成立日期 | established_date | 日期 | 否 | 日期选择器，格式 YYYY-MM-DD，不可选未来日期 |

### 2.3 联系信息

| 字段名 | 字段标识 | 类型 | 必填 | 说明 |
|--------|---------|------|------|------|
| 联系人 | contact_person | 文本 | 否 | 主要对接人姓名，最大长度 50 字符 |
| 联系电话 | contact_phone | 文本 | 否 | 手机号（11位）或固话（带区号），最大长度 20 位 |
| 联系邮箱 | contact_email | 文本 | 否 | 标准 Email 格式，最大长度 100 字符 |
| 所在地区 | region | 枚举 | 否 | 省市区三级联动选择器 |
| 详细地址 | address | 文本 | 否 | 最大长度 200 字符 |

### 2.4 结算信息

| 字段名 | 字段标识 | 类型 | 必填 | 说明 |
|--------|---------|------|------|------|
| 开户银行 | bank_name | 文本 | 否 | 开户行名称，最大长度 100 字符（含支行） |
| 银行账号 | bank_account | 文本 | 否 | 最大长度 30 位，仅允许数字；展示时后 8 位以 * 遮罩 |

### 2.5 其他信息

| 字段名 | 字段标识 | 类型 | 必填 | 说明 |
|--------|---------|------|------|------|
| 备注 | remark | 文本 | 否 | 最大长度 500 字符 |
| 创建人 | created_by | 文本 | — | 系统自动记录，不可编辑 |
| 创建时间 | created_at | 日期时间 | — | 系统自动记录，格式 YYYY-MM-DD HH:mm |
| 最后修改人 | updated_by | 文本 | — | 系统自动记录，不可编辑 |
| 最后修改时间 | updated_at | 日期时间 | — | 系统自动记录，格式 YYYY-MM-DD HH:mm |

**字段约束说明：**
- `supplier_code` 全局唯一，创建后置灰不可修改
- `credit_code` 全局唯一（非必填，但填写后不可与已有记录重复）；格式为 18 位统一社会信用代码，校验不通过时提示「请输入正确格式的统一社会信用代码（18位）」
- `bank_account` 列表和详情页展示时后 8 位打码（如：6228 **** **** 8888），编辑页面明文展示
- `established_date` 不可选择今天之后的日期

## 六、异常与边界处理

| 场景 | 处理方式 |
|------|---------|
| 供应商编码重复 | 提示「供应商编码已存在，请更换」 |
| 统一社会信用代码重复 | 提示「该统一社会信用代码已被供应商「[名称]」使用，请核实后再提交」 |
| 统一社会信用代码格式错误 | 提示「请输入正确格式的统一社会信用代码（18位）」 |
| 删除已有采购业务关联的供应商 | 提示「该供应商已存在关联采购数据，无法删除，请先解除关联或将其禁用」 |
| 批量删除中混有被引用供应商 | 提示「已选 X 条中，Y 条因被引用无法删除，其余 Z 条删除成功」 |
| 状态切换（启用→禁用）影响采购业务 | 切换前提示「禁用后该供应商将无法在采购单中被引用，是否继续？」 |
| 银行账号含非数字字符 | 字段下方提示「银行账号只能包含数字」，不可提交 |
| 导出含银行账号 | 导出文件中银行账号列自动脱敏（后8位替换为 *），在导出前提示「导出数据将对银行账号进行脱敏处理」 |
| 导入含信用代码重复数据 | 返回导入结果：成功 N 条、失败 X 条（含原因），可下载失败明细 |
| 网络异常 | 表格区域显示「加载失败，点击重试」 |
| 无操作权限 | 相关按钮不显示或置灰 |

## 七、默认假设（自动推断的内容，请核对）

- **供应商编码不可修改**：编辑页置灰；如业务允许修改，请告知
- **统一社会信用代码为选填但全局唯一**：填写时触发唯一性校验；如需强制必填，请告知
- **银行账号脱敏规则**：列表、详情、导出均打码（后8位），编辑态明文展示；如脱敏规则不同请告知
- **无审核流程**：新增供应商后直接可用；如需资质审核流程（待审核→审核通过→启用），请告知，届需增加审核状态和审核页面
- **一个供应商一个银行账号**：如需支持多银行账号，需独立设计「供应商账户管理」子模块
- **供应商类型枚举值**：默认「生产商 / 经销商 / 服务商 / 代理商 / 其他」，请根据实际业务调整
- **无层级关系**：供应商之间无母子公司关联；如有，请补充说明
