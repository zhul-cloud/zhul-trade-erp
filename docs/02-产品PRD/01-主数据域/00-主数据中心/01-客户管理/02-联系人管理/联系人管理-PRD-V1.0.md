# 客户管理 - 联系人管理 PRD

**文档版本：** V1.0
**创建时间：** 2026-05-09
**功能范围：** 主数据中心客户管理模块下的客户联系人信息增删改查管理

---

## 一、功能概述

**功能目标：** 集中维护各客户的联系人信息，为销售跟进、商务沟通等业务场景提供准确的联系方式数据，支持按客户维度查询和管理其下所有联系人。

**使用角色：** 数据管理员、超级管理员、业务操作员

**入口路径：** 主数据域 → 00-主数据中心 → 00-客户管理 → 02-联系人管理

---

## 二、数据字段定义

| 字段名 | 字段标识 | 类型 | 必填 | 说明 |
|--------|---------|------|------|------|
| 联系人编码 | contact_code | 文本 | 是 | 全局唯一，最大长度 20 位，仅支持字母数字；可手工录入或系统自动生成 |
| 姓名 | contact_name | 文本 | 是 | 最大长度 50 字符 |
| 所属客户 | customer_id | 枚举 | 是 | 关联客户基本信息，展示「客户名称（客户编码）」；只能选择状态为启用的客户 |
| 部门 | department | 文本 | 否 | 联系人所在部门，最大长度 50 字符 |
| 职位 | position | 文本 | 否 | 联系人职位/头衔，最大长度 50 字符 |
| 联系电话 | phone | 文本 | 否 | 格式校验：手机号（11位）或固话（带区号），最大长度 20 位 |
| 联系邮箱 | email | 文本 | 否 | 标准 Email 格式，最大长度 100 字符 |
| 微信 / 企微 | wechat | 文本 | 否 | 微信号或企业微信账号，最大长度 50 字符 |
| 是否主要联系人 | is_primary | 布尔 | 是 | 是 / 否，默认否；标记该联系人是否为客户的首选联系人，同一客户可有多个主要联系人 |
| 状态 | status | 枚举 | 是 | 启用 / 禁用，默认启用 |
| 备注 | remark | 文本 | 否 | 最大长度 300 字符 |
| 创建人 | created_by | 文本 | — | 系统自动记录，不可编辑 |
| 创建时间 | created_at | 日期时间 | — | 系统自动记录，格式 YYYY-MM-DD HH:mm |
| 最后修改人 | updated_by | 文本 | — | 系统自动记录，不可编辑 |
| 最后修改时间 | updated_at | 日期时间 | — | 系统自动记录，格式 YYYY-MM-DD HH:mm |

**字段约束说明：**
- `contact_code` 全局唯一；如选择手工录入，重复时提示「联系人编码已存在，请更换」
- `customer_id` 必填，联系人必须挂靠至一个已存在且启用的客户；客户被禁用后，其下联系人仍可查看但不可被业务引用
- `phone`、`email` 至少填写一项（建议前端给出软提示，不强制报错）
- `is_primary` 同一客户可同时存在多个主要联系人，无互斥限制

## 五、页面详细说明

### 5.1 联系人列表页

**页面用途：** 展示所有联系人数据，支持按客户等条件搜索筛选和管理操作

**页面布局（从上到下）：**

**① 页面标题区**
- 左侧：页面标题「联系人管理」，面包屑导航（主数据中心 / 客户管理 / 联系人管理）
- 右侧：无

**② 搜索筛选区**
- 联系人编码：文本输入框，placeholder「请输入联系人编码」，支持模糊搜索
- 姓名：文本输入框，placeholder「请输入联系人姓名」，支持模糊搜索
- 所属客户：带搜索的下拉选择框，placeholder「请输入客户名称搜索」，支持模糊匹配客户名称或编码
- 是否主要联系人：下拉选择框，选项「全部 / 是 / 否」
- 状态：下拉选择框，选项「全部 / 启用 / 禁用」
- 操作按钮：蓝色「查询」按钮 + 白色「重置」按钮（重置后自动触发查询）

**③ 操作按钮区**
- 左侧：蓝色「+ 新增」按钮
- 右侧：「导出」按钮（将当前筛选结果导出为 Excel 文件）；「导入」按钮（含模板下载入口）

**④ 数据表格**

| 列名 | 宽度 | 说明 |
|------|------|------|
| 复选框 | 40px | 用于批量操作 |
| 序号 | 60px | 当前页内序号，非数据库 ID |
| 联系人编码 | 140px | 纯文本展示 |
| 姓名 | 100px | 纯文本展示 |
| 所属客户 | auto | 展示客户名称，可点击跳转至该客户详情页（有权限时） |
| 部门 | 120px | 纯文本展示 |
| 职位 | 100px | 纯文本展示 |
| 联系电话 | 130px | 纯文本展示 |
| 联系邮箱 | auto | 纯文本展示，超长省略号截断 |
| 是否主要联系人 | 110px | Tag 标签：「主要」（蓝色）/ 「—」 |
| 状态 | 80px | 开关组件，可直接切换启用/禁用；切换前弹出确认提示「确认要禁用该联系人吗？」 |
| 创建时间 | 160px | 格式：YYYY-MM-DD HH:mm |
| 操作 | 160px | 固定在右侧：查看 \| 编辑 \| 删除（文字按钮，竖线分隔） |

- 默认排序：创建时间倒序
- 无数据时：展示空状态插图，文案「暂无联系人数据，点击新增开始创建」，下方显示「新增联系人」按钮
- 表格底部：分页组件，默认每页 10 条，可切换 10 / 20 / 50 条，显示总条数

**⑤ 批量操作区**（勾选数据后出现）
- 文案：「已选 X 条」
- 按钮：红色「批量删除」按钮

### 5.2 新增联系人页面

**触发方式：** 点击列表页「新增」按钮
**页面规格：** 独立页面，顶部标题「新增联系人」，面包屑：主数据中心 / 客户管理 / 联系人管理 / 新增联系人

**表单字段（双列布局，每行两个字段）：**

| 字段标签 | 组件类型 | 必填 | 校验规则 | placeholder |
|---------|---------|------|---------|------------|
| 联系人编码 ★ | 文本输入框 | 是 | 全局唯一，最大 20 位，仅字母数字 | 请输入联系人编码 |
| 姓名 ★ | 文本输入框 | 是 | 最大 50 字符 | 请输入联系人姓名 |
| 所属客户 ★ | 带搜索下拉框 | 是 | 只可选启用状态的客户 | 请搜索并选择所属客户 |
| 是否主要联系人 ★ | 单选（是/否） | 是 | — | 默认选「否」 |
| 部门 | 文本输入框 | 否 | 最大 50 字符 | 请输入部门名称 |
| 职位 | 文本输入框 | 否 | 最大 50 字符 | 请输入职位 |
| 联系电话 | 文本输入框 | 否 | 手机号或固话格式 | 请输入联系电话 |
| 联系邮箱 | 文本输入框 | 否 | Email 格式 | 请输入联系邮箱 |
| 微信 / 企微 | 文本输入框 | 否 | 最大 50 字符 | 请输入微信号或企业微信 |
| 状态 ★ | 单选（启用/禁用） | 是 | — | 默认选「启用」 |
| 备注 | 多行文本框（3行） | 否 | 最大 300 字符 | 请输入备注 |

> 备注字段单独占一整行（跨双列）
> 联系电话和联系邮箱均为空时，页面顶部显示黄色软提示「建议至少填写一种联系方式」，不阻止提交

**底部按钮（固定在页面底部）：** 「取消」按钮（白色，返回列表）+ 「保存」按钮（蓝色）

**提交逻辑：**
- 点击「保存」→ 前端校验必填字段和格式
- 校验通过 → 调用新增接口
  - 成功：跳转回列表页并刷新，顶部显示绿色提示「新增联系人成功」
  - 失败（编码重复）：页面内字段下方红色提示「联系人编码已存在，请更换」
  - 其他失败：展示接口返回错误原因
- 点击「取消」→ 弹出确认框「确认离开？当前填写内容将不会保存。」→ 确认后返回列表

## 六、异常与边界处理

| 场景 | 处理方式 |
|------|---------|
| 删除被业务模块引用的联系人 | 提示「该联系人已被其他业务数据引用，无法删除，请先解除关联」 |
| 所属客户被禁用 | 该客户下的联系人列表仍可正常查看和管理，但在业务录入中不可被选用；状态列展示「客户已禁用」角标提示 |
| 新增时选择了禁用客户 | 下拉列表中不展示禁用状态的客户，从源头拦截 |
| 联系电话格式错误 | 字段下方红色提示「请输入正确的手机号或固定电话」，不可提交 |
| 联系邮箱格式错误 | 字段下方红色提示「请输入正确的邮箱地址」，不可提交 |
| 联系人编码重复 | 提示「联系人编码已存在，请更换」 |
| 批量删除中混有被引用的联系人 | 提示「已选 X 条中，Y 条因被业务引用无法删除，其余 Z 条删除成功」 |
| 导入含错误格式数据 | 返回导入结果页：成功 N 条、失败 X 条，可下载失败明细 |
| 网络异常 | 表格区域显示「加载失败，点击重试」，带重试按钮 |
| 无操作权限 | 相关按钮不显示或置灰不可点 |

## 七、默认假设（自动推断的内容，请核对）

- **联系人必须挂靠至客户**：联系人不能独立存在，所属客户为必填字段；如业务上支持独立联系人，请告知
- **同一客户可有多个主要联系人**：「是否主要联系人」为标记字段，无互斥约束；如业务要求每个客户有且只有一个主要联系人，请告知（届时需增加自动切换逻辑）
- **联系人编码建议不修改**：编辑页面将编码置灰，如业务允许修改请告知
- **联系电话和邮箱为软提示非强制**：至少填一项为建议而非校验；如需强制填写，请告知
- **联系人被删除不影响历史业务数据**：业务单据中已引用的联系人信息以快照形式保留；如有引用，删除前会有拦截提示
- **导出字段**：默认导出表格所有展示列；如有特殊导出字段需求请补充
