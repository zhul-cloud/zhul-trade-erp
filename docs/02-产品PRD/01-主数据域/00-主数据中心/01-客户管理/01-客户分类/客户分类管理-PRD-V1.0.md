# 客户管理 - 客户分类 PRD

**文档版本：** V1.0
**创建时间：** 2026-05-09
**功能范围：** 主数据中心客户管理模块下的客户分类标准字典维护，支持两级分类结构

---

## 一、功能概述

**功能目标：** 统一维护客户分类标准数据，为客户基本信息录入提供规范的分类选项，保障客户数据分类口径一致，支持后续按分类维度的统计分析。

**使用角色：** 数据管理员、超级管理员

**入口路径：** 主数据域 → 00-主数据中心 → 00-客户管理 → 01-客户分类

---

## 二、数据字段定义

| 字段名 | 字段标识 | 类型 | 必填 | 说明 |
|--------|---------|------|------|------|
| 分类编码 | category_code | 文本 | 是 | 全局唯一，创建后不可修改；最大长度 20 位，仅支持字母和数字 |
| 分类名称 | category_name | 文本 | 是 | 最大长度 50 字符，同级分类下名称唯一 |
| 上级分类 | parent_id | 枚举 | 否 | 选择已有的一级分类，不选则为一级分类；最多支持两级层级 |
| 分类描述 | description | 文本 | 否 | 对该分类的用途或范围说明，最大长度 200 字符 |
| 排序号 | sort_order | 数字 | 否 | 整数，默认 0，同级分类按排序号升序排列，数字越小越靠前 |
| 状态 | status | 枚举 | 是 | 启用 / 禁用，默认启用 |
| 备注 | remark | 文本 | 否 | 最大长度 200 字符 |
| 创建人 | created_by | 文本 | — | 系统自动记录，不可编辑 |
| 创建时间 | created_at | 日期时间 | — | 系统自动记录，格式 YYYY-MM-DD HH:mm |
| 最后修改人 | updated_by | 文本 | — | 系统自动记录，不可编辑 |
| 最后修改时间 | updated_at | 日期时间 | — | 系统自动记录，格式 YYYY-MM-DD HH:mm |

**字段约束说明：**
- `category_code` 全局唯一，创建成功后永久不可修改，编辑弹窗中该字段置灰
- `category_name` 在同一父级下唯一；跨不同父级允许重名
- `parent_id` 只能选择一级分类（即本身无上级的分类）作为父级，禁止选择二级分类为父级，确保层级不超过两级
- 一级分类禁止将自身设为上级（循环引用检测）

## 五、页面详细说明

### 5.1 客户分类列表页

**页面用途：** 展示所有客户分类数据，支持搜索筛选和管理操作，以扁平列表形式展示（一级和二级分类均在同一表格中，通过「上级分类」列区分层级）

**页面布局（从上到下）：**

**① 页面标题区**
- 左侧：页面标题「客户分类」，面包屑导航（主数据中心 / 客户管理 / 客户分类）
- 右侧：无

**② 搜索筛选区**
- 分类编码：文本输入框，placeholder「请输入分类编码」，支持模糊搜索
- 分类名称：文本输入框，placeholder「请输入分类名称」，支持模糊搜索
- 上级分类：下拉选择框，选项「全部 + 所有一级分类名称列表」（用于筛选某一级下的二级分类）
- 状态：下拉选择框，选项「全部 / 启用 / 禁用」
- 操作按钮：蓝色「查询」按钮 + 白色「重置」按钮（重置后自动触发查询）

**③ 操作按钮区**
- 左侧：蓝色「+ 新增」按钮
- 右侧：「导出」按钮（将当前筛选结果导出为 Excel 文件）

**④ 数据表格**

| 列名 | 宽度 | 说明 |
|------|------|------|
| 复选框 | 40px | 用于批量操作 |
| 序号 | 60px | 当前页内序号，非数据库 ID |
| 分类编码 | 140px | 纯文本展示 |
| 分类名称 | auto | 纯文本展示；二级分类在名称前增加缩进样式或「└」符号以体现层级 |
| 上级分类 | 150px | 展示上级分类名称，一级分类显示「—」 |
| 分类描述 | auto | 超长省略号截断，hover 展示完整内容 |
| 排序号 | 80px | 数字展示 |
| 状态 | 80px | 开关组件，可直接切换启用/禁用；切换前弹出确认提示「确认要禁用该分类吗？禁用后该分类将无法在客户录入时被选择。」 |
| 创建时间 | 160px | 格式：YYYY-MM-DD HH:mm |
| 操作 | 160px | 固定在右侧：查看 \| 编辑 \| 删除（文字按钮，竖线分隔） |

- 默认排序：先按层级（一级在前，二级跟随其父级展示），同级内按排序号升序、创建时间倒序
- 无数据时：展示空状态插图，文案「暂无分类数据，点击新增开始创建」，下方显示「新增客户分类」按钮
- 表格底部：分页组件，默认每页 10 条，可切换 10 / 20 / 50 条，显示总条数

**⑤ 批量操作区**（勾选数据后出现）
- 文案：「已选 X 条」
- 按钮：红色「批量删除」按钮

### 5.2 新增客户分类弹窗

**触发方式：** 点击列表页「新增」按钮
**弹窗规格：** 宽 600px，标题「新增客户分类」，右上角关闭按钮

**表单字段（单列排列）：**

| 字段标签 | 组件类型 | 必填 | 校验规则 | placeholder |
|---------|---------|------|---------|------------|
| 分类编码 ★ | 文本输入框 | 是 | 全局唯一，最大 20 位，仅字母数字 | 请输入分类编码 |
| 分类名称 ★ | 文本输入框 | 是 | 最大 50 字符，同级下唯一 | 请输入分类名称 |
| 上级分类 | 下拉选择框 | 否 | 只展示一级分类供选择；不选则本条记录为一级分类 | 请选择上级分类（不选则为一级分类） |
| 分类描述 | 文本输入框 | 否 | 最大 200 字符 | 请输入分类描述 |
| 排序号 | 数字输入框 | 否 | 整数，最小 0，默认填入 0 | 请输入排序号 |
| 状态 ★ | 单选（启用/禁用） | 是 | — | 默认选中「启用」 |
| 备注 | 多行文本框（2行） | 否 | 最大 200 字符 | 请输入备注 |

**底部按钮：** 「取消」按钮（灰色）+ 「确认」按钮（蓝色）

**提交逻辑：**
- 点击「确认」→ 前端校验必填字段和格式
- 校验通过 → 调用新增接口
  - 成功：弹窗关闭 + 列表刷新 + 页面顶部显示绿色提示「新增成功」
  - 失败（编码重复）：弹窗不关闭，编码字段下方红色提示「分类编码已存在，请更换」
  - 失败（同级名称重复）：提示「该上级分类下已存在相同名称，请更换」
  - 其他失败：弹窗不关闭，展示接口返回错误原因

### 5.3 编辑客户分类弹窗

**触发方式：** 点击列表行「编辑」按钮
**弹窗规格：** 与新增弹窗相同，标题改为「编辑客户分类」

**与新增的差异：**
- 打开弹窗时自动回填当前行所有数据
- **分类编码** 字段置灰，禁止编辑（创建后永久不可修改）
- **上级分类** 字段：若该分类已有下级分类（即本身是一级分类且有子分类），则不允许修改上级分类（置灰），避免层级逻辑混乱；否则可修改
- 提交成功后显示「编辑成功」提示

## 六、异常与边界处理

| 场景 | 处理方式 |
|------|---------|
| 删除已被客户引用的分类 | 提示「该分类已被 X 个客户使用，无法删除，请先解除引用或将其禁用」 |
| 删除含有子分类的一级分类 | 提示「该分类下存在 X 个子分类，请先删除或移动子分类后再操作」 |
| 批量删除中混有被引用分类 | 提示「已选 X 条中，Y 条因被引用无法删除，其余 Z 条删除成功」，列表刷新后高亮失败条目 |
| 禁用含子分类的一级分类 | 切换前提示「禁用后，其下 X 个子分类也将同步禁用，是否继续？」|
| 禁用已被客户使用的分类 | 切换前提示「该分类已被 X 个客户使用，禁用后这些客户的分类字段将显示为『已禁用』，是否继续？」|
| 分类编码重复 | 新增/保存时提示「分类编码已存在，请更换」，表单不关闭 |
| 同级名称重复 | 提示「该上级分类下已存在相同名称的分类，请更换」 |
| 无操作权限 | 相关按钮（新增、编辑、删除）不显示或置灰不可点 |
| 网络异常 | 表格区域显示「加载失败，点击重试」，带重试按钮 |

## 七、默认假设（自动推断的内容，请核对）

- **层级深度**：默认最多支持两级（一级分类 + 二级分类）；如需三级及以上，需改为树形组件展示，请告知
- **列表展示方式**：默认扁平列表（一二级混合展示，通过缩进区分）；如需树形表格（可折叠展开）请告知
- **分类编码生成**：默认手工录入；如需系统自动生成，请补充编码规则
- **已被引用的分类不允许删除**：只能禁用，具体引用范围为「客户基本信息的分类字段」，如有其他引用模块请补充
- **禁用一级分类时子分类联动禁用**：若业务上子分类可独立保持启用状态，请告知
- **排序号**：同级分类按排序号升序排列；相同排序号时按创建时间倒序，规则以实际业务为准
