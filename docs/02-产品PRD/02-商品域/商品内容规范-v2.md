# 商品内容规范 v2

ERP 的资料包、营销包下载模版，ERP 的上传解析，以及 AI 技能 `fouwell-product-content` 的输出，都以本规范为唯一标准。两边不一致时以本规范为准。

完整示例见 [商品内容规范-v2示例](商品内容规范-v2示例/)（Delta VFD015M21A 的资料包与营销包，由技能实际输出按本规范整理）。

## 1. 通用约定

| 约定 | 说明 |
|---|---|
| 文件 | 一个商品一个文件，UTF-8 Markdown，不超过 1MB |
| frontmatter | 文件开头用 `---` 包住，必须有：`schema: 2`、`type`（`facts` 资料包 / `marketing` 营销包）、`brand`、`model`、`lang`。其他键（如 `updated`、`status`）忽略 |
| 语言 | 资料包 `lang: zh`；营销包 `lang: en`。俄文只有独立站：写在英文营销文件的「## 独立站俄文」章节里；也可以单独一个 `lang: ru` 文件，只写「## 独立站」 |
| 一级标题 | 全文只有一个，如 `# Delta VFD015M21A 商品资料`，不解析 |
| 二级标题 | 章节，名称固定（见下文）。标题后可带括号说明，按开头匹配 |
| 三级标题 | 营销包里各平台的单项，名称固定；社媒每一节是一篇帖子或一个视频方案 |
| 表格 | 第一行为表头，第二行为分隔线，列顺序按本规范；多出的列忽略 |
| 空值 | 空、`—`、`-`、含「[待确认]」的值视为没有，不写入 |
| 内部附录 | `## 内部附录` 及其后内容整段跳过，用于营销计划、事实引用映射、审核记录、编辑说明等只给人看的内容 |
| 其他章节 | 不认识的章节跳过并在预览里提示 |

## 2. 资料包（`type: facts`，中文，写共享商品库）

| 章节 | 格式 | 写入 ERP |
|---|---|---|
| `## 产品识别` | 「项目 \| 内容」，项目用：中文名称、英文名称、系列、品类 | 商品名称为空时写入中文名称（没有中文用英文名称），英文名称不单独保存；系列按同品牌系列库名称匹配（忽略大小写、空格和末尾 Series/系列），商品没有系列时写入 |
| `## 一句话规格摘要` | 一段中文，≤300 字 | 替换规格摘要 |
| `## 规格参数` | 「事实编号 \| 项目 \| 数值及单位 \| 条件/范围 \| 证据状态 \| 来源」 | 每行一条中文规格：名称=项目，值=数值及单位；条件、证据状态、来源说明分别保存。来源编号（S02、S03）按「来源索引」换成名称。未核实的旧规格替换，已核实的保留 |
| `## 关键未知字段` | 「项目 \| 当前状态 \| 对发布的影响」 | 资料待确认项（关键未知字段） |
| `## 应用需求` | 「场景 \| 买家需求 \| 产品作用 \| 选型前提 \| 证据性质/来源」 | 应用场景：标题=场景，描述=产品作用；选型前提 |
| `## 兼容替代型号` | 「原型号 \| 兼容说明」 | 型号关系（兼容），按型号合并 |
| `## 技术问答` | `Q:` / `A:` 成对，或 `1. **问题** 答案` | 共享 FAQ，待平台审核，按问题去重 |
| `## 技术资料` | 每行 `- [标题](链接)` | 技术资料，按地址合并 |
| `## 物流信息` | 「字段 \| 内容」：净重、毛重、尺寸（长×宽×高）、包装方式、单箱数量、特殊运输要求 | 只补空；重量换算 kg、尺寸换算 mm；标「估」的重量不写 |
| `## 海关信息` | 「字段 \| 内容」：HS 编码（中国）、原产地、报关品名（中文）、报关品名（英文） | 只补空；HS 去点后 6–10 位数字；原产地换成两位国家码 |
| `## 来源索引` | 「编号 \| 发布者及范围 \| 日期 \| 链接 \| 支持事实」 | 链接为 http(s) 的导入为技术资料（标题=发布者及范围）；相对路径（照片等）不导入 |
| `## 冲突与待确认` | 编号列表，每条以 `**要点**` 开头 | 资料待确认项（冲突与待确认） |
| `## 平台参考价` | 「价格类别 \| 平台/网站 \| 成色 \| 参考价格（USD） \| 来源原价 \| 来源链接」，链接写 `[标题](https://…)` | 平台参考价（公开挂牌价，共享商品库）：每次导入整份替换，取价日期取 frontmatter 的 `updated`（没有时为导入日期）；挂牌价不是成交价、采购成本或报价。文件里没有可写入的 `## 商品平台参考价` 时，同时生成商品卡片的平台参考价：不看类目参考行，取全新（New 开头、全新、新品）里的最低价，没有全新取所有行的最低价；币种 USD，汇率取系统美元汇率（没有设置为「未计算」），来源写平台、成色与价格类别 |
| `## 商品平台参考价` | 「字段 \| 内容」：币种、参考价（原币）、汇率（原币 → 人民币）、价格来源、取价日期 | 商品卡片的平台参考价（一个商品一条，共享商品库），不进公开挂牌价：币种为 ISO 4217 代码；参考价大于 0，HALF_UP 保留 2 位；人民币汇率按 1，其他币种汇率可不填（人民币参考价显示「未计算」），填了须大于 0、保留 6 位；人民币参考价 = 原币 × 汇率，HALF_UP 保留 2 位；价格来源最长 128 字；取价日期 YYYY-MM-DD，表内没有时取 frontmatter 的 `updated`。空、破折号、含「[待确认]」或「未知」的值不写入、不覆盖已有值：币种和参考价都未知时整节不写入，只知道其一时报错；汇率未知时沿用原汇率（币种不变时） |

- 资料待确认项每次导入整份替换；文件里没有这两个章节时清空。
- 平台参考价、商品平台参考价之外的价格与采购参考、包装说明等章节不导入（采购成本放 `## 内部附录`）。两个参考价章节可以同时出现，这时商品卡片按 `## 商品平台参考价` 写入，不再从挂牌价生成。

## 3. 营销包（`type: marketing`，写本公司）

默认一个文件包含本公司启用的全部平台，独立站后面接「## 独立站俄文」；只含一个平台章节的文件只更新该平台。上传时关键词库、每个平台、独立站俄文各拆成一项，分别预览、分别写入。

### 3.1 关键词库

`## 关键词库`：「优先级 \| 分类 \| Keyword \| 搜索意图 \| 事实依据」

- 优先级 P1/P2/P3 对应核心、主要、长尾（也认「核心 / 主要 / 长尾」）。
- 整份替换本公司该商品的关键词总库，库内顺序按表格顺序；重复的词（不分大小写）只留第一个。
- 不在新库里的词，各平台对它的选用一并去掉。

### 3.2 阿里国际站、中国制造网

`## 阿里国际站`、`## 中国制造网` 下的三级标题：

| 单项 | 格式 | 写入 ERP |
|---|---|---|
| `### 标题` | 「版本 \| English title \| 字符数 \| 角度」，第一行为推荐 | 推荐标题（≤128 字符）+ 备选标题 |
| `### 选用关键词` | 每行 `- keyword`，须在关键词库里 | 该平台选用；不在库里的按主要档补进总库并提示 |
| `### 产品属性` | 「Attribute \| Value」 | 产品属性表 |
| `### 卖点` | 每行 `- 卖点`（Buyer benefits 亦可） | 卖点，不限条数与长度 |
| `### 产品详情` | 正文段落（Product details 亦可） | 产品详情 |
| `### FAQ` | `1. **问题** 答案` 或 `Q:` / `A:` | 平台 FAQ |
| `### 询盘引导语` | 一段 | 引导语 |

**中国制造网用工业产品页版式**：`## 中国制造网` 下先写 `### 标题`、`### 选用关键词`，再用四个加粗二级标题，最后是 `### 询盘引导语`。这四个二级标题紧跟在中国制造网之后，导入时归回中国制造网，不当作新章节：

| 区块 | 格式 | 写入 ERP |
|---|---|---|
| `## **Technical Specifications**` | 「Specification \| Details」两列表格 | 产品属性 |
| `## **Key Features and Benefits**` | 恰好五项，每项一个加粗编号小标题（`**1. Heading**`）加一到两句说明 | 卖点，每项一条「小标题: 说明」 |
| `## **Product Details**` | 英文正文，可用加粗小标题分段 | 产品详情 |
| `## **FAQ**` | 每条 `**1. Question?**` 换行后写答案 | 平台 FAQ |
| `### 询盘引导语` | 一段，写在 FAQ 之后 | 引导语 |

阿里国际站仍用上表的三级标题（如果也写成这四个加粗二级标题，同样归回阿里国际站）。

### 3.3 独立站

`## 独立站` 下的三级标题：

| 单项 | 格式 | 写入 ERP |
|---|---|---|
| `### SEO 字段` | 「Field \| English copy」，Field 用 SEO Title、Meta Description、H1、URL Slug | SEO 标题（≤120）、SEO 描述（≤320）、H1、URL 别名 |
| `### 首屏定义块` | 一段，40–60 词 | 首屏定义块（GEO） |
| `### 页面正文` | 正文，可含小标题、规格表 | 产品长描述（≤5000） |
| `### FAQ` | 同上 | 营销问答 |
| `### 图片说明文字` | 「图片 \| English Alt Text」 | 图片说明文字 |

### 3.3a 独立站俄文

`## 独立站俄文`：写在英文营销文件里（`lang: en`），三级标题与独立站完全相同，内容写俄文（SEO 字段表的 Field 列保留英文名称，URL Slug 用拉丁字母）。导入后写入独立站俄文；独立站要英文、俄文都写入才算完成。

单独重做俄文时，也可以用只含 `## 独立站`、`lang: ru` 的文件。

### 3.4 社媒

`## 社媒` 下每个三级标题一篇：

- 以 `LinkedIn`、`Facebook` 开头：一篇帖子，标题里「｜」后面是这篇的角度，正文原样保存（含联系方式、话题标签、表情符号）；
- 以 `YouTube` 开头：一个视频方案（主视频、Shorts），原样保存（标题、描述、分镜表、缩略图文案）。

## 4. 旧格式

- 没有 `schema: 2` 的文件按旧格式（v1 任务包：`type`、`platform`、固定章节）解析，预览提示「旧格式」。
- llm-wiki 商品文件（没有 `type`、有「基本信息」章节）按资料包导入。
