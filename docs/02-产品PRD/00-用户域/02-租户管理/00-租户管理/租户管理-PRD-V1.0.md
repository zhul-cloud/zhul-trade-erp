# 租户管理 PRD V1.0

> 文档版本：V1.0
> 创建日期：2026-05-29
> 产品：烛龙ERP（外贸业财一体化中台，多租户 SaaS）
> 模块路径：平台超级管理员 → 租户管理

---

## 1. 功能概述

### 1.1 功能目标

为平台超级管理员提供对所有租户的全生命周期管理能力，包括：创建租户、配置套餐与有效期、日常启用/禁用操作、到期续期、以及重置租户管理员密码。

### 1.2 使用角色

| 角色 | 说明 |
|------|------|
| 平台超级管理员（Super Admin） | 唯一有权访问本模块的角色，属于平台层账号，不隶属于任何租户 |

### 1.3 入口路径

```
平台后台（Super Admin Console）
  └── 左侧导航 → 租户管理 → 租户列表
```

URL 示例：`/platform/tenants`

## 2. 数据字段定义

### 2.1 租户基本信息（tenant）

| 字段名 | 字段标识 | 类型 | 必填 | 说明 |
|--------|----------|------|------|------|
| 租户ID | id | BIGINT | 是（系统生成） | 主键，自增 |
| 租户编码 | tenant_code | VARCHAR(20) | 是（系统生成） | 格式 TN+数字，如 TN1000，全局唯一，不可修改 |
| 租户名称 | tenant_name | VARCHAR(100) | 是 | 公司/团队名称，平台内唯一 |
| 套餐ID | package_id | BIGINT | 是 | 关联 tenant_package.id |
| 套餐名称 | package_name | VARCHAR(100) | — | 冗余字段，展示用 |
| 联系人姓名 | contact_name | VARCHAR(50) | 是 | 租户管理员真实姓名 |
| 联系人手机 | contact_phone | VARCHAR(20) | 是 | 用于通知和找回密码 |
| 联系人邮箱 | contact_email | VARCHAR(100) | 是 | 租户管理员登录账号 |
| 状态 | status | TINYINT | 是 | 0=禁用，1=启用；默认 1 |
| 到期时间 | expire_time | DATETIME | 是 | UTC 存储；到期后系统自动将状态置为禁用 |
| 最后续期时间 | last_renew_time | DATETIME | 否 | 每次续期后更新 |
| 备注 | remark | VARCHAR(500) | 否 | 平台内部备注，租户侧不可见 |
| 创建时间 | created_at | DATETIME | 是（系统生成） | UTC |
| 更新时间 | updated_at | DATETIME | 是（系统生成） | UTC |
| 删除时间 | deleted_at | DATETIME | 否 | 软删除标记 |

### 2.2 租户管理员账号（关联 sys_user）

租户创建时同步在 sys_user 表中创建一条管理员账号记录，字段如下（仅列关键字段）：

| 字段名 | 字段标识 | 类型 | 必填 | 说明 |
|--------|----------|------|------|------|
| 用户ID | id | BIGINT | 是 | 主键 |
| 租户ID | tenant_id | BIGINT | 是 | 关联 tenant.id |
| 登录账号 | username | VARCHAR(100) | 是 | 与 contact_email 相同 |
| 密码 | password | VARCHAR(255) | 是 | bcrypt 加密存储 |
| 角色 | role | VARCHAR(50) | 是 | 固定值 TENANT_ADMIN |
| 状态 | status | TINYINT | 是 | 随租户状态联动 |

### 5.2 P-TN-02 新增租户抽屉

#### 5.2.1 布局

- 组件类型：Drawer（右侧抽屉）
- 宽度：600px
- 标题：「新增租户」
- Footer：左侧「取消」default 按钮，右侧「确认创建」primary 按钮

#### 5.2.2 表单字段

| 序号 | 标签 | 控件类型 | 必填 | Placeholder / 默认值 | 校验规则 |
|------|------|----------|------|----------------------|----------|
| 1 | 租户名称 | Input | 是 | 请输入公司或团队名称 | 长度 2~100 字符；平台内唯一（失焦后异步校验） |
| 2 | 套餐 | Select | 是 | 请选择套餐 | 必选；仅展示状态=启用的套餐 |
| 3 | 联系人姓名 | Input | 是 | 请输入联系人姓名 | 长度 2~50 字符 |
| 4 | 联系人手机 | Input | 是 | 请输入手机号码 | 中国大陆手机号格式；平台内唯一 |
| 5 | 联系人邮箱 | Input | 是 | 请输入邮箱地址（将作为登录账号） | Email 格式；平台内唯一（失焦后异步校验） |
| 6 | 到期时间 | DatePicker | 是 | 请选择到期日期 | 不可选今日及以前；精度到日，存储时取当天 23:59:59 UTC |
| 7 | 备注 | TextArea | 否 | 选填，平台内部备注（租户不可见） | 最大 500 字符；行高 3 |

#### 5.2.3 提交逻辑

1. 前端表单校验通过后调用 `POST /api/platform/tenants`
2. 后端原子操作：
   - 插入 tenant 记录，自动生成 tenant_code（TN + 自增序列，从 TN1000 开始）
   - 插入 sys_user 记录（role=TENANT_ADMIN，password 随机生成12位临时密码）
3. 成功响应后：
   - 关闭抽屉
   - 弹出成功 Toast：「租户创建成功，管理员账号：{email}，临时密码：{tmp_pwd}，请妥善告知」（Toast 持续显示，需手动关闭，不自动消失）
   - 刷新列表

#### 5.2.4 交互细节

- 套餐 Select 支持搜索过滤
- 提交中状态：「确认创建」按钮显示 loading，禁止重复点击
- 取消时若表单已有修改，弹出二次确认：「确认放弃当前填写内容吗？」

## 6. 异常与边界处理

| 场景 | 触发条件 | 处理方式 |
|------|----------|----------|
| 租户名称重复 | 提交时后端返回唯一性冲突 | 租户名称字段下方红色提示：「该租户名称已存在」 |
| 邮箱已被注册 | 提交时后端返回邮箱唯一性冲突 | 邮箱字段下方红色提示：「该邮箱已被其他账号使用」 |
| 手机号已被注册 | 提交时后端返回手机唯一性冲突 | 手机字段下方红色提示：「该手机号已被其他账号使用」 |
| 选择已禁用套餐 | 套餐在提交前被禁用 | 后端返回错误，前端 Toast 提示：「所选套餐不可用，请重新选择」，并清空套餐选择 |
| 到期时间设为过去 | 绕过 DatePicker 直接发请求 | 后端校验返回错误：「到期时间不可早于当前时间」 |
| 续期日期早于当前到期时间 | 指定到期日期模式下 DatePicker 限制失效 | 后端返回错误：「指定日期不可早于当前到期时间」 |
| 启用已过期租户 | 手动启用但 expire_time < NOW() | 弹出额外警告：「该租户已过期，启用后将在下次定时任务执行时再次被自动禁用，建议先续期」，需二次确认方可继续 |
| 禁用操作中有用户在线 | 租户有活跃 Session | 继续执行禁用；已登录 Session 在下次请求时返回 401，由前端跳转至登录页 |
| 网络超时 | 请求超过 10s 无响应 | 按钮恢复可点击状态，Toast 错误提示：「操作超时，请稍后重试」 |
| 并发重复提交 | 短时间内同一操作重复调用 | 前端按钮 loading 防重；后端幂等键拦截，返回 200 + 原结果 |
| 删除操作 | — | 本模块不提供租户删除功能；所有删除走软删除 + 线下审批流程 |
| 列表加载失败 | 接口返回 5xx | 表格区域显示错误状态：「数据加载失败，请刷新页面重试」，并展示刷新按钮 |

## 7. 默认假设

1. **租户编码**：后端自动生成，格式 TN+4位以上数字（从 TN1000 开始递增），前端仅展示，不允许手动输入。
2. **时区显示**：数据库存 UTC，前端统一转为 Asia/Shanghai 展示（平台级配置，不在本 PRD 范围内调整）。
3. **套餐下拉**：新增/编辑时仅展示 status=1（启用）的套餐。若当前租户已绑定套餐被禁用，编辑时原套餐仍可展示以保持现有绑定，但无法重新选择该套餐。
4. **管理员账号**：每个租户有且仅有一个 TENANT_ADMIN 账号，与联系人邮箱一一绑定；租户内部追加用户由租户侧自行管理，不在本 PRD 范围内。
5. **密码策略**：临时密码长度 12 位，含大写字母、小写字母、数字各至少1位，无特殊字符。租户管理员首次登录后系统强制要求修改密码。
6. **审计日志**：所有操作（新增、编辑、禁用、启用、续期、重置密码）均写入 sys_operation_log，记录操作人 ID、操作时间、操作类型、变更前后数据快照（JSON diff 格式）。
7. **列表默认排序**：按 created_at 降序，最新创建排最前。支持点击列头切换排序。
8. **续期月份计算**：使用自然月（Java `LocalDateTime.plusMonths(n)`），非固定30天。
9. **到期自动禁用**：由后端 Spring Scheduler 定时任务执行，建议频率每小时一次；以服务器时间为准，与前端无耦合。
10. **本 PRD 不覆盖**：租户注销/删除流程、租户数据迁移导出、套餐升降配变更通知、多租户数据库隔离策略。
