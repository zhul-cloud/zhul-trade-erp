# 租户套餐管理 PRD V1.0

> 文档版本：V1.0
> 创建日期：2026-05-29
> 产品：烛龙ERP（外贸业财一体化中台，多租户 SaaS）
> 模块路径：平台超级管理员 → 租户管理 → 套餐管理

---

## 1. 功能概述

### 1.1 功能目标

为平台超级管理员提供套餐的配置与管理能力。套餐定义了租户可访问的菜单范围，通过套餐实现功能权限的批量分配，避免逐租户配置菜单的繁琐操作。

### 1.2 使用角色

| 角色 | 说明 |
|------|------|
| 平台超级管理员（Super Admin） | 唯一有权访问本模块的角色，属于平台层账号，不隶属于任何租户 |

### 1.3 入口路径

```
平台后台（Super Admin Console）
  └── 左侧导航 → 租户管理 → 套餐管理
```

URL 示例：`/platform/packages`

### 1.4 业务约束

- 套餐与菜单为多对多关系，通过 `menu_ids`（JSON 数组）存储
- 已有租户使用的套餐**不可删除**（可禁用）
- 禁用套餐不影响已绑定该套餐的租户当前会话，下次登录时生效限制（具体联动规则由权限模块负责）
- 修改套餐菜单范围将实时影响所有绑定该套餐的租户可见菜单

## 2. 数据字段定义

### 2.1 租户套餐（tenant_package）

| 字段名 | 字段标识 | 类型 | 必填 | 说明 |
|--------|----------|------|------|------|
| 套餐ID | id | BIGINT | 是（系统生成） | 主键，自增 |
| 套餐名称 | package_name | VARCHAR(100) | 是 | 平台内唯一 |
| 套餐描述 | description | VARCHAR(500) | 否 | 面向平台管理员的内部说明 |
| 可用菜单ID列表 | menu_ids | JSON | 是 | 存储菜单 ID 数组，如 [1,2,5,8]；至少选择1个菜单 |
| 状态 | status | TINYINT | 是 | 0=禁用，1=启用；默认 1 |
| 绑定租户数 | tenant_count | INT | — | 冗余统计字段，异步更新，展示用 |
| 创建时间 | created_at | DATETIME | 是（系统生成） | UTC |
| 更新时间 | updated_at | DATETIME | 是（系统生成） | UTC |
| 删除时间 | deleted_at | DATETIME | 否 | 软删除标记 |

### 2.2 系统菜单（sys_menu，只读引用）

| 字段名 | 字段标识 | 类型 | 说明 |
|--------|----------|------|------|
| 菜单ID | id | BIGINT | 主键 |
| 父菜单ID | parent_id | BIGINT | 0 表示根节点 |
| 菜单名称 | menu_name | VARCHAR(100) | 展示名 |
| 菜单类型 | menu_type | TINYINT | 1=目录，2=菜单，3=按钮 |
| 路由路径 | path | VARCHAR(255) | 前端路由 |
| 排序 | sort | INT | 同层级排序权重 |
| 状态 | status | TINYINT | 0=禁用，1=启用 |

### 5.2 P-PKG-02 新增套餐抽屉

#### 5.2.1 布局

- 组件类型：Drawer（右侧抽屉）
- 宽度：720px
- 标题：「新增套餐」
- Footer：左侧「取消」default 按钮，右侧「确认创建」primary 按钮

#### 5.2.2 表单字段

| 序号 | 标签 | 控件类型 | 必填 | Placeholder | 校验规则 |
|------|------|----------|------|-------------|----------|
| 1 | 套餐名称 | Input | 是 | 请输入套餐名称，如「标准版」「专业版」 | 长度 2~100 字符；平台内唯一（失焦后异步校验） |
| 2 | 套餐描述 | TextArea | 否 | 选填，描述该套餐的适用场景和功能范围 | 最大 500 字符；行高 3 |
| 3 | 可用菜单 | Tree（多选，Checkbox） | 是 | — | 至少勾选 1 个菜单节点；见 5.2.3 |

#### 5.2.3 菜单树组件说明

```
可用菜单  [全选] [展开全部] [折叠全部]          已选：{n} 个菜单
+------------------------------------------------------------+
| [v] 工作台                                                  |
| [v] CRM 客户管理                                            |
|   [v] 客户列表                                              |
|   [v] 商机管理                                              |
|   [ ] 客户报表                                              |
| [v] OMS 订单管理                                            |
|   [v] 订单列表                                              |
|   [ ] 订单导出（按钮）                                      |
| [ ] 财务管理                                                |
|   [ ] 应收账款                                              |
|   [ ] 应付账款                                              |
| ...                                                        |
+------------------------------------------------------------+
```

- 勾选父节点自动级联勾选所有子节点；取消父节点级联取消所有子节点
- 子节点部分勾选时，父节点显示半选（indeterminate）状态
- 菜单树数据来源：`GET /api/platform/menus/tree`，仅展示 status=1 的菜单节点
- 树高度固定 400px，内容超出时垂直滚动
- 右上角实时显示已选菜单数量：「已选：{n} 个菜单」

#### 5.2.4 提交逻辑

1. 前端校验通过后调用 `POST /api/platform/packages`
2. 请求体：`{ package_name, description, menu_ids: [1, 2, 5, ...] }`
3. 成功响应后：
   - 关闭抽屉
   - Toast 成功提示：「套餐「{package_name}」创建成功」，3秒后自动消失
   - 刷新列表

#### 5.2.5 交互细节

- 提交中：「确认创建」按钮显示 loading 状态，禁止重复点击
- 取消时若表单已有修改，弹出二次确认：「确认放弃当前填写内容吗？」
- 「全选」按钮：全部已选时文字变为「取消全选」，点击取消所有勾选
- 「展开全部」/「折叠全部」：控制树节点展开状态，不影响勾选

### 5.3 P-PKG-03 编辑套餐抽屉

- 组件类型：Drawer，宽度 720px，标题：「编辑套餐 — {package_name}」
- 与新增共用表单组件，打开时从接口获取当前套餐数据并回填（含菜单树勾选状态）
- **全部字段均可修改**：套餐名称、套餐描述、可用菜单
- Footer：左侧「取消」，右侧「保存修改」primary 按钮
- 提交调用 `PUT /api/platform/packages/{id}`
- 成功后 Toast：「套餐「{package_name}」已更新」，3秒后自动消失；刷新列表

**特别说明**：若该套餐已绑定租户，在菜单树上方展示内联警告提示（黄色 Alert）：

```
+----------------------------------------------------------+
|  注意：此套餐已被 {n} 个租户使用，修改菜单范围后，       |
|  所有绑定租户的可见菜单将立即变更。                      |
+----------------------------------------------------------+
```

### 5.4 P-PKG-04 禁用/启用确认对话框

#### 禁用确认

- 标题：「确认禁用套餐？」
- 内容（根据绑定租户数动态显示）：

  若 tenant_count = 0：
  ```
  确认禁用套餐「{package_name}」吗？禁用后该套餐不可被新租户选择。
  ```

  若 tenant_count > 0：
  ```
  套餐「{package_name}」当前有 {n} 个租户在使用。
  禁用后，该套餐不可被新租户选择，但已绑定的租户暂不受影响。
  ```

- 按钮：取消（default）/ 确认禁用（danger，红色背景）

#### 启用确认

- 标题：「确认启用套餐？」
- 内容：「启用后，套餐「{package_name}」可被新租户选择使用。」
- 按钮：取消（default）/ 确认启用（primary）

提交后 Toast：「操作成功」，列表对应行状态 Badge 即时更新，无需整页刷新。

---

### 5.5 P-PKG-05 删除确认对话框

#### 5.5.1 可删除场景（tenant_count = 0）

- 标题：「确认删除套餐？」
- 内容：「确认删除套餐「{package_name}」吗？此操作不可恢复。」
- 按钮：取消（default）/ 确认删除（danger，红色背景）
- 提交调用 `DELETE /api/platform/packages/{id}`（软删除，设置 deleted_at）
- 成功后 Toast：「套餐已删除」，从列表移除对应行

#### 5.5.2 不可删除场景（tenant_count > 0）

后端返回 409 Conflict，前端展示拦截提示 Modal（仅告知，非操作确认框）：

- 标题：「无法删除套餐」
- 内容：
  ```
  套餐「{package_name}」当前有 {n} 个租户正在使用，无法删除。

  建议操作：
  · 如需停用该套餐，可使用「禁用」操作；
  · 如需彻底删除，请先将相关租户切换至其他套餐，再执行删除。
  ```
- 按钮：仅「我知道了」（default，居中），点击关闭 Modal

## 6. 异常与边界处理

| 场景 | 触发条件 | 处理方式 |
|------|----------|----------|
| 套餐名称重复 | 提交时后端返回唯一性冲突 | 套餐名称字段下方红色提示：「该套餐名称已存在」 |
| 未选择菜单直接提交 | menu_ids 为空数组 | 前端校验拦截，菜单树下方红色提示：「请至少选择一个菜单」，阻止提交 |
| 菜单树加载失败 | GET /api/platform/menus/tree 返回 5xx | 菜单树区域显示错误状态：「菜单加载失败，」[重新加载] 链接按钮 |
| 删除有绑定租户的套餐 | tenant_count > 0 | 展示不可删除提示 Modal（见 5.5.2），不执行删除 |
| 编辑时套餐已被删除 | 打开编辑后提交返回 404 | Toast 提示：「该套餐已不存在，请刷新页面」，关闭抽屉并刷新列表 |
| 菜单节点被平台下线 | 编辑回填时 menu_ids 中存在 status=0 的菜单 | 回填时过滤掉无效菜单 ID，菜单树顶部黄色 Alert：「原套餐中有 {m} 个菜单已下线，已自动移除，请确认后保存」 |
| 禁用套餐后仍有租户绑定 | 正常业务场景 | 不拦截，禁用后套餐在新增/编辑租户时不可选择；已绑定租户保持现有权限不变 |
| 网络超时 | 请求超过 10s 无响应 | 按钮恢复可点击状态，Toast 错误提示：「操作超时，请稍后重试」 |
| 并发重复提交 | 短时间内同一操作重复调用 | 前端按钮 loading 防重；后端幂等键拦截，返回 200 + 原结果 |
| 列表加载失败 | 接口返回 5xx | 表格区域显示错误状态：「数据加载失败，请刷新页面重试」，展示刷新按钮 |

## 7. 默认假设

1. **菜单树数据**：由 `sys_menu` 表维护，套餐管理模块只读引用；菜单本身的增删改属于独立的「菜单管理」模块，不在本 PRD 范围内。
2. **menu_ids 存储策略**：存储用户实际勾选的节点 ID（含中间层目录节点和叶子节点），不做去重/压缩处理；权限校验时由权限模块负责向上/向下展开。
3. **禁用套餐的影响范围**：禁用套餐仅阻止新建租户选择该套餐，已有绑定关系的租户功能访问不受即时影响；是否同步限制已绑定租户由权限模块配置决定（超出本 PRD 范围）。
4. **菜单变更实时性**：编辑套餐菜单范围保存后，绑定该套餐的租户在下次刷新页面时生效新菜单范围，不强制踢出已登录用户。
5. **时区显示**：数据库存 UTC，前端统一转为 Asia/Shanghai 展示。
6. **审计日志**：所有操作（新增、编辑、禁用、启用、删除）均写入 sys_operation_log，记录操作人 ID、操作时间、操作类型、变更前后数据快照（JSON diff 格式）。
7. **列表默认排序**：按 created_at 降序，最新创建排最前。支持点击列头切换排序。
8. **套餐数量限制**：当前版本无上限；后续可按平台策略配置。
9. **本 PRD 不覆盖**：菜单管理（sys_menu CRUD）、套餐价格/计费配置、套餐版本历史记录、租户套餐变更通知推送、套餐克隆/复制功能。
