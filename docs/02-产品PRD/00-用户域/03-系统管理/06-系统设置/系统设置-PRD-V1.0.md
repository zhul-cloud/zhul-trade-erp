# 系统设置 PRD V1.0

> 文档版本：V1.0 | 创建日期：2026-05-29 | 产品：烛龙ERP（外贸业财一体化中台）

---

## 1. 功能概述

### 1.1 功能目标

提供租户级别的系统配置集中管理能力。运维人员和租户管理员可在不重启服务的前提下动态调整系统行为参数，如系统名称、登录页样式、安全策略、会话超时等。配置分为"系统内置配置"（可改值，不可删键）和"自定义配置"（可增删改）两类。

### 1.2 使用角色

| 角色 | 操作权限 |
|------|---------|
| 超级管理员 | 查看全部配置；编辑所有配置值；管理自定义配置（增删改） |
| 租户管理员 | 查看本租户配置；编辑本租户配置值；管理本租户自定义配置 |
| 普通管理员 | 仅查看（视角色授权） |

### 1.3 入口路径

顶部导航 → 系统管理 → 系统设置（路由：`/system/config`）

## 2. 数据字段定义

### 2.1 系统配置表（sys_config）

| 字段名 | 字段标识 | 类型 | 必填 | 说明 |
|--------|---------|------|------|------|
| 主键 | id | BIGINT | 是 | 自增主键 |
| 租户ID | tenant_id | BIGINT | 是 | 多租户隔离；内置配置 tenant_id=0，各租户可覆盖 |
| 配置键 | config_key | VARCHAR(128) | 是 | 唯一标识，如 sys.site.name；点分层级命名，租户内唯一 |
| 配置名称 | config_name | VARCHAR(128) | 是 | 可读名称，如"系统名称" |
| 配置值 | config_value | TEXT | 是 | 实际配置值，统一以字符串存储 |
| 配置类型 | config_type | VARCHAR(32) | 是 | 值类型标注：STRING / INTEGER / BOOLEAN / JSON / URL；用于前端渲染合适的编辑组件 |
| 是否内置 | is_builtin | TINYINT | 是 | 0=自定义，1=系统内置；内置配置不可删除键 |
| 是否加密 | is_encrypted | TINYINT | 是 | 0=明文，1=加密存储（如密钥类配置）；加密配置值展示脱敏 |
| 配置分组 | config_group | VARCHAR(64) | 是 | 分组标签，如 基础设置 / 安全策略 / 邮件设置 / 外观设置 |
| 备注 | remark | VARCHAR(256) | 否 | 配置项说明，展示在编辑弹窗内 |
| 创建人ID | created_by | BIGINT | 是 | 操作人用户ID |
| 创建时间 | created_at | DATETIME | 是 | UTC 时间 |
| 更新人ID | updated_by | BIGINT | 是 | 操作人用户ID |
| 更新时间 | updated_at | DATETIME | 是 | UTC 时间 |
| 删除时间 | deleted_at | DATETIME | 否 | 仅自定义配置可软删除；内置配置此字段永远为 NULL |

**索引规范：**
- `idx_tenant_key`：(tenant_id, config_key)，唯一索引
- `idx_tenant_group`：(tenant_id, config_group)
- `idx_is_builtin`：(is_builtin)

**列表表格列定义：**

| 列名 | 字段 | 说明 |
|------|------|------|
| 配置键 | config_key | 等宽字体展示，最长超出截断并 Tooltip 显示完整值 |

### 5.2 编辑配置值弹窗

**弹窗规格：** 宽度 520px。

**弹窗内容：**
- 顶部只读展示区（灰色背景卡片）：配置键、配置名称、类型、来源（内置/自定义）、备注说明。
- 中部可编辑区：根据 `config_type` 渲染不同组件。

| config_type | 编辑组件 | 校验规则 |
|-------------|---------|---------|
| STRING | Input / TextArea（长内容） | 最长 4096字符 |
| INTEGER | InputNumber | 整数；部分配置有范围限制（如密码长度 6~32） |
| BOOLEAN | Switch | true / false，存储为字符串 "true" / "false" |
| JSON | TextArea（等宽字体）+ 实时 JSON 校验 | 合法 JSON 格式 |
| URL | Input | 以 http/https 开头或以 / 开头的相对路径 |

- 底部提示文字：若配置修改后需重启服务生效，展示提示"⚠ 该配置修改后需重启服务生效"（由字段 `remark` 中预设）。
- 加密配置：编辑时输入框使用 Password 类型，已有值显示"（已配置，修改请重新输入）"，留空表示不修改。

**底部按钮：** [取消] [保存]

---

### 5.3 新增自定义配置弹窗

**弹窗规格：** 宽度 520px。

| 字段 | 组件类型 | 必填 | 校验规则 |
|------|---------|------|---------|
| 配置键 | Input | 是 | 点分层级命名，小写字母+数字+点+下划线，4~128字符，租户内唯一；不可使用 sys. 前缀（系统保留） |
| 配置名称 | Input | 是 | 1~128字符 |
| 配置类型 | Select | 是 | STRING / INTEGER / BOOLEAN / JSON / URL |
| 配置值 | 动态渲染（同编辑弹窗规则） | 是 | 与类型对应的格式校验 |
| 配置分组 | Select | 是 | 选项：基础设置 / 安全策略 / 外观设置 / 邮件设置 / 自定义（默认自定义） |
| 是否加密 | Switch | 是 | 默认关；开启后值加密存储、界面脱敏显示 |
| 备注 | TextArea | 否 | 最多256字符 |

**提交成功后：** 关闭 Modal → Toast"新增成功" → 切换到对应分组 Tab，高亮新增行。

---

### 5.4 删除自定义配置确认

- 仅"自定义配置"（`is_builtin=0`）的行显示"删除"操作。
- 点击删除直接弹出 Confirm（无前置检查）：
  - 内容："确认删除配置项「{config_name}」（键：{config_key}）？删除后不可恢复，请确认没有业务代码依赖此配置键。"
  - 按钮：[取消] [确认删除]（danger 样式）
- 删除为软删除（写入 `deleted_at`）。

### 5.5 配置值变更审计

每次配置值修改，后端记录操作日志：

| 记录字段 | 说明 |
|---------|------|
| operator_id | 操作人用户ID |
| operator_name | 操作人姓名 |
| config_key | 被修改的配置键 |
| old_value | 修改前的值（加密配置记录 ****） |
| new_value | 修改后的值（加密配置记录 ****） |
| operated_at | 操作时间 UTC |
| ip | 操作人 IP |

> 审计日志可在"操作日志"模块查阅，本 PRD 不涵盖日志展示页面。

## 6. 异常与边界处理

| 场景 | 错误码 | 处理方式 |
|------|--------|---------|
| 配置键重复 | `CONFIG_KEY_DUPLICATE` | 表单行内报错"配置键已存在" |
| 配置键使用 sys. 保留前缀 | `CONFIG_KEY_RESERVED_PREFIX` | 前端实时校验："sys. 为系统保留前缀，自定义配置请使用其他前缀" |
| 编辑内置配置的键或来源 | — | 键和来源字段只读，不提供编辑入口 |
| 删除内置配置 | `CONFIG_BUILTIN_FORBIDDEN` | 内置配置行不显示"删除"按钮；接口层兜底返回错误 |
| INTEGER 类型值非整数 | — | 前端 InputNumber 组件约束，提交前校验 |
| JSON 类型值格式非法 | — | TextArea 实时解析，错误时行内提示"JSON 格式不合法"，阻断提交 |
| URL 类型值格式非法 | — | 前端正则校验，行内提示"请输入合法的 URL 地址" |
| BOOLEAN 类型值修改 | — | Switch 切换后实时显示"true"/"false"文本预览 |
| 配置值超长 | — | 前端字符计数，超出限制时提示并阻断提交 |
| 加密配置编辑留空 | — | 视为"不修改"，后端保留原值 |
| 加密配置值回显 | — | 一律显示 ****，不可复制查看原始值 |
| 配置修改需重启生效 | — | 在编辑弹窗内显示警告提示（由 remark 字段配置） |
| 搜索无结果 | — | 列表显示空状态"未找到符合条件的配置项" |
| 接口超时/网络错误 | — | Toast 提示"网络请求失败，请稍后重试" |
| 无操作权限 | `FORBIDDEN` | 编辑/删除按钮不渲染；接口403时 Toast 提示"无操作权限" |

## 7. 默认假设

1. 系统内置配置（`is_builtin=1`）由部署时的初始化脚本写入，`tenant_id=0` 为全局模板；各租户首次访问时按需从全局模板继承，形成租户独立的配置副本（`tenant_id=租户ID`），不同租户的配置修改互不影响。
2. 配置键使用 `sys.` 前缀的为系统保留命名空间，自定义配置不可使用此前缀。
3. 配置值统一以 VARCHAR/TEXT 字符串存储；业务代码按 `config_type` 做类型转换。
4. 加密配置值（`is_encrypted=1`）在数据库中存密文，后端通过 AES 加密；前端展示时一律脱敏为 ****，编辑时重新输入覆盖。
5. 配置数据应用层做内存缓存（TTL 建议 1~5 分钟），配置修改后主动推送失效事件。
6. 删除操作仅适用于自定义配置，且为软删除（写入 `deleted_at`）。内置配置的 `deleted_at` 字段永远为 NULL。
7. 所有配置修改操作须记录完整操作审计日志，包含操作人、操作前后值、IP、时间。
8. 所有 DATETIME 字段后端存储 UTC，前端按用户时区展示，格式 `YYYY-MM-DD HH:mm`。
9. 本 PRD 配置项仅覆盖租户级别配置；超级管理员的平台级配置（如全局限流、存储配置）通过独立的运维管理后台配置，不在此页面展示。
