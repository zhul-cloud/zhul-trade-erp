## 1. 功能概述

### 1.1 功能目标

为租户超级管理员提供系统菜单资源（目录、菜单、按钮）的可视化管理能力，支持三级树形结构的增删改查、排序调整及状态控制，为角色权限分配提供资源数据基础。

### 1.2 使用角色

| 角色 | 操作范围 | 说明 |
|------|----------|------|
| 租户超级管理员（super_admin） | 全部操作 | 可管理全部菜单资源 |
| 系统管理员（sys_admin） | 查看 + 编辑菜单/按钮 | 不可新增/删除目录级节点 |

> 注：菜单管理属高权限敏感操作，普通用户无入口访问。

### 1.3 入口路径

顶部导航 → 系统管理 → 菜单管理
路由：`/system/menus`

## 2. 数据字段定义

### 2.1 资源表（resource）

| 字段名 | 字段标识 | 类型 | 必填 | 说明 |
|--------|----------|------|------|------|
| 资源ID | id | BIGINT | 是 | 主键，系统自动生成 |
| 租户ID | tenant_id | BIGINT | 是 | 所属租户，多租户隔离 |
| 资源编码 | resource_code | VARCHAR(64) | 是 | 格式：RS+类型缩写+主键，系统生成，全局唯一 |
| 资源名称 | resource_name | VARCHAR(64) | 是 | 菜单显示名称，同层级内唯一 |
| 资源类型 | resource_type | TINYINT | 是 | 1-目录 2-菜单 3-按钮 |
| 父节点ID | parent_id | BIGINT | 是 | 顶级节点填0 |
| 路由路径 | route_path | VARCHAR(256) | 条件 | type=2（菜单）时必填，如 /system/users |
| 组件路径 | component_path | VARCHAR(256) | 条件 | type=2（菜单）时必填，前端组件相对路径 |
| 权限标识 | permission | VARCHAR(128) | 条件 | type=3（按钮）时必填，如 system:user:add |
| 图标（浅色） | icon_light | VARCHAR(256) | 否 | 浅色主题图标，图标名称或URL |
| 图标（深色） | icon_dark | VARCHAR(256) | 否 | 深色主题图标，图标名称或URL |
| 排序号 | sort_order | INT | 是 | 同父节点下升序排列，默认99 |
| 微应用标识 | micro_app_key | VARCHAR(64) | 否 | 微前端子应用标识，如 crm、oms |
| 是否外链 | is_external | TINYINT | 是 | 1-外链（新标签打开）0-内部路由，默认0 |
| 是否缓存 | is_cache | TINYINT | 是 | 1-keep-alive缓存 0-不缓存，默认1 |
| 是否隐藏 | is_hidden | TINYINT | 是 | 1-不在侧边栏显示 0-显示，默认0 |
| 状态 | status | TINYINT | 是 | 1-启用 0-禁用，默认1 |
| 创建人 | created_by | BIGINT | 是 | 操作人 user_id |
| 创建时间 | created_at | DATETIME | 是 | UTC时间 |
| 更新时间 | updated_at | DATETIME | 是 | UTC时间 |
| 删除时间 | deleted_at | DATETIME | 否 | 软删除标记，NULL表示未删除 |

### 2.2 资源类型说明

| 类型值 | 类型名称 | 层级位置 | 特殊说明 |
|--------|----------|----------|----------|
| 1 | 目录 | 第一级（根节点或目录子节点） | 可包含菜单，不含路由，无前端组件 |
| 2 | 菜单 | 目录子节点 | 对应前端页面，须填路由路径和组件路径 |
| 3 | 按钮 | 菜单子节点 | 对应页面内操作权限，须填权限标识 |

**列说明：**
- 菜单名称：带层级缩进（每级缩进16px），前置图标区分类型（目录=FolderOutlined，菜单=MenuOutlined，按钮=ThunderboltOutlined）
- 资源编码：等宽字体，hover显示复制图标，点击复制到剪贴板
- 类型：Tag显示，目录=蓝色，菜单=绿色，按钮=橙色
- 排序：数字显示，点击进入行内编辑（InputNumber），失焦或回车保存，立即提交 PATCH 请求
- 状态：Switch 控件，可直接点击切换，切换前弹出确认（若有子节点则说明级联影响）
- 隐藏：是/否 文字展示；按钮节点类型不适用，显示"--"
- 操作列：
  - 目录、菜单节点：+子节点、编辑、禁用/启用、删除
  - 按钮节点：编辑、禁用/启用、删除（无+子节点按钮）

**工具栏交互：**
- 展开全部：所有树节点展开到最深层
- 折叠全部：收起至顶级目录节点
- 名称搜索：Input，输入后过滤，仅显示匹配节点及其父节点路径，关键字高亮黄色，父节点自动展开；清空后恢复完整树
- 新增顶级目录：打开新增抽屉，类型预设为目录，父节点为空

**排序调整（V1.0 内置方案）：**
- 通过点击排序号字段在线编辑 sort_order 数值
- 同一父节点下按 sort_order 升序渲染
- 拖拽排序为可选功能，V1.1 迭代实现

**从行操作"+子节点"打开时：**
- 从目录行点击：类型预设"菜单"，父节点预设为该目录（只读不可改）
- 从菜单行点击：类型预设"按钮"，父节点预设为该菜单（只读不可改）

**父节点选择器过滤规则：**
- 选类型为菜单时：父节点 TreeSelect 仅可选资源类型=1（目录）的节点
- 选类型为按钮时：父节点 TreeSelect 仅可选资源类型=2（菜单）的节点
- 选类型为目录时：父节点可选已有目录或留空（顶级），但已有菜单/按钮节点不可选

**校验规则：**
- 资源名称：必填，2-64字符，blur 时调用接口校验同层级内是否重名
- 路由路径（菜单）：必填，以 `/` 开头，blur 时校验租户内唯一性
- 组件路径（菜单）：必填，不以 `/` 开头，格式如 `module/page/index`
- 权限标识（按钮）：必填，格式 `模块:资源:操作`（均小写，冒号分隔），blur 时校验全局唯一性
- 排序号：必填，正整数 1-9999

**提交逻辑（POST /api/system/resources）：**
1. 后端生成 resource_code（RS + 类型数字 + id，如 RS2000123）
2. 写入 resource 表
3. 成功：关闭抽屉，树形列表刷新，新增节点自动定位并高亮3秒，父节点自动展开
4. 失败：抽屉保持，显示具体错误信息

### 5.3 P-MNU-03 编辑节点抽屉

**标题：** "编辑资源节点 - {resource_name}"

布局与新增抽屉一致，差异：
- 资源类型：只读 Tag 展示（不可切换类型）
- 资源编码：只读展示
- 父节点：只读展示当前父节点名称（不可修改层级归属，需移动则删除重建）
- 表单回填当前节点所有字段值

**提交逻辑（PUT /api/system/resources/{id}）：**
1. 允许修改字段：资源名称、路由路径、组件路径、权限标识、微应用标识、图标（浅/深）、排序号、是否外链、是否缓存、是否隐藏、状态
2. 校验与新增相同，校验唯一性时排除当前节点自身
3. 若 status 从1改为0，同步级联禁用所有子节点
4. 成功：关闭抽屉，树形列表局部刷新该节点，显示"节点信息已更新"

### 5.4 P-MNU-04 删除确认弹窗

**情况A：节点有子节点，不可删除**

```
+--------------------------------------------+
| 无法删除                                   |
+--------------------------------------------+
| 节点「订单管理」下还有 3 个子节点：         |
|                                            |
|  · 销售订单（菜单，含5个按钮）             |
|  · 采购订单（菜单，含3个按钮）             |
|  · 退换货申请（菜单，含2个按钮）           |
|                                            |
| 请先删除全部子节点后再执行此操作。          |
+--------------------------------------------+
|                              [我知道了]    |
+--------------------------------------------+
```

**情况B：节点已被角色引用，二次确认**

```
+--------------------------------------------+
| 删除确认                                   |
+--------------------------------------------+
| ! 警告：节点「新增订单」已被以下角色引用：  |
|                                            |
|   销售员、报价员、客户经理 共 3 个角色     |
|                                            |
| 删除后，上述角色将自动失去此节点权限，      |
| 且操作不可恢复。                           |
|                                            |
| 确认继续删除？                             |
+--------------------------------------------+
|                    [取消]  [确认删除]      |
+--------------------------------------------+
```

**情况C：节点无子节点且无角色引用，普通确认**

```
+--------------------------------------------+
| 确认删除                                   |
+--------------------------------------------+
| 确认删除节点「查看订单列表」？              |
| 此操作不可恢复。                           |
+--------------------------------------------+
|                    [取消]  [确认删除]      |
+--------------------------------------------+
```

**删除逻辑（DELETE /api/system/resources/{id}）：**
1. 后端检查子节点：`SELECT COUNT(*) FROM resource WHERE parent_id=? AND deleted_at IS NULL`，有则返回 400 + 子节点列表 → 前端展示情况A，阻断流程
2. 后端检查角色引用：`SELECT role_id FROM role_resource WHERE resource_id=?`，有则返回关联角色信息 → 前端展示情况B，用户可确认继续
3. 执行删除：软删除 resource（设 deleted_at=NOW()）+ 物理删除 role_resource 中相关记录（同一事务）
4. 清除关联角色权限缓存（Redis）
5. 成功：列表刷新，显示 Message "节点已删除"

## 6. 异常与边界处理

| 场景 | 处理方式 | 用户提示 |
|------|----------|----------|
| 同层级资源名称重复 | blur实时校验 + 提交时后端校验 | "同级下已存在同名节点，请更换" |
| 路由路径租户内重复（菜单） | blur实时校验 | "该路由路径已被其他菜单使用" |
| 权限标识全局重复（按钮） | blur实时校验 | "该权限标识已存在，请更换" |
| 删除有子节点的节点 | 后端返回400，展示情况A弹窗，阻断 | 展示子节点列表，仅提供关闭按钮 |
| 删除被角色引用的节点 | 展示情况B弹窗，用户二次确认后可删 | 展示引用角色名称，确认后执行 |
| 禁用有子节点的目录/菜单 | 弹窗说明级联影响，确认后级联禁用 | "下级 X 个子节点将同步禁用，确认继续？" |
| 排序号在线编辑接口失败 | 恢复原值显示 | "排序保存失败，请重试" |
| 菜单树接口加载失败 | 展示空状态 + 重试按钮 | "菜单数据加载失败，请刷新页面" |
| 父节点选择超出允许类型 | 前端 TreeSelect 过滤可选节点 | 不可选的节点置灰，hover提示类型限制 |
| 并发编辑同一节点 | 后端乐观锁校验 updated_at | "数据已被其他管理员修改，请刷新后重试" |
| 路由路径格式错误（不以/开头） | 前端正则实时校验 | "路由路径需以 / 开头" |
| 权限标识格式错误 | 前端正则实时校验 | "权限标识格式为：模块:资源:操作（小写字母，冒号分隔）" |
| 搜索无匹配结果 | 树形为空，显示空状态 | "未找到匹配的菜单节点" |

## 7. 默认假设

1. 资源编码（RS+类型数字+主键ID）由后端系统自动生成，不可手动修改。
2. 层级约定：目录（第1级）→ 菜单（第2级）→ 按钮（第3级），按钮下不能再有子节点。目录可嵌套目录，但建议不超过2层目录（即：根目录 > 子目录 > 菜单 > 按钮）。
3. 禁用父节点时，级联禁用所有后代节点，保持树形一致性；启用父节点时不自动启用子节点（需手动逐一启用）。
4. 菜单资源变更（增/删/改/禁用）均清除关联角色的权限缓存，确保权限实时生效。
5. 菜单管理的资源树为本租户私有，不同租户的菜单数据相互隔离。
6. 路由路径（route_path）在本租户范围内唯一；权限标识（permission）在全系统全局唯一。
7. 图标选择器支持两种输入方式：内置 Ant Design Icons 图标名称选择 + 自定义图片URL直接输入。
8. 微应用标识（micro_app_key）通过独立的微前端注册表维护，本期通过下拉框选择，留空表示主应用。
9. 拖拽排序为 V1.0 可选功能，默认不上线，通过修改 sort_order 数值调整顺序，V1.1 迭代拖拽实现。
10. 所有删除操作对 resource 表执行软删除，对 role_resource 关联表执行物理删除。
11. 操作审计日志记录所有增删改操作，包含操作人 user_id、时间（UTC）、变更前后字段快照，保留180天。
12. 时间存储为UTC，页面展示时转换为用户本地时区（默认东八区）。
