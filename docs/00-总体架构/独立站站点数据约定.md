# 独立站站点数据约定（第 1 版）

ERP 与自动发布站点之间只通过这份约定交换数据，站点怎么生成页面由站点仓库自己负责。完整格式以站点仓库的 `erp/README.md` 为准（fouwell.com：`zhul-cloud/fouwell-website`），本文只记 ERP 这边需要遵守的要点。对应 OpenSpec 变更 `website-publish`。

## 站点仓库提供的脚本

| 脚本 | 用途 |
| --- | --- |
| `erp/build.sh [文件]` | 读取站点数据文件，写入站点的数据文件，重新构建英文和俄文全部页面，写入发布单标记，更新缓存版本号 |
| `erp/verify.js 检查清单 [--root 目录]` | 用真实浏览器、禁用缓存检查商品页；带 `--root` 是部署前的本地检查，不带是线上检查 |
| `erp/export-existing.js [--out 文件]` | 把站点现有商品按同一格式导出，供导入使用 |

每一步在标准输出打印一行 JSON；失败时标准错误最后一行是 `{"errors":[…]}`，退出码非 0。

## 站点数据文件 `erp/site-data.json`

```json
{
  "schemaVersion": 1,
  "site": { "code": "fouwell.com", "nonGenuineBrands": ["PWERUN", "Generic", "General"] },
  "generatedAt": "2026-11-27T08:00:00.000Z",
  "release": "WP10001",
  "products": [ … ]
}
```

- **全量**：包含站点上的全部商品，按展示顺序排列。导入后 ERP 没改过的商品，按导出时的内容原样带上。站点上有、文件里没有的商品会让构建失败（不支持下架）。
- **商品**：站点 `js/data.js` 里 `PRODUCTS` 的一条，加上六个字段：
  - `slug`：发布后锁定的链接别名，必须与站点按品牌、系列、型号算出的一致，否则构建失败；
  - `release`：最近一次发布这个商品的发布单号，写进中英文商品页的 `<meta name="erp-release">`。每次构建都要带上，没在这次发布里的商品才能保留原标记；
  - `photos`：`[{src, tag: "Photo"|"Marketing"}]`，第一张是图集主图；
  - `videos`：`[{src, title}]`；
  - `spec_ru`：俄文一句话规格；
  - `deep_ru`：俄文的规格、应用场景、型号关系、FAQ。
- **其余字段原样写入**：包括本文没有列出的站点独有字段，所以导入后再发布不会丢字段。
- **必填**：`brand`、`model`、`spec`、`series`（可以为空字符串）；`cat` 必须是站点的品类代码；`status` 必须是站点的状态（`instock`、`legacy`、`discont`、`quote`）。
- **售价**：`sell_price` 为正数，必须同时带 `sell_price_currency`。
- **素材地址**：`photo`、`linkedin`、`photos[].src`、`videos[].src` 以 `/`（仓库里的文件）或 `https://`（OSS 公开桶）开头：
  - ERP 发布的素材一律给 OSS 完整链接，不往仓库里写文件；
  - 导入的旧商品保留原来以 `/assets/...` 开头的路径。

## 链接别名算法

```
slugPiece(s) = 转小写 → 空格、_、.、/ 连续出现时换成一个 "-" → 去掉 a-z、0-9、- 以外的字符 → 合并连续的 "-" → 去掉首尾 "-"
slug         = [slugPiece(品牌), slugPiece(系列), slugPiece(型号)] 去掉空的部分后用 "-" 连接
页面         = /products/<slug>/ 和 /ru/products/<slug>/
```

ERP 生成链接别名时必须用同一算法，否则构建会因别名不一致而失败。

## 检查清单（verify.js 的输入）

`[{ "url": "https://fouwell.com/products/<slug>/", "images": 6, "video": true, "release": "WP10001" }]`

逐页检查以下几项：
- 返回 200；
- canonical 等于 `url`；
- `images` 大于 0 时，主图实际加载出来（宽度大于 0）；
- 缩略图数量等于 `images`；
- `video` 为 `true` 时有视频区块，为 `false` 时没有；
- 页面里的发布单标记与 `release` 一致。

旧素材没有提交进仓库，只在线上服务器上，所以本地检查要加 `--asset-fallback https://fouwell.com`：仓库里找不到的 `/assets/...` 文件改从线上站点取。
