> 文档版本：V1.0 | 创建日期：2026-05-29 | 产品：烛龙ERP（外贸业财一体化中台）

## 1. 功能概述

### 1.1 功能目标

登录日志模块记录所有用户的登录行为轨迹，包括登录成功、登录失败及当前在线状态，提供安全审计、异常登录排查能力。管理员可通过强制下线功能使异常在线用户的 Token 立即失效，保障账号安全。

### 1.2 使用角色

| 角色 | 权限说明 |
|------|----------|
| 超级管理员 | 查看所有租户登录日志、导出、强制下线任意在线用户 |
| 租户管理员 | 查看本租户所有用户登录日志、导出、强制下线本租户在线用户 |
| 普通管理员（具备日志查看权限） | 查看本租户登录日志、导出；强制下线权限需单独授权 |

> 登录日志为只读模块，不可编辑或删除记录。强制下线操作本身会触发一条操作日志记录（type=2）。

### 1.3 入口路径

```
顶部导航 → 系统管理 → 登录日志
菜单路由：/system/login-log
```

## 2. 数据字段定义

底层数据表：`sys_log`（type = 1）

| 字段名 | 字段标识 | 类型 | 必填 | 说明 |
|--------|----------|------|------|------|
| 主键ID | id | BIGINT | 是 | 自增主键 |
| 租户ID | tenant_id | VARCHAR(64) | 是 | 多租户隔离，由后端从 Token 注入 |
| 操作人工号 | operator_code | VARCHAR(64) | 是 | 登录用户唯一标识 |
| 操作人姓名 | operator_name | VARCHAR(128) | 是 | 登录用户显示名（即用户名） |
| 操作时间 | operate_time | DATETIME | 是 | 登录时间，UTC 存储，前端按用户时区展示 |
| 操作IP | ip | VARCHAR(64) | 是 | 客户端 IP 地址 |
| 操作结果 | result | TINYINT | 是 | 0=登录失败，1=登录成功 |
| 操作内容 | content | JSON | 否 | 存储浏览器、操作系统、登录地点等扩展信息（见下方结构） |
| 日志类型 | type | TINYINT | 是 | 固定值 1（登录日志） |
| 创建时间 | created_at | DATETIME | 是 | 同 operate_time，UTC |
| 更新时间 | updated_at | DATETIME | 是 | 系统维护字段 |
| 删除标记 | deleted_at | DATETIME | 否 | 软删除，NULL 表示有效记录 |

### content 字段结构说明（登录日志专用）

```json
{
  "browser":    "Chrome 124.0",
  "os":         "Windows 11",
  "location":   "广东省深圳市",
  "token_id":   "abc123xyz",
  "is_online":  true,
  "fail_reason": "密码错误"
}
```

| 子字段 | 类型 | 说明 |
|--------|------|------|
| browser | String | 浏览器名称及版本，由 User-Agent 解析；解析失败为"未知" |
| os | String | 操作系统名称及版本，由 User-Agent 解析；解析失败为"未知" |
| location | String | IP 地址解析地理位置（市级精度）；解析失败为"未知" |
| token_id | String | 登录成功时签发的 Token 标识，用于强制下线；result=0 时为 null |
| is_online | Boolean | 当前是否仍在线（Token 未过期且未被踢出）；result=0 时为 false |
| fail_reason | String | 登录失败原因；仅 result=0 时存在，如"密码错误"、"账号已禁用" |

## 6. 异常与边界处理

| 场景 | 处理方式 |
|------|----------|
| 搜索结果为空 | 表格显示空状态，文案：「未找到符合条件的登录日志」 |
| 查询时间范围超过 90 天 | 允许查询，表格顶部 Warning Banner：「查询范围较大（> 90天），可能影响响应速度」 |
| 导出数据超过 50,000 条 | 拦截请求，Toast 错误提示：「当前数据量超过5万条，请缩小查询时间范围后再导出」 |
| 导出超时（> 30s） | Toast 错误：「导出超时，请缩小范围重试」，按钮恢复可用 |
| IP 地理位置解析失败 | 登录地点列显示「未知」，不影响其他列展示 |
| User-Agent 解析失败 | 浏览器/操作系统列各自显示「未知」 |
| 强制下线时 Token 已自然过期 | 后端幂等处理，返回成功；前端提示「已成功强制下线」，刷新列表 |
| 强制下线当前登录账号 | 后端校验拦截，返回业务错误码，Toast 提示：「不能强制下线当前登录账号」 |
| 强制下线无权限 | 接口返回 403，Toast 错误：「无权限执行此操作」；按钮恢复可用 |
| 网络请求失败（列表加载） | 表格区域显示「加载失败，请刷新重试」，含【重试】链接 |
| 查询时间开始 > 结束 | DateRangePicker 自身校验阻止选择，不允许提交 |
| operate_time 无时区配置 | 按 UTC+8（中国标准时间）展示 |
| 日志数据超出保留期（已归档） | 列表顶部 Info Banner：「所选时间范围内部分数据已归档，当前仅显示在线数据」；查询正常返回热数据 |
| is_online 状态与实际不一致（缓存延迟） | 以后端实时 Token 有效性为准；强制下线接口做最终判断；前端「在线」标识仅供参考 |
| 强制下线部分失败 | 失败用户保持勾选状态（列表刷新后重新勾选），提示用户重试 |
| content 字段为 null 或格式损坏 | 登录地点、浏览器、操作系统列均显示「未知」；不影响其他列展示 |

## 7. 默认假设

1. **日志保留策略**：生产环境热存储保留不少于 15 天；超期日志由系统自动归档，前端查询仅限热存储数据。
2. **分页默认值**：默认每页 20 条，可切换 20 / 50 / 100 条。
3. **权限隔离**：多租户场景下，tenant_id 由后端从 JWT Token 解析注入查询条件，前端不传递，防止越权。
4. **强制下线权限**：独立权限节点 `sys:login-log:force-logout`，需在角色权限中单独授予；无此权限的用户不渲染强制下线按钮。
5. **Token 失效机制**：强制下线通过 token_id 加入后端黑名单（Redis）实现；黑名单 TTL 与 Token 原有效期一致，到期自动清理。
6. **在线状态精度**：is_online 字段由登录/登出/Token 刷新事件维护，存在分钟级延迟；实际有效性以后端实时校验为准。
7. **IP 地理位置解析**：登录时由后端调用离线 IP 库（如 GeoIP2）解析并写入 content.location，不在查询时实时解析。
8. **User-Agent 解析**：浏览器和操作系统信息在登录时由后端 User-Agent 解析库处理并写入 content，不在前端解析。
9. **导出权限**：与查看权限相同，有查看权限即可导出，无需单独配置导出权限节点。
10. **默认查询时间**：页面初始化加载最近 7 天，避免全量扫描导致性能问题。
11. **强制下线操作留痕**：每次强制下线成功均在操作日志（sys_log type=2）中记录完整操作轨迹，含被下线用户信息。
