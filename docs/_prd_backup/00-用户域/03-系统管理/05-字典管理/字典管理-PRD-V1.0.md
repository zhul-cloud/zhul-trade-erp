# 字典管理 PRD V1.0

> 文档版本：V1.0 | 创建日期：2026-05-29 | 产品：烛龙ERP（外贸业财一体化中台）

---

## 1. 功能概述

### 1.1 功能目标

提供系统数据字典的集中维护能力。字典管理分为两层：字典类型（字典目录）和字典项（具体键值对）。通过字典管理，各业务模块的下拉选项、状态枚举等可在不修改代码的情况下灵活配置，避免硬编码。

### 1.2 使用角色

| 角色 | 操作权限 |
|------|---------|
| 超级管理员 | 全部操作，包括内置字典的字典项编辑 |
| 租户管理员 | 管理本租户字典类型及字典项（内置类型不可删除，项可编辑） |
| 普通管理员 | 查看（增删改权限视角色授权而定） |

### 1.3 入口路径

顶部导航 → 系统管理 → 字典管理（路由：`/system/dict`）

## 2. 数据字段定义

### 2.1 字典类型表（dict_type）

| 字段名 | 字段标识 | 类型 | 必填 | 说明 |
|--------|---------|------|------|------|
| 主键 | id | BIGINT | 是 | 自增主键 |
| 租户ID | tenant_id | BIGINT | 是 | 多租户隔离；内置字典 tenant_id=0 |
| 字典类型编码 | dict_type | VARCHAR(64) | 是 | 唯一标识符，如 sys_user_status；蛇形命名，租户内唯一 |
| 字典类型名称 | dict_name | VARCHAR(128) | 是 | 展示名，如"用户状态" |
| 是否内置 | is_builtin | TINYINT | 是 | 0=自定义，1=系统内置；内置字典不可删除 |
| 状态 | status | TINYINT | 是 | 0=禁用，1=启用；默认 1 |
| 备注 | remark | VARCHAR(256) | 否 | 补充说明 |
| 创建人ID | created_by | BIGINT | 是 | 操作人用户ID |
| 创建时间 | created_at | DATETIME | 是 | UTC 时间 |
| 更新人ID | updated_by | BIGINT | 是 | 操作人用户ID |
| 更新时间 | updated_at | DATETIME | 是 | UTC 时间 |
| 删除时间 | deleted_at | DATETIME | 否 | 软删除；内置字典不可软删除 |

### 2.2 字典项表（dict_item）

| 字段名 | 字段标识 | 类型 | 必填 | 说明 |
|--------|---------|------|------|------|
| 主键 | id | BIGINT | 是 | 自增主键 |
| 租户ID | tenant_id | BIGINT | 是 | 与所属字典类型一致 |
| 字典类型ID | dict_type_id | BIGINT | 是 | 外键关联 dict_type.id |
| 字典类型编码 | dict_type | VARCHAR(64) | 是 | 冗余存储，方便查询 |
| 字典项编码 | item_code | VARCHAR(64) | 是 | 同字典类型下唯一，如 ENABLED |
| 字典项名称 | item_name | VARCHAR(128) | 是 | 展示名，如"启用" |
| 字典值 | item_value | VARCHAR(256) | 是 | 实际存储/传输的值，如 1 / true / ENABLED |
| 样式标签 | css_class | VARCHAR(64) | 否 | 前端渲染用，如 success / warning / error |
| 显示图标 | list_class | VARCHAR(64) | 否 | Tag 颜色或图标标识 |
| 排序号 | sort_order | INT | 是 | 同字典类型下排序，升序，默认 0 |
| 是否默认 | is_default | TINYINT | 是 | 0=否，1=是；同字典类型只允许一个默认值 |
| 状态 | status | TINYINT | 是 | 0=禁用，1=启用；默认 1 |
| 备注 | remark | VARCHAR(256) | 否 | 补充说明 |
| 创建人ID | created_by | BIGINT | 是 | 操作人用户ID |
| 创建时间 | created_at | DATETIME | 是 | UTC 时间 |
| 更新人ID | updated_by | BIGINT | 是 | 操作人用户ID |
| 更新时间 | updated_at | DATETIME | 是 | UTC 时间 |
| 删除时间 | deleted_at | DATETIME | 否 | 软删除标记 |

**索引规范：**
- dict_type 表：`idx_tenant_type`：(tenant_id, dict_type)，唯一索引
- dict_item 表：`idx_type_code`：(dict_type_id, item_code)，唯一索引；`idx_dict_type`：(dict_type)

## 5. 页面详细说明

### 5.1 字典管理主页面

**整体布局（左侧目录 + 右侧内容）：**

```
+-------------------------------------------------------------+
| 面包屑：系统管理 / 字典管理                                   |

|                    |                                        |
| [+ 新增字典类型]    | 当前字典：用户状态 (sys_user_status)    |

| -------------------| ----------------------------------------|
| 系统内置           | +--------+--------+------+------+------+|
|  用户状态     [选中]| | 字典项码 | 字典名  | 字典值| 状态 | 操作 ||
|  订单状态          | +--------+--------+------+------+------+|

|  客户等级          |                                        |

```

**左侧字典类型列表：**
- 按 `is_builtin` 分组展示：上方"系统内置"，下方"自定义"。
- 每条目展示：字典类型名称 + 小角标（内置标记"内置"badge）。
- 支持关键词搜索（按 dict_name 模糊匹配）。
- 点击条目：右侧切换展示该字典类型的字典项。
- 每个条目 hover 时出现"编辑"和"删除"图标按钮。
- 内置字典：删除图标置灰并 Tooltip 提示"系统内置字典不可删除"。

**右侧字典项区域：**
- 未选中字典类型时：展示空状态"请在左侧选择一个字典类型"。
- 选中后显示字典类型名称 + 编码，以及字典项表格。
- 工具栏：[+ 新增字典项]。

**右侧字典项表格列定义：**

| 列名 | 字段 | 说明 |
|------|------|------|
| 字典项编码 | item_code | 文本展示 |
| 字典项名称 | item_name | 文本展示 |
| 字典值 | item_value | 文本展示 |
| 样式标签 | css_class | 若有值则以对应颜色 Tag 展示 |
| 是否默认 | is_default | 勾选图标展示 |
| 排序 | sort_order | 数字展示 |
| 状态 | status | Badge 展示 |
| 操作 | — | 编辑 / 删除 |

| 字典项编码 | Input | 是 | 大写字母+下划线，2~64字符，同字典类型下唯一；编辑时只读 |
| 字典项名称 | Input | 是 | 1~128字符 |

| 是否默认 | Switch | 是 | 默认关；开启时若同字典类型已有默认项，后端自动将原默认项改为非默认 |
| 排序号 | InputNumber | 是 | 整数，0~9999，默认 0 |
| 状态 | RadioGroup | 是 | 启用 / 禁用，默认启用 |
| 备注 | TextArea | 否 | 最多256字符 |

**底部按钮：** [取消] [确定]

---

### 5.4 删除字典类型确认

前置检查顺序：
1. 是否内置（`is_builtin=1`）→ 是则 Toast 阻断"系统内置字典不可删除"。
2. 是否有未删除的字典项 → 有则 Toast 阻断"请先删除该字典类型下的所有字典项"。
3. 通过后弹出 Confirm："确认删除字典类型「{dict_name}」？"，[取消] [确认删除]。

### 5.5 删除字典项确认

无前置依赖检查，直接弹出 Confirm："确认删除字典项「{item_name}」？" [取消] [确认删除]。

## 6. 异常与边界处理

| 场景 | 错误码 | 处理方式 |
|------|--------|---------|
| 字典类型编码重复 | `DICT_TYPE_CODE_DUPLICATE` | 表单行内报错"字典类型编码已存在" |
| 删除内置字典类型 | `DICT_BUILTIN_FORBIDDEN` | 前端图标置灰阻断；后端兜底返回错误 |
| 删除有字典项的字典类型 | `DICT_TYPE_HAS_ITEMS` | 前端预检阻断，Toast 提示"请先删除该字典类型下的所有字典项" |
| 字典项编码在同类型下重复 | `DICT_ITEM_CODE_DUPLICATE` | 表单行内报错"字典项编码在当前字典类型下已存在" |
| 字典类型编码格式不合法 | — | 前端实时校验"编码仅支持小写字母和下划线" |
| 字典项编码格式不合法 | — | 前端实时校验"编码仅支持大写字母和下划线" |
| 同字典类型设置多个默认值 | — | 后端自动将旧默认项改为非默认，不报错；前端 Switch 开启时 Tooltip 提示"设为默认后，原默认项将自动取消" |
| 禁用字典类型 | — | 允许操作；禁用状态的字典类型在业务模块下拉中不可见 |
| 禁用字典项 | — | 允许操作；禁用状态的字典项在业务模块下拉中不可见 |
| 网络错误/接口超时 | — | Toast 提示"网络请求失败，请稍后重试" |
| 左侧列表为空 | — | 显示空状态"暂无字典数据" + 新增引导 |
| 右侧无字典项 | — | 显示空状态"该字典类型下暂无字典项，点击「新增字典项」添加" |

## 7. 默认假设

1. 系统内置字典（`is_builtin=1`）由系统初始化脚本写入，`tenant_id=0` 表示全局共用；各租户可见但不可删除该字典类型，字典项可编辑。
2. 自定义字典为租户私有（`tenant_id=当前租户ID`），各租户完全隔离。
3. 字典类型编码和字典项编码在创建后不可修改，保证业务代码中硬引用的稳定性。
4. 业务模块通过 `dict_type` 编码查询字典项，只返回 `status=1` 且 `deleted_at IS NULL` 的条目，按 `sort_order` 升序排列。
5. 软删除后的字典类型和字典项在管理页面不展示，但保留历史数据完整性。
6. 所有 DATETIME 字段后端存储 UTC，前端按用户时区展示，格式 `YYYY-MM-DD HH:mm`。
7. 字典数据建议在应用层做内存缓存（TTL 5分钟），修改字典后主动刷新缓存。
