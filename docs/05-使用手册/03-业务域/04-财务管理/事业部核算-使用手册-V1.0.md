# 事业部核算使用手册

> 文档版本：V1.0
> 适用版本：ver 1.3.0
> 面向角色：老板 / 租户管理员 · 财务 · 事业部合伙人
> 最近更新：2026-10-23

一家公司按「一个渠道一个合伙人团队」经营时（如阿里国际站团队、中国制造网团队），可以把每个团队设为**事业部**：运营、供应链、财务人事、IT 等组成**共享中台**，为各事业部服务，老板统一管理；每个事业部单独核算收入、成本、费用和利润，合伙人按本事业部的利润分红（出资与分红在系统外计算）。

没有设置事业部的公司，各页面不出现事业部字段，统计口径与以前一样。

## 1. 设置事业部

位置：**系统管理 → 部门管理**（需要「编辑部门」权限）。

1. 在左侧部门树选中团队对应的部门，如「外贸部门-阿里国际站」。
2. 右侧「独立核算」一栏点 **标记为事业部**，选择**开始核算月份**，保存。
   - **第一个事业部**：公司已有的客户、商机、询盘、报价、PI、订单、收款、收款账户、结汇单、费用单、其他收入会**全部归入它**（弹窗会提醒）。
   - 之后再标记的事业部不接收已有单据，从开始核算月份起参与公共费用分摊。
3. 事业部下的下级部门（业务组、采购组）都属于这个事业部；**事业部不能嵌套**，已标记部门的上级和下级不能再标记。
4. 没有标记、也不在事业部之下的部门不独立核算，包括**共享中台**（运营、供应链、综合、IT 等部门）和总经办、公司根节点。它们的费用记为「公共」，按销售额比例分摊。

建议的部门树：

```
福州福唯科技有限公司
├─ 总经办
├─ 共享中台（不标记）
│   ├─ 运营部门
│   ├─ 供应链部门
│   ├─ 综合部门
│   └─ IT 部门
├─ 阿里国际站事业部（标记为事业部）
│   ├─ 业务部
│   └─ 采购部
└─ 中国制造网事业部（标记为事业部）
    ├─ 业务部
    └─ 采购部
```

事业部采购部负责本事业部订单的询价、下单和跟单；供应商准入、价格体系等由共享中台的供应链部门统一管理。
5. 部门树上带「事业部」标签的就是事业部；已有单据的事业部不能取消标记。

页面下方「核算设置」可修改**最低分摊比例**（默认 20%），见第 6 节。

**合伙人的角色**：在「角色管理」把合伙人角色的数据权限设为「自定义」，只勾选本事业部（或其下级部门）。这样合伙人只能看到本事业部的业务数据和统计。

## 2. 单据归属哪个事业部

单据的事业部在**创建时**记下，以后业务员调部门不影响历史单据：

| 单据 | 归属 |
|---|---|
| 客户、商机 | 登记时负责人主部门所在的事业部；负责人在共享中台或总经办时须手动选择 |
| 询盘、报价、PI、销售订单 | 跟随客户 |
| 采购需求、采购订单、应付、付款、退款、出运 | 跟随销售订单 |
| 收款 | 跟随订单；未认领到账先按收款账户的事业部，认领后改为订单的 |
| 费用单、其他收入 | 录入时选择「某个事业部」或「公共」；关联订单型号的费用跟随订单 |

同一个客户以后从其他渠道来询盘，仍归首次接触的事业部。在客户列表**转移客户**时，可勾选「同时转到新负责人所在的事业部」，只影响之后新建的单据。

## 3. 收款账户与收款

- **业务设置 → 收款账户**：每个账户选择所属事业部；默认账户按「事业部 + 币种」各一个。开 PI 时带出本事业部该币种的默认账户，也只能选本事业部的账户。
- **登记到账**时如果选了其他事业部的账户，会提示「可能收错账户」：可以改选本事业部的账户，也可以点「确认没收错，继续保存」。保存后收款仍计入**订单的事业部**，收款记录上标记「账户与订单不一致」，方便事后调账。
- 收款管理的收款记录、未认领到账都可以按事业部筛选。

## 4. 结汇

每个事业部各自一个先进先出池子：登记结汇单时选择事业部（默认取入账账户的事业部），只分摊到本事业部同币种的到账；估算汇率也按事业部分别取。某个事业部结汇不影响其他事业部的到账。

## 5. 费用单与其他收入

新建费用单时选择**所属事业部**：

| 费用 | 建议选择 |
|---|---|
| 阿里国际站年费、直通车 | 阿里国际站事业部 |
| 中国制造网会员费 | 中国制造网事业部 |
| 事业部业务员的工资、医社保、绩效 | 业务员所在事业部 |
| 房租、水电、ERP、CRM、软件；共享中台与总经办人员的工资社保 | 公共 |

关联了订单型号的费用跟随订单，不用选。其他收入同样可以选事业部或公共。费用单、其他收入列表都可以按事业部（含「公共」）筛选。

## 6. 公共费用怎么分摊

「公共」的费用与其他收入每月按销售收入比例分给当月参与核算的事业部：

1. 比例 = 事业部当月销售收入 ÷ 各事业部当月销售收入合计；
2. 每个事业部**至少承担最低分摊比例**（默认 20%），低于的按最低比例计，其余事业部按销售收入分剩下的部分；
3. 当月各事业部都没有销售收入时平分；
4. 事业部从开始核算的月份起参与；之前的月份由其他事业部承担。

例：11 月公共费用 ¥26,990，阿里国际站事业部销售 ¥825,000，中国制造网事业部 ¥200,000。按销售额中国制造网为 19.51%，低于 20%，按 20% 承担 ¥5,398，阿里国际站承担 80% 即 ¥21,592。

最低分摊比例 × 事业部数不能超过 100%（2 个事业部最多 50%）。

## 7. 统计与合伙人能看到什么

**统计分析 → 经营统计 / 利润统计 / 销售统计** 顶部有事业部切换：

- 老板、财务（数据权限「全部」）：可看「全公司」或任一事业部。
- 合伙人（数据权限只含本事业部）：固定为本事业部，带锁，看不到其他事业部和全公司合计。

经营统计按事业部查看时：

- 预计盈亏 = 销售毛利 − 退款 + 其他收入 − **直接费用** − **分摊的公共成本**；
- 「分摊比例」列显示本事业部当月承担的比例；
- 点每月前面的「+」展开，看各费用类别的直接费用与分摊成本；
- 各事业部之和等于全公司。

## 8. 常见问题

**Q：标错了第一个事业部怎么办？**
已有单据归属后不能直接取消。请联系管理员用数据修正处理，不要新建同名部门绕过。

**Q：某个月中国制造网一单没成，为什么还要分房租？**
每个事业部至少承担最低分摊比例（默认 20%），这是合伙人之间约定的规则，可在「核算设置」调整。

**Q：以前月份的数字为什么变了？**
分摊比例按当月销售收入实时计算，订单修改后对应月份会重算。分红前请财务导出当月经营统计留档。
