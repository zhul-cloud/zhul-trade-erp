# 询盘大附件使用手册

客户发来的清单、图纸往往很大。询盘附件现在可以传大文件，AI 也会把整个文件解析完，不再只看前面一部分。

## 能传多大

| 项目 | 限制 |
| --- | --- |
| 文件类型 | JPG、PNG、PDF、XLS、XLSX、CSV（不收 ZIP、RAR 等压缩包） |
| 单个文件 | 不超过 500MB |
| 一张询盘单的附件合计 | 不超过 2GB，不限个数 |
| 铭牌图片 | 不变：每次最多 20 张，单张不超过 10MB，不计入上面的合计 |

新建询盘单、追加型号、修改询盘三处都按这个规则。从商机带入附件时也按 2GB 合计计算，放不下的不带入，页面会提示有几个没带入。

## 上传

选中文件就开始上传，每个文件一行，显示已传大小和百分比。

- **上传中**：右边有「取消」，取消后这个文件作废。
- **网络中断**：系统会自动重试；还是传不上时显示「网络中断，已传 x / y MB」，网络恢复后点「继续上传」，已经传完的部分不会重传。
- **还没传完不能提交**：底部会提示「还有 n 个附件没传完」，提交按钮不可用。这时关闭弹窗会先确认，确认后正在上传的文件中断。
- 上传中关闭或刷新浏览器页面，浏览器会先提示确认。

### 选文件时就拦下的

| 提示 | 原因 | 怎么办 |
| --- | --- | --- |
| 超过 500 MB，可拆分后再传 | 单个文件太大 | 把文件拆成几份再传 |
| 只支持图片（JPG、PNG）、PDF、Excel | 类型不对 | 压缩包先解压，传里面的文件 |
| 附件合计会超过 2.0 GB（已有 x GB） | 这张询盘的附件加起来太大 | 删掉不需要的附件；修改询盘时删掉旧附件后可以再传 |

点「知道了」关掉这一行。

### 传完后才发现的

| 提示 | 原因 | 怎么办 |
| --- | --- | --- |
| 文件类型不支持，只支持 JPG、PNG、XLS、XLSX、CSV、PDF，文件已删除 | 按文件内容判断不是这几种（如改过扩展名的文件） | 点「移除」，换成正确的文件重新选 |
| 文件大小与声明不一致，已删除，请重新上传 | 传输过程中文件出了问题 | 点「移除」后重新选这个文件 |
| 上传服务暂时不可用，请联系管理员 | 文件存储的配置有问题 | 联系管理员处理后点「重试」 |
| 服务器存储空间不足 | 服务器磁盘满了 | 联系管理员 |

这些情况都不会清空已经填写的其他内容。

## AI 解析大附件

附件不大时和以前一样，一次解析完。附件很大（合计超过 18MB，或 PDF 超过 20 页）时，AI 会分成多批解析：

- 询盘详情显示「已解析 x / y 批」和进度条。可以先离开页面，解析完成后询盘变为「待确认」。
- 同一个型号出现在多处时自动合并：单位相同的数量相加，「纠正说明」里写明出现在哪几页或哪几行；单位不同的不相加，标为「待核实」，请自己核对。
- 个别页面损坏、某一批解析失败，不影响其他部分。确认页顶部会列出「n 处内容未能解析」，写明是哪个文件的哪一页或哪几行，请对照原文手动补充。
- 只有整个询盘一个型号都没解析出来，才算解析失败。
- 联网核验每批各自计算「最大搜索次数」；达到上限的那批型号标「待核实」，备注「未联网核验」。

解析时间随附件大小增加，几百页的文件可能要几十分钟。超过 20 分钟没有任何进度、或者总共超过 3 小时，会判为解析失败，可以「重新解析」或改为手动录入。
