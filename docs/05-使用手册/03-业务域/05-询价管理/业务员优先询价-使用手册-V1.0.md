# 业务员优先询价使用手册

询盘确认后，询价任务先给询盘负责人。能自己找的先领走，找不了的转给采购。采购负责人在「询价分配」里看到的，都是确实需要分配的任务。

## 流程

```text
询盘确认，按品牌 + 品类拆成任务
        │
        ▼
   待业务处理 ── 我来询价 ──▶ 询价中（业务员自询）──▶ 已回价
        │                          │
    转采购 / 到时间                │ 找不到，转给采购继续找
        ▼                          ▼
     待分配 ◀───────────────────────
        │
   采购负责人分配给采购或兼职 ──▶ 询价中 ──▶ 已回价
```

## 业务员

在「采购管理 → 我的询价 → 待认领」，或询盘详情的询价任务里操作。只能处理自己负责的询盘。

| 操作 | 什么时候用 | 结果 |
| --- | --- | --- |
| 我来询价 | 自己能找 | 任务进入「待处理」，提交的回价不用审核，直接生效 |
| 转采购 | 一看就找不了 | 任务立即进入待分配 |
| 不处理 | 忙不过来 | 到时间自动转给采购，之后不能再认领 |

一张询盘可以部分认领：比如领走 2 个任务，转走 1 个。

默认时限是普通任务 2 小时、紧急任务 30 分钟。

### 找到一部分，剩下的找不到

在任务上点「退回」，弹窗里选择要转出的型号：

- **待询价的型号**：一定会交出去。
- **无货的型号**：默认选中。不想让别人再找就取消勾选，这个型号按无货给客户报价。
- **有价的型号**：默认不选。想让别人比价可以勾选；对方没找到时，仍用你的价格。
- **已报给客户的型号**：不能交出。

提交回价后如果还有无货型号，系统会提示要不要转交。已回价的任务也能转交，询盘会从「可报价」回到「询价中」。用了这些型号价格的草稿报价单不会自动变，采购回价后要重新取价。

## 采购和兼职

被转交的任务打开后，需要找的型号排在前面，并能看到退回原因和上一轮查过的渠道、店铺、结果、备注。其他型号标明不需要找，也可以补充报价。

- 正式采购能看到上一轮价格，兼职看不到。
- 找不到时同样可以按型号退回。任务还有回价在等审核时不能退回，要等审核完。
- 任务退回后重新分配，超时重新计时。

## 采购负责人

「询价分配 → 待分配」只显示已转给采购的任务，等待时长从进入待分配算起。

- 待业务处理和业务员自询中的任务不显示，也不计入进行中任务数。
- 业务员自询完成后显示在「已回价」，标记「业务员自询」，仍可以查看和指定成本价。
- 开启规则自动分配时，任务在业务员转采购或超时流转时才按规则分配。被退回的任务不自动分配。

## 询价统计

「采购管理 → 询价统计」：

- **按月份**：询价工作量按月显示业务员自询、采购询价和自询占比，月份按询盘日期。型号转交后，业务员和采购各算一次。
- **按人员**：业务员、采购、兼职放在同一张表。转出是交给别人继续找的型号，不计入这个人的有价、无货、待回价；有价率 = 有价 ÷（型号数 − 转出）。

业务员通常挑自己能找的做，采购接的多是难找的，这些数字适合看趋势和工作量，不建议直接当绩效。

## 管理员设置

**上线后必须做：**

1. 收回业务员角色的「询价分配」菜单，否则业务员仍能分配任务。
2. 在角色管理核对「我的询价 → 可接询价任务」权限。有这个权限的账号才是采购人员，才会出现在分配候选人里。升级时只自动授给有「我的询价」菜单、没有询盘菜单的角色；既做业务又做采购的角色要手动勾选。

**可以调整：** 在系统设置里修改以下两项，单位是分钟。设为 0 表示不经过业务员，任务直接进入待分配。

- `inquiry.sourcing.sales-window-minutes`：普通任务时限，默认 120
- `inquiry.sourcing.sales-window-urgent-minutes`：紧急任务时限，默认 30

修改只影响之后生成的任务。
