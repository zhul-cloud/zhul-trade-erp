# 询价分配延后与回价录入使用手册

## 询价分配：延后

暂时不用处理的任务可以延后到某天。延后的任务离开「待分配」，到那天自动回来，「待分配」里只留今天该处理的。

### 怎么延后

| 入口 | 延后哪些任务 |
| --- | --- |
| 勾选任务，批量操作栏点「延后」 | 选中的任务 |
| 任务行「⋯」→「延后这个任务」 | 这一个任务 |
| 任务行「⋯」→「延后整张询盘」 | 这张询盘下还在待分配的全部任务；已在询价中的不受影响 |

日期可选明天、3 天后、下周一，或自己选一天（最多 180 天后）。原因选填，最多 100 字。

### 延后之后

- 「待分配」卡片显示「另有 n 个已延后」。
- 延后的任务不进待分配列表和数字，不参与按推荐、按规则和自动分配，也不发待分配通知。
- 到延后那天自动回到待分配，「已等待」从那天 0 点算起。
- 询盘详情里，任务状态旁显示「延后到 MM-DD」，鼠标移上去看原因。

### 已延后列表

在「待分配」页签点「已延后 n」切换。任务按回来的日期分组，同一张询盘延后到同一天的合成一行。

- **现在处理**：任务马上回到待分配，等待时长从现在算。
- **改日期**：重新选回来的日期。

再点一次「已延后」（或右侧 ×）回到待分配列表。

## 我的询价：录入回价

### 按回价状态筛选型号

任务详情的型号列表上方可以筛选：

| 筛选 | 含义 |
| --- | --- |
| 未回价 | 自己在这个型号还没有任何记录，与「只复制未回价的型号」口径一致 |
| 草稿 | 只存了草稿 |
| 已提交 | 已提交或待审核 |

筛选只影响显示，保存草稿和提交回价仍按整个任务处理。切换任务时回到「全部」。

### 随时保存

- 往下滚动时，任务标题和「粘贴报价」「复制话术」「退回」「保存草稿」「提交回价」固定在页面顶部。
- 某个型号有改动时，卡片右上角显示「● 未保存」和「保存草稿」，只保存这一个型号，其他型号的改动留在页面上。
- 已提交过的型号改动后，卡片上的按钮是「保存修改」，和顶部「保存修改」规则相同。

### 粘贴报价：AI 识别

公司开启了 AI（业务设置 → AI 设置）时，「粘贴报价」多一个「AI 识别」；没开启时只有按规则识别，用法不变。

| 识别方式 | 适合 | 原文上限 |
| --- | --- | --- |
| AI 识别 | 供应商发来的整段报价：型号写法不规范、价格在前在后、一段里有多个任务的型号 | 20,000 字 |
| 按规则识别 | 每行一个型号、写法规范 | 10,000 字 |

1. 选渠道与店铺（或供应商），粘贴原文，点「AI 识别」。
2. 识别中显示已用时间，可以点「取消」。同一个人同一时间只跑一个识别，再点一次会取消上一次。
3. 超过 90 秒或识别失败时弹窗里会提示，可以重试，或改用「按规则识别」。

识别结果只列这个任务里的型号：

- **单价**按不含税显示。原文是含税价时，下面用红字标出含税价和税率（不含税价 = 含税价 ÷ (1 + 税率)，两位小数，四舍五入）。改单价就是改不含税价。
- **把握**：「确定」是型号和价格都写得清楚；「请核对」整行标橙色，表示型号是简写或推断出来的、价格或税率需要推断，或者货况、货期、税率不在字典里（这些项已经清空）。
- **原文里的其他型号**：原文里属于你其他待处理任务的型号，按任务列出。点「打开并带上原文」会打开那个任务并弹出粘贴报价，原文、渠道和店铺都已经填好。原文不保存，离开我的询价就清掉。
- **不在你的任务里**：哪个任务都对不上的型号，点「展开」查看。

核对后点「填入 n 条（不保存）」。填入规则和按规则识别一样：同一渠道、同一店铺的草稿覆盖，其余追加；已报给客户的型号不填入；填入后还要自己保存草稿或提交回价。

## 兼职采购：审核中

回价需要审核的账号多一个「审核中」页签。

| 页签 | 什么任务 |
| --- | --- |
| 待处理 | 还有没填的型号，或有型号被退回 |
| 审核中 | 每个型号都已提交（含无货），至少一个还在等审核 |
| 已回价 | 全部审核通过 |

审核中的任务照常能打开修改，改完点「保存修改」重新进入审核。被退回后任务回到「待处理」。
