# 铭牌图片与附件预览使用手册

客户发来的型号铭牌照片，单独传进「铭牌图片」。AI 解析时会认出型号，并把每张图对应到型号上；采购在「我的询价」里能直接看到自己任务里型号的铭牌图。其他询盘附件（询价清单、聊天截图等）采购仍然看不到。

询盘单里的附件和铭牌图片都在当前页预览，不再打开新页面。

## 流程

```text
新建询盘单：询盘内容 + 询盘附件 + 铭牌图片
        │
        ▼
   AI 解析：识别型号，并判断每张铭牌图对应哪一行
        │
        ▼
   确认页：核对对应关系，可以改；对不上的留在「未对应型号」
        │
        ▼
   确认后：询盘单详情按型号分组显示；采购在「我的询价」里看到
```

## 业务员

### 上传

新建询盘单、追加型号、修改询盘的弹窗里都有两个上传区：

| 上传区 | 放什么 | 谁能看到 |
| --- | --- | --- |
| 询盘附件 | 询价清单 Excel、规格书 PDF、聊天截图等 | 业务员这边能看到这张询盘单的人 |
| 铭牌图片 | 型号铭牌照片，只收 JPG、PNG | 另外，采购能看到自己任务里型号的图 |

- 铭牌图片每次（新建或追加一次）最多 20 张，单张不超过 10MB，不占询盘附件「最多 10 个」的名额。
- 只有铭牌图片、不写正文也能提交。
- 采购能看到铭牌图片，带客户公司名、联系方式的图片不要放进铭牌区，放到询盘附件里。

### 确认解析结果

确认页上方列出这次的全部铭牌图片，每张图下面的下拉框显示它对应第几行：

- AI 对上的图已经选好行，对不上的标橙色「未对应型号」；
- 选错了直接在下拉框里改，一张图只能对应一行；
- 删掉某行时，对应这行的图自动变成未对应；
- 型号列下面也显示这一行的铭牌缩略图，点开可以放大看。

手动录入的询盘也在这里对应。不对应也能确认，确认后在详情里随时可以改。

### 询盘单详情

- 「原始内容」里的附件显示为缩略图，点开在当前页预览。
- 「铭牌图片」单独一块，按型号分组，没对上的放在最后的「未对应型号」组。
- 点图片右下角的「···」可以改对应的型号，或删除这张图。每次修改都记操作日志，采购那边同步变化。
- 修改询盘时补传的铭牌图片不会解析，先放进「未对应型号」，再在这里对应。
- 已取消、历史迁移的询盘单只能看，不能改。

### 预览

- 图片可以点左右箭头或按键盘 ← → 切换同一组的其他图片，下面一排缩略图可以直接点。
- PDF 在弹窗里直接显示。
- Excel 浏览器不能预览，点开直接下载。
- 弹窗右下角可以「下载」原文件。

## 采购

在「采购管理 → 我的询价」打开任务：

- 每个型号的描述下面显示它的铭牌图，点开预览，可以左右切换；
- 这张询盘单里业务员还没对上型号的铭牌图，在任务顶部的橙色提示里，找货时可以对照着看；
- 兼职采购也能看到铭牌图片；
- 别的任务的型号的图、询盘附件都看不到。

采购负责人在「询价分配」打开任务详情，看到的铭牌图片和采购一样。

## 常见问题

**老的询盘单里，铭牌照片放在附件里了，采购能看到吗？**

不能。老询盘单的附件不做转换。需要时，在询盘单详情点「修改」，把照片补传到铭牌区，再在「铭牌图片」里对应到型号。

**AI 把图对错了怎么办？**

确认前在确认页的下拉框里改；确认后在询盘单详情的「铭牌图片」里点「···」改。

**素材管理里会怎样？**

对上型号的铭牌图只算进那个型号的「客户来图」；没对上的铭牌图和其他询盘图片，仍然算进这张询盘单的全部型号。
