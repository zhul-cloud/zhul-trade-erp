# 客户档案使用手册

> 文档版本：V1.0
> 适用版本：含数据库迁移 V1.4.7 的版本
> 面向角色：业务员 · 业务负责人 · 老板 / 租户管理员
> 最近更新：2026-11-03

客户档案把「值不值得跟、买不买得起、用什么技术、该找谁谈、有什么坑」分成五个模块记下来，看得到**完整度**，可以慢慢补全。能从询盘、订单里算出来的信息由系统自动带出，不用填。

## 1. 五个模块

位置：**销售管理 → 客户管理 → 打开客户**。客户详情按五个模块分区显示：

| 模块 | 回答的问题 | 内容 |
|------|-----------|------|
| ① 基础画像与定性 | 值不值得跟 | 公司类型（就是原来的「客户角色」）、行业（原「应用行业」）、官网、LinkedIn、成立年份、公司规模、潜力评级；系统带出询盘数、首次和最近询盘日期 |
| ② 商业与供应链能力 | 买不买得起、怎么买 | 主营产品、年度采购量估算（美元，只是估算）、现有中国供应商、质量要求、价格敏感度、清关能力、付款习惯（原「默认付款方式」）；系统带出近 12 个月成交额和订单数 |
| ③ 工控技术偏好 | 用什么技术 | 现有使用品牌、设计能力、常用通讯协议、电源电压、认证要求、售后维修能力；系统带出常用品牌（询盘型号按品牌计数，前 5 个） |
| ④ 关键决策人 | 该找谁谈 | 联系人卡片，见第 4 节 |
| ⑤ 国家与宏观背景 | 有什么坑 | 国家、城市、时区、时差；所在国家的电压、插头、节假日、外汇管制、关税、认证（取国家资料，见第 5 节） |

- 标「系统」的信息由系统算出来，不能手改，没有相关单据时显示「暂无」。
- 鼠标移到字段上能看到**来源**：人工（谁、哪天改的）、迁移、系统、「背调 BGxxxx」（从背调报告采纳的，点编号打开报告，见《客户背调与档案补全使用手册》）。人工改过的字段来源就变成人工。
- 外汇管制为「严格」的国家，客户详情顶部会提示「{国家}外汇管制严格，注意收款方式」。

## 2. 完整度与建档状态

客户详情顶部显示**档案完整度 n/5**，下面列出每个没完成的模块还缺什么。每个模块的核心项全部填好才算完成：

| 模块 | 核心项 |
|------|--------|
| ① 基础画像 | 客户名称、公司类型、行业、官网或 LinkedIn（填一个即可）、公司规模、潜力评级 |
| ② 商业能力 | 主营产品、质量要求、价格敏感度、清关能力、付款习惯 |
| ③ 技术偏好 | 现有使用品牌（或系统已有常用品牌）、设计能力、常用通讯协议、电源电压（或国家资料里已有电压）、售后维修能力 |
| ④ 决策人 | 至少一个联系人同时填了姓名、职位类别、决策权重、沟通风格 |
| ⑤ 宏观背景 | 国家、城市、时区，且这个国家的国家资料已填电压和外汇管制 |

- 5/5 为「**已建档**」，否则为「**待完善**」，由完整度自动得出，不能手改。
- 成立年份、年度采购量、中国供应商、认证要求、DISC、禁忌喜好、对华态度、活跃时间都是选填，不影响完整度。
- 完整度不影响客户的创建、启用，也不影响在询盘、报价、PI 里选这个客户。
- 建议先补**有成交的客户**。

## 3. 编辑档案

客户详情点「**编辑档案**」（或某个模块右上角的「编辑」），弹窗按 ①–⑤ 分页签，可以来回切换，一次保存全部改动。

- 带 `*` 的是计入完整度的核心项；页签上会提示这个模块还缺什么。
- 单选、多选的选项来自字典，管理员可以在「系统管理 → 字典管理」里改名、新增或停用。
- 年度采购量估算不能为负。
- 客户名称、地址、税号、默认交易条件、收货与单证信息仍在原来的「**编辑**」里改。

## 4. 联系人与决策人画像

客户详情右侧「**联系人**」卡片，点「添加」：

- **联系方式**：姓名（英文，必填）、职位原文、邮箱、电话、WhatsApp、其他联系方式；
- **决策人画像**：职位类别（采购 / 工程师 / 老板 / 销售 / 其他）、决策权重（拍板人 / 建议者 / 执行者）、沟通风格、性格（DISC）、禁忌与喜好、对华态度、活跃时间（北京时间段）。

规则：

- 每个客户最多一个**主联系人**。第一个联系人自动成为主联系人；可以把别的联系人设为主联系人。
- 主联系人的联系方式保存后同步到客户的「主联系人」，询盘、PI 等原来用主联系人的地方照旧。
- 删除主联系人前，要先把另一个联系人设为主联系人；只剩一个联系人时可以直接删。
- 升级前客户上已有的主联系人，已自动搬进联系人列表，画像为空，补上即可。
- 个人画像只在系统内显示，能看到这个客户的人才能看到，**客户导出不包含画像**。

## 5. 国家资料

位置：**业务设置 → 国家资料**。按国家维护一次，这个国家的所有客户都能看到，各公司自己维护。

- 列表同时列出**已维护**的国家，以及本公司有客户、但**还没维护**的国家（显示客户数），客户多的排在前面。可以按「未维护」「外汇管制严格」筛选。
- 内容：工业电压与频率（多选）、插头类型、外汇与支付管制（无 / 一般 / 严格，加说明）、重大节假日、进口关税备注、常见认证要求。
- 客户详情的宏观背景里，没有维护的国家显示「这个国家还没有资料」，有权限的人可以直接点去维护。
- 保存后，这个国家所有客户的完整度会立即重算。
- 需要「国家资料」菜单权限；升级时已自动授给有「汇率设置」菜单的角色。每次修改记操作日志。

## 6. 潜力评级与经营等级

两者分工不同：

| | 潜力评级 | 经营等级 |
|---|---|---|
| 回答 | 这个客户值不值得投入精力跟 | 成交后投入多少精力维护 |
| 谁定 | 业务员评 1–5 星 | 系统按 RFM 自动算 S / A / B / C |
| 适用 | 所有客户 | 有未取消销售订单的客户；没有的显示「未成交」 |
| 计入完整度 | 是 | 否 |

### 经营等级怎么算

原来的「客户等级」改名为「经营等级」，不再手工标记。按未取消的销售订单（含历史迁移订单）算三项分数，每项 1–5 分：

- **R 近度**：距最近一次订单 30 天以内 5 分，30–90 天 4 分，90–180 天 3 分，180–365 天 2 分，更久 1 分；
- **F 频次**：近 12 个月订单数 13 张及以上 5 分，6–12 张 4 分，3–5 张 3 分，1–2 张 2 分，0 张 1 分；
- **M 金额**：近 12 个月销售额折合美元，9,000 及以上 5 分，4,700 以上 4 分，4,000 以上 3 分，1,800 以上 2 分，其余 1 分。美元订单取原币金额，其他币种按订单人民币金额 ÷ 汇率设置里当前的美元汇率折算（四舍五入保留两位）。

**综合分数** = 0.3 × R + 0.4 × F + 0.3 × M（保留一位小数）；4.5 及以上为 S，3.5 及以上为 A，2.5 及以上为 B，其余为 C。分界和权重都可以在系统设置里改（见第 9 节）。

- 每天凌晨 02:30 自动重算，详情显示计算时间。
- 客户详情按最终等级显示**建议跟进频率**：S 每 7 天、A 每 14 天、B 每 30 天、C 每 60 天。
- 点经营等级打开 **RFM 明细**：首单与最近订单日期、近 12 个月订单数与销售额、三项分数及落在哪一档、算式、参与计算的订单（点订单号可打开）。

### 人工调整

业务员可以参考潜力评级，把经营等级**上调或下调一级**（不能超出 S–C），必须写原因。之后每天重算时保留调整方向，例如计算等级从 B 变成 C，上调一级后显示 B。取消调整即恢复计算等级。列表上调整过的标「已调整」，悬停显示原因和调整人；调整与取消都记操作日志。没成交的客户不能调整。

## 7. 疑似重复与合并客户

位置：**客户管理 → 「疑似重复」页签**。只列你数据范围内的客户，满足任一条件即成组：

- 规范化后的名称相同且国家相同；
- 任一联系人的邮箱相同；
- WhatsApp 或电话相同（只比较数字，少于 6 位不比较）。

每组显示客户编码、名称、国家、负责业务员、完整度、询盘数和订单数，以及成组原因。

**不是重复**：点「不是重复」后这组不再出现；以后组内客户的条件变了或有新客户加入，会重新出现。

**合并**（需要「合并客户」按钮权限，升级时已授给有「转移客户」权限的角色）：

1. 点「合并」，选择**保留**哪个客户，另一个为**被合并**客户；
2. 弹窗列出将要改挂的单据数（按类型）和将要搬过去的联系人，确认无误后点「确认合并」；
3. 系统在一次操作里完成：
   - 被合并客户的商机、询盘、报价、PI、销售订单、出库单、出运单、售后单、单证主体全部改挂到保留客户，单据上已打印的客户名称等不变；
   - 联系人搬过去，邮箱或 WhatsApp 和保留客户已有联系人相同的不重复建；被合并客户的主联系人在保留客户里变成普通联系人；
   - 保留客户**为空**的画像字段用被合并客户的值补上，已有值的不覆盖；
   - 被合并客户从列表消失，备注追加「已并入 CUSxxxxx」；保留客户的负责业务员不变；
   - 记一条操作日志。

- **合并不能撤销**，确认前请核对清楚。
- 被合并客户有**客户余额流水或退款单**时不能合并，提示「这个客户有客户余额或退款记录，请先联系财务处理」。
- 没有「合并客户」权限的人能看到疑似重复，但没有「合并」按钮。

## 8. 客户列表

新增的列与筛选：

- **潜力**、**经营等级**、**档案完整度**（n/5，悬停显示缺项）三列；
- 筛选：经营等级（含「未成交」）、建档状态（已建档 / 待完善）、缺的模块（如「缺：决策人」只列出没有合格决策人的客户）；
- 排序：潜力评级按星数排，未评的在最后；经营等级按 S、A、B、C 排，同级按综合分数，未成交在最后。

## 9. 管理员设置

**系统管理 → 系统设置**，经营等级参数（平台默认值，租户可以覆盖）：

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 经营等级 R 分界（天） | 30,90,180,365 | 依次为 5/4/3/2 分的上限，超过最后一个为 1 分 |
| 经营等级 F 分界（单） | 13,6,3,1 | 依次为 5/4/3/2 分的下限，0 单为 1 分 |
| 经营等级 M 分界（美元） | 9000,4700,4000,1800 | 依次为 5/4/3/2 分的下限 |
| 经营等级权重 R,F,M | 0.3,0.4,0.3 | 综合分数的权重 |
| 经营等级分界 S,A,B | 4.5,3.5,2.5 | 综合分数不低于分界即为该等级，其余为 C |
| 建议跟进间隔 S,A,B,C（天） | 7,14,30,60 | 客户详情显示的建议跟进频率 |

改完后第二天凌晨重算生效。

**字典管理**里新增 14 个字典（公司规模、质量要求、价格敏感度、清关能力、设计能力、通讯协议、电压、认证、售后维修能力、职位类别、决策权重、沟通风格、DISC、对华态度），可以改名、新增或停用；停用的选项不再出现在下拉里，历史记录仍显示原名称。

## 10. 常见问题

**Q：客户只填了名称和国家，完整度是 0/5，会影响下单吗？**
不会。完整度只是提示，不影响客户的创建、启用和在单据里使用。

**Q：技术偏好里我没填品牌，为什么算完成了？**
系统从这个客户的询盘型号里统计出了常用品牌，或者国家资料里已有电压，这两项可以由系统补上。

**Q：维护了国家资料，客户的宏观背景还是没完成？**
还要客户自己填了城市和时区，并且国家资料里填了电压和外汇管制。跨时区的国家（如巴西、美国）选国家后不会自动带出时区，需要手工选。

**Q：经营等级为什么和昨天不一样？**
每天凌晨按最新订单重算。距最近订单的天数每天都在变，R 分可能下降；人工调整的方向会保留。

**Q：合并错了能恢复吗？**
不能在页面上撤销。被合并客户只是软删除，但单据已经改挂，需要找管理员在数据库层面处理。所以合并前务必核对弹窗里的单据数。
