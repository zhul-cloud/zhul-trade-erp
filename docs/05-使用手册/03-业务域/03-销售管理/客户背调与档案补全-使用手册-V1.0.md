# 客户背调与档案补全使用手册

> 文档版本：V1.0
> 适用版本：含数据库迁移 V1.4.8 的版本
> 面向角色：业务员 · 业务负责人 · 租户管理员 · 运维
> 最近更新：2026-11-12

客户档案（见《客户档案使用手册》）的很多字段，业务员自己并不知道。这一版加了两件事：

- **客户背调**：让 AI 联网查一遍客户，回答「是不是真客户」「值不值得跟」，并把查到的信息作为**字段建议**，勾选后直接写进档案；
- **档案补全**：把一个客户还缺的项按「谁能给出答案」分成四步，一次补完一个客户。

## 1. 发起 AI 背调

位置：**销售管理 → 客户管理 → 打开客户 → 右上角「AI 背调」**；也可以在「档案补全」第②步发起。

- 交给 AI 的内容：客户名称、国家、官网、已填的档案字段、联系人姓名和**邮箱域名**、系统算出的成交情况和常用品牌、最近 3 张询盘的原文。**联系人的电话、WhatsApp、完整邮箱不会发出去。**
- 背调在后台进行，大约 3–5 分钟。期间按钮显示「背调中」，右侧「背调报告」里这一份显示「背调中…」；页面不用刷新，完成后弹出「背调完成」，失败时弹出原因。
- 失败的报告会记下原因，直接再点「AI 背调」重新发起即可。
- **24 小时提醒**：这个客户 24 小时内已经背调过时，会先问「再背调一次？」，并显示上次的报告编号、结论和大致用量，可以点「先看上次的报告」。只提醒不拦截，点「仍要背调」就会发起。
- 同一个客户同时只能有一份「背调中」的报告。
- 公司没有配置可用的 AI 时，按「业务设置 → AI 设置」里「未配置时的处理」提示，不生成报告。

### 背调前检查

点「AI 背调」后，先弹出「背调前检查」，列出这次会交给 AI 的信息哪些有、哪些缺，再决定是否背调。**只提示，不拦截。**

| 分组 | 检查项 | 怎么算「有」 |
|------|--------|--------------|
| 关键信息 | 官网 | 档案填了官网 |
| 关键信息 | 企业邮箱 | 至少一个联系人的邮箱不是免费邮箱（Gmail、Hotmail、Outlook、Yahoo、QQ、163 等）；只有免费邮箱时显示「联系人用的是 gmail.com，找不到公司」 |
| 关键信息 | 询盘原文 | 这个客户有贴了客户原文的询盘，最多算 3 张 |
| 其他信息 | 名称、国家 | 新建客户时已必填 |
| 其他信息 | 领英 | 档案填了 LinkedIn 公司页 |
| 其他信息 | 公司信息 | 公司类型、行业、主营产品都填了 |

- **信息充足度只看三项关键信息**：一项都没有为「很少」，一项为「一般」，两项及以上为「充足」。很少时 AI 多半只能给出待核实清单。
- 缺的项后面有「**去补充**」：官网、领英、公司信息打开档案编辑（只缺主营产品时直接到「商业与供应链」页签），企业邮箱打开主联系人（没有联系人时新建一个）。保存后回到检查窗口，充足度随之更新。询盘原文没有入口，在「询盘管理」登记询盘时贴上客户原文。
- 按钮：「先去补充」关闭窗口；信息很少时为「**仍要背调**」，一般和充足时为「**直接背调**」。之后照常走 24 小时提醒和发起。
- 没有客户编辑权限的人看得到检查结果，但没有「去补充」。
- 客户详情右侧「背调报告」卡片也常驻显示检查结果：还没有背调时显示完整清单；已有报告时只显示一行「信息：一般 · 缺 …」，点「展开」看完整清单。

## 2. 上传背调报告

在桌面端用「烛龙客户背调」技能做好的报告，也可以导进来。位置：客户详情右上角「**上传报告**」。

- 两种方式二选一：**上传 PDF**（不超过 10MB），或**粘贴报告文字**（不超过 60000 字）。
- 扫描版 PDF 没有可读文字，会提示「这个 PDF 没有可读文字，请粘贴报告文字」，并自动切到粘贴。
- AI **只从报告里提取**核心结论和字段建议，**不联网**，比 AI 背调便宜得多，约 1 分钟完成。
- 报告正文就是上传的文字；PDF 原件保存在报告上，报告详情里点「下载原件」。
- 之后的查看、采纳、导出和 AI 背调完全一样。

## 3. 背调报告

每次背调或上传都保存为一份独立的报告，编号形如 **BG20261103001**（BG + 日期 + 当天序号）。

客户详情右侧「**背调报告**」：最近一份已完成报告的结论置顶（主要矛盾、第一步行动），下面按时间倒序列出历次报告：编号、来源（AI 背调 / 上传）、跟进优先级、综合评分、发起人和时间。超过 3 份时点「全部 N 份」展开。点编号打开报告详情：

| 区域 | 内容 |
|------|------|
| 核心结论 | 跟进优先级（立即重点跟进 / 正常跟进 / 低优先级 / 不建议跟进）、综合评分 1–5、主要矛盾、第一步行动、客户身份、产品货源、关键发现、最大障碍 |
| 本次用量 | 模型、输入 token、输出 token、联网搜索次数、耗时。只记数量，不折算金额 |
| 报告正文 | 背调当时的快照，之后改档案不会改变报告 |
| 字段建议 | 见第 4 节 |

- **导出 PDF**：内容为核心结论、正文和字段采纳情况，文件名为「客户名称_报告编号.pdf」。
- **删除**：报告发起人可以删；有「客户背调」权限、且数据范围包括发起人的管理者也可以删。删除后报告不再显示，**已经采纳进档案的字段保留**，字段来源显示「背调 BGxxx（已删除）」。
- 能看到这个客户的人就能看报告。

## 4. 采纳字段建议

报告详情右下「**字段建议**」逐条列出 AI 建议的值：所属模块（①–⑤）、字段、当前值 → 建议值、依据、来源链接。

- **默认勾选**：当前为空的建议默认勾上；当前已有值的默认不勾，旁边标「会覆盖原值」，勾上采纳就覆盖。
- 点「**采纳 N 条**」：值写入客户档案，按档案原有规则校验，字段来源记为这份报告。档案里鼠标移到来源上能看到采纳人和时间，点「背调 BGxxx」可以打开报告。
- 不想要的点「**忽略未勾选**」，以后不再算「待处理」。
- **无法采纳**的会直接标出原因：
  - 选项型字段的建议值不在现有选项里（「选项不存在」）；
  - 联系人建议没有姓名；
  - 付款习惯需要定金比例或账期天数，AI 给不出，请在「编辑档案」里手工填。
- **联系人建议**：先按邮箱找已有联系人，找不到再按姓名找；找到就更新，否则新建联系人。
- 报告的**综合评分**同时作为「潜力评级」的建议（例如 4 分 → 4 星）。
- 现有使用品牌只按名称记录。
- 采纳需要「编辑客户」权限；每次采纳记操作日志。

## 5. 档案补全

位置：**销售管理 → 客户管理 → 「档案补全」页签**。一次补全一个客户。

### 左侧：待补全的客户

- 只列你数据范围内、启用、还没建档（完整度不到 5/5）的客户；
- 排序：有成交的在前，按经营等级 S、A、B、C；没成交的按潜力评级，同星数按最近活动（询盘、订单、商机）；
- 每行显示完整度、还差几项，有「已问客户、等回复」的显示已问几天；
- 列表上方显示「今天已补完 N 个客户」（你今天补到 5/5 的客户数）；
- 一次加载 20 个，底部「加载更多」。

### 右侧：四步补全

每一步只列这个客户**还缺**的核心项；一步全部完成就折叠为「已完成」。

| 步骤 | 内容 | 怎么做 |
|------|------|--------|
| ① 系统已经知道 | 询盘推导的常用品牌、国家资料里的电压和认证 | 只读，显示「自动补上 N 项」。国家资料缺失时提示「去维护国家资料」 |
| ② AI 背调能查到 | 行业、官网或 LinkedIn、公司规模、主营产品、城市、联系人职位类别等公开信息 | 没背调过的直接点「AI 背调」或「上传报告」。180 天内已有报告的，这里显示报告结论和待处理的字段建议，勾选后点「采纳」。报告里没查到的，点「手动填写」 |
| ③ 你自己就能判断 | 公司类型、潜力评级、质量要求、价格敏感度，主联系人的沟通风格 | 直接点选。有背调报告时，潜力评级旁边显示「背调建议 N 星」 |
| ④ 只能问客户 | 设计能力、常用通讯协议、电源电压、售后维修能力、清关能力、付款习惯、现有使用品牌，主联系人的决策权重 | 每项有一句英文问法，点「复制」发给客户，或「复制全部问题」拼成一段。发出后勾「已经问了，等回复」。拿到回答后在下拉里选 |

- 付款习惯、现有使用品牌这类需要多个值的字段，点「去填写」打开「编辑档案」弹窗；还没有联系人时，点「添加联系人」。
- 底部提示「保存后还差 N 项」。点「**保存**」只保存；点「**保存，下一个客户**」保存后打开下一位，补到 5/5 的客户会离开列表。
- 保存的字段来源记为人工；某个字段填上后，它的「已经问了」自动清除。

## 6. 权限

| 操作 | 需要的权限 |
|------|-----------|
| 看背调报告、档案补全页签 | 「客户管理」菜单，且客户在你的数据范围内 |
| 发起 AI 背调、上传报告 | 「客户背调」按钮权限。升级时已自动授给有「编辑客户」权限的角色，可在角色管理里调整 |
| 采纳 / 忽略字段建议、在档案补全里保存 | 「编辑客户」 |
| 删除报告 | 报告发起人；或有「客户背调」权限、且数据范围包括发起人的人 |

## 7. 管理员设置

- **AI 设置**（业务设置 → AI 设置）：背调用公司在这里配置的 AI 方式（平台订阅或自己的 API Key），联网搜索次数上限也在这里设。
- **问法**（系统管理 → 系统设置，分组「customer」，键名 `customer.ask.*`）：档案补全第④步每个字段的英文问法，平台给了默认值，公司可以改成自己的说法。

## 8. 维护说明：两份背调技能

背调逻辑有**两份**技能，内容要保持一致：

| | 位置 | 用途 |
|---|------|------|
| 原版 | zhul-skills 仓库 `02-背调/烛龙客户背调/SKILL.md` | 桌面端使用，输出中文报告并生成 PDF 放到桌面 |
| 系统版 | 本仓库 `scripts/ai-orchestrator/skills/customer-background/SKILL.md` | AI 编排服务使用，输出 JSON（核心结论、报告正文、字段建议），另有只做提取的 extract 模式 |

系统版是从原版改写的，差别：删掉了生成 PDF 的模块五；输出改为 JSON；新增字段建议和 extract 模式。

**改背调逻辑时**（背调模块、评分标准、优先级规则）：

1. 原版和系统版**一起改**；
2. 更新系统版文件头部注释里的同步来源（原版的提交号和日期）；
3. 系统版改动需要重新构建并部署 AI 编排服务镜像才生效，原版改动在 zhul-skills 里提交并运行 `./install.sh`；
4. 只改系统版独有的部分（JSON 格式、字段建议、extract 模式）时，不用动原版。

字段建议能用的字段在后端 `BackgroundFields` 里定义；增减字段时，系统版技能里的字段说明和后端要一起改。

## 9. 常见问题

**Q：一次 AI 背调大概用多少？**
报告详情的「本次用量」记了模型、token 和联网次数。上传报告只做提取、不联网，用量小得多。

**Q：背调结果和我知道的不一样怎么办？**
不勾、点「忽略」即可，建议不会自动写进档案。已经采纳的也可以在「编辑档案」里改，改后来源变成人工。

**Q：报告删了，档案里采纳的值会不会没了？**
不会。值保留，来源显示「（已删除）」。

**Q：为什么有的建议显示「无法采纳：选项不存在」？**
AI 给的值不在字典选项里。可以手工选一个最接近的，或者请管理员在字典管理里新增这个选项后再到报告里采纳。

**Q：档案补全里看不到某个客户？**
已建档（5/5）、停用、或不在你数据范围内的客户不会出现。
