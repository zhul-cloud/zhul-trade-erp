# 销售订单部分取消使用手册

> 文档版本：V1.0
> 适用版本：含数据库迁移 V1.4.2 的版本
> 面向角色：业务员 · 采购员 · 仓管 · 财务
> 最近更新：2026-11-01

供应商说某个型号缺货、或客户只想取消其中几个时，不用再整单取消、重开 PI、重新转单：在销售订单上**按型号部分取消**，订单号不变，采购、库存、收款自动跟着调整。

部分取消**不算退款**：订单销售额减少，客户多付的钱进入「待处理多收」，由财务转客户余额或退回客户，不进退款统计、不扣利润。质量问题等售后退款在第三期「售后管理」上线。

## 1. 业务员：部分取消

位置：**销售管理 → 销售订单 → 订单详情**，右上角「部分取消」（能取消订单的人都能部分取消）。

1. 在弹窗里给要取消的型号填**取消数量**。每行显示当前数量、已出库数量和**最多可取消**数量：
   - 最多可取消 = 当前数量 − 已出库（出库中、已交货代、已出运）；
   - 已经出运的货不能部分取消，请走售后；超过上限时输入框标红，不能下一步。
2. 选**取消原因**（供应商缺货 / 客户取消部分 / 其他），选「其他」时必须填说明。
3. 点「下一步」，确认框列出：
   - 订单合计怎么变（按百分比的整单折扣按新小计重算；固定金额的折扣不变，超过新小计时按小计封顶）；
   - 采购与库存会怎么处理（见第 3、4 节）；
   - 已到账超过新合计时，多出的金额进入「待处理多收」。
4. 点「确认部分取消」。**确认后不能撤回**；客户又要回来时，按原流程开 PI 或手动建单。

不能部分取消的情况：

| 情况 | 提示 |
|------|------|
| 订单已完成（客户已收货） | 按钮置灰，「订单已完成，请走售后」 |
| 订单已取消、历史迁移的订单 | 不显示按钮 |
| 所有型号都要取消 | 「所有型号都要取消，请用「取消订单」」 |

## 2. 订单上看到什么

- **数量**列显示剩余数量，下面写「原 10 · 已取消 5」。
- 全部取消的型号**保留在列表里**，型号划线、标「已全部取消」，进度显示「不再跟进」，不再参与订单进度、货物状态和「客户已收货」判断，也不能勾选改进度、采购员。
- **合计**改叫「订单合计（部分取消后）」，下面另列 PI 合计（发给客户的 PI 不改、不出新版本）。
- **部分取消记录**：每次的时间、型号、数量、金额、原因、说明、操作人，以及对采购与库存的处理结果。
- **收款**按订单合计计算：已到账超过订单合计时显示紫色的「多收」，标「待财务处理」。
- 操作日志记一条「部分取消」。

## 3. 采购员：处理被标记的采购订单

部分取消后，系统按下面的顺序扣采购：

1. **还没排进采购单的需求**：直接减少；
2. **草稿采购订单**：草稿行数量减少（减到 0 的行删除），采购员不用处理；
3. **已在仓**（合格入库、还没出库）：转入闲置库存，见第 4 节；
4. **已下单还没到货**：采购订单行标「**来源订单减少 N 个**」，采购单顶部有橙色提示，采购日志记一条「来源订单部分取消」。

被标记的采购订单，**采购数量不会自动改**（已经和供应商下了单）。请和供应商确认：

- **能退**：取消这张采购订单，重新下单；
- **保留**：什么都不用做。到货验收时，超出订单需要的合格数量会**自动转入闲置库存**，不算进订单成本。

系统外采购的型号（没有采购需求）只改订单，不处理采购。

## 4. 仓管：闲置库存的新来源

位置：**仓库管理 → 闲置库存**。

闲置库存现在有两个来源，「来源」列先显示类型，再显示单号；可以按来源筛选，关键字也能搜销售订单号：

| 来源 | 什么时候产生 | 成本单价 |
|------|-------------|---------|
| 到货差异 | 采购员处理多发时选「暂存」 | 采购订单行的不含税人民币单价 |
| 订单部分取消 | 部分取消时货已在仓；或保留的采购到货后超出订单需要 | 采购订单行的不含税人民币单价 |

处置方式不变：退回供应商、报废、转样品。

冲销一张采购入库单时，它转入的闲置库存如果还在「暂存中」会一并撤回；已经处置过的不能冲销。

## 5. 财务：多收怎么处理

位置：**财务管理 → 收款管理 →「待处理多收」**页签。

- PI 转成的订单，收款状态与多收**按订单合计**计算（以前按 PI 合计）。部分取消后已到账超过订单合计的部分出现在待处理多收里。
- 处理方式与客户多付相同：**转客户余额**（下一张 PI 抵扣）或**退回客户**（生成余额提现退款单）。
- 多收**不算退款**，不进经营统计的「退款」列，不扣订单利润；订单收入按「已到账与订单合计取小」。
- 整单取消订单后，PI 的应收回到 PI 合计；如果这时多收已经转给客户并被使用，系统会提示不能取消。

## 6. 常见问题

**Q：部分取消后 PI 要重新发给客户吗？**
不用，也不会出新版本。客户看到的 PI 还是原金额，订单详情会同时显示订单合计和 PI 合计。

**Q：取消错了怎么办？**
部分取消不能撤回。客户要回来的部分，按原流程开 PI 或手动创建订单。

**Q：采购员保留了采购单，货到了会怎样？**
验收时，订单还需要的数量照常入库算给订单；超出的合格数量自动转入闲置库存（来源「订单部分取消」），在采购日志里有记录。

**Q：已经交给货代的货能部分取消吗？**
不能。可取消上限已经扣除出库中、已交货代、已出运的数量；已出运的货走售后。
