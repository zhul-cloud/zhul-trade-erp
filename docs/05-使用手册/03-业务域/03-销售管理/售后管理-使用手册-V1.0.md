# 售后管理使用手册

> 文档版本：V1.0
> 适用版本：含数据库迁移 V1.4.4 的版本（补发订单从 V1.4.4 起）
> 面向角色：业务员 · 仓管 · 采购员 · 财务 · 老板 / 租户管理员
> 最近更新：2026-11-02（新增「补发」）

客户收货后出了问题（质量、少发、发错、使用咨询），统一登记**售后单**，跟进记录、退货、退款和费用都挂在售后单上，结案时能看到这次售后一共花了多少。

三条线彼此独立、按需使用：

| 线 | 单据 | 谁做 |
|----|------|------|
| 跟进 | 售后单（AS） | 业务员（负责人可以改成采购、技术等任何人） |
| 货 | 退货单（TH）→ 退货入库 → 去向 | 业务员发起，仓库验收，采购员处理去向 |
| 钱 | 退款申请（RA）→ 退款单（TK） | 业务员申请，（可选审批，）财务执行 |
| 补发 | 售后补发订单（SO，0 元） | 业务员发起，采购、仓库、物流照常处理 |

缺货、客户取消部分型号请用订单的「部分取消」，不走售后（见《销售订单部分取消使用手册》）。

## 1. 登记售后单

位置：**销售管理 → 售后管理 → 新建售后单**，或在**销售订单详情点「售后」**（已完成的订单也有这个按钮），客户、订单与型号自动带出。

- **有订单**：选订单，勾选有问题的型号并填数量；
- **没有订单**：只选客户，手填型号、品牌、数量，用于客户说不清订单号时的追溯。
- **问题等级**：待确认、S1 安全或重大风险、S2 设备停机、S3 功能受限、S4 外观附件、S5 使用咨询。S1 先提醒客户停机断电，不等资料齐全。
- 现象（必填）、客户诉求、收到时间、证据附件（照片、视频、PDF）。
- **负责人**默认订单业务员；**下一步行动**与**下次更新客户时间**选填，过了时间没更新会在列表标红。

## 2. 跟进与处理

售后单详情：

- **跟进记录**：每次和客户、供应商沟通后写一条，可附图片或文件。退货、退款、费用、等级和状态变化会自动写进时间线。
- **处理**（右侧「编辑」）：
  - 改等级必须写原因，时间线记「等级 S3 → S2：原因」；
  - 原因与责任：调查中、产品质量、运输包装、选型兼容、安装使用、超保或正常损耗；
  - 处理方案可多选：远程指导、补寄配件、当地维修、退回检测或维修、换货、退款、其他；
  - 负责人、下一步、下次更新客户时间。
- 方案给客户后点「改为待客户确认」，客户回复后再改回处理中。

列表顶部四张卡片：处理中、待客户确认、**需要更新客户**（下次更新时间已过）、本月结案。

## 3. 退货

1. **业务员发起**：售后单详情点「发起退货」，填退回数量（不超过已出运数量减去其他退货单的数量），客户寄回的快递单号可以后补。
2. **仓库验收**：**仓库管理 → 退货入库**「待入库」页签点「验收」，填实收与合格数量，可拍照。录错了可以「撤回」重新验收（处理去向之前）。
3. **采购员处理去向**：「待处理」页签点「处理去向」，每个型号的数量可以拆到不同去向，合计等于实收：
   - **退回供应商**：选供应商（默认原采购订单的供应商），填快递单号、运费、供应商同意的退款或抵扣金额；
   - **转闲置库存**：只能是合格品，生成闲置库存，来源「售后退货」；
   - **报废**：填原因。

处理后不能撤回。本期退回供应商只登记金额冲减订单成本，供应商实际退款还没和应付、付款打通。

## 4. 申请退款

- **业务员**在售后单详情点「申请退款」（没有售后单时也可以在订单详情点「申请退款」）：金额（不超过可申请金额 = 已到账 − 已退款 − 其他待处理申请）、原因、建议去向（转客户余额、银行汇款、原路退回平台；平台收款的订单只能原路退回）、客户收款信息。
- **财务**在**财务管理 → 退款管理 →「退款申请」页签**：
  - 「执行」：打开登记退款的表单，按申请带出金额、原因、去向，按原来的规则填实际退出人民币和凭证，保存后生成售后退款单并关联售后单；
  - 「驳回」：填原因。
- 退款单作废后，申请回到「待财务处理」。
- 财务直接登记退款的入口保留，登记时可以选这张订单的售后单。

## 5. 售后费用

补寄运费、维修费、检测费等：

- 售后单详情点「登记费用」（有费用单维护权限的人才看到），分摊到所选型号，自动关联售后单；
- 或在**财务管理 → 费用管理**新建费用单，分摊到订单型号后，在「关联售后单」里选。

费用照旧计入原订单成本，售后单上汇总显示。

## 6. 补发（换货、补寄配件）

需要再给客户发一次货时，在售后单详情点「**补发**」（售后单要关联订单）：

1. 勾选原订单里要补发的型号，填数量（不超过订单数量）；要补寄配件时点「手填型号（补寄配件）」，填型号、品牌、数量。
2. **申报单价**：原订单型号默认原单价，配件必须填。只用于商业发票（CI）和装箱单（PL），订单金额仍是 0。
3. 采购员默认原订单型号的采购员，可以改；可以写一句说明。
4. 点「生成补发订单」，系统生成一张销售订单，标「售后补发」，售后单时间线记一条「补发订单 SO…」。

补发订单：

- 客户、币种、事业部、业务员取原订单；**不出 PI、不收款**，收款状态「无需收款」，不能登记收款、余额抵扣和退款；
- 照常生成采购需求，采购、入库、出库、出运和普通订单一样；需要时可以整单取消或部分取消；
- 出 CI / PL 时按申报单价出金额，型号描述后注明「Free of charge replacement, no commercial value」；
- 销售订单列表可以按「来源：售后补发」筛选，编号下显示原订单号。

补发订单还没出运（也没取消）时，售后单不能结案。补发的货又出问题时，可以对补发订单再登记售后、再补发，成本仍计入最初的订单。

## 7. 结案与撤销

- **结案**：选最终原因与责任（不能是「调查中」），填处理结果。有没处理完的退货单、待处理的退款申请或还没出运的补发订单时不能结案，会提示具体单据。结案后只能添加跟进记录。
- **撤销**：误建的售后单，没有退货单（作废的不算）、退款申请（撤回的不算）、退款单和费用单时才能撤销。

## 8. 对订单利润的影响

| 动作 | 对原订单 |
|------|---------|
| 售后退款（含转客户余额） | 冲减订单收入，计入经营统计「退款」 |
| 售后费用 | 计入订单成本 |
| 退回供应商 | 按供应商退款冲减订单成本；退回运费计入订单成本 |
| 转闲置库存 | 按原采购成本（采购订单不含税人民币单价，按合格入库加权）冲减订单成本 |
| 报废 | 不冲减 |
| 售后补发 | 补发订单的采购货款、开票成本、采购费用、运费和费用单都计入原订单成本；补发订单没结算时原订单也是「未结算」 |

订单详情的成本明细里有「售后退货冲减」，可以点到退货单；有补发时列出「售后补发」，可以点到补发订单。补发订单自己不算收入和毛利，也不计入销售统计、利润统计和经营统计的销售收入与订单数。

## 9. 管理员设置

- **退款申请审批**：系统管理 → 系统设置 →「退款申请需要审批」，默认关闭。打开后，业务员提交的申请先进「待审批」，由有「审批退款申请」按钮权限的人（默认只有租户管理员）在退款管理 → 退款申请页签通过或驳回，通过后才交财务。
- 菜单与权限：「售后管理」默认给有销售订单菜单的角色；「退货入库」给有采购入库或采购订单菜单的角色，验收需要「退货验收」，处理去向需要「退货去向处理」。

## 10. 常见问题

**Q：客户只是咨询怎么用，要建售后单吗？**
建议建，等级选 S5 使用咨询，方便统计工作量；确认是产品故障后再调整等级，原记录保留。

**Q：换货怎么做？**
需要寄回旧货时先「发起退货」，再点「补发」生成补发订单，新货走正常的采购和出运；补发的成本计入原订单。用闲置库存直接补发暂不支持，请先照常走采购。

**Q：供应商答应退款但钱还没到，怎么登记？**
处理去向时填供应商同意的金额，订单成本先按这个金额冲减；实际到账核对在第二期和应付打通后完成。
