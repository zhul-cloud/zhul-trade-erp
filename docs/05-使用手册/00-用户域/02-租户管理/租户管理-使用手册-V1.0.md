## 1. 部署与启动

本地/开发环境使用仓库内的一键脚本即可拉起全部依赖服务，无需手动逐个启动。

**第 1 步：执行一键启动脚本**

```bash
cd zhul-erp
./scripts/dev-up.sh              # 默认带假数据 AI 编排服务，够跑通询盘解析
./scripts/dev-up.sh --ai none    # 不需要询盘 AI 解析时可跳过
```

脚本会依次检查/拉起 MySQL、Redis，再启动后端（Spring Boot，Flyway 自动执行数据库迁移与种子数据），最后启动前端。已经在运行的服务会自动跳过。

**第 2 步：等待端口就绪**

脚本会轮询端口并打印 `✓ 已就绪`，后端最长等待 120 秒（首次启动含 Flyway 建表，稍慢）。全部就绪后会打印访问地址和内置账号。

**第 3 步：打开前端地址**

浏览器访问 `http://localhost:8000`，会自动跳转到登录页。

> 💡 **日志与停止：** 运行日志在 `.dev-run/*.log`；停止全部服务用 `./scripts/dev-down.sh`。若某个服务启动失败，先看对应日志文件排查，而不是重复执行启动脚本。

> ⚠️ **JDK 版本：** 若本机默认 `mvn` 解析到高版本 JDK（如 JDK 21+/26），Lombok 编译可能报出一堆莫名其妙的 `找不到符号` 错误。脚本内部已通过 `scripts/dev-env.sh` 固定使用 JDK 17，手动执行 `mvn` 命令时同样需要 `source scripts/dev-env.sh` 后再跑。

## 2. 登录入口与内置账号

系统种子数据**只内置一个平台超级管理员账号**，不预置任何示例租户/套餐——需要按第 3 节的流程，自己从 0 到 1 建套餐、建租户，新租户的管理员账号会在创建时自动生成：

| 账号 | 密码 | 账号类型 | 可见范围 |
|------|------|----------|----------|
| `platform` | `admin123` | 平台超级管理员 | 跨租户：租户管理、套餐管理、商品主数据可写 |

> 🔒 **生产环境务必先改密码。** 此账号仅用于本地体验/联调，正式对外前请重置密码。

登录页地址：`http://localhost:8000/login`，输入用户名密码即可，「记住我」可保持 7 天会话。

## 3. 平台管理员操作指南

用 `platform` 账号登录后，顶部栏左侧会显示「平台管理」标识（登录后始终能看到当前账号所属的租户/平台身份），左侧导航依次是 工作台 → 商品管理 → 询盘管理 → 系统管理 → 「tenant」（租户管理，仅平台账号可见），tenant 分组下是 **list**（租户列表）和 **package**（套餐管理）两个子页面。

> ℹ️ 当前版本侧边栏菜单文案暂未补充中文语言包，界面上显示的是英文原始标识（如 `system`、`list`、`package`），本手册按实际显示的英文标签配中文说明，不影响功能使用。

### 3.1 套餐管理（仅平台账号）

套餐决定了一个租户能看到哪些功能菜单，是创建租户前的「模板」。当前没有预置任何套餐，需要先在这里新建至少一个，才能在第 3.2 节新增租户时选择。

**路径：** 左侧 `tenant → package`

1. **新增套餐** — 点击右上角「新增套餐」，填写**套餐名称**（2~100字符，需平台内唯一）、**套餐描述**（选填），在下方菜单树中勾选该套餐可用的功能菜单——勾选父节点会级联勾选所有子菜单，也可用「全选/取消全选」「展开全部/折叠全部」快速操作。菜单树至少要勾选 1 项才能保存，否则会在树下方提示「请至少选择一个菜单」。
2. **编辑套餐** — 若该套餐已被租户使用，编辑抽屉顶部会有黄色提示告知已绑定的租户数——修改菜单范围会**立即**影响所有绑定该套餐的租户可见菜单，请谨慎操作。
3. **禁用 / 启用** — 禁用后该套餐不再出现在新增/编辑租户的套餐下拉框中，但**已绑定的租户不受影响**，功能不会被收回。
4. **删除** — 只有**绑定租户数为 0** 的套餐才能删除（软删除，可恢复）；若有租户在用，会弹出提示，建议改用「禁用」，或先把相关租户切换到其他套餐再删除。

### 3.2 租户管理（仅平台账号）

每一个「租户」对应一个独立的客户/团队，数据互相隔离。这里是开通新客户、管理其服务状态的地方。

**路径：** 左侧 `tenant → list`

1. **新增租户** — 点击「新增租户」，填写：
   - **租户名称** —— 公司/团队名称，2~100字符，平台内唯一
   - **套餐** —— 选择上一步准备好的套餐
   - **联系人姓名 / 手机** —— 该租户的业务联系人
   - **联系人邮箱** —— 将**直接作为该租户管理员的登录账号**，必须唯一
   - **到期时间** —— 必须晚于今天，服务到期后到期日的 23:59:59 失效

   提交后会**自动创建该租户的管理员账号**，并在页面顶部一次性显示「管理员账号 + 临时密码」——务必当场复制并转告对方，此密码不会再次展示。

2. **续期** — 支持两种方式：按时长（1/3/6/12 个月，从**当前到期时间**顺延）或直接指定新的到期日期（不能早于当前到期时间）。
3. **禁用 / 启用** — 禁用会**立即**让该租户下所有用户无法登录（已登录的会话也会被拦截）；启用后恢复正常登录。请在禁用前确认对方业务不受影响。
4. **重置密码** — 当租户管理员丢失密码、且对方没有绑定邮箱/无法自助找回时，平台可在此直接重置——同样会一次性显示新的临时密码，需要立刻转告对方。

> ✅ **建议顺序：** 先在「套餐管理」建好套餐 → 再到「租户管理」新增租户并选择该套餐 → 把生成的管理员账号+临时密码交给客户 → 客户自行登录并按 [4.1 节](#41-首次登录--找回密码租户管理员) 完成首次登录。

### 3.3 商品主数据管理（仅平台账号可写）

商品库（品牌、品类、系列、商品）是**全平台共享**的一份数据，不属于任何单一租户——所有租户看到的是同一套商品目录，只是各自的询盘/订单等业务数据互相隔离。

**路径：** 左侧 `product` 分组下的 `brands`（品牌）、`categories`（品类）、`series`（系列）、`products`（商品列表）。

- 用 `platform` 账号登录后，以上四个页面均可新增/编辑/删除。
- 普通租户账号登录后同样能看到这些页面，但只能查看，看不到「新增/编辑/删除」按钮——服务端也会拒绝这类账号的写请求，前端隐藏按钮只是第一层保护。
- 品牌/品类支持"停用"而非直接删除已被商品引用的记录，避免误删导致商品数据悬空。

> ℹ️ 如果需要让某个租户自建私有的商品库（而非共享平台目录），当前版本尚不支持，需要走后续需求评估。

## 4. 租户管理员操作指南

租户创建后，对方使用「联系人邮箱 + 临时密码」登录，看到的是**仅限本租户**的数据和菜单——不会看到「租户管理」入口，也看不到其他租户的任何信息。

### 4.1 首次登录 / 找回密码（租户管理员）

1. **用临时密码登录** — 访问 `http://localhost:8000/login`，用户名填邮箱，密码填平台管理员转发的临时密码。
2. **自助修改密码（推荐首次登录后立即操作）** — 登录页点击「忘记密码?」，依次填写**用户名（邮箱）**和**邮箱**验证身份 → 系统发送 6 位验证码（10分钟内有效）→ 输入验证码 → 设置新密码。

> ⚠️ **本地开发环境未接入真实邮件服务**，验证码不会真的发到邮箱，而是打印在后端日志里，可通过以下方式查看：
>
> ```bash
> tail -f .dev-run/backend.log | grep 模拟邮件发送
> ```
>
> 日志会打印形如 `[模拟邮件发送] 找回密码验证码 username=xxx, email=xxx, code=123456` 的记录，把 code 填进验证码输入框即可。生产环境接入真实邮件服务商后，用户会直接收到邮件。

若邮箱本身无法接收邮件或该功能尚未上线，也可以联系平台管理员，通过「租户管理 → 重置密码」直接换发一个新的临时密码。

### 4.2 系统管理（租户管理员）

登录后左侧 `system` 分组内是本租户的组织与权限配置，全部数据只在本租户范围内生效：

| 菜单（页面显示） | 中文含义 | 用途 |
|------|------|------|
| user | 用户管理 | 为本租户添加员工账号，分配角色，重置员工密码，启用/禁用账号 |
| role | 角色管理 | 创建角色，勾选该角色可见的菜单/按钮权限，批量授权给用户 |
| menu | 菜单管理 | 只读查看系统全部菜单结构（增删改属于平台侧配置，租户不可操作） |
| dept | 部门管理 | 维护本租户的组织架构树 |
| position | 岗位管理 | 维护职位/岗位字典，员工入职时选择 |
| dict | 字典管理 | 维护下拉选项等基础数据字典 |
| config | 系统设置 | 站点名称、Logo 等展示类配置 |
| log/operate | 操作日志 | 查询本租户内的关键操作记录 |
| log/login | 登录日志 | 查询登录记录，支持强制下线在线用户 |

> ℹ️ 新建租户时自动生成的管理员账号，默认使用「租户管理员」角色，拥有本租户内系统管理的全部权限，可以据此再创建更细分的角色（比如只给"用户管理"权限）分给普通员工，而不必人人都用管理员账号登录。系统内置角色只保留「租户管理员」和「普通员工」两个，此前还有一个「系统管理员」角色，因为跟「租户管理员」功能完全重合、容易让人误会两者是不同层级的管理员，已经下线。

### 4.3 商品数据查看（租户管理员）

左侧 `product` 分组可以浏览平台维护的品牌/品类/系列/商品信息，用于报价、询盘等业务场景引用——但不会看到「新增/编辑/删除」类按钮，这部分数据由平台统一维护，见 [3.3 节](#33-商品主数据管理仅平台账号可写)。

## 5. 常见问题

**Q：租户账号登录后，为什么看不到"租户管理"菜单？**

A：这是设计如此，不是权限没配对。租户管理/套餐管理是平台专属功能，只有 `platform` 账号能看到和使用；租户管理员账号（不管是不是超级管理员）在侧边栏里都不会显示这两个入口。

**Q：新建租户时选不到刚建的套餐？**

A：套餐下拉框只显示**状态为启用**的套餐，检查是否该套餐处于「禁用」状态。

**Q：临时密码没记住/复制丢了怎么办？**

A：临时密码只在创建/重置的那一刻显示一次，之后无法再查看原文。租户管理员可走 [忘记密码](#41-首次登录--找回密码租户管理员) 自助找回；平台管理员也可以在「租户管理」里对该租户重新执行一次「重置密码」。

**Q：禁用租户会不会丢数据？**

A：不会。禁用只是拦截登录（级联同步 `account`/`user_basic` 状态），业务数据原样保留；重新启用后立即恢复访问。

**Q：套餐/租户可以彻底删除吗？**

A：套餐删除是软删除（`deleted_at` 标记），且要求绑定租户数为 0；租户本身当前版本不提供删除入口，只能禁用，符合"不物理删除业务数据"的项目规范。
