# 方案 C · 单色紫，渐变只留给主按钮和关键数字

沿用方案 A 的紫色，但把渐变收紧：**渐变只用在页面里唯一的主按钮，以及关键数字**（指标卡的「87」、档案完整度的「7」）。其余全部改为单色紫。

## 与方案 A 的区别
| 元素 | 方案 A | 方案 C |
|------|--------|--------|
| 主按钮 | 紫 → 洋红渐变 | **保留渐变** |
| 关键数字 | 紫 → 青渐变 | **保留渐变** |
| Logo 方块 | 紫 → 洋红 → 青渐变 | 单色 `#7C3AED` |
| 卡片顶部细线 | 渐变 | 单色 `#8B5CF6` |
| 完整度进度条 | 紫 → 青逐段过渡 | 单色 `#8B5CF6` |
| 向导背景 | 紫色极光渐变 | 单色 `#0E0B22` |
| 选中态、开关、序号圆点 | `#7C3AED` | 不变 |

- 每页只有一个渐变主按钮（列表页「新建商品」、向导「下一步」等），符合「一个屏幕一个主 CTA」的规则
- 结构、文案、交互与方案 A 完全相同，只收紧渐变

## 包含的画板（6 个关键画板，不是整套）
商品列表、商品档案（总览）、档案·FAQ 与审核、新建向导第 1 步、新建向导完成页、上传图片弹窗。
