# 产品原型

- **视觉以 `.claude/context/ui-design-patterns.md` 为准。** 各业务域目录里的 `.op` 原型是当时的业务确认记录，只用来确认字段、流程和页面结构，颜色和样式不再作为依据。
- **界面改造后的样板**在 `界面改造/`：销售订单列表与详情、登记到账弹窗、工作台、主题色对比板、外壳（F 开头）。各页样板里的侧栏和顶栏是早先画的，外壳以 F 开头的图为准。改原型就改 `界面改造/生成脚本/` 里的脚本，再运行 `python build.py`。
- **旧版视觉的备选方案**已移到 `docs/_backup/ui-v3/`，已作废。
