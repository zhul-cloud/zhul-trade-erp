# 烛龙ERP — 文档中心

外贸业财一体化智能中台，工控产品外贸专属。

## 目录结构

```
docs/
├── 00-总体架构/        # 系统总体架构全景图
├── 01-业务架构/        # 业务架构全景图（PDF + 思维导图）
├── 02-产品PRD/         # 产品需求文档（按域/版本管理）
├── 03-产品原型/        # UI 原型设计稿
└── 04-数据模型/        # 数据库 Schema SQL 文件
```

## 开发流程

```
业务架构 → PRD需求文档 → 产品原型 → 数据模型 → 接口文档 → 编码开发
```
