# 财务模块上下文

## 业财联动规则

| 业务事件 | 财务动作 |
|----------|----------|
| 合同签订 | 创建销售合同台账，预计应收 |
| 发货确认 | 生成应收账款，确认收入（或按发货百分比确认） |
| 开具发票 | 关联应收，记录税务凭证 |
| 收到货款 | 核销应收账款，记录银行流水 |
| 汇率结算 | 计算汇兑损益，生成财务凭证 |
| 采购付款 | 核销应付账款 |
| 退货 | 冲销对应收入和应收 |

## 科目体系（简化版）

```
资产类
  ├── 货币资金（银行存款-USD/EUR/RMB）
  ├── 应收账款（按客户、币种）
  ├── 预收账款
  └── 存货

负债类
  ├── 应付账款（按供应商、币种）
  └── 预收款项

收入类
  └── 主营业务收入（按产品线、地区）

成本类
  ├── 主营业务成本
  ├── 运费
  └── 报关费

损益类
  ├── 汇兑损益
  └── 财务费用
```

## 成本核算维度

每笔订单需核算：
1. **产品成本**：采购/生产成本
2. **物流成本**：运费、报关费、保险费
3. **金融成本**：LC手续费、汇率损益
4. **销售费用**：佣金、回扣
5. **毛利** = 收入 - 产品成本 - 物流成本
6. **净利润** = 毛利 - 金融成本 - 销售费用

## 财务计算规则

- **金额精度**：保留2位小数，四舍五入（HALF_UP）
- **汇率精度**：保留6位小数
- **利润率**：保留4位小数（百分比显示2位）
- **本位币**：人民币（CNY），所有外币金额需换算
- **收入确认时点**：以提单日期或客户签收日期为准（需配置）
