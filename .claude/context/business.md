# 外贸业务上下文

## 核心业务流程

```
询盘 → 报价 → 客户确认 → 合同签订 → 备货/采购 → 生产/备货 → 装箱出货
→ 报关 → 提单/装船 → 运输 → 目的港清关 → 客户收货 → 对账收款
```

## 关键业务术语

| 术语 | 说明 |
|------|------|
| FOB | 离岸价，卖方负责到装运港 |
| CIF | 到岸价，含运费+保险 |
| EXW | 出厂价，买方负责全程物流 |
| LC | 信用证，银行担保的支付方式 |
| TT | 电汇，最常见支付方式 |
| DP/DA | 付款交单/承兑交单 |
| 提单(BL) | 货物所有权凭证，海运必备 |
| 报关单 | 海关申报文件 |
| 装箱单(PL) | 货物明细清单 |
| 形式发票(PI) | 成交确认，用于开证或付款 |
| 商业发票(CI) | 正式结算发票 |
| 原产地证(CO) | 证明货物产地，享受关税优惠 |

## 收款方式与账期

- **预付款（TT in Advance）**：风险最低，客户下单前付全款或定金
- **信用证（LC）**：银行介入，30-90天单据期
- **赊销（OA）**：货到后付款，30/60/90天账期，风险高
- **D/P、D/A**：通过银行托收

## 多币种场景

主要币种：USD（美元）、EUR（欧元）、GBP（英镑）、JPY（日元）、RMB（人民币）

汇率处理原则：
- 订单签订时锁定汇率（合同汇率）
- 收款时以实际到账汇率记账
- 汇兑差异单独核算（汇兑损益科目）

## 客户分层

- A类：年采购额 > 100万美元，信用优质
- B类：年采购额 50-100万美元，正常信用
- C类：年采购额 < 50万美元或新客户，需预付或LC
