# 前端 UI 设计规范（业务后台页面）

## 状态：已确认（首版落地于用户管理页，2026-08-27）

来源：`docs/03-产品原型/00-用户域/用户管理.op`（可编辑设计稿）及同目录下的
`用户管理-列表页.png`、`用户管理-新增弹窗.png`（效果参考图）。新建后台管理页面
（客户、订单、供应商、商品……）时，优先复用本文档定义的结构和 Design Token，
保持全站视觉统一，减少重复设计决策。

## 设计 Token

### 颜色

| 用途 | 变量名 | 值 |
|------|--------|-----|
| 页面背景 | bg | `#F5F6F8` |
| 侧边栏背景 | siderBg | `#001529` |
| 侧边栏文字（未激活） | siderText | `rgba(255,255,255,0.75)` |
| 侧边栏文字（弱） | siderTextMuted | `rgba(255,255,255,0.45)` |
| 卡片/表面 | white | `#FFFFFF` |
| 边框 | border | `#E5E7EB` |
| 主文字 | text | `#111111` |
| 次文字 | textSub | `#6B7280` |
| 占位/弱文字 | textSubtle | `#9CA3AF` |
| 品牌主色 | primary | `#1677FF` |
| 主色浅底 | primarySoft | `#E8F3FF` |
| 成功/启用 | green | `#16A34A` |
| 成功浅底 | greenSoft | `#F0FDF4` |
| 中性/禁用 | gray | `#6B7280` |
| 中性浅底 | graySoft | `#F3F4F6` |
| 危险/删除 | danger | `#DC2626` |

统计卡片等场景可扩展辅助强调色，如新增类指标用紫色 `#7C3AED` / 浅底 `#F3E8FF`。
**遇到不支持 `rgba()` 字符串的渲染场景（如 OpenPencil 画布填充色），一律换算成
等效纯色 hex，不要用带透明度的字符串做纯色填充**——这是踩过的坑：透明度混合
后的纯色可以用 rgba，但普通不透明填充必须是纯 hex。**这个坑不止发生在填充色上
——OpenPencil 渲染器里 `rgba()` 用在文字/图标颜色（`fill`）上同样不生效**（会渲染成
接近全黑、几乎不可读，而不是预期的半透明白），所以 `siderText` / `siderTextMuted`
这两个 token 在 OpenPencil 设计稿里必须换算成等效纯色再使用：`siderText`
(rgba(255,255,255,0.75)) → `#BFC5CA`，`siderTextMuted`(rgba(255,255,255,0.45))
→ `#737E89`。（询盘单模块设计时发现并修正，2026-09-03）

### 字号 / 字重

| 场景 | 字号 | 字重 |
|------|------|------|
| 页面主标题（如"用户管理"） | 22px | 700 |
| 页面副标题/说明 | 13px | 400 |
| 统计卡片数值 | 28px | 700 |
| 弹窗标题 | 16px | 600 |
| 分组小标题（表单 section） | 14px | 600 |
| 表格表头 | 13px | 600 |
| 表格正文 / 表单输入值 | 13–14px | 400 |
| 表单字段 label | 13px | 400（必填加红色 `*`） |
| 辅助说明 / hint | 12px | 400 |

### 圆角 / 间距 / 阴影

- 卡片圆角 12px，按钮/输入框圆角 8px，标签（tag）圆角 6px，胶囊状态圆角用 `height/2`
- 页面内容 padding 24px，卡片内部 padding 20–24px
- 卡片间距 16px，表单字段组间距 16–26px
- 统一浅阴影：`offsetX:0, offsetY:1, blur:3, spread:0, color:"rgba(0,0,0,0.05)"`（卡片）
- 弹窗更强阴影：`offsetX:0, offsetY:8, blur:24, spread:-4, color:"rgba(0,0,0,0.16)"`

## 页面外壳（所有后台页面通用）

- **左侧导航 Sider**：宽 240px，深色背景 `siderBg`，顶部 Logo（图标+"烛龙ERP"）+
  导航树；一级菜单/分组用图标+文字，二级子菜单缩进（左 padding 52px）；
  **当前激活项用纯色 `primary` 背景块 + 白色加粗文字**，不要用低透明度色块
  （对比度不够、在深色底上几乎看不清）。
- **顶部 Header**：高 64px，白底，左侧面包屑（父级 / 当前页，当前页加粗），
  右侧搜索/通知图标 + 用户头像（圆形，纯色底+姓名首字）+ 用户名。
- **内容区**：浅灰背景 `bg`，padding 24，内部各块纵向 gap 16。

## 列表页结构（自上而下）

1. **页面标题区**：主标题 22px/700 + 一句话说明 13px/textSub，帮助新用户理解本页作用。
2. **统计卡片行**（可选，视业务是否有汇总指标）：3–4 张等宽卡片横排，每张卡片内部：
   图标胶囊（36×36，圆角10，浅色底+对应强调色图标）+ 指标名 → 大号数值(28/700) →
   一行强调色 hint（占比/环比等）。用于列表页顶部给出概览，比纯表格更有信息量。
3. **筛选卡片**：白底卡片，横向排列筛选项，每项 = label(13px) + 输入框/下拉(36px高)，
   末尾接"查询"（实心 primary 按钮）+"重置"（描边按钮）。**筛选项≤4个时单行放下即可
   （参考用户管理页）；超过4个或含日期范围等宽字段时，改为多行网格排列**（每行3–4项，
   项与项之间横向 gap 24+、行间 gap 16–20），"查询"+"重置"固定放在筛选区末尾（多行时
   放最后一行右侧，或单独一行右对齐），不要让筛选项逐项独占一整行纵向堆叠——那样会
   把筛选卡片拉得过高，扫读效率差。
4. **操作行**：左侧"共 N 条记录"说明文字，右侧主操作按钮（如"新增X"，实心 primary+图标）。
5. **表格卡片**：白底卡片，表头浅灰底 `#FAFAFA`；行高按内容复杂度取 40–60px；
   **多字段拼一列**：如"用户名+昵称"合并为一个"用户"列，左侧圆形头像（姓名首字，
   按行序号从调色板取色）+ 右侧姓名(13/600)与副名(12/textSub)纵向堆叠，
   比拆成多列更省横向空间、更易扫读。状态/角色类字段用胶囊标签（浅底+对应色文字），
   不要用纯文本。操作列放文字链接（primary 色，危险操作如"删除"用 danger 色），
   用 gap 12 横排，不加分隔符。
6. **分页器**：卡片底部横条，左侧"共 N 条"，右侧页码按钮（28×28 圆角6，当前页实心
   primary，其余描边）。

## 表单弹窗结构（新增/编辑类）

**核心原则：字段必须按业务属性分组，禁止把所有字段拉平堆成一条长表单。**
字段一多，纯瀑布式排列会让用户找不到重点、输入体验差。

- 弹窗宽度按分栏字段数调整：单列表单 480–560px，双栏表单建议 640px。
- 结构：Header（标题+关闭图标，底部分割线）→ Body（分组内容，可滚动）→
  Footer（右对齐"取消"+"确定"按钮，顶部分割线）。
- **分组（section）**：每组 = 图标(15px, primary色) + 组标题(14/600) 一行，
  下方 1px 分隔线，再下方是该组的字段内容。分组命名按语义，例如：
  - 用户表单：基础信息 / 组织信息 / 账号设置
  - 商品表单：基础信息 / 规格信息 / 物流信息 / 价格信息……
  - 订单表单：客户信息 / 商品明细 / 收付款信息……
- **字段行（fieldRow）**：同一行内可放 1–2 个等宽字段（横向 gap 16），根据字段
  重要性/长度决定独占一行还是两两并排——短字段（如用户名/昵称、部门/岗位）并排，
  长字段或需要更多注意力的字段（如角色、密码说明）独占一行。
- 必填字段 label 后加红色 `*`；下拉类字段用输入框造型 + 右侧 `chevron-down` 图标。
- 开关类字段（如"启用状态"）不放进 grouped 字段区，作为独立一行放在其所属分组
  末尾，label 左 + Switch 控件右（space_between）。

## 复用方式

新页面设计时：

1. 先确定这一页是"列表页"还是"表单/弹窗页"，套用对应结构骨架。
2. 颜色、字号、圆角、阴影直接抄本文档 Token，不要现场调新值。
3. 表单字段先按业务属性分组命名（参考上面的分组示例），再决定每组内字段怎么
   两两并排，禁止拿到字段列表就从上到下平铺。
4. 用 OpenPencil（`op design` / `op insert`，见项目内 openpencil-skill）出设计稿，
   产物统一存到 `docs/03-产品原型/{域}/{页面名}.op` + 对应 `.png` 效果图。
