# inquiry-parser · 询盘解析 Skill

## 任务目标
- **输入**：原始询盘内容（纯文字 / 铭牌图片 / Excel 文件）
- **输出**：标准化产品明细 JSON 数组（供后续 skill 使用）
- **触发条件**：由 AGENTS.md 编排层调用，每次处理一条询盘

---

## 操作步骤

### 步骤 0 · 输入类型判断与预处理

**文字输入** → 直接进入步骤 2

**图片输入** → 进入步骤 1（铭牌提取）后进入步骤 2

**Excel 文件输入**（强制规则：读完所有行再处理）
```
动作：读取所有 sheet 的全部数据行
完成标志：获取到最后一行，确认总行数
※ 使用 read_file / parse_excel 等价工具
```
读取完成后输出：「已读取 Excel，共 [N] 行有效数据（Sheet: [名称]），开始解析。」

**Excel 预处理四步（读取后必须执行）**

① 定位表头行：跳过连续空行，第一个含非空单元格的行 = 表头行；`\n` 换行表头合并为单行

② 定位数据列：跳过全空列（如 A 列全空则从 B 列开始）

③ 列名映射（中英文均支持）：

| 可能的列名 | 映射字段 |
|-----------|----------|
| Model / 型号 / 物料号 / 料号 / P/N / Part No | `original_model` |
| Make / Brand / 品牌 / 厂家 / 制造商 / Manufacturer | `brand` |
| Qty / Quantity / 数量 / Total Req. Qty | `quantity` |
| UOM / Unit / 单位 | `unit`（转换为中文单位，见步骤 ④ 单位转换规则） |
| Delivery / 交期 / Lead Time | `delivery` |
| Description / Remark / 备注 | 并入 `note` |

④ 特殊值处理：

| 情形 | 处理方式 |
|------|----------|
| 未找到表头 | 第1列=型号，第2列=品牌，第3列=单位，第4列=数量；说明推断依据 |
| unit 字段（见下方单位转换规则）| 转换为中文单位后填入，禁止保留英文原文 |
| brand 含 `/` 双品牌（如 POLYPENCO/SHIBAKEI）| 取第一个，第二品牌写入 note |
| 型号含规格范围（如 213.53.063_0 TO 28 KG/CM^2）| 整段保留为 original_model，note 注明「型号含内嵌规格，请核实」 |
| 单元格为空但非最后行 | 跳过，继续读取 |

**单位转换规则（必须在填入 `unit` 字段前执行）：**

**规则一：固定映射（与品类无关，直接转换）**

| 英文原文（大小写不敏感）| 中文单位 |
|----------------------|---------|
| Set / Sets | 套 |
| Pair / Pairs / Pr | 对 |
| M / Meter / Metre / Meters / Metres | 米 |
| MM / Millimeter / Millimeters | 毫米 |
| KG / Kilogram / Kilograms | 千克 |
| G / Gram / Grams | 克 |
| L / Liter / Litre / Liters / Litres | 升 |
| Roll / Rolls | 卷 |
| Box / Boxes | 箱 |
| 台 / 个 / 套 / 只 / 块 / 件 / 条 / 根 / 米 / 千克 / 升 / 卷 / 箱 / 对 / 批 | 保留原文（已是中文） |

**规则二：按品类判断（适用于 Nos / No / No. / Pcs / PC / EA / Each / Unit / 空白）**

| 品类 | 中文单位 |
|------|---------|
| PLC / HMI / 变频器 / 伺服驱动器 / 伺服电机 / 软启动器 / UPS / 减速机 | 台 |
| 电源模块 / I/O模块 / 通信模块 / 工业网络 | 块 |
| 传感器 / 断路器 / 接触器 / 继电器 | 只 |
| 液压阀 / 液压缸 / 液压泵 / 气动阀 / 气动缸 / 压力表 / 流量计 / 温度仪表 / 液位计 / 仪表附件 | 个 |
| 轴承 / 联轴器 / 齿轮 / 齿条 / 直线导轨 / 工程塑料件 / 密封件 / 紧固件 / 标准件 | 个 |
| 液压管件 / 气动管件 | 根 |
| 其他 / 品类未知 | 个（默认） |

**规则三：兜底**
- 无法判断时，填 `个`，在 `note` 中注明「单位原文为 [{原文}]，已按默认规则转换，请核实」

### 步骤 1 · 图片铭牌提取（仅图片输入时执行）

输出一句提取摘要：
> 「从图片中识别到：品牌=[X]，型号=[X]，电压=[X]，功率=[X]，频率=[X]，其他=[X]」

疑似 OCR 错误在括号内标注，如：`6ES7214-1AG4O（末位 O 疑似应为数字 0）`

---

### 步骤 2 · 全量产品提取

扫描全部输入，列出所有产品条目（内部列表，不对外展示）。

**提取规则：**
- 识别型号格式：字母+数字组合、带连字符的编码、括号内补充规格
- 不因"看起来是同一产品"而提前合并

**拆分规则：**

| 场景 | 处理方式 |
|------|----------|
| 不同品牌 | 独立条目 |
| 不同品类 | 独立条目 |
| 不同型号 | 独立条目 |
| 同品牌同型号，数量来自多行 | 合并，数量累加，note 注明来源行 |
| 主机 + 配套模块 | 各自独立，note 注明配套关系 |

---

### 步骤 3 · 联网搜索验证与型号纠正

**每个提取到的型号，必须执行，不得跳过。**

**搜索执行：**
```
查询词（按优先级依次尝试，有可信结果则停止）：
  第1优先："{brand} {original_model} 参数规格 datasheet"
  第2优先："{original_model} 工控 PLC 变频器 型号"
  第3优先："{original_model} site:{品牌官网域名}"

※ 品牌官网域名见 MEMORY.md
※ 未知品牌执行 A/B/C 三步搜索策略（见 MEMORY.md）
```

**搜索结果评估（三问判定）：**

- **Q1 型号是否存在？**
  - 否 → confidence: `待核实`，note: 「联网搜索未找到该型号，请核实」

- **Q2 型号是否正确（与原文一致）？**
  - 是 → confidence: `确认`，用搜索结果填充 description
  - 否 → Q3

- **Q3 能否确定正确型号？**
  - 能（唯一匹配）→ confidence: `已纠正`，执行纠正
  - 否（多个可能）→ confidence: `待核实`，note 列出候选型号

**纠正执行：**
- `original_model`：严格保留原文，不修改
- `model`：填写搜索确认的正确型号
- `correction_note`：`「客户原文 [X] 疑似有误：[描述]，根据 [来源] 纠正为 [Y]」`

**禁止纠正的情况：** 多个可能匹配 / 搜索无结果 / 仅依赖相似型号类比推断

---

### 步骤 4 · 输出 JSON 明细数组

所有条目以数组格式统一输出，置于代码块内：

```json
[
  {
    "brand": "品牌名（中文写中文，英文品牌保留英文原文）",
    "original_model": "客户原文型号（永不修改）",
    "model": "纠正后型号（无纠正时与 original_model 相同）",
    "correction_note": "纠正说明（无纠正时填空字符串）",
    "category": "品类",
    "quantity": 1,
    "unit": "中文单位（按转换规则填入，如：台/个/套/只/块/根/米/千克）",
    "delivery": "",
    "description": "来自联网搜索，品牌+系列+关键规格，50字以内",
    "confidence": "确认/已纠正/待核实/未识别",
    "note": ""
  }
]
```

**category 合法枚举值：**

电气控制类：`PLC` / `HMI` / `变频器` / `伺服驱动器` / `伺服电机` / `传感器` / `断路器` / `接触器` / `继电器` / `软启动器` / `工业网络` / `电源模块` / `I/O模块` / `通信模块` / `UPS`

液压气动类：`液压阀` / `液压缸` / `液压泵` / `液压管件` / `气动阀` / `气动缸` / `气动管件`

机械传动类：`齿轮` / `齿条` / `联轴器` / `轴承` / `减速机` / `直线导轨`

仪表检测类：`压力表` / `流量计` / `温度仪表` / `液位计` / `仪表附件`

其他：`工程塑料件` / `密封件` / `紧固件` / `标准件` / `其他`

---

## 输出规范

- **成功**：返回完整 JSON 数组 + 统计摘要（共 N 条 | 确认 X | 已纠正 Y | 待核实 Z | 未识别 W）
- **失败**：返回错误描述，标注失败步骤，不返回空数组

## 错误降级

| 失败场景 | 降级处理 |
|----------|----------|
| Excel 读取失败 | 返回「文件读取失败：[原因]」，终止本次调用 |
| 单个型号搜索超时 | confidence 填「待核实」，note 填「搜索超时」，继续处理其余型号 |
| 全部搜索失败 | 所有条目标为待核实，返回 JSON 并注明「网络异常，搜索未执行」 |
